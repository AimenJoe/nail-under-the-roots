# 0027: 오프닝의 "???" = 모모(히로인). 물들었다가 나중에 돌아온다. 종은 미정

- 상태: 채택 (2026-10-25, 사장 설정). 종(어떤 동물인지)은 정하지 않았다.
- 후속: 종은 0029가 굴토끼로 정했다.

## 결정
1. 오프닝에서 Naïl에게 "돌아가"라고 하고 사라지는 그림자 이웃(지금 이름표 "???")은 **모모**다. 이름은 나중에 밝혀진다(그때까지 이름표는 "???").
2. 모모는 **귀여운 여자 캐릭터, 히로인**. 뿌리에 물든 상태로 처음 나오고, 이야기 뒤에서 **제정신으로 돌아온다**(컨셉의 "보스 → 동료 → 플레이어블" 흐름과 맞을지는 종과 함께 정한다).
3. 지금 그림(초상화 칸 4: 그림자 + 빛나는 초록 눈 + 몸을 감은 뿌리)은 정체를 숨긴 모습으로 유지한다. 종이 정해지면 물든 모습·돌아온 모습 초상화를 따로 그린다(`tools/art/portraits.py`).

## 종을 고를 때 볼 것(제안, 결정 아님)
- 땅속 세계에 사는 진짜 동물, 이미 쓴 종(두더지·쥐·다람쥐·청설모·라쿤)과 실루엣이 겹치지 않을 것.
- 물든 모습과 돌아온 모습의 차이가 그림으로 크게 보일 것.
- 보스 패턴이 곧 나중 기술 세트가 된다(docs/decisions/0003) → 종의 몸짓이 전투 동작이 될 것.
