# 0032: 튜토리얼 보스 — 들쥐 대장 보리

- 상태: 채택 (2026-10-25, 사장 "튜토리얼 보스도 하나 만들고 넘어가도록").

## 결정
1. 필드 남쪽 **공터**(던전 방과 같은 20×12칸, 위 두 줄 벽에 문 `++`). 튜토리얼이 끝나야 문이 열리고(포포: "남쪽 공터 문을 열어 둘게"), 안으로 들어서면 문이 닫히고 대장이 깬다. 싸우는 동안 카메라는 공터를 한 방처럼 비춘다. 이기면 문이 열리고 굴 입구(D)가 살아난다 → 쉼터(0030).
2. 대장 = **들쥐 대장(보리)**: 들쥐 마을의 늙은 대장이 뿌리에 물든 모습. 졸개(쥐)의 대장이라 이야기가 이어지고, 0003대로 이긴 보스는 돌아와 쉼터의 이웃이 된다(나중에 플레이어블 후보).
3. 패턴(`enemy.rs` Behavior::Chief, 수치 `species.rs` CHIEF):
   - 돌진 ↔ 뛰어 찍기를 번갈아. 예고 0.75초(졸개보다 길게, 바닥 예고 0025 그대로).
   - 체력 반 아래면 세 번에 한 번 울부짖어 생쥐 떼(셋)를 부른다(두 번까지).
   - **공격 중(예고 포함)엔 맞아도 멈추지 않는다**(슈퍼아머). 아닐 때 맞으면 짧게만 멈칫. 돌진이 벽·바위에 박히면 2.2초 어질어질 — 그때가 때릴 틈. 패링은 그대로 멈추게 한다(보상).
   - 체력 36, 넉백 거의 안 받음. 처치: 뿌리 심장 + 씨앗 6.
4. 화면: 보스는 32×32 그림(`tools/art/chief.py`, 졸개의 두 배 크기·같은 픽셀 밀도). 아래 가운데에 이름 + 체력 막대(그동안 튜토리얼 힌트는 숨김). 초상화 3칸(물든 노려봄 · 돌아온 보리 보통·기쁨).
5. 장면: 들어서면 대장의 한마디 → 이기면 보리로 돌아와 Naïl 곁으로 걸어와 고마워하고, 굴 아래 쉼터에서 기다리겠다며 먼저 내려간다. Naïl: "그 아이도… 이렇게 돌아올 수 있을까"(모모를 잇는다, 이름은 아직 모름).
6. 쓰러지면 공터 싸움은 처음부터(대장은 다시 자고 부하는 사라진다).

## 같이 고친 것
- **컷씬 배우 좌표**: 월드 패스가 끝나면 카메라가 화면 고정(HUD)으로 바뀌는데, 배우를 월드 좌표로 그리고 있었다. 오프닝은 카메라가 (0, 0)인 첫 화면이라 우연히 맞았다. 지도 다른 곳(공터)의 컷씬에서 보리가 화면 밖에 그려져 헤드리스 확인에서 드러남 → `Renderer::to_view`로 화면 좌표로 바꿔 그린다.
- **컷씬 연타 보호**: 보스를 잡는 순간까지 공격을 연타하면 그 입력이 대사를 다 넘겼다(헤드리스 확인). 컷씬 시작 1초, 줄마다 0.3초는 확인을 버린다.

## 왜
- 튜토리얼에서 배운 것(돌진 예고 읽기·벽으로 유도·패링·필살기)을 한 상대에게 다 써 보게 하는 시험. 슈퍼아머는 "맞으면서 때리기"를 막고 "피하고 빈틈에" 리듬을 강제한다(작은 적과 다른 손맛).
- 공터를 던전 방 모양으로: 문 잠금·카메라 경계를 그대로 다시 쓴다(새 구조 없음).
