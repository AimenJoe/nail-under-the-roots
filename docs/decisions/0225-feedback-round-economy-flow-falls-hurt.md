# 0225. 사장 피드백 한 묶음: 반딧불 값, 마을에서 곧장 쉼터로, 실뿌리 셋째에 끝 + 끝 연출, 맞음 피드백

- 날짜: 2026-10-28
- 상태: 채택(개발판). 사장 피드백 2026-10-28

## 1. 반딧불 값 ×3
- 사장: "반딧불 수집량이 너무 많아. 줍는 애니메이션 자체는 기분 좋으니, 가격을 높일까?"
- 잰 것(코드, 길마다 층마다 첫 굴의 적 반딧불 기댓값): 첫 길 ≈ 80, 둘째 ≈ 120, 셋째 ≈ 150 → 길 셋 한 런 ≈ 350, 주인·부술 것·숨은 자리를 더하면 400~450. 저널 보상(`Light`)도 다 합쳐 ≈ 690.
- 쓰는 곳은 재주(세 캐릭터 다 해서 940) + 독 발톱(120) = 1,060 → **세 런이면 다 깨웠다**.
- 줍는 손맛(끌려오는 반딧불·오르는 음)은 두고 값만 올린다: `TALENT_PRICE_MUL = 3`(재주 120~240, 독 발톱 360, 모두 3,180). 한 캐릭터를 다 깨우는 데 길 셋 런으로 대여섯 번, 셋 다면 여덟 번 남짓 + 저널.
- 이미 깨운 재주는 그대로. 반딧불 떨어뜨리는 수는 그대로.

## 2. 마을에서 곧장 첫 쉼터로
- 사장: "마을에서 시작할 때 튜토리얼 맵으로 가는 것도 이상한 흐름이야. 다시 쉼터로 내려가니까."
- 전: 보리가 돌아온 런은 마을 뿌리 길 → 땅 위 필드 공터(굴 입구 위, 지름길 0151) → 입구 → 첫 쉼터. 내려왔는데 다시 땅 위였다.
- 이제: `World::descend_to_first_camp` — 내려가는 전환(지층 단면, 0156)을 다 덮인 자리부터 틀어 필드를 보이지 않고 마을(0 m) → 첫 쉼터. 쉼터 이어하기는 예전대로. 첫 런·튜토리얼은 필드 그대로.
- 쉼터 도착 한마디(포포)는 단면이 다 흐른 뒤에(`App::pending_camp`). 전에는 바꾸는 순간 대화가 떠 월드가 멈추고 단면이 중간 깊이에 섰다 — 필드·길 끝에서 내려갈 때도 같았다. 런 첫 한마디도 도착 한마디 뒤에.

## 3. 실뿌리 셋 = 세 번 쓰러지면 끝 + 끝 연출
- 사장: "3번 죽었을 때 죽는 게 아니라 3번+1번 더 죽어야 리셋인 듯? 죽었을 때도 뭔가 애니메이션이 있어야 할 듯. 그냥 죽었을 때랑 구분되도록."
- 0210은 "셋이 다 감긴 뒤 또"라 넷째에 끝났다. HUD의 셋 = 쓰러질 수 있는 수로 맞춘다: `run_over` = `falls + 1 >= RUN_LIVES`(셋째 쓰러짐에 끝). 둘째 뒤 알림 "하나 남았다", 안내(쉼터 주제) 글도 열한 언어.
- 끝나는 쓰러짐은 따로(`App::draw_run_lost`): 더 어둡게, 화면 가장자리에서 보랏빛 실뿌리 열넷이 1.4초 동안 나일까지 자라고(`RUN_LOST_GROW`) 둘레를 고리 셋으로 감는다. 땅 울림 소리, 보랏빛 "실뿌리에 감겼다"(`dead_final`), "확인: 마을로 돌아가기"(`dead_final_hint`). HUD 실뿌리도 그 동안 셋째가 감긴다. 보통 쓰러짐(붉은 "쓰러졌다")은 그대로.
- 개발 시나리오 "쉼터: 실뿌리 둘"(실뿌리 둘·체력 1·곁에 들쥐).

## 4. 맞았을 때 알 수 있게
- 사장: "피격에 대한 효과음/흔들림 같은 것도 없어서 맞았는지 구분 잘 안 됨."
- 원인: 있긴 했다. 흔들림은 세기²(0.55² × 4 = 1.2px)라 0.1초 만에 0px — KB `melee-light-and-charged-attack-feel`의 "trauma²는 작은 타격을 0으로". 소리는 Kenney 주먹 타격(무거운)이라 적을 때리는 소리(같은 주먹 타격, 보통)와 구분이 안 됐다.
- 더한 것: 카메라 킥 5px(밀려난 쪽, 제곱 곡선 밖), 흔들림 0.7, 화면 가장자리 붉은 테두리 0.35초(흔들림 설정을 따른다), 합성 '아야'(`Id::Ouch`, 1250→560Hz 짧게 내려가는 소리)를 타격 소리 위에.

## 사람이 볼 것
- 재주 값이 너무 비싸지 않은지(한 런에 하나쯤 깨우는 느낌인지).
- 마을 → 첫 쉼터 전환, 셋째 쓰러짐의 실뿌리 연출 길이(1.4초 + 고리 0.5초), 맞음 테두리·아야 소리가 거슬리지 않은지.
