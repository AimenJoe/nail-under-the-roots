# 0198. 길의 꽃잎을 꽃밭에서 띄우기 · 공격 예고 진하기 설정 · 설정 창 터치로 나가기

- 날짜: 2026-10-28
- 상태: 채택(v0.4.3 패치, 0193 갈래 — patch-0.4에서 고치고 release/v0.5에 합친다).
- 사장: "꽃잎 떨어진 배경 근처에 다른 꽃들이 많아서 눈에 띄지 않네…" / "공격예고 너무 진하다. 니 말대로 옵션이 필요할듯" / "터치스크린에서는.. 목록 같은 거 밑으로 스크롤하기 어려운데..?"

## 1. 길의 꽃잎(0190·0194)
- **왜 안 보였나**: 꽃잎(5×4px, 회분홍)이 Sunnyside 꽃(빨강·파랑·하양, 같은 크기)이 무리 지어 핀 자리 바로 옆 흙길에 있었다. 색과 크기가 꽃과 같아 "무늬"로 읽혔다.
- **바꾼 것**(`render/fx.rs draw_left_petal`): 꽃잎 몸 7×5px + **어두운 테두리**(놓인 물건으로 읽히게), 색은 조금 밝게(시든 빛보다 읽히는 것이 먼저), 밑에 **숨 쉬듯 밝아지는 옅은 빛 자리**(2초 주기), 1.6초마다 위로 오르는 **열십자 반짝임**.
- 처음엔 밟혀 눕은 흙 자리(어두운 갈색 타원)를 깔았는데 흙길 위에서는 구멍처럼 보여 뺐다(헤드리스 확인).
- 줍는 판정·자리(`field::petal_road`)는 그대로.

## 2. 공격 예고 진하기 설정(0197을 잇는다)
- 설정 → **공격 예고**(10~100%, 기본 **50%**). 잉크의 투명도·빈 안쪽·가운데 X에 같은 배율(`설정/70%`)을 곱한다 — 70%가 0196·0197의 값(0.25). 기본 50%는 0.18쯤.
- 0%는 두지 않는다: 예고는 놀이 정보라 끄는 것이 아니라 옅게만.
- 바닥별 잉크(0197: 밝은 바닥 짙은 빨강)는 그대로 — 옅게 해도 풀밭에서 밝기 차가 남는다.
- 저장: `prefs` 칸 20(+1). 옛 저장(0)은 기본값으로 읽는다 → MAGIC은 그대로. 월드는 `World::juice.tells`(배율)만 본다.
- 배경(Xbox 접근성 지침 102 등): 대비·진하기를 사람이 고를 수 있게. 사람마다 화면·시력·밝기가 달라 "은은하지만 보인다"의 값이 하나로 정해지지 않는다(0192·0196·0197을 거치며 확인).

## 3. 설정 창 터치로 나가기·굴리기
- 줄이 열하나(예고 줄)가 되어 아홉 줄만 보인다. 그동안 가려진 줄은 키·패드로 커서를 움직여야만 보였고, ▲▼는 그림뿐이었다 — **터치만으로는 돌아가기 줄에 닿을 수 없어 설정에서 나갈 길이 없었다**(웹 모바일).
- 닫기 단추(✕, 다른 창과 같은 `close_button`, 바깥 누르기도 닫기)와 누를 수 있는 ▲▼(`Hit::SettingScroll`, 가려진 다음 줄로 커서를 옮겨 한 줄 굴린다).

## 남은 것(다음 패치 제안)
- 다른 목록(저널·도감·안내·개발 목록)도 터치로는 가려진 줄을 못 본다. 앨범·상태 탭만 ▲▼를 누를 수 있다. 제안: **손가락으로 끌어 굴리기**(메뉴에서 터치 이동량 → 줄 굴리기, 마우스 휠도) + 모든 ▲▼를 누를 수 있게, 굴리기 도우미 하나로 묶기(지금은 화면마다 따로 짠 같은 공식이 넷).

## 확인
- `cargo test`(prefs: 칸 20 읽고 쓰기·옛 저장은 기본값).
- 헤드리스: 꽃잎(새 시작 → 오프닝 건너뛰기 → 임시 순간이동 패치로 꽃잎 앞, 커밋 안 함), 설정 창(한국어·포르투갈어, 예고 줄·▲·✕로 나가기), 예고 50%(꽃 핀 입구·심층).

## 사람이 볼 것
- 기본 50%가 알맞게 은은한지(전보다 옅다). 꽃잎이 이제 보이는지, 반짝임이 과하지 않은지.
