# 0062: 지도를 한 장으로 굽는다 — 네모난 벽과 단조로운 바닥 벗어나기

- 상태: 채택 (2026-10-25). 0010(환경은 같은 타일에 색조·장식·어둠)을 이어 그림 방식을 바꾼다.
- 후속(2026-10-26 점검): "어두워짐 동안 한 번 굽기"는 0068이 프레임마다 나눠 굽기(`terrain::Baker`)로 바꿨다.
- 사장: "맵 자체가 다 네모네모에 너무 단조로워. 어떻게 좀 더 고급지게?" → A(코드로 그리기) 먼저, 이어 B(둥근 방 모양).

## 문제(헤드리스 화면으로 본 것)
- 벽: 위쪽만 곧은 벼랑 띠였다. 윗면은 바닥과 같은 초록 사각형이었고 모든 모서리가 직각이었다.
- 바닥: 한 색 풀 위에 작은 흙 얼룩을 고르게 찍었다. 큰 변화(길·풀/흙 덩어리)가 없었다.
- 깊이: 벼랑 아래 그늘이 4px 띠 하나였다.

## 결정
1. **장소가 바뀔 때 지도 전체를 CPU에서 한 장(월드 1px = 1px)으로 굽는다**(`src/terrain.rs`).
   - 렌더러가 열쇠(벽 칸·환경·흙길)를 매 프레임 재고, 다를 때만 다시 굽는다.
   - 충돌은 그대로 16px 칸이다. 그림만 칸에서 벗어난다.
2. **벽 모양**: 칸 가운데 값(벽 1·바닥 0)을 겹선형으로 잇고 값 잡음(±0.23)을 더해 0.5에서 자른다.
   - 곧은 벽은 칸 경계를 따라 물결치고, 모서리는 둥글다.
   - 잡음 폭이 0.5보다 작아 칸 가운데 ±4px는 늘 제 칸 쪽이다. 테스트로 묶었다: 벽 그림이 걷는 곳을 가리지 않는다.
3. **3/4 벼랑**: 아래가 바닥인 벽의 아래쪽 16px가 흙 앞면이다.
   - 앞면: 물결치는 지층, 박힌 돌, 늘어진 뿌리(환경마다 비율), 위에서 늘어진 잎 1~3px.
   - 그 위 윗면: 덤불(왼쪽 위 빛의 잎 뭉치), 뿌리 지대는 뿌리 줄, 심층은 돌과 금.
   - 바닥과 닿는 곳은 어두운 테두리 1px와 밝은 안쪽 줄.
4. **바닥**:
   - 큰 잡음 띠 세 단(경계는 2×2 바둑판으로 섞음, 2×2 px마다 한 번 재기).
   - 반대 재질 얼룩: 들판·뿌리 지대는 흙, 심층은 이끼.
   - 던전 흙길: 문에서 방 가운데로, 폭 4~7px가 출렁이고, 가장자리에 조약돌.
   - 그늘: 벼랑 앞면 아래로 5px 계단, 옆벽 곁 1~2px.
5. **장식은 무리 짓는다**: 칸 해시에 저주파 밀도(0.15~1.85배)를 곱한다(`terrain::decor_at`). 어둠 뒤 빛나는 버섯 다시 그리기도 같은 함수를 써서 자리가 맞는다.
6. **매 프레임 바뀌는 칸**(잠긴 문·굴 입구·출구·저장 지점·뿌리 길)은 굽지 않고 위에 그린다. 굽기에서는 바닥이다. 출구가 생겨도 다시 굽지 않는다.
7. **굽기 시간**(던전 100×60칸 = 1600×960px, 네이티브 릴리스 약 100ms):
   - 둘레 두 칸 안에 바닥이 없는 벽 칸은 64×64 주기 무늬로 채운다(화면에 거의 안 나온다).
   - 칸마다 3×3이 같으면 1px 계산을 건너뛴다.
   - 바닥 큰 잡음은 반 해상도로 잰다.
   - 처음 280ms에서 줄였다. 장소를 바꾸는 어두워짐 동안 한 번이다.

## 하지 않은 것
- 웨이브 아레나(격자 없는 방: 실의 꿈, 개발 아레나)는 예전 타일 그림 그대로다.
- dual grid 16칸 오토타일(처음 안)은 쓰지 않았다. 한 장 굽기가 모서리·잡음·그늘을 칸 제약 없이 그린다.
  - Sunnyside 팩이 들어오면 팩 타일을 같은 모양(`shape`) 위에 찍는 쪽으로 다시 본다.

## 확인
- 단위 테스트: 칸 가운데 ±4px는 제 칸 쪽이다. 열쇠는 출구·문 같은 칸에 안 바뀌고, 벽·환경에 바뀐다.
- 굽기 속도 테스트(무시 테스트, 손으로 돌림).
- 헤드리스: 쉼터·필드·던전·심층·마을 화면.
