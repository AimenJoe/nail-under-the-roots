# 0202. 강공격 모으기를 눈에 띄게: 발밑 게이지 고리 · 딱 맞춘 창 · 다 모인 몸빛

- 날짜: 2026-10-28
- 상태: 채택(v0.4.5 패치, 0193 갈래).
- 사장: "강타 모으기가 제대로 눈에 띄게 표시되진 않는 듯.."

## 무엇이 약했나
- 모으는 동안의 표시는 발톱 끝의 작은 빛(지름 4~10px, 투명도 35%)과 1px 웅크림, 다 모인 뒤의 옅은 부채꼴 선과 0.03초 번쩍뿐이었다. 싸움 중에는 "얼마나 모였나"·"지금 떼면 되나"를 볼 수 없었다.
- "딱 맞춘 강타"(다 모인 뒤 0.15초 안에 떼기, 0168)는 창이 어디인지 보이지 않았다.

## 다른 게임에서 본 것(2차 출처 — 영상·글로 본 손맛, 수치 출처는 없음)
- 젤다 회전베기·할로우 나이트 큰 베기: 모이는 동안 무언가가 **차오르고**, 다 모이면 **한 번 번쩍 + 쥐고 있는 내내 빛**(순간 효과만으로 끝내지 않는다).
- 셋 다 "차오름(얼마나) → 다 참(이제) → 쥐는 동안(유지)"을 모양으로 따로 보인다.

## 결정(`render/actors.rs`)
- **발밑 게이지 고리**(`draw_charge_ring`): 발 둘레 타원(10×4.5)이 위에서부터 시계 방향으로 찬다(2px, 따뜻한 흰빛). 어두운 밑줄을 먼저 깔아 풀밭·어두운 굴 어디서나 보인다 — 예고(0186)는 밑줄을 뺐지만 이건 플레이어 자신의 표시라 또렷한 쪽.
  바닥에 그린다(스프라이트 밑, `draw_charge_under`): 몸 뒤 호는 몸에 가리고 발 앞 호가 보인다.
- **딱 맞춘 창**(다 모인 뒤 `HEAVY_PERFECT` 0.15초): 고리가 굵은 금빛 + 바깥으로 튀는 점 넷, 몸에 밝은 흰 실루엣(0.6). "지금 떼라".
- **창이 지난 뒤 쥐고 있는 동안**: 가는 흰 고리가 천천히 맥박 + 몸에 옅은 흰 실루엣(0.06~0.26). 강공격은 아직 나간다는 뜻.
- 발톱 끝 빛은 조금 크고 진하게(지름 최대 12px, 50%).
- 모양으로도 갈린다(차오르는 호 → 굵은 닫힌 고리 → 가는 고리) — 색만으로 가르지 않는다(0150).
- 모든 캐릭터(Naïl·모모, v0.5의 도토)에 같은 표시.

## 확인
- 헤드리스(개발 → 꽃 핀 입구·어두운 심층, J를 쥐고 프레임마다): 차오르는 호 → 금빛 고리 + 몸빛 → 가는 고리, 풀밭과 어두운 바닥 둘 다에서 보인다.

## 사람이 볼 것
- 고리가 싸움을 가리거나 박자 고리(0174)와 헷갈리지 않는지(박자 고리는 둥근 원이 닫혀 오고, 이건 발밑 타원이 차오른다).
- 딱 맞춘 창 0.15초가 금빛 고리로 잡히는지.
