# 0047: 반딧불은 마을로 — 큰 나무의 재주(자리 넷, 둘 중 하나)

- 상태: 채택 (2026-10-25). 사장이 "반딧불도 써야 한다"고 했고, 고르기에서 "큰 나무에서 기술 깨우기"를 골랐다. 0021("반딧불 = 기술 해금")과 0040("영구 성장은 옆으로")을 처음 만든다.

## 결정
1. **반딧불을 마을로 보낸다**(기록 `glowbugs_banked`).
   - 쉼터에 닿을 때 들고 있던 반딧불이 모두 마을로 간다. 알림: "쉼터에 닿았다. 체력 가득, 반딧불은 마을로 보냈다."
   - 런이 끝날 때도 보낸다: 가장 깊은 곳에 닿거나, 일시정지에서 "다시 하기"·"타이틀로"를 고를 때.
   - 쓰러지면 잃는 30%(0019)는 마지막 쉼터 뒤에 주운 것에서만 깎인다. 쉼터가 Dead Cells의 구역 끝처럼 안전 지점이 된다.
   - 첫 시작(Normal)만 보낸다. 오늘의 굴·개발 시나리오는 기록을 건드리지 않는다(0041).
2. **큰 나무의 재주**(`src/talents.rs`): 마을 큰 나무 밑동에서 "큰 나무"로 연다.
   - 자리 넷, 자리마다 갈래 둘(Hades 밤의 거울의 두 갈래). 갈래마다 좋은 점과 나쁜 점이 함께 있다.

     | 자리 | A | B |
     |---|---|---|
     | 굴파기(40) | 깊은 굴: 땅속 0.6초, 솟구침 반지름 22, 대기 ×1.4 | 얕은 굴: 땅속 0.2초, 반지름 12, 대기 ×0.55 |
     | 패링(60) | 되받아치기: 튕겨낸 돌진에 피해 2, 분노 0 | 빛 모으기: 분노 +8(보통 +4), 피해 없음 |
     | 드릴(80) | 긴 드릴: 돌진 ×1.5, 분노 차는 속도 ×0.75 | 짧은 드릴: 돌진 ×0.55, 분노 ×1.6 |
     | 먹기(50) | 꼭꼭 씹기: 먹는 시간 ×2, 산딸기 2칸 | 한입에: 먹는 시간 ×0.4 |

   - 깨우기는 반딧불로 한 번(괄호 = 갈래 하나 값). 깨운 갈래끼리는 마을에서 언제든 공짜로 바꿔 끼거나 뺀다. 안 끼면 지금 게임 그대로다.
   - 조작: 위아래 = 자리, 좌우 = 갈래, 확인 = 깨우기·끼기·빼기. 터치는 칸을 누른다.
   - 기록 키: `talent.<자리>.<a|b>`(깨움), `talent_pick.<자리>`(0 없음·1 A·2 B).
   - 튜토리얼만 빼고 모든 시작에 건다(개발 시나리오에서도 고른 재주로 시험한다).
3. 드릴 소리는 돌진 길이마다 따로 만든다(보통·긴·짧은). 소리 하나가 시동부터 돌진 끝까지 가는 규칙(0024)을 지킨다.
4. 마을 오른쪽 위에 "맡긴 반딧불 n"을 마을 씨앗 아래에 보인다.
5. 런 사이 한마디(0041 표): 반딧불을 처음 보낸 뒤 마을의 포포가 "큰 나무 밑동에 가 봐"라고 알려 준다.
6. 글 33줄 다섯 언어. DeepL이 굴파기를 "Oyster Harvesting", 끼기를 "stuck"·"clicked"·"挟む", 맡긴 반딧불을 "The Firefly I Entrusted"로 읽어 모두 고쳤다. 기존 용어(패링 = はじく·弹开·Aparar, 분노 = いかり·怒气·Fúria)를 따랐다.

## 왜
- 반딧불은 가장 많이 줍는데 쓸 데가 없었다. 0021이 정한 "기술 해금"을 런 밖에 두면 진 런도 무언가를 남긴다(KB `roguelite-replay-axes.md`).
- 둘 중 하나: 영구 수치가 크면 난이도와 "내가 늘었다"가 무너진다(0040). 갈래가 서로 반대 방향이면 깨워도 세지는 게 아니라 손에 맞는 쪽을 고르는 것이 된다.
- 쉼터에서 보내기: 30% 잃기가 계속 의미 있고(쉼터 전까지는 들고 다니는 위험), 그만두거나 쓰러져도 대부분은 남는다.
- 바꿔 끼기를 공짜로 둔 이유: Hades는 열쇠가 들지만, 우리 재주는 옆으로 가는 선택이라 시험해 보는 비용이 없어야 한다.

## 확인
- 단위 테스트: 안 끼면 기본 게임과 같다, 갈래마다 얻는 것과 잃는 것이 있다, 기록 키가 바뀌지 않는다, 마을 나무 밑동에서 확인 = 큰 나무.
- 헤드리스: 반딧불 130 기록으로 마을 → 포포 한마디 → 나무 밑동 말풍선 "J 큰 나무" → 창(한·일·포), 깨우기(130 → 90 → 10), 끼기 표시, 기록.
- 사람 판정이 남았다: 값(한 런에 반딧불이 얼마나 모이는지에 맞는지), 갈래가 정말 반대로 느껴지는지(특히 되받아치기·꼭꼭 씹기), 쉼터 보내기가 자연스러운지.
