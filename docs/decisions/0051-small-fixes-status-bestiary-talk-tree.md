# 0051: 작은 정리 — 상태 탭의 재주, 털빛 초상화, 도감 쪽 넘기기, 이웃 말 걸기, 큰 나무 가지

- 상태: 채택 (2026-10-25). 사장: "지금 바로 할 수 있는 것부터 하자." 0046~0049의 "다음"에 남은 작은 일들이다.

## 결정
1. **상태 탭에 낀 재주**:
   - 필살기 설명 아래에 "재주: 깊은 굴 · 짧은 드릴"을 보인다. 없으면 "아직 없다 · 마을 큰 나무에서 깨운다".
   - 굴파기 대기 숫자에 재주 배율을 넣었다.
   - 낡은 안내("씨앗은 상점에서 쓴다(곧)")를 지금 규칙으로 고쳤다: 반딧불은 쉼터에서 마을로 가서 큰 나무에서 쓰고, 씨앗은 포포의 가게에서 쓴다.
2. **대화창의 Naïl도 털빛을 따른다**:
   - `portraits.py`가 털빛 1~3마다 표정 넷을 더 그린다(칸 18~29). 배우가 `Portrait::nail(fur)`로 고른다.
   - 시트를 한 줄 12칸으로 접었다. 한 줄로 늘어놓으면 2,640px가 되는데, 오래된 폰의 텍스처 한도(2,048px)를 넘는다.
3. **도감 설명을 쪽으로 나눈다**:
   - 이야기·공격·요령을 한 쪽에 하나씩, 칸 끝까지 쓴다. 칸마다 두 줄에서 말없이 잘리던 문제(0046)를 고친 것이다. 그래도 넘치면 마지막 줄에 "…".
   - 확인(또는 설명을 누르기)으로 넘긴다. 처음엔 좌우로 했지만 일시정지에서 좌우는 탭을 바꿔서 지도 탭으로 넘어가 버렸다.
   - 일본어 대장 공격 글은 네 줄에 들어가게 줄였다.
4. **이웃 말 걸기가 진행을 따른다**(`story.rs` `When::TalkBori`·`TalkMomo`, 한 번씩):
   - 보리: 모모가 돌아온 뒤 / 반쪽 엔딩 뒤(할매) / 다섯 번 쓰러진 뒤(패링 요령) / 큰 나무 재주를 안 뒤.
   - 모모: 반쪽 엔딩 뒤(가족 걱정) / 보리가 돌아온 뒤(이웃이던 옛 이야기).
   - 맞는 줄이 없으면 지금처럼 늘 하는 말을 돌린다. 글 6줄 다섯 언어, 직접 썼다.
5. **상태 탭 체력 하트**: 고정 자리에 그려서 일본어에서 "5 / 5"를 덮었다(이전부터). 숫자 바로 뒤에 그린다.
6. **큰 나무 일러스트 가지**:
   - 굵기가 같은 곡선 여섯 개 → 갈라지며 가늘어지는 가지(세 번 갈라짐, 끝이 살짝 처짐). 밑동이 벌어지게 했다.
   - 음영은 줄기와 가지를 따로 준다. 먼 가지가 새까매지지 않게.
   - 사슴뿔처럼 보이던 문제(0049)를 고친 것이다.

## 확인
- 단위 테스트: 털빛 초상화 칸 번호, 말 걸기 줄(진행 순서·한 번만·없으면 기본 말).
- 헤드리스(한·일): 상태 탭 재주 줄·하트 자리, 도감 1/3 → 2/3(확인), 보리의 "모모가 돌아왔구나".
- 큰 나무 일러스트 위쪽을 원본 크기로 봤다.
