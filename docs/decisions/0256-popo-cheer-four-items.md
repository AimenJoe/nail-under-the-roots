# 0256. 포포의 응원 = 항목 넷(길의 주인 건너뛰기는 뺀다)

- 날짜: 2026-10-29
- 상태: **구현**(개발판)
- 사장(2026-10-29): "포포의 응원에서 길의 주인 스킵은 좀 너무하지 않나? 스토리 진행에도 별 도움 되지 않고. 그 외에는 좋아 보인다." — 0254 §4 제안을 채택하되 주인 건너뛰기는 뺀다.

## 정한 것
설정의 "포포의 응원" 줄은 이제 창으로 가는 줄(→). 창에 항목 넷, 고른 항목 아래에 하는 일 한 단락(열한 언어).

| 항목 | 값 | 하는 일 |
|---|---|---|
| 받는 피해 | 끔 / -25% / -50% / -75% / 쓰러질수록 | `Player::resist`. "쓰러질수록" = 20% + 쓰러질 때마다 2%, 80%까지(0041의 예전 방식, `ASSIST_DEATHS`는 이 값일 때만 센다) |
| 쓰러져도 계속 | 끔 / 켬 | `World::assist`: 실뿌리 없음(런이 안 끝남), 맡기지 않은 반딧불 70% 남김, 굴 안에서 그만둬도 맡긴다 |
| 공격 예고 길게 | 끔 / +30% / +60% | `World::tell_mul` → 적이 깰 때 `Enemy::apply_knots(knots, tells)`가 `windup_mul`에 곱한다(예고 그림·도토리 지뢰 심지도 같이 늘어난다) |
| 받아치기 창 넓게 | 끔 / +50% / +100% | `Player::parry_assist`가 `PARRY_WINDOW`에 곱한다(실뜨기 `parry_mul`과 따로) |

- **길의 주인 건너뛰기를 뺐다**: 예전에는 도움 모드에서 주인에게 쓰러지면 그 런의 주인 싸움이 없어졌다(0046·0210). 주인을 이기는 것이 이야기(돌아오는 이웃)를 여는 길이라 건너뛰면 이야기도 안 나아간다. 지금은 쓰러져도 주인은 남는다 — 대신 위 셋으로 싸움 자체를 쉽게 한다.
- 기록(슬롯마다): `assist` 깃발 = 쓰러져도 계속(키 이름 그대로), `assist_resist`(단계 + 1, 0 = 칸 없음과 가르려고), `assist_tells`·`assist_parry`. 받는 피해 칸이 없는 옛 기록에서 `assist`가 켜져 있으면 "쓰러질수록 + 쓰러져도 계속"으로 읽는다 — 예전 한 줄 켜기와 같은 도움(`assist::Assist::read`, 시험 있음).
- 코드: 순수한 `src/assist.rs`(읽기·쓰기·단계·배율) + 창 `App::update_assist`·`draw_assist`(`app/settings.rs`, 장면 `Scene::Assist`).

## 다른 게임(2차, 0254 §4)
Celeste·Dead Cells의 항목별 도움, Hades God Mode의 쌓이는 저항 — 도움을 하나로 묶지 않고 고르게 하는 것이 요즘 관례. 보스 건너뛰기는 Celeste에서도 "챕터 건너뛰기"가 따로 있지만, 이 게임은 보스가 곧 이야기라 넣지 않는다.
