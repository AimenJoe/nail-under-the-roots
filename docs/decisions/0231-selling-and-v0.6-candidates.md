# 0231. 팔 것인가, 그리고 v0.6 후보(시장 조사)

- 날짜: 2026-10-29
- 상태: **제안**(사장: "0.6 마일스톤 작성을 위해 시장조사를 좀 하자. 이정도로 만들어진 게임의 가격 및 비즈니스 모델을 어떻게 설정해야 할지.. 돈을 벌 수 있는 방법이 있긴 한지.."). 전체 조사는 `docs/research/2026-10-market-and-pricing.md`(출처 1차·2차·추정 구분, 확인 못 한 것 목록).
- 한계: 조사의 웹 근거 대부분은 검색 요약으로만 읽었다(Steam·Gamalytic 페이지가 이 세션에서 막힘). Android 개발자 확인만 원문으로 확인했다. 숫자는 결정 전에 원문으로 다시 본다.

## 한 줄
**돈은 "가능하지만 작다".** Steam $9.99, 마케팅 없이 첫해 개발자 몫 약 130만~450만 원, Steam 페이지 6~12개월 + 데모 + Next Fest로 위시리스트 5~8천이면 약 1,300만~2,500만 원(추정). 그보다 큰 것은 운이 섞인 히트다. 판매를 가장 잘 예측하는 것은 출시 때 위시리스트 수다.

## 팔기 전에 걸리는 셋
1. **AI 그림 공개 표시**(가장 큰 위험): 스프라이트·초상화·일러스트·타이틀이 Steam의 "Pre-Generated"에 해당한다. 표시가 붙은 게임은 신작의 3분의 1이지만 추정 매출은 10~27%라는 집계, "절대 안 산다" 8% 설문이 있다(2차). 귀여운 도트 게임을 사는 사람에게 더 아프다(추정).
2. **웹에서 게임 전체가 무료**: 유료판과 관계를 정해야 한다(데모로 줄이기 / 전체 무료 + 유료판에 네이티브·업적·클라우드).
3. **레포가 공개**: 레포만 받으면 거의 완전한 게임을 빌드한다. AI 그림은 저작권 보호가 약해(미국 판결·한국 안내서) 가져가도 막기 어렵다.

## 가격·모델(추천, 추정)
- 지금 분량이면 **$7.99~9.99**. $12.99~14.99는 다회차 깊이(20시간+)·캐릭터 4~5·지대 5~6·사람 그림·데스크톱/Deck이 있을 때.
- 맞는 정도: Steam 유료 1.0 + 데모 + Next Fest **높음** · 앞서 해보기 **중간**(졸업작 21%만 1.0이 더 팔림, 2차) · itch **보조** · 모바일 유료/열기·광고·Kickstarter **낮음**(패드 전제, iOS 패드 없음).

## v0.6 "큰 것" 후보(판매 근거가 많은 순)
1. **"팔 수 있는 판"**: 얼굴 그림을 사람 손으로(캡슐·키 아트 외주 $300~700, 주인공 셋 스프라이트·초상화를 `tools/pixel`로 다시) + Windows/Linux 네이티브 빌드 + Deck 확인 + (선택) 업적·클라우드. AI 표시를 줄이거나 없앤다.
2. **다회차 깊이**: 난이도 사다리 + 넷째 캐릭터 + 보스 갈래 — 가격대를 한 칸 올리는 근거.
3. 로컬 협동(근거 약함, 비용 큼). 4. 모바일 정식(1.0 뒤).

## 사장이 정할 것
1. **팔 것인가.** 안 판다면 지금 구조 + 0223 공개 데모가 맞다.
2. 판다면: 레포 공개 범위 — (A) 코드 공개·콘텐츠(그림·글) 비공개 레포로 옮기기(추천) / (B) 판매 때 비공개 / (C) GPL로 활짝.
3. 웹 무료판의 역할(데모로 줄이기 / 전체 유지).
4. v0.6 = 후보 1(추천) / 2 / 그 밖.
5. 바로 할 수 있는 권리 정리(v0.5.x): Gemini를 쓴 제품·날짜·약관 사본 기록, Sunnyside V2.1 라이선스 원문 다시 뜨기, 게임 안 크레딧·라이선스 화면, 2027년 전 Android 개발자 확인(제한 배포 계정이면 20대까지 무료).
