# 0212. 도토 공중 던지기는 가장 가까운 적에게 저절로 · Naïl 걷기 칸의 눈을 하나로

- 날짜: 2026-10-28
- 상태: 채택(사장 "도토의 달리다 뛰는 건, 자동 조준으로 가장 가까운 적에게 쏴야 될 듯, 아니면 메리트가 없어", "나일 걷는 애니메이션, 눈이 바뀌는 부분 이상하네")

## 1. 도토 공중 던지기(0209·0211 위에)
- 예전: 멀리뛰기 동안 공격을 누르면 1타 하나를 스틱 쪽으로. 뛰는 동안 스틱은 뛰는 방향이라 적을 겨누기 어렵고, 누르지 않으면 아무것도 없어 모모의 착지 밟기에 견줄 보상이 없었다.
- 이제: 멀리뛰기 꼭대기(`JUMP_TIME`의 반)에서 **저절로**, 도토리가 닿는 거리 안의 **가장 가까운 적**에게 **셋째 타(부채꼴 셋)**를 한 번 던진다(`Player::air_target` — 월드가 넘기는 `targets`, 드릴 조준 0139와 같은 목록). 꼭대기 전에 공격을 누르면 그때 던진다(적이 없으면 겨눈 쪽으로). 닿는 적도 누름도 없으면 던지지 않는다.
- 공중 무적 + 저절로 겨눈 셋 = 물러나며(또는 들어가며) 쏘는 도토의 몸(0195)에 맞는 보상.
- 안내 "달리기와 멀리뛰기" 글의 도토 대목을 열한 언어로 고쳤다.
- 시험 `momo_stomps_and_doto_throws_once_in_the_air`: 누르면 셋 한 번, 적·누름 없으면 없음, 적이 있으면 꼭대기에서 저절로 그 적 쪽(방향 내적 > 0.99).

## 2. Naïl 걷기 눈
- 원본 걷기 넷이 칸마다 눈을 조금씩 다르게 그렸다: 까만 두 점 / 번진 보라 / 흰 빛점 / 가로 두 점. 1배로 걸으면 눈이 깜빡이듯 바뀌었다.
- `tools/art/nail_ai.py` `same_eye`: 서기 칸의 눈(까만 두 점 + 왼쪽 아래 남빛 한 점)을 걷기 칸마다 **눈동자 자리**에 맞춰 찍고, 원래 눈 점(빛점·번진 보라)은 둘레 털색으로 지운다. 코 분홍을 기준으로 맞췄더니 코 모양이 칸마다 달라 눈이 둘이 됐다 → 가장 짙은 눈동자 점의 위·왼쪽을 기준으로.
- `nail.png`·털빛 셋·사이트 걷는 띠(`sp_nail`)를 다시 만들었다. 서기·동작 칸은 그대로.
