# 0236. 반딧불·씨앗을 덜 떨어뜨린다

- 날짜: 2026-10-29
- 상태: **구현**(v0.5.x 패치 후보). 사장: "아직도 이코노미는 손봐야겠다. 씨앗도, 반딧불도 너무 흔하네."
- 앞: 0225는 반딧불 **값**만 ×3 올렸다(떨어뜨리는 수는 그대로). 그래서 화면에는 여전히 많이 떨어지고, 씨앗은 손대지 않았다.

## 잰 것(바꾸기 전, 시험 `economy_probe` — 길마다 처음부터 끝까지 한 줄로 걸은 기댓값, 시드 40개 평균)
| | 굴 | 처치 | 반딧불 | 씨앗 |
|---|---|---|---|---|
| 첫 길 | 3.4 | 33 | 109 | 25 |
| 둘째 길 | 3.4 | 44 | 152 | 27 |
| 셋째 길 | 3.4 | 46 | 161 | 27 |
| 한 런 | | | **422** | **78** |
- 쉼터 가게(산딸기 3·지렁이 10·뿌리 심장 14·장신구 12)에 길마다 씨앗 25~27 → 심장 + 지렁이를 늘 다 산다. 고를 일이 없다.
- 반딧불 422/런이면 재주 전부(3,180 + 독 발톱 360, 저널 보상 ≈690 빼고 ≈2,850)를 여섯 런 남짓에 다 깨운다.

## 바꾼 것
- 잡몹 반딧불 범위 ×0.55(반올림, 최소 1), 길의 주인 ×0.58(예: 대장 20~24 → 12~14). 잡몹 씨앗 확률 ×0.5(주인은 그대로 1).
- 상자 씨앗 3~5 → 2~3, 주인 씨앗 6 → 4, 끝 무리 씨앗 3 → 2, 부술 것의 씨앗 0.30 → 0.18·반딧불 0.10 → 0.06, 쉼터 숨은 자리 반딧불 6 → 4.
- 값(`TALENT_PRICE_MUL` 3, 가게 값)은 그대로.

## 바꾼 뒤(같은 시험)
| | 반딧불 | 씨앗 |
|---|---|---|
| 첫 길 | 63 | 15 |
| 둘째 길 | 86 | 16 |
| 셋째 길 | 90 | 16 |
| 한 런 | **239**(−43%) | **48**(−38%) |
- 길마다 씨앗 ≈15: 뿌리 심장(14) **또는** 장신구(12)+산딸기 — 쉼터마다 하나를 고른다.
- 재주 전부: ≈2,850 / 239 ≈ 열두 런(세 캐릭터·독 발톱 포함, 저널 보상 따로). 한 캐릭터 몫은 너댓 런.
- 줍는 손맛(끌려오는 반딧불·오르는 음)은 그대로, 줍는 횟수만 준다.

## 하지 않은 것
- 마을 씨앗(`VILLAGE_SEEDS_*`, 꾸미기 가게 몫, 런 끝에 받는다)은 그대로 — 다른 화폐다. 너무 흔하면 따로 말해 달라.
- 실뜨기(난이도 매듭)의 배율·저널 보상은 그대로.

## 확인
- `cargo test economy_probe -- --ignored --nocapture`로 다시 잰다(수치를 바꾸면 이 표를 고친다).
- 사람 판정: 두세 런 해 보고 쉼터 가게에서 고민이 생기는지, 재주가 너무 더디지 않은지.
