# 0057: 한국어 이름은 "나일"

- 상태: 채택 (2026-10-25).
- 사장: "영어명 Naïl은 좀 이질감 있으니 '나일'이라고 하는 것도 좋을 듯".

## 결정
1. 한국어 표에서 주인공 이름을 **나일**로 쓴다. 이야기·대사·설명 7줄, 대화창 이름, 고르기 창 카드가 모두 바뀐다.
2. 이름은 `i18n::Strings::name_nail` 한 칸에 둔다. 전에는 `equipment.rs`에 "Naïl"이 박혀 있었다(0013 위반).
3. 다른 언어는 그대로 "Naïl"이다(영어·포르투갈어는 라틴 문자, 일본어·간체는 사장 판정 전).
4. 타이틀 로고("Naïl / Under the Roots")와 창 제목은 게임 이름이라 그대로 둔다. 사장: "타이틀의 Naïl은 괜찮아. 아래 부제랑 통일감 있고"(2026-10-25).
5. 문서·코드 식별자는 그대로 Naïl(`nail.py`, `draw_nail` …)이다.

## 왜
- 한글 문장 가운데 라틴 문자 이름(트레마 ï 포함)은 읽는 흐름을 끊는다. 다른 이웃(포포·보리·모모·도토·콩이·수수)은 모두 한글 이름이다.
- 기존 조사("Naïl은", "Naïl이")가 이미 "나일" 발음을 따르고 있어 글을 고칠 곳이 없었다.
