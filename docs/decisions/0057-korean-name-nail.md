# 0057: 이름은 어느 언어에서나 "나일"로 읽힌다

- 상태: 채택 (2026-10-25).
- 사장: "한자 나일은 사실 잡을 나, 해 일이야" → 간체는 한자로.
- 사장: "영어명 Naïl은 좀 이질감 있으니 '나일'이라고 하는 것도 좋을 듯", 이어서 "일어 발음도 나일로 되도록 해줘. 다른 언어도 웬만하면".

## 결정
1. 한국어 표에서 주인공 이름을 **나일**로 쓴다. 이야기·대사·설명 7줄, 대화창 이름, 고르기 창 카드가 모두 바뀐다.
2. 이름은 `i18n::Strings::name_nail` 한 칸에 둔다. 전에는 `equipment.rs`에 "Naïl"이 박혀 있었다(0013 위반).
3. 언어마다 "나-일" 두 소리로 읽히게 쓴다.
   | 언어 | 이름 | 왜 |
   |---|---|---|
   | 한국어 | 나일 | |
   | 일본어 | ナイル | 나·이·루. 일본어 표기의 보통 규칙(받침 ㄹ → ル). 이웃 이름(ボリ·モモ·ドト)과 같은 가타카나 |
   | 간체 | 拿日 | 이름의 한자(잡을 나 拿, 해 일 日 — 땅속에서 해를 잡으러 가는 두더지). 중국어에서 한자가 있는 한국 이름은 한자로 쓰고 보통화로 읽는 것이 관례다(ná rì). 소리는 "나일"과 조금 다르지만 뜻을 살렸다. 처음엔 소리 음역 奈伊였다 |
   | 영어·브라질 포르투갈어 | Naïl | 트레마(ï)가 바로 "a와 i를 따로 읽어라"는 표시다(naïve처럼). 빼면 영어는 nail(손톱)로 읽는다. 포르투갈어식 Naíl(강세 표시)은 타이틀 로고와 철자가 갈라져 두지 않았다 |
4. 타이틀 로고("Naïl / Under the Roots")와 창 제목은 게임 이름이라 그대로 둔다. 사장: "타이틀의 Naïl은 괜찮아. 아래 부제랑 통일감 있고"(2026-10-25).
5. 문서·코드 식별자는 그대로 Naïl(`nail.py`, `draw_nail` …)이다.

## 왜
- 한글 문장 가운데 라틴 문자 이름(트레마 ï 포함)은 읽는 흐름을 끊는다. 다른 이웃(포포·보리·모모·도토·콩이·수수)은 모두 한글 이름이다.
- 기존 조사("Naïl은", "Naïl이")가 이미 "나일" 발음을 따르고 있어 글을 고칠 곳이 없었다.

## 함께 고친 것
- 간체 표에서 "Naïl"이 빠지자 라틴 글자 몇 개(버튼 이름 J, ï)가 미리 굽는 글자 목록에서 빠졌다. 그 뒤 고르기 창에서 macroquad 글자 아틀라스가 그리는 도중 두 배로 커졌고, 콘솔에 "glBindTexture called with an already deleted texture"가 나왔다.
  - 원인: macroquad `text/atlas.rs`. 아틀라스가 넘치면 크기를 두 배로 하고 텍스처를 지웠다 새로 만든다. 같은 프레임에 이미 쌓인 글은 지워진 텍스처를 본다.
  - 고침: `Strings::glyphs()`에 출력 가능한 ASCII 전부 + ï를 넣었다. 두 배 크기 글(타이틀·쓰러짐)도 미리 굽는다(`Renderer::present`). 다섯 언어 헤드리스에서 경고가 사라졌다.
