# 0245. 사장 시험 고침: 도토 런이 끝까지 도토, 할매 방, 굴파기 장신구, 그림 셋

- 날짜: 2026-10-29
- 상태: **구현**(개발판). 사장 시험에서 나온 것.

## 고친 것
1. **도토(모모)로 고르면 끝까지 그 캐릭터**: 엔딩의 말하는 초상화가 Naïl이었다(`cutscene::nail_actor`가 모모만 갈랐다) → `characters.rs` 표의
   `portrait`·이름·색으로. 엔딩 뒤 땅 위로 올라오는 전환·마을도 Naïl이었다(`flow::character`가 마을을 Naïl로) → 마을도 고른 캐릭터.
   그 캐릭터의 이웃(모모·도토)은 마을 자리에 따로 서지 않는다(`App::village_state`).
2. **할매 방(가장 깊은 곳) 가운데 투명벽**: 기본 방(`Room::new`)의 기둥 둘을 그림(소품)만 지우고 충돌(`solids`)은 남겨 두었다 → 둘 다 비운다.
3. **무엇을 칠지 모르겠다**: 새 할매 그림(0219) 갈래가 일찍 돌아가 **매듭 셋이 아예 그려지지 않았다** → 매듭을 그리고, 안 끊긴 매듭 위에
   통통 뛰는 화살표 + 퍼지는 고리(`render/deep.rs draw_knots`). 만남 장면 끝에 "할매에게 이어진 매듭 셋만 끊는다" 한 줄(`deep_goal`, 열한 언어).
4. **도토에게 굴파기 장신구**: 흙 한 줌(굴파기 -40%)·할매의 실(굴파기 -30%)은 `only: Some(Mole)`. 회피 대기 시간은 캐릭터마다 장신구가 따로 있다(모모 토끼풀 잎 등).
5. **그림**: 도토 파 내려가기(`dig.py`)가 모모의 긴 토끼 귀 + 작은 꼬리였다 → 술 달린 작은 귀 + 등을 덮는 큰 꼬리.
   게임 속 도토 걷기는 같은 달리기 그림을 1px 띄운 두 칸이었다 → 사장이 좋다고 한 달리기 바운드 네 칸을 낮게 띄워 걷기로(`doto.png` 칸 12~15, 느리게).
   마을 큰 나무 밑동 → 뿌리 아래 넓은 그늘 + 뿌리 끝을 덮는 풀 포기(`render/sorted.rs draw_root_grass`).
