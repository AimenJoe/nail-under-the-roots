# 0039: 컷씬 일러스트 — 한 장 그림 + 내레이션, 지금은 코드로 그린 임시 그림

- 상태: 채택 (2026-10-25). 사장 "몇몇 컷씬에서 쓰일 일러스트 그려야 할 듯", "다 넣어야지! 컷신을 보는 것도 게임의 재미야".
- 사장 선택:
  - 엔진 + 임시 그림 먼저(나중에 사람이 그린 그림으로 갈아 끼움)
  - 픽셀, 초상화처럼 2배 밀도
  - 장면은 전부

## 결정
1. **컷씬 스텝 두 개를 더한다**(`cutscene.rs`).
   - `Step::Illust(Option<Illust>)`: 화면 전체 그림을 띄우거나 내린다.
   - `Step::Narrate(Tr)`: 이름·초상화 없이 아래 띠에 가운데 맞춤 글을 띄운다.
   - 장면 바꾸기는 `cut_to`(어두워짐 → 그림 바꿈 → 밝아짐).
   - 대사는 그림 위에 늘 쓰던 대화창으로 뜬다.
2. **그림은 640×360, 게임 픽셀의 2배 밀도**(초상화 0015와 같은 방식).
   - 패닝하는 그림은 더 크다. 큰 나무 640×560 아래로, 할매 704×360 옆으로, 마지막 꽃 640×440 아래로.
   - 패닝은 부드럽게 출발하고 멈추며, 정수 원본 px로 움직인다.
   - 그림마다 입자를 하나씩 둔다: 마른 잎·먼지·반짝이·꽃잎·포자. 시간만으로 정하므로 건너뛰어도 같은 그림이 나온다(`illust.rs`).
3. **장면 8개**(이야기는 0037, 대사는 다섯 언어):

   | 그림 | 어디서 | 지금 게임에서 |
   |---|---|---|
   | `great_tree` 시드는 큰 나무 → 땅속 보라 실 | 오프닝 첫머리, 내레이션 둘 | 새 게임 |
   | `mother_burrow` 어미가 Naïl을 굴 밖으로 | 오프닝, 내레이션 + 엄마 "오늘부터 네 굴을 찾아." | 새 게임 |
   | `bori_freed` 보리에게서 실이 풀린다 | 들쥐 대장 처치 컷씬 첫머리 | 튜토리얼 보스 |
   | `momo_bloom` 모모의 꽃이 핀다 | 모모 세 번째 승리 뒤 | 개발 "이야기 일러스트"(모모 보스가 아직 없다) |
   | `halmae_deep` 누룩 할매 | 반쪽 엔딩·참 엔딩 첫머리 | 개발 "이야기 일러스트" |
   | `last_bloom` 큰 나무의 마지막 꽃 | 참 엔딩 | 〃 |
   | `sprout` 흰 실이 새싹을 감싼다 | 참 엔딩 | 〃 |
   | `molehill` 새싹 아래 마을과 새 두더지 둔덕 | 에필로그(멀리서 엄마가 보고 돌아간다) | 〃 |

4. **임시 그림은 `tools/art/illust.py`가 만든다.**
   - 계단식 그라디언트, 마스크에 구 음영 띠, 베지어 실·뿌리, 캐릭터 외곽선을 쓴다.
   - 1px 디더는 쓰지 않는다(아래 "홀수 배율").
   - 사람이 그린 그림으로 바꾸려면 같은 이름 PNG를 `assets/art/illust/`에 넣는다(사양: `docs/art/cutscene-illustrations.md`).
5. **새 이야기 인물**(엄마·모모·누룩 할매)은 초상화가 아직 없어 이름표 + 색 네모로 둔다. 초상화는 다음 일이다.
6. 개발 시나리오 **"이야기 일러스트"**: 모모 → 반쪽 엔딩 → 참 엔딩·에필로그를 이어서 튼다.

## 왜
- 이 게임의 이야기는 "떠나보내기"라 감정의 정점이 몇 장면에 몰려 있다(0037). 16px 스프라이트로는 표정·크기·빛을 보여 줄 수 없다. 한 장 그림이 그 순간을 붙잡는다(JRPG·비주얼 노벨의 CG).
- 2배 밀도를 고른 이유: 게임과 같은 도트 결을 지키면서 표정에 여유가 생긴다. 초상화 파이프라인과 크기 셈법을 그대로 쓴다.
- 엔진과 임시 그림을 먼저 만드는 이유: 장면 길이·대사 위치·패닝 속도는 그림이 있어야 판정할 수 있다. 사람 일러스트는 그 판정이 끝난 뒤 사양에 맞춰 받는 편이 다시 그리는 비용을 줄인다.
- 내레이션을 따로 둔 이유: 일러스트 장면은 "누가 말하나"보다 "무슨 일이 일어났나"가 많다. 이름표·초상화가 그림을 가리지 않게 한다.

## 비용·한계
- **홀수 배율**(예: 960×540 창 = 배율 3)에서는 원본 1px이 화면 1.5px로 늘어나 고르지 않다. 초상화처럼 짝수로 줄이면 그림이 화면의 2/3로 작아져서, 꽉 채우는 쪽을 골랐다. 1px 디더·체크 무늬는 얼룩지므로 쓰지 않는다(사람 그림 사양에도 적었다).
- 그림 8장을 시작할 때 모두 불러온다(합 약 130KB). 장면이 늘면 나눠 부르기를 생각한다.
- 대화창·내레이션 띠가 보이는 창의 y 248 아래를 덮는다. 그림의 중요한 것은 위 2/3에 둔다.
- 임시 그림은 임시다. 인물이 덩어리 몇 개라 표정·자세가 단순하다.

## 확인
- 단위 테스트 3개:
  - 패닝 끝이 정수 px이고 시작·끝이 맞음.
  - 그림마다 파일 이름·번호가 하나씩.
  - 입자가 그림 밖으로 나가지 않음.
- 헤드리스:
  - 데스크톱(배율 3, 한국어)과 폰(배율 2, 일본어)으로 오프닝을 확인했다. 큰 나무 → 패닝 → 엄마 장면, 내레이션·대사.
  - 개발 "이야기 일러스트" 22장면이 모두 떴다.
- 사람 판정은 남았다: 장면 길이, 패닝 속도, 내레이션 줄 수, 그림 분위기.
