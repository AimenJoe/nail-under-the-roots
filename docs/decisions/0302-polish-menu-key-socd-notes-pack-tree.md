# 0302. 손질 묶음 — M으로 닫기·맞선 키·수첩 이웃 아이콘·짐 그림·재주 목표 빼기·고르기 칸

- 날짜: 2026-11-23
- 상태: **채택**(사장 2026-11-23 수정 목록)
- 바탕: 0247(재주 나무 보이기·목표 핀), 0259(짐 꾸리기), 0269 2.7(마을 수첩), 0280(키보드 배치)

## 1. 지도 키(M)로 메뉴 닫기
지도 키(기본 M·패드 Select)는 메뉴를 지도 탭에 연다. 같은 키를 다시 누르면 닫힌다(`app/pause.rs update_pause` — 뒤로·메뉴·지도 키). 연 키로 닫는 것이 흔한 기대다.

## 2. 움직임 점검(best practice)
코드로 확인한 것(1차): 60Hz 고정 틱 + 렌더 보간(`prev_pos`), 프레임 dt 상한 0.25초, 키 에지는 프레임 사이에 모아 다음 틱에 한 번(`Input::pending`), 쥔 값(이동·쥐기)은 틱마다 그대로, 스틱 방사형 데드존 0.2 + 다시 늘이기, 대각선 정규화, 원 대 사각형 밀어내기(벽 따라 미끄러짐·모서리 둥글게), 바깥 힘(물살·적과 몸 부딪기) 뒤에도 벽 밀어내기, 회피·뛰기·땅속은 적을 통과. 즉시 가속(관성 없음)은 탑다운 액션의 보통 선택이다.
고친 것 하나: **키보드 맞선 방향(왼쪽+오른쪽)**을 같이 쥐면 멈췄다(중립). 손가락을 굴려 방향을 바꿀 때 몇 프레임 멈칫한다 → **나중에 누른 쪽**, 나중 것을 떼면 아직 쥔 앞의 것(`input::socd_axis`, 시험 `opposing_keys_take_the_latest`). 패드·터치는 축이라 해당 없음.

## 3. 마을 수첩의 이웃 아이콘
수첩 목록에서 장소 줄은 그림이 있었는데 이웃 줄은 비어 있었다(`draw_note_spot`이 이웃이면 아무것도 안 그림 — 자세히 칸은 초상화). 목록 줄에는 마을 지도에 선 모습 그대로(`VillagePic::Neighbor` → `draw_note_neighbor`, 0.5배라 화면 배율에서 점이 또렷).

## 4. 짐 꾸리기 그림
- 씨앗 주머니가 너무 빨리 반짝였다: 창 그림이 바닥에 놓인 줍는 것의 표시(빛 자리·퍼지는 고리·별 `draw_pickup_mark`)를 씨앗 셋마다 제각각 그렸다. 창에서는 알 몸만(`draw_seed`).
- 목록의 ●○ 점(싼 수/최대)은 뺐다 — 같은 정보가 자세히 칸의 `n/최대`와 목록 아래 "다음 모험에" 줄에 있다.

## 5. 재주 나무
- **목표 정하기(0247 목표 핀)를 뺐다**: 아직 못 깨우는 칸에서 확인 = "안 돼" 소리만. 거기까지의 길(금빛 테두리)·칸 수·합계·모자란 수는 고른 칸에서 그대로 보인다. 일시정지 상태 탭의 목표 줄, 칸의 깃발 표시도 뺐다. 옛 기록 키 `tree_goal.<캐릭터>`는 읽지 않고 남겨 둔다(다른 뜻으로 다시 쓰지 않는다).
- **둘 중 하나 고르기 칸**: 두 칸이 같은 갈림 그림이라 "둘 중 하나"인지, 각각 무엇인지 칸만 보고는 몰랐다 →
  - 칸 그림 = 갈림의 **이 칸 쪽 가지만 밝게**(왼쪽 칸 = 왼쪽 가지, 오른쪽 칸 = 오른쪽 가지, 다른 가지는 옅게),
  - 두 칸을 **한 틀로 묶는다**(옛 밑줄 괄호 대신),
  - 자세히 칸에 "둘 중 하나 · 옆 칸: <이름>"(열한 언어 `tree_pick_other`). 안내 `h_tree_d`의 목표 문장은 이 규칙으로 바꿨다.
