# 0219. C4 누룩 할매 새 그림(가장 깊은 곳 + 마을, 원본 한 장에서 두 크기)

- 날짜: 2026-10-28
- 상태: 개발판(사장 "할매부터 해야 되지 않을까?" — 0191 C4 "보스 다섯"에 빠져 있던 가장 깊은 곳의 주인)

## 왜 지금
- 할매는 마지막 장소(0162)의 주인이고 반쪽 엔딩 뒤 마을 이웃(0045)이다. 둘 다 코드 그림(타원 더미 + 버섯 갓)이었다. 보스 다섯을 새 그림으로 바꾼 뒤 할매만 남으면 마지막 장면만 옛 그림이 된다.

## 받기(0206과 같은 길)
- 실루엣 먼저(`tools/art/halmae_silhouette.py`): 96칸, 키 87px·폭 96px(Naïl의 다섯 배 — 할매는 싸우지 않고 "실이 모이는 곳"이라 화면 한가운데 크게). 표지 셋: 울퉁불퉁한 솜 더미(매끈한 공이 아니다), 머리 위 버섯 갓 셋(가운데가 가장 크다), 밑동에서 퍼지는 보라 뿌리실(매듭으로 이어지는 실의 시작). 처음 실루엣은 뿌리실이 가늘어 안 보여 굵혔다.
- 여섯 칸: 숨 둘(들숨·날숨) · 당기기(질끈 눈, 뿌리 팽팽) · 움찔(매듭이 깎일 때, 걱정 눈썹) · 놓아주기(눈을 뜬다) · 기쁨(^ ^).
- 받은 것(`sources/ai/sprites/halmae_v1.png`): 여섯 칸 모두 버섯 자리가 같다. 칸 사이로 뿌리가 맞닿아 덩어리로는 못 나눠 빈 열(x 335·679, 아래 줄 331·676)에서 잘랐다. **아래 줄이 위 줄보다 4.5% 크게** 왔다(버섯 끝~몸 밑 320px 대 306px).

## 옮기기(`tools/art/halmae_ai.py`)
- 원본 한 장 → 두 크기: 줄 0 **96칸**(외곽선 안 키 84, 가장 깊은 곳), 줄 1 **40칸**(키 34, 마을). 처음엔 마을을 32칸 키 28로 했으나 얼굴이 사라졌다.
- 줄마다 기준 칸을 두고 아래 줄은 그 비만큼 줄인다(같은 배율이면 표정마다 몸이 커졌다 작아진다).
- 색표는 늘 위 줄 들숨 칸에서(줄마다 고르니 아래 줄의 볼이 갈색이 됐다).
- **마을 크기의 얼굴을 다시 찍는다**: 원본의 4px 눈선은 키 34로 줄이면 1px도 안 남아 볼만 남거나(숨·당기기·기쁨) 얼굴이 다 사라졌다(움찔·놓아주기). 큰 칸에서 눈(가운데 40% 폭·키 45~85% 줄의 어두운 점 중 쪽마다 맨 위 3줄 — 입이 섞이면 눈이 볼 높이로 내려갔다)·볼(분홍)의 자리를 찾아 몸 겉 네모 비율로 옮기고, 줄이며 남은 찌꺼기를 얼굴 바탕색으로 덮은 뒤 감은 눈 ‿ / 뜬 눈 / 기쁜 눈 ^를 찍는다. 눈은 볼보다 2줄 위.
- 흰 실루엣 줄은 없다(할매는 맞지 않는다).

## 게임
- `Art::halmae`(`art/halmae.png`)·`art::draw_halmae(tex, frame, big, feet)`. 없으면 예전 코드 그림.
- 가장 깊은 곳(`render/deep.rs draw_deep`): 숨 두 칸을 번갈아, 당기기 예고·뻗기 중 = 당기기, 매듭이 맞아 떠는 동안(`Knot::shake`) = 움찔, 셋 다 끊은 뒤 `done_t` 1.0초부터 = 놓아주기(눈을 뜬다, 예전 코드 그림과 같은 때), 2.4초부터 = 기쁨. 발바닥은 가운데 + 28(얼굴이 예전 그림의 얼굴 자리에 온다). 빛·그림자·실·매듭은 그대로 코드.
- 마을(`render/actors.rs draw_halmae_at`): 40칸 숨 두 칸, 발은 다른 이웃과 같은 자리.
- **마을 지도에서 보리(b)를 모닥불 왼쪽(8, 6)으로**: 할매(H)가 커져 한 칸 아래 대각선의 보리가 할매 얼굴을 가렸다. 처음엔 네 칸 왼쪽(15, 6)으로 옮겼으나 큰 나무 밑동 바로 아래라 나무와 겹쳤다(사장) — 나무 줄(14열)에서 떨어뜨리고, 토끼풀 가족(j)·물웅덩이(W)와도 안 겹치는 자리.
- 헤드리스: 가장 깊은 곳(숨 → 당기기 예고에 질끈 → 매듭을 치면 움찔), 마을(반쪽 엔딩 기록: 오른쪽 위에 할매, 보리는 모닥불 곁).

## 사장 확인
- 가장 깊은 곳에서 할매 크기(화면의 3할쯤)가 알맞은지, 당기기·움찔 표정이 예고로 읽히는지, 놓아줄 때 눈을 뜨는 순간이 엔딩으로 이어지는지. 마을에서 40칸 할매의 얼굴이 읽히는지, 보리의 새 자리가 괜찮은지.
