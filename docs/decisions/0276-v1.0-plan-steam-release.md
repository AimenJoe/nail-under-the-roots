## 무엇이 이미 있나
- PC 셋(Windows zip·macOS 겸용 `.app`·Linux tar.gz)을 CI가 만든다(`build-desktop.yml`, 0240). 실행 파일 옆 `assets`를 찾아서 Steam으로 켜도 그림·소리를 찾는다(`main.rs assets_dir`).
- 저장 자리는 OS마다 한 곳(`profile::data_dir`: `%APPDATA%\nail`·`~/Library/Application Support/nail`·`~/.local/share/nail`), 슬롯 셋 + `prefs.txt`.
- 패드(gilrs)·버튼 그림이 지금 쓰는 장치를 따른다(0036) — Steam Deck의 "패드면 패드 글자만" 조건과 같다.
- 게임 안 라이선스 화면, AI 공개 원칙(0232: 무엇을 어떻게 썼는지 구체적으로).
- 저널(발자국) 목표 표(`journal.rs`)와 이야기 깃발(`profile::key`) — 업적의 조건을 새로 셀 것이 거의 없다.

## 조사(2026-11-04)
- **Rust 연동**: `steamworks` 크레이트(MIT/Apache, `steamworks-sys`가 SDK를 동적으로 읽는다). 업적은 `user_stats().achievement(id).set()` → `store_stats()`, 콜백은 매 프레임 `run_callbacks()`. [2차: docs.rs 문서]
- **SDK 재배포**: Valve SDK 계약은 `redistributable_bin`을 **우리 게임과 함께 실행 파일 꼴로만** 나눠 주게 한다 — 공개 레포에 DLL·`.so`를 커밋하지 않는다. → 구현에서 보니 `steamworks-sys`가 크레이트 안에 재배포 파일을 싣고 빌드 때 `OUT_DIR`로 복사하므로 비공개 레포에 따로 둘 것도 없다(아래 "구현"). 크레이트가 crates.io로 받는 파일은 우리가 커밋하는 것이 아니다(법률 판단은 아님). [1차: SDK Access Agreement 검색 요약]
- **업로드 파이프라인**: SteamPipe를 `steamcmd`로. 커뮤니티 액션 `game-ci/steam-deploy`(도커 — Windows 러너에서 안 됨) 또는 `steamcmd`를 직접. 인증은 **업로드 전용 빌더 계정**(앱 메타데이터 편집·변경 게시 권한만) + 한 번 만든 `config.vdf`를 시크릿으로(가끔 만료 → 다시 로그인). 기본(default) 브랜치로 바로 올리지 말고 `beta` 같은 브랜치로 올린 뒤 사장이 파트너 사이트에서 기본으로 옮긴다. [2차: 액션 README]
- **Steam 클라우드**: Auto-Cloud(코드 없음, 파트너 사이트에서 OS별 저장 경로를 적는다) vs Remote Storage API. 파일이 작고 적으면 Auto-Cloud로 충분 — 우리는 `profile` 몇 KB + `prefs.txt`. [1차: Steamworks Cloud 문서 검색 요약]
- **Steam Deck 검증**: 패드 글자만(키보드 글자 숨김), 가장 작은 글자 1280×800에서 9px 이상(12px 권장), 1280×800 또는 1280×720, 글 입력은 패드로. 글자 크기가 가장 흔한 탈락 이유. 우리 화면은 320×180 × 4 = 1280×720(위아래 40px 띠)이고 글꼴 11px × 4 = 44px라 넉넉하다. [1차: Steamworks Deck 호환 문서 검색 요약 + 2차]
- **업적 수**: 비슷한 로그라이트 10~130개(Into the Pit 10, Neon Abyss 35, Forgotten Mines 50). 갈아 넣는 반복보다 이야기·발견에 붙인 것이 낫다는 쪽(Hades 사례), 이야기 업적은 숨김(스포일러). 완료율 자료는 못 찾음. [2차]

## 구현 — S1·S2 뼈대(2026-11-04, `release/v1.0`)
- **S1**: Cargo 기능 `steam = ["dep:steamworks"]`, `steamworks` 0.13은 PC 대상에만(`cfg(not(any(wasm32, android, ios)))`). `src/steam.rs` `Steam`: `start`(Steam 연결 — 실패하면 콘솔 한 줄 + 연결 없이), `tick`(매 프레임 콜백, 첫 프레임에 옛 기록 따라잡기), `sync`(기록이 바뀐 뒤 새로 이룬 업적만 `set` + `store_stats` 한 번). 기능이 없으면 모두 빈 손(웹·Android·iOS·직접 받은 PC 판은 그대로). 앱은 `App::frame` 첫 줄에서 `tick`, `save_profile` 끝에서 `sync`.
- 앱 번호는 넣지 않았다 — Steam으로 켜면 Steam이 알려 주고, 개발 중에는 실행 파일 옆 `steam_appid.txt`(레포 밖).
- `steamworks-sys`는 크레이트 안에 OS별 재배포 파일(`redistributable_bin`)을 싣고 빌드 때 `OUT_DIR`로 복사한다 — 레포에 SDK 파일을 넣지 않아도 된다. 묶음(S4)은 그 파일을 실행 파일 옆에 둔다.
- **S2**: `src/achievements.rs` 표 서른(이야기 16 — 엔딩 뒤 것 9개는 숨김, 싸움 6, 탐험 3, 이웃 3, 마을 2). 조건·이름·설명은 저널 목표(`journal::goal`)에서 빌린다 → 새 번역 없음, 저널과 업적이 어긋나지 않는다. API 이름은 대문자·밑줄, 한 번 올리면 바꾸지 않는다. 시험 셋(표 ↔ 저널, 한 번만 열림, 엔딩 뒤 숨김).
- **등록표** `docs/steam/achievements.md`(열한 언어 이름·설명 + 숨김 표시): `cargo test write_steam_achievement_sheet -- --ignored`가 만든다. 앱이 생기면 사장이 파트너 사이트 "통계 및 업적"에 옮긴다(아이콘 64px 열림·잠김 둘씩은 다음 일).
- 업적 아이콘(2026-11-04): `tools/steam/achievement_icons.py` → `docs/steam/icons/<API>_ACHIEVED.png`·`<API>_UNACHIEVED.png`(64점 그림을 4배로 = 256×256, 서른 쌍 + 한눈에 보기 `sheet.png`). 게임에 이미 있는 우리 그림만 — 컷씬 일러스트(2배로 저장돼 128을 잘라 반으로 = 점 그대로)·초상화(64를 잘라 그대로)·스프라이트(정수 배), 타일 팩 그림은 쓰지 않는다. 테두리는 발자국 갈래 색, 잠김은 흑백·어둡게·회색 테. 시험 `every_achievement_has_both_icons`.
- 제3자 라이선스: `tools/licenses.py`가 `cargo metadata`를 기능 없이 불러 선택 의존성(steamworks)을 빠뜨렸다 → `--all-features`로 고쳐 `assets/THIRD_PARTY_LICENSES.txt`에 `steamworks`·`steamworks-sys`(MIT/Apache)가 들어갔다. Valve SDK 파일 자체는 SDK 계약을 따른다(고지 의무 없음, 재배포는 게임과 함께만).

### 진행할 것(순서)
1. **사람: 본인 확인 → 앱 만들기** → 앱 번호·데포 번호 셋(Windows·macOS·Linux). 결제 뒤 출시까지 30일 대기가 이미 돌고 있다(KB 판매 규칙 노트).
2. **S1 실기**: `steam_appid.txt`(레포 밖)로 개발판을 켜 연결·업적 하나 열기·Steam 오버레이(Shift+Tab)가 macroquad 창 위에 뜨는지. 오버레이가 안 뜨면 OpenGL 후킹 문제라 기록해 둔다.
3. **S2 등록**: 파트너 사이트 "통계 및 업적"에 서른(API 이름·숨김·아이콘 두 장·열한 언어) → 게시 → 실기에서 하나씩 열리는지.
4. **S4 `steam-deploy.yml`**: 릴리스 때 PC 셋을 `--features steam`으로 다시 빌드 → OS마다 데포 폴더(실행 파일 + 재배포 파일 + `assets`) → `steamcmd`로 `beta` 브랜치. 확인할 것: 리눅스 실행 파일이 옆의 `libsteam_api.so`를 찾는지(`rpath $ORIGIN` 또는 실행 스크립트), macOS `.app`의 `Contents/MacOS`에 dylib, Windows `steam_api64.dll`. 시크릿 셋(빌더 계정 이름·`config.vdf`·앱/데포 번호).
5. **S3 Auto-Cloud**: 파트너 사이트에 OS별 기록 폴더(`slot*`·`prefs.txt`) 루트와 패턴, 사용자당 용량·파일 수 → 두 기기에서 이어하기. Steam 원문(Cloud 문서)은 **저장 경로가 Steam 사용자마다 갈리게** 하라고 한다 — 지금 `profile::data_dir`는 OS 사용자 폴더 하나라, 한 PC의 두 Steam 계정이 같은 슬롯을 쓴다. Steam 판만 계정 번호 하위 폴더(`nail/<accountID>/`, 처음 켤 때 옛 폴더에서 옮기기)를 둘지 정한다(작은 코드, 권장). 루트는 Cross-Platform + OS별 Root Override.
6. **S5 Steam Deck**: 1280×800 띠·글자 크기(지금 44px로 넉넉)·패드만으로 처음부터 끝까지·잠자기/깨기. 리눅스 판을 기본으로(Proton 아님). Deck이 없으면 Valve 검증 요청.
7. **S6 상점 페이지**: 캡슐 그림(크기별), 스크린숏 5장 이상(`tools/site/shots.js`), 트레일러(`tools/site/clip.js` 가짜 시계 클립), 설명 한·영 + 열한 언어, AI 공개 문구(0232 원칙: 무엇을·어떻게), 나이 등급 설문, 가격 → **Coming Soon을 2주 이상** 열어 두고(검토 요청은 공개 7영업일 전) 출시.
8. **출시 전 손질**: 버그 고치기, 쌓인 "실기로 볼 것"(v0.6.22~v0.9), 열한 언어 넘침 검사, 번역 검수(원어민 없음 — 0232 사람 몫).

### 고려할 것(사장이 정할 것 포함)
- **무료판과 Steam판이 함께 간다**(사장 답 둘째 표): 웹·APK는 전판 그대로, Steam은 $0.99 "응원값". 이 모양의 앞선 예는 Mindustry(오픈소스, itch·GitHub 무료, Steam 유료 — 사는 까닭으로 업적·클라우드·자동 업데이트·개발자 응원이 꼽힌다) [2차: GamingOnLinux·itch 댓글]. 그러니 Steam판이 주는 것은 **업적·클라우드·자동 업데이트·Deck** — 상점 글은 "응원"과 이 넷을 정직하게.
- **Steam 안에서는 Steam판만 알린다**: Steamworks FAQ 인용 "Steam으로 내는 게임과 Steam의 소통에서는 Steam판과 Steam에서 받을 수 있음만 알린다", 상점 설명 글에는 바깥 링크를 못 단다(2024-09, 공식 사이트는 상점 편집기의 링크 칸으로) [2차: PC Gamer·GamesRadar 보도]. → 상점 글·Steam 소식에 "웹에서 무료" 문구·링크를 쓰지 않는다. 게임 안에 바깥 링크는 없다(2026-11-04 확인). 무료판 안내는 공식 페이지·SNS에서만(그건 허용).
- **가격 바닥 원문 확인**(Steamworks 가격 문서): 기본가는 $0.99 등급 이상, 할인으로 내려갈 수 있는 바닥은 그 50%(약 $0.49). 상점 설명 글·그림에는 바깥 링크·암시 URL 금지(링크는 기본 정보 탭의 칸으로, 원문 확인).
- **$0.99의 셈**: Valve 몫 30%를 빼면 한 장에 약 $0.69(지역 가격·세금·환불 전). Steam Direct $100은 조정 총매출 $1,000을 넘으면 돌려받는다(약 1,010장). 할인 바닥이 기본가의 절반이라 할인 행사의 여지는 거의 없다 — 출시 할인은 하지 않는 쪽이 자연스럽다.
- **세금·서류**: W-8BEN(한국 저작권 사용료 10%) — 납세자번호를 첫 정산 뒤 넣으면 그동안 뗀 30%는 못 돌려받는다. 은행 계좌.
- **한국 등급분류**(2026-11-04, 원문 확인 — GCRB 수수료 안내 페이지·법제처 게임산업법[시행 2025-10-23]):
  - 법 21조①: 유통·이용 제공을 목적으로 제작·배급하는 자는 **제작·배급 전에** 위원회 또는 자체등급분류사업자에게 등급을 받는다. 면제는 대회·전시·교육·시험용·**영리 목적이 아닌 것**(4호)뿐 — 팔면 면제 밖. Steam은 자체등급분류사업자가 아니다(보도, 2026-10까지 지정 소식 없음).
  - 받는 곳: PC는 **GCRB**(게임콘텐츠등급분류위원회) — 2025-11-01부터 청불까지(보도). 온라인 신청만.
  - 수수료(GCRB 조견표, 2013-02-07~, 부가세 포함) = 플랫폼 기초가액 × 이용형태 × 장르 × 한글화. PC/온라인 기초 36만 원, "기타(오픈마켓·다운로드게임 등)"는 용량으로 10~100MB 4만 원·100~300MB 8만 원·300MB 이상 36만 원. NON 네트워크 1.0, 장르 2군(캐주얼액션·어드벤처) 2.0, 한글 1.0(제출 자료 하나라도 비한글이면 1.5). **중소기업(50인 미만·매출 50억 이하) 또는 개인 제작 오픈마켓 게임물은 50% 감면(환급).**
  - 우리 셈(어느 칸인지는 GCRB에 확인): PC 묶음은 압축 약 35MB(v0.9.0 Release) → "기타 다운로드 10~100MB"로 보면 4만 × 2.0 = **8만 원 → 감면 4만 원**, "PC/온라인"으로 보면 36만 × 2.0 = **72만 원 → 감면 36만 원**.
  - 받은 뒤: 내용을 고치면 사전 또는 24시간 안에 내용수정신고(21조⑤, 등급 판단에 영향이 없음이 명백한 경미한 것은 면제 — 버그 고치기 패치는 대개 이쪽). 상호·등급·내용정보를 표시해야 한다(33조①, PC는 포장 표면 — 다운로드판은 상점 페이지·게임 안 어디에 둘지 GCRB에 물을 것). 확률형 아이템 표시(33조②)는 **돈으로 사는 아이템만**이라(2조 11호) 우리는 해당 없음.
  - 게임제작업 등록(25조①): "게임제작업을 영위하려는 자"는 시군구에 등록, 면제는 국가·교육기관·공공기관·기기 같은 경우뿐 — **개인 면제 조항은 없다.** 팔면 등록하는 쪽이 맞아 보인다(관할 구청 확인).
  - 길: (가) 출시 전에 GCRB 등급(권장 — 한국어가 첫 언어), (나) 한국을 판매 지역에서 빼고 나중에. 무료 웹판이 판매 뒤에도 "영리 목적이 아닌 것"으로 남는지는 확인 못 함.
- **맥 공증**: 공증 없이 먼저(사장 답 3). 실기에서 Gatekeeper가 막으면 Apple $99/년 + 공증을 S4에 더한다.
- **AI 공개**: Content Survey의 Pre-Generated 칸에 그림(스프라이트 원본·초상화·일러스트·타이틀)을 구체적으로. 한 줄 문구는 망한 게임들의 모양(KB). 업적 아이콘도 그 그림을 자른 것이라 같은 공개에 든다.
- **업적 API 이름은 올린 뒤 바꾸지 않는다**: 등록 전에 이름·숨김을 사장이 한 번 훑는다. 아이콘은 PNG(파트너 사이트가 JPG·PNG 둘 다 받는다고 알려져 있으나 원문 확인 전).
- **버전 둘**: Steam 판(`--features steam`)과 직접 받는 PC 판이 같은 버전 번호. 기록 폴더도 같아서 둘을 오가도 기록이 이어진다(클라우드는 Steam 판만).
