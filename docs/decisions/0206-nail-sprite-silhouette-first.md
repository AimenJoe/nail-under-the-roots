## 무엇이 잘못됐나
- 16칸 털뭉치(0203 C3 "새 옷")는 사장 판정 "두더지 같지 않다". 한 색 실루엣 시험을 해 보니 **덩어리**(종·주먹밥)였다 — 두더지라는 말을 색(분홍 코·목도리)만 하고 있었다. 주둥이·발톱을 2px 늘려도 덩어리였다.
- 원인: 디자인을 초상화(큰 그림)에서 먼저 정하고 작게 옮겼다. 작은 크기에서는 모양만 남는다. 도트 쪽 권장 순서는 거꾸로 — **실제 크기에서 실루엣부터**, 한 색으로 칠해도 누군지 보이는지(2차: playbooks pixel-art-sprites, sprite-ai 16×16 가이드).

## 정한 것
- **크기 32칸**(몸 키 약 28px, 발바닥 줄 30). 사장이 나노바나나 원본을 28px로 줄인 판을 골랐다. 같은 점 크기라 믹셀이 아니다. 들쥐(16칸)의 두 배쯤 — 무리 속에서 주인공이 먼저 보인다(0203 값 위계).
- **실루엣 시안 1(물방울 몸)**: 짧은 주둥이 + 얼굴 바로 앞의 크고 둥근 분홍 코(처음엔 길게 뻗은 주둥이였다 → 사장 "코가 너무 길다". 캐리커처 두더지는 짧고 큰 둥근 코 — 꼬마 두더지 크르테크도 첫 편의 긴 코를 뒤에 줄였다, 2차: TV Tropes·3 Seas Europe; 긴 주둥이는 진짜 두더지 해부라 귀여움이 준다), 옆으로 편 삽 손과 크림 발톱 부채, 털 끝이 삐죽한 통통한 몸, 주황 목도리. 시안 2(둥근 몸 + 긴 주둥이)·3(낮게 기는 몸 — 아르마딜로 같다)는 버렸다. 털빛·코·목도리·성격·초상화·일러스트는 그대로.
- 참고 그림은 코드로(`tools/art/nail_silhouette.py` → `tools/art/sources/ai/sprites/ref/`): 실루엣(한 색, 16배)과 색 안내. 원뿔 주둥이는 부리·당근으로 읽힌다(KB). 두더지라는 말은 이제 **둥근 코 + 옆으로 편 큰 손**이 한다(가장 긴 것은 손).
- 그림 길: 사장이 실루엣·색 안내·초상화·첫 시트(그림 맛)를 붙여 나노바나나 시트를 받는다 → `strip_logo.py` → `tools/art/nail_ai.py`(마젠타 번짐 걷기·다수결 줄이기·기준 칸 색표 MAXCOVERAGE·같은 배율·발바닥 30·털빛) → 한 색 실루엣 시험 → 게임(`art::NAIL_CELL` 32, 아직 안 함).
- 시트는 둘로: A = 서기 2·걷기 4, B = 치기 3·들기·맞음·쓰러짐(A가 정해지면 A를 붙여서).
