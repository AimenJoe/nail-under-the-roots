# 0250. 도토 공중 던지기는 적이 없어도 겨눈 쪽으로, 장신구 나오는 곳 줄이기

- 날짜: 2026-10-29
- 상태: **구현**(v0.6.10 후보, 배포는 사장에게 묻는다)
- 사장(2026-10-29): "모으기 점프 했을 때 도토리 투척도 자동 조준 대상이 없을 경우 수동 조준 방향으로 발사되어야 함."
  "장신구 드롭 확률 및 경로가 너무 많아." "무기는 또 어떻게 얻을 수 있지?"

## 1. 도토 공중 던지기(`player/run.rs tick_jump`)
- 전(0212): 꼭대기에서 저절로 던지는 것은 닿는 거리 안에 적이 있을 때만. 적이 없으면 공격을 눌러야 던졌고, 그때도 오른쪽 스틱만 봤다
  (키보드·왼쪽 스틱으로 방향을 잡고 있어도 뛰는 쪽으로 나감).
- 지금: 꼭대기에서 **늘 한 번**. 닿는 적이 있으면 가장 가까운 적, 없으면 손으로 겨눈 쪽 — 오른쪽 스틱 → 이동 입력 → 뛰는 쪽 순서
  (평타가 방향을 고르는 순서 `attack.rs`와 같다). 꼭대기 전에 누르면 그때 같은 규칙으로.
- 안내 `h_run_d`에 "(적이 없으면 겨눈 쪽으로)", 열한 언어.

## 2. 장신구가 나오는 곳
한 런(길 셋 × 고르는 칸 셋)에서 칸을 고르게 골랐을 때의 기대값(`route.rs` 칸 확률로 계산):

| 나오는 곳 | 전 | 지금 |
|---|---|---|
| 둥지 상자(`Nest`, 칸 설명 "장신구 상자가 있다") | 확정 · ≈1.1개 | 확정 · ≈1.1개 |
| 실타래 엘리트(`Elite`, "풀어 주면 장신구") | 확정 · ≈0.7개 | 확정 · ≈0.7개 |
| 저장고 상자(`Cache`) | 확정 · ≈1.7개 | **없음** — 반딧불 한 줌(`CACHE_GLOWBUGS` 6) |
| 보통 싸움방을 비울 때 | 5% · ≈1.5개 | **없음** |
| 쉼터 가게 | 쉼터마다 하나(씨앗 12) | 그대로 |
| 합(공짜) | **≈5개** | **≈1.8개** |

끼는 칸은 둘(큰 나무에서 셋). 다섯 개 남짓 주우면 고르는 맛보다 "또 나왔네"가 됐다. 이제 장신구는 **길 지도에서 고르는 칸의 확정 보상**이라
"장신구가 필요하면 둥지·실타래로 간다"가 길 고르기의 이유가 된다(무작위 5%는 그 계획을 흐렸다). 저장고는 씨앗·반딧불·길 무기(30%) 칸.
- 개발 시나리오의 옛 던전(길 칸 없음)의 상자는 그대로 장신구.
- 시험 `cache_chest_gives_glowbugs_not_a_charm`.
