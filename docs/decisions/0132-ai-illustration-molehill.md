# 0132. 나노바나나 일러스트 `molehill`

- 날짜: 2026-10-26
- 상태: 채택. 0131에 이은 여덟째 장. 첨부: 엄마 초상화(`ref_mom`), "Aspect ratio 16:9", 보라 실 없음.

## 결정(`tools/art/sources/ai/illust/molehill.png`)
- 한 번에 채택. 아침 들판, 분홍 꽃이 핀 어린 나무, 둥근 문·창·굴뚝의 둔덕 마을, 가운데 새 흙더미, 왼쪽에서 고개를 내민 엄마. ✦는 16:9 자리.
- 흙더미가 높이 61~77%라 아래쪽이 내레이션 창에 걸리지만, 윗부분이 창 위로 보여 흙더미로 읽힌다(프롬프트의 "60%보다 낮지 않게"는 조금 어겼다).
- 엄마는 "고개만"보다 몸이 조금 더 나왔고 "멀리 작게"보다 가깝다. 장면의 뜻(멀리서 바라보다 땅속으로 돌아간다)은 읽혀 그대로 둔다.

## 확인
- 헤드리스: 개발 → "이야기 일러스트"의 마지막 세 화면("새싹" · "새싹 아래 마을 한쪽에, 작은 흙더미가 하나 생겼다." · "멀리서 그 흙더미를 바라보던 누군가가, 조용히 땅속으로 돌아갔다.")에서 흙더미 윗부분·엄마·마을이 창 위다.
