# 0215. 모모·도토 달리며 모으기에도 땅울림

- 날짜: 2026-10-28
- 상태: 채택(사장 "이 둘의 모으기도 땅파기 모으기처럼 구구구 하는 효과가 있어야 할 듯")

## 왜
- 꾹 쥐기는 이 게임에서 "모았다 떼면 터진다"(0209). Naïl의 땅파기 모으기는 손에 느낌이 있다(0158): 시작 순간 땅이 우는 소리 + 흙 고리, 모으는 동안 힘만큼 흔들림과 흙알, 더미가 들썩인다. 모모·도토의 달리기는 표시(0211)만 있고 소리·몸·화면이 조용해 "모으는 중"이 손에 오지 않았다.

## 규칙
- 멀리뛰기를 뛸 수 있게 되는 순간(`RUN_MIN` 0.2초 뒤, 표시가 밝아지는 때)부터 땅파기 모으기와 같은 말:
  - 시작: 땅울림 소리(`sfx::Id::Rumble`) + 작은 흙 고리.
  - 달리는 동안: 흔들림(땅파기를 다 모았을 때의 `RUN_RUMBLE` 0.6배), 다섯 틱마다 발밑 흙알 둘.
  - 몸이 좌우로 1px 떤다(강공격 다 모임·땅파기와 같은 떨림).
  - 뛰거나(멀리뛰기) 멈추거나(짧게 떼기·공격·맞음) 하면 소리를 끊는다 — 월드가 "뛸 수 있음"이 켜지고 꺼지는 틱을 본다(`World::run_rumble`), 어느 길로 나가든 한 곳에서.
- 거리는 늘 같으니(0211) 울림은 커지지 않고 고르게 — "지금 떼면 뛴다"는 신호.

## 시험
- `running_rumbles_once_the_jump_is_ready`: 쥐고 달려 `RUN_MIN`을 넘기면 켜지고, 떼서 뛰면 꺼진다.
