# 0021: 이웃은 진짜 동물, 적은 물든 이웃(잡몹 = 쥐) · 화폐 둘(반딧불 = 기술, 씨앗 = 상점)

- 상태: 채택 (2026-10-25, 사장 지시)

## 결정
1. **세계**: 땅속 이웃은 실제 동물(라쿤·쥐·다람쥐·청설모 …). 적은 그 이웃이 뿌리 독에 **물든 모습**이다: 붉게 빛나는 눈 + 등의 보라 뿌리. 물들지 않은 이웃(라쿤 포포)은 눈이 맑다.
2. **잡몹은 쥐가 주로**. 종류마다 행동 하나와 수치가 `src/species.rs` 표에 있다.

   | 종 | 행동 | 성격 |
   |---|---|---|
   | 들쥐 | 돌격(떨다가 직진) | 기본, 가장 흔함 |
   | 생쥐 | 돌격(짧게), 셋이 떼로 | 한 대면 쓰러짐, 빠름 |
   | 시궁쥐 | 돌격(길게·세게), 넉백 덜 받음 | 튼튼함, 많이 아픔, 깊을수록 많이 |
   | 다람쥐 | 거리 두고 도토리 던지기 | 패링으로 되돌리는 연습 상대 |
   | 청설모 | 웅크렸다 뛰어 덮치기(착지 자리 고리 표시, 둘레 피해) | 새 행동. 내려앉은 뒤가 빈틈 |

   뽑기(`species::roll`): 쥐 셋이 절반 넘게, 깊이가 깊을수록 시궁쥐·청설모가 늘어난다.
3. **도감 탭**(메뉴): 만난 이웃만 이름·그림·이야기·공격·요령. 적의 능력은 **숫자 대신 말**("한 대면 쓰러짐/약함/튼튼함/아주 튼튼함", "조금 아픔/많이 아픔", "느림/보통/빠름/아주 빠름") — 표의 수치에서 저절로 고른다(`species::words`). 플레이어 능력은 상태 탭에 숫자로.
4. **화폐**: 반딧불 = **기술 해금**용(많이 나옴, 쓰러지면 30% 잃음). 씨앗 = **상점 화폐**(드물게: 종마다 확률, 보물 상자 3~5, 보스 6. 잃지 않음). 둘 다 끌려온다. 상점·해금 화면은 아직.
5. 최대 체력 +1은 "생명의 씨앗"에서 **뿌리 심장**으로 이름을 바꾼다(씨앗이 화폐가 됐으므로). 보스가 준다.
6. 회복: 산딸기 = 체력 1, 쥬시 지렁이 = 체력 전부(0017 그대로. 들고 있으면 쓰러질 때 한 번 일어나는 것도 그대로).

## 왜
- "물든 이웃"이면 적을 쓰러뜨리는 게 구해 주는 일이 되고(컨셉의 "제정신으로 돌아온 이웃"), 그림 문법 하나(붉은 눈 + 보라 뿌리)로 적/이웃이 한눈에 갈린다.
- 쥐 한 무리를 크기·속도·떼로 나누면 그림 한 벌(쥐 몸)을 팔레트·비율로 늘려 종을 늘릴 수 있다. 1인 개발 비용이 낮다.
- 도감을 말로: 숫자는 비교·최적화를 부르고 모험의 분위기를 깬다. 말이면 "시궁쥐는 아주 튼튼하구나"로 충분하다. 플레이어 쪽은 장신구를 고르려면 숫자가 필요하다.
- 화폐 둘: 기술(성장 방향)과 물건(소모·장비)을 따로 모으면 "무엇에 쓸까"가 둘로 갈려 서로를 잠식하지 않는다. 기술 쪽을 흔하게, 상점 쪽을 드물게 둔다.

## 재검토 조건
- 반딧불·씨앗 드롭 수가 해금·상점 가격과 안 맞으면(가격이 생긴 뒤) 조정.
- 쥐가 너무 비슷해 보이면 실루엣(귀·꼬리·크기)을 더 벌린다(`tools/art/critters.py`).
