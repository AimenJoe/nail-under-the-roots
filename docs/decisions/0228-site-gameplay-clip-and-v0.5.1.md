## 클립을 만든 방법(`tools/site/clip.js`)
- 0155에서는 헤드리스 녹화(`recordVideo`, VP8)가 도트를 뭉개 영상을 넣지 않았다. 실시간 스크린숏을 이으면 칸 간격이 고르지 않다.
- Playwright `page.clock.install()`로 페이지 시계(`Date`·`requestAnimationFrame`)를 멈춘 뒤 `clock.runFor(1000/30)` + 스크린숏을 되풀이 → 30fps 고른 무손실 칸. macroquad JS 번들은 `requestAnimationFrame`으로 돌고 시간을 `Date.now`로 재서 그대로 따라온다. 키 입력(`keyboard.down/up`)은 시계와 상관없이 들어간다.
- 대본대로 누르는 손은 적을 못 봐서 자꾸 쓰러졌다 → 찍기 전용 Cargo 기능 `clip`(`Player::is_invulnerable`이 늘 참). 배포 빌드에는 넣지 않는다. 페이지 크레딧에 그렇다고 적었다.
- H.264 `crf 16`·`-tune animation`·yuv420p: 3배 확대한 도트가 원본 칸과 눈으로 구분되지 않았다(확대 비교). 12초 1.6 MB(crf 12는 2.1 MB, 20은 1.1 MB).
- 함정: 브라우저 셋을 한꺼번에 돌리면(swiftshader) 서로 느려져 칸당 4초가 넘고, 메뉴 키를 놓쳐 엉뚱한 장면이 찍혔다. 하나씩이면 480칸에 1분.
