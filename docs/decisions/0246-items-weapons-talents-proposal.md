## 1. 장신구 드롭 — 구현
- 상자를 열거나 실타래 엘리트를 풀어 주면 장신구가 **가방으로 바로 가지 않고 바닥에 떨어진다**: 위에서 떨어져 한 번 튀고,
  끈 달린 방울 모양(장신구 색)에 줍는 표시(`draw_pickup_mark`). 상자는 앞(아래)에 떨군다.
- 보통 싸움방을 비우면 `CHARM_ROOM_DROP`(5%)로 장신구가 떨어진다(한 런 싸움방 ≈ 30 → 평균 1~2개). 그 캐릭터 것만(`charm_pool`).
- 줍지 않고 장소를 떠나면 가방으로 들어간다(`sweep_pickups`) — 잃지 않는다.
- 바닥 무기(`Pickup`)와 같은 자리: `Pickup { item: Gift }`(무기·장신구).

## 2. 모모·도토 무기 — 제안(각 셋, Naïl 발톱처럼 "다르게 싸우는 것")
| 캐릭터 | 무기 | 손맛 | 얻는 곳 |
|---|---|---|---|
| 모모 | **들풀 각반**(기본, 지금 뒷발) | 톡톡 둘 + 뒷발 차기 | 처음부터 |
| 모모 | **가시덩굴 각반** | 가볍고 빠른 4연타, 마지막 타가 가시를 남긴다(밟은 적 피해 1) | 길의 상자·가게 |
| 모모 | **조약돌 덧신** | 무거운 2연타, 마지막 타가 등딱지·가시를 연다(바위 발톱처럼) | 콩이가 마을에서 만들어 준다 |
| 모모 | **꽃잎 발목끈** | 박자 창이 넓고 박자 타에 기가 두 배 | 저널 "모모와 가장 깊은 곳" |
| 도토 | **도토리**(기본) | 곧게 둘 + 부채꼴 셋 | 처음부터 |
| 도토 | **솔방울** | 가볍고 멀리, 벽에 한 번 튕긴다 | 길의 상자·가게 |
| 도토 | **호두** | 느리고 무겁다, 맞으면 쪼개져 작은 조각 셋 | 수수가 만들어 준다 |
| 도토 | **밤송이** | 떨어진 자리에 가시가 남는다(밟은 적 피해) | 저널 "도토와 가장 깊은 곳" |
- 만드는 것: 무기마다 `Moveset` 표 한 줄 + 던진 것·발 그림(코드) + 가방 아이콘 색 + 글 열한 언어 + 안내 한 줄. 그림을 새로 받을 것은 없다.

## 3. 캐릭터 장신구 — 제안(셋씩 더 → 캐릭터마다 6~8개)
- Naïl: **지렁이 굴 지도**(땅속에서 빨리 움직인다), **두더지 코털**(가까운 적 예고가 조금 일찍 보인다), **흙 묻은 장갑**(강타 모으기가 빠르다).
- 모모: **민들레 솜**(깡충 거리 +20%, 대신 최대 체력 -1), **아침 이슬**(박자 맞춘 차기에 기 두 배), **굴토끼 수염**(이어 뛰기 첫 밟기 피해 +1).
- 도토: **볼주머니**(도토리 게이지 칸 +1), **꼬리털 빗**(뒤로 뛰기 대기 -30%), **송진**(큰 도토리에 맞은 적이 잠깐 느려진다).
- 회피 대기 줄이기는 캐릭터마다 이름이 다르게(굴파기·깡충·뒤로 뛰기) — 도토에게 "굴파기"가 나오는 일이 없게.

## 4. 큰 나무 재주 늘리기 — 제안
지금 8개(캐릭터마다)는 몇 런이면 다 깨운다. 두 갈래(A·B 중 하나) 규칙은 그대로 두고:
- **자리 넷 → 여덟**: 지금 넷(회피·받아치기·특기·먹기)에 **체력**(시작 체력 +1 / 산딸기 칸 +1), **반딧불**(쓰러져도 반은 남김 / 끌어오는 거리 넓게),
  **무기**(마무리 타 피해 +1 / 박자 창 넓게), **길**(쉼터 가게 값 -20% / 샘 회복에 실뿌리 하나 풀림).
- **갈래마다 세 단계**(I → II → III): 같은 갈래를 더 깨우면 세진다(값은 단계마다 두 배쯤). 자리 8 × 갈래 2 × 단계 3 = 캐릭터마다 48칸.
- 화면: 큰 나무 창을 두 쪽(자리 1~4 / 5~8)으로, 단계는 잎 점 셋.
- 반딧불 값은 `economy_probe`로 한 런 벌이(≈240)에 맞춰 다시 잡는다 — 다 깨우는 데 30런쯤.
