# 0192. 적 예고는 은은하게 — 투명도 0.3

- 날짜: 2026-10-28
- 상태: 채택. 0190의 예고 투명도(0.45·0.06)와 0160의 X 진하기(0.85)를 바꾼다. 모양·색·채움·시점(0185~0188)은 그대로.
- 사장: "아직 공격 예고가 너무 눈에 확 띄네, 은은하게 해 놔야 하는 게 맞음. 투명도 더 늘려야겠다."

## 왜
- **예고는 알려 주는 것이지 화면의 주인공이 아니다.** 적의 몸짓(떨림·붉어짐)과 바닥의 면이 함께 "언제·어디"를 말하면 충분하고, 면이 가장 진한 색이 되면 적과 Naïl보다 먼저 눈이 간다.
- **튀는 곳은 어두운 바닥이었다.** 같은 붉은색·같은 투명도라도 바닥이 어두우면 밝기 차가 커진다. 0.45에서 흑백 밝기 대비(WCAG 식)는 굴 바닥 1.84·심층 어둠 2.08, 풀밭은 1.15였다. 풀밭에서 이미 잘 읽히던 것은 밝기가 아니라 **붉은 색조와 2px 테두리의 모양** 덕이다. 그러니 어두운 곳에서 남는 밝기 차를 덜어 내도 읽기는 풀밭 아래로 떨어지지 않는다.

## 결정
- `TELE_A` 0.45 → **0.3**(테두리 = 다 찬 채움), `TELE_BASE_A` 0.06 → **0.04**(빈 안쪽).
- 못 받아치는 원의 가운데 X(`TELE_MARK_A`) 0.85 → **0.6** — 면이 옅어졌는데 X만 진하면 X가 따로 떠 보인다.
- 안내 그림(`render/help.rs`)도 같은 상수를 쓰니 같이 옅어진다.

## 확인
- 헤드리스 비교(개발 → 꽃 핀 입구·어두운 심층·토끼풀): 0.3에서 들쥐 돌진 띠·다람쥐 던지기 띠·토끼풀 원과 X가 바닥에 깔리면서도 채움이 테두리에 닿는 순간이 보인다.
- 0.3의 흑백 대비: 굴 바닥 1.48·심층 어둠 1.57·풀밭 1.13(1형 근사 1.30·1.37·1.23). 어두운 곳은 여전히 풀밭보다 높다.
- `tools/a11y/cvd.py`(0150): 풀밭은 다섯 보기 모두 띠가 남는다. 어두운 바닥의 1·2형·흑백은 옅어진다 — 거기서도 모양(띠·X)과 적의 몸짓이 남는다.

## 사람이 볼 것
- 0.3이 "은은"한지, 여러 적이 겹친 방·심층 어둠에서 놓치지 않는지. 더 내린다면 다음 후보는 0.25(풀밭 테두리가 남는지는 아직 찍어 보지 않았다).
