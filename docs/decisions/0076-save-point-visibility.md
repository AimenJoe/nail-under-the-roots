# 0076. 저장 지점을 눈에 띄게: 더하는 빛 + 움직임

- 날짜: 2026-10-26
- 상태: 채택

## 배경
사장 피드백: "저장 포인트가 너무 눈에 띄지 않아."

그전 그림은 작은 초록 버섯 다섯 개와 옅은 초록 원(알파 0.1 안팎)이었다. 풀밭이 초록이라 **색상도 명도도 바탕과 비슷했다.** 화면에서 보니 원은 거의 보이지 않았다. 다음으로 금빛 반투명을 겹쳐 봤는데, 초록 위에 반투명 노랑을 섞으니 탁한 올리브색이 됐다. 섞기(알파 블렌딩)는 바탕을 덮을 뿐 더 밝게 만들지 못한다.

## 결정
- **빛은 더해서 그린다.** `render.rs`의 `light_material`이 셰이더는 기본 그대로 두고 섞기만 `SrcAlpha + One`로 바꾼다. 바탕이 밝아지므로 초록 풀밭에서도, 어두운 쉼터(뿌리 어둠 0.38)에서도 빛으로 보인다. 재질을 못 만들면 보통 섞기로 옅게 그린다.
- 빛은 어둠 위에 그린다(`draw_save_lights`, `draw_darkness` 다음). 빛을 내는 것이 어둠에 묻히지 않게 하려는 것이다. 버섯 자체는 지도 위 특별 칸에서 그린다(`draw_save_ring`).
- 그림:
  - 버섯 다섯 → 일곱. 둥근 갓 7px에 외곽선을 둘렀고 고리를 키웠다(11×6).
  - 버섯이 선 자리의 풀을 짙게 했다. 실제 균환처럼 보이고, 명도 대비도 생긴다.
  - 후광 세 겹이 숨쉰다.
  - 포자 다섯이 위로 떠오른다. 멈춘 바탕 사이에서는 움직임이 가장 먼저 눈에 들어온다.
  - **아직 저장하지 않은 고리**에는 빛기둥이 높이(32px) 선다. 지금 부활 지점인 고리는 기둥이 낮다(12px). "아직 안 들른 곳"이 더 크게 부른다.
- 지도(미니맵)의 초록 점은 그대로 둔다.

## 남은 것
- 실기·웹에서 눈에 띄는지, 너무 번쩍이지 않는지는 사장 판정이다(사람이 할 일).
