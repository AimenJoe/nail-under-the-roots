# 0014: 지원 언어와 "처음부터 다국어" — 구조는 지금, 번역은 물결로

- 상태: 채택 (2026-10-25). 0013(문자열 표)을 넓힌다.

## 맥락
사장 결정: 중국어·일본어는 Ark Pixel 원본으로 언어별 폰트를 만든다(추천안). 그리고 처음부터 다국어를 염두에 두고 간다.
다른 게임들(조사, 2차 출처): Steam에서는 영어 다음으로 **중국어 간체·일본어·한국어**, 그다음 **러시아어·브라질 포르투갈어·스페인어**, 그다음 독일어·프랑스어·번체·폴란드어·터키어 순을 권하는 글이 많다. 예전 표준이던 EFIGS(영·프·이·독·스) 우선은 PC에선 낡았다는 평. 진지한 인디가 노리는 세트로 러·포(브)·일·중(간/번)을 꼽는 의견도 있다. Steam이 정식 지원하는 언어는 29~30개. 번역비는 상점 페이지만이면 언어당 수백 달러, 게임 전체면 중간 규모 인디 기준 수천 달러라는 추정.

## 결정
1. **지금(0차): 한국어·영어·일본어·중국어 간체** 4개. 일본어·간체는 Ark Pixel Font 12px(OFL)에서 그 언어 표가 쓰는 글자만 뽑은 폰트(`tools/fonts/build_cjk.py` → `assets/fonts/NailCJK-*.ttf`, 각 80~100KB).
2. **1차(체험판·상점 페이지 전): 번체(대만), 러시아어, 브라질 포르투갈어, 스페인어.** 글꼴은 이미 된다(Ark에 번체 모양·키릴·라틴 확장이 있다). 번역만 추가.
3. **2차(출시 전): 독일어·프랑스어·폴란드어·터키어**(·이탈리아어).
4. **안 하는 것(지금 구조로는 못 함)**: 아랍어·히브리어(오른쪽→왼쪽), 태국어·힌디어(글자 조합 셰이핑). macroquad 글자 그리기는 셰이핑을 안 한다. 필요해지면 별도 결정.
5. **번역은 늦게, 구조는 지금**: 글이 아직 매주 바뀐다. 지금 10개 언어를 번역하면 바뀔 때마다 10배로 고친다. 그래서 0차 4개만 유지하고, 나머지는 **글 동결(스트링 프리즈) 뒤** 한꺼번에. 대신 구조가 언어를 견디는지는 지금부터 매번 확인한다:
   - **가짜 언어 Pseudo**(개발 빌드, 설정 → 언어 끝): 영어를 악센트 글자로 바꾸고 40% 늘린다. 넘치는 칸, 표를 거치지 않은 글(악센트가 없음)을 찾는다.
   - **글자 폭이 다른 언어**: 한자·가나는 12px 칸이라 한글(8px)보다 1.5배 넓다. 새 화면은 일본어로도 본다.
   - **배치 규칙**: 고정 폭 칸에는 `ui.fit()`(넘치면 …), 긴 글은 `ui::wrap()`(띄어쓰기 없는 일본어·중국어는 글자 단위 + 금칙, 너무 긴 단어는 쪼갬), 탭은 폭 안에서 여백을 줄인다. 한 줄 안내는 두 줄까지 자란다.
   - **문장 조각을 잇지 않는다**, 숫자는 자리표시자, 복수형이 필요한 문장은 피해서 쓴다(러시아어·폴란드어 대비 — "1 / 15 칸"처럼).
6. **언어 고르기**: 기기 선호 목록에서 가진 첫 언어, 없으면 영어(0013). 번체 지역(zh-TW·HK·MO, zh-Hant)은 간체로 바꾸지 않고 다음 선호 언어로 넘긴다(번체가 생기면 그쪽).
7. **번역 품질**: 지금 영어·일본어·간체는 Claude 초안. 1차 언어를 넣을 때 원어민 검수(또는 번역가)를 같이 한다.

## 왜
- 다국어 비용의 대부분은 번역이 아니라 "나중에 고치기"(하드코딩 글, 영어 길이에 맞춘 UI, 글자 없는 폰트)다. 그 셋은 지금 막았다.
- 그러나 번역 자체는 글이 굳기 전에 하면 버리는 돈이다. 그래서 물결로.
- 한중일은 폰트가 언어마다 다르다(한자 통합, KB reference/fonts/cjk-pixel-fonts.md). Ark는 언어별 모양을 갖고 있고 제작자 창작·OFL이라 상업 배포가 깨끗하다.

## 비용
- 일본어·간체 표를 고치면 `build_cjk.py`를 다시 돌려야 한다(Ark 체크아웃 필요). 빠뜨리면 `cargo test`가 실패한다.
- 폰트 파일 3개(Galmuri 450KB + 일본어 77KB + 간체 100KB)를 시작할 때 읽는다.
- Ark에 없는 글자는 문구를 바꿨다: 層(→エリア·深み), 奖·摇·纵. 앞으로도 생기면 바꾸거나 `tools/fonts/patch/`에 찍는다.

## 재검토 조건
- 체험판 일정이 잡히면 1차 언어를 시작한다. 번역가가 붙으면 표를 CSV로 내보내고 받는 도구를 만든다.
- 셰이핑이 필요한 언어 요청이 오면 텍스트 렌더링을 다시 본다.
