# 0163. 얇은 장면 채우기: 물든 것의 등장 셋, 모모의 도망, 할매의 놓아주기, 실에 잠기기

- 날짜: 2026-10-27
- 상태: 채택. 사장: "군데군데 부족한 컷씬과 특별 이벤트의 이펙트·특수효과 등을 추가해야겠어." 조사(코드 기준)에서 얇은 곳 열 가지를 추려 보였고, 사장이 **이야기 축 넷**(1·2·5·6)을 골랐다. 나머지(쉼터 모닥불·발톱 받기·저장 고리·큰 나무·저널·꿈·마을 나무 성장)는 다음에.

## 왜
0159로 모모의 등장만 장치(음악 끊김·어둠·팬·카드·울림)를 얻었고, 같은 무게의 장면들(대장·도토·콩이의 등장, 모모의 도망, 가장 깊은 곳의 끝과 잠듦)은 대화창뿐이었다. 같은 문법을 쓰면 "물든 것이 나타난다"가 한 가지 그림으로 읽힌다. 새 글은 없다(카드는 도감 이름, 잠드는 한 줄은 있던 토스트 글).

## 결정

### 1. 물든 것의 등장 셋(`cutscene::tainted_meet_steps`, `boss_intro`·`doto_meet`·`kongi_meet`)
모모의 두 번째 만남과 같은 짧은 판: 음악 끊김 → 어둠이 Naïl 둘레만(0.5초) → 빛·카메라가 상대에게(0.9초) → 보라 울림으로 일어섬(`Cue::Rise`, 흔들림) → **'???' 카드**(설명은 도감 이름: 들쥐 대장·물든 청설모·물든 아르마딜로) → 말 두 줄(그대로) → 빛·카메라 복귀, 보스 곡. 자리는 대장은 공터의 적(`Kind::Chief`), 도토·콩이는 `adv.boss_last`. 배우는 안 보이고 월드의 적을 그대로 그린다. 꽃잎 복선은 모모만.

### 2. 모모의 도망(`momo_flee`)
말한 뒤 시든 꽃잎이 흩날리며(흔들림) 뛰어가고, 굴 자리에서 **파고들어 사라진다**(`Cue::Vanish`: 파는 소리 + 흙 튐 + 어두운 먼지 + 실 몇 올). 그 뒤 Naïl의 말.

### 3. 할매의 놓아주기(`World::deep_release_fx`, `DEEP_DONE_DELAY` 1.4 → 3.4초)
셋 다 끊긴 뒤 엔딩까지: 0.4초 할매의 남은 실이 풀리고(흰 고리·실 소리), 1.0초 **흰 꽃잎**, 1.6초 더 큰 풀림, 2.3초 반짝임과 꽃잎. 그림(`draw_deep`): 빛이 커지고(`LightSrc` 반지름 96 → 186) **눈을 뜬다**(1초쯤부터 둥근 동공). "놓아준다"가 보이게.

### 4. 실에 잠기기(`cutscene::deep_sleep`, `AfterCut::Respawn`)
세 번 감기면 토스트 + 페이드 대신 장면: 음악 끊김 → 보라 어둠이 Naïl 둘레 46px로(0.9초) → **실이 휘감는다**(`Cue::Wrap`: 조여 오는 보라 고리 셋·어두운 먼지·실, 땅 울림) → 어둠이 14px까지 닫힘(1.1초) → 한 줄(`deep_sleep`, 내레이션) → 검게. 끝나면 앱이 되살아나기 전환(`AfterCut::Respawn`), 되살아날 때 어둠·침묵·카드를 걷는다(`respawn_at_save`).

## 확인
- `cargo test` `tainted_intros_are_staged_like_momo`(셋 다 Hush → 카드 → Rise → Hush 해제, 말 두 줄 그대로; 잠드는 장면은 어둠 1.0·울림; 도망은 Vanish), `deep_knots_cut_and_three_wraps_put_you_to_sleep`(놓아주기 소리·꽃잎이 엔딩 전에). 142개.
- 헤드리스 Chromium: 대장(공터)·도토의 등장(어둠 → 팬 → 카드 → 말 → 보스 바), 잠드는 장면(어둠이 닫힘 → 한 줄 → 쉼터에서 깸).
- 사람이 볼 것: 등장 연출이 세 보스에 모두 어울리는지(대장은 대낮 공터라 어둠이 더 도드라진다), 놓아주기 3.4초가 길지 않은지, 눈 뜬 할매 얼굴, 잠드는 장면 뒤 되살아나기 토스트("반딧불을 조금 잃었다")가 거슬리지 않는지.
