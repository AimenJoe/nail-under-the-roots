# 0265 — 이벤트 저장, 이웃 말은 캐릭터마다(표 하나), 선물은 본인 것, 회피 이름

- 날짜: 2026-11-02
- 상태: 채택(사장 2026-11-02, 0264 보고에 대한 답). 0264의 5초 주기 저장을 대신한다.
- 사장: "5초 주기로 저장하는건 좀 그렇지 않나? 어떤 이벤트를 기준으로" → "저장방식은 니가 정한 이벤트에 거는것으로", "대사는 캐릭터별로 쓰자. 만약에 어렵다면 리팩토링하는 방향도 검토", "아이템은 본인에게 주는것으로", "실의꿈은 별 상관 없어", "회피는 각 캐릭터의 회피 기술 이름이 되도록", "모모 두번째 조우는 그냥 놔둬도 말이 될듯".

## 1. 저장은 이벤트에(주기 저장 걷음)
왜 주기가 아니라 이벤트인가:
- 주기 저장은 싸움 한가운데도 이어하기에 적는다(체력·가방). 지는 싸움에서 끄고 이어서 굴을 다시 하는 길이 생긴다 — 체크포인트는 안전한 경계에서(KB 저장 노트의 원칙).
- "언제 저장되나"를 말로 할 수 있다: 방을 비우면·다음 방으로 넘어서면·물건을 받으면·멈추면.
- 0264의 "같은 글이면 안 쓰기"(`profile::put`)는 그대로라, 이벤트가 잦아도 바뀐 것이 없으면 쓰지 않는다.

| 이벤트 | 어디서 | 적는 것 |
|---|---|---|
| 싸움방을 비움(문이 열림) | `AdvEvent::RoomCleared` | 기록 + 이어하기 |
| 문이 열린 채 다른 방으로 넘어섬 | `AdvEvent::RoomEntered`(잠긴 싸움 중엔 안 냄) | 기록 + 이어하기(지난 방에서 주운 것까지) |
| 상자를 엶 | `Interact::Chest` | 기록 + 이어하기 |
| 물건(무기·장신구)을 받음 | `App::take_gifts` | 기록 + 이어하기 |
| 일시정지(지도 포함)를 엶 | `App::open_pause` | 기록, 이어하기는 문이 잠긴 싸움 중이 아닐 때 |
| 그대로인 것 | 보스·이야기 사건·쉼터 도착·굴 출구·쓰러짐/깨어남·타이틀로·다시 하기·PC 창 닫기 | 0259·0264 |

한 곳 `App::save_progress(run)`이 기록(`save_profile`)과, `run`이면 이어하기(`checkpoint_run`, 장소를 바꾸는 중이면 건너뜀)를 적는다. `AUTOSAVE_EVERY`·`App::autosave`는 없앴다.
- 시험: `room_boundaries_are_save_points`(싸움이 시작될 때는 아무것도, 비우면 `RoomCleared`, 넘어서면 `RoomEntered` 한 번, 머물면 더 없음).
- 헤드리스 웹(빈 기록 → 오프닝 → 튜토리얼): 허수아비를 친 뒤 12초 가만히 = localStorage 쓰기 0회, 일시정지를 연 순간 12ms 뒤 한 번(77 → 119바이트).
- 남는 것: 마지막 이벤트 뒤 앱이 죽으면 그 사이(방 하나의 싸움 정도)를 잃는다.

## 2. 이웃의 말은 캐릭터마다 — 표 하나로(리팩터링)
- 전: 말 걸기의 늘 하는 말·선물이 `app/stage.rs`에 이웃마다 배열·가드로 흩어져(보리·수수·콩이·토끼풀·도토·모모·Naïl 일곱 갈래), Naïl의 요령이 모모·도토에게도 나왔다.
- 지금: `story.rs`의 표 둘. 앱은 "선물이 있으면 선물, 아니면 늘 하는 말" 두 갈래만 본다.
  - `CHATTER`: (이웃, 듣는 캐릭터 또는 누구에게나, 셋, 표정). 요령·겪은 일을 말하는 이웃은 캐릭터마다 한 줄씩(수수·콩이·마을의 Naïl).
  - `GIFTS`: (이웃, 받는 캐릭터, 무기, 한마디). 아직 없을 때 한 번.
  - `story::speaker(who)`: 이웃 → 화자.
- 시험 `neighbor_talk_is_written_for_each_character`: 표에 있는 이웃은 캐릭터 셋 모두에게 줄이 있고(마을의 Naïl은 다른 캐릭터에게만), 모모·도토가 듣는 줄에 Naïl의 동사·무기 말(발톱·굴로·솟구·두더지·나일이)이 없고, 선물은 받는 캐릭터의 무기 종류.

새 줄(한국어, 열한 언어 직접 씀):
| 이웃 | 모모에게 | 도토에게 |
|---|---|---|
| 수수(무기 바꾸기) | 뒷발에 신는 걸 바꾸면 차는 맛이 달라져. 가시덩굴 각반은 따끔하고, 조약돌 덧신은 묵직하지. | 던지는 걸 바꾸면 손맛이 달라져. 솔방울은 가볍게 멀리 가고, 호두는 쩍 갈라지지. |
| 콩이(등딱지) | 등딱지는 위만 단단해. 그래도 위에서 쿵 내려앉으면 버틸 수가 없어. 그건 반칙이야, 헤헤. | 등딱지는 위만 단단해. 배는 말랑하지. 그러니까 밑에 묻어 둔 도토리가 펑 터지는 건 반칙이야, 헤헤. |
| 콩이(무거운 무기) | 조약돌 덧신은 무거워. 차는 동안엔 깡충 못 뛰니까, 다 차고 나서 뛰어. | 호두는 무거워. 던지는 동안엔 뒤로 못 뛰니까, 다 던지고 나서 물러나. |

근거: 모모 이어 뛰기 착지(`StrikeKind::Stomp`)·도토 묻은 도토리(`Burst`)는 등딱지를 연다(`Enemy::receive`), 조약돌 덧신·호두의 회피 캔슬은 마지막 타 뒤(0.24·0.18초).

## 3. 선물은 본인에게
- 콩이 귀환(`cutscene::kongi_returns`): 이긴 캐릭터 본인의 무거운 무기 — Naïl 바위 발톱, 모모 조약돌 덧신(원래 콩이가 만든 덧신), 도토 호두. 한마디도 캐릭터마다(`kongi_b4_momo`·`kongi_b4_doto`).
- 보스 표의 덤 깃발(`Boss::extra_flags` = 바위 발톱)은 없앴다: 받는 순간 무기 깃발이 선다(`take_gifts`). 이미 바위 발톱을 가진 옛 기록은 그대로.
- 다른 캐릭터가 콩이를 깨웠으면 마을에서 받는다: Naïl ← 콩이 바위 발톱(새 줄 `kongi_stone`), 모모 ← 콩이 조약돌 덧신(그대로), 도토 ← 수수 호두(그대로).
- 시험 `kongi_gives_the_winner_their_own_weapon`.

## 4. 회피 이름은 캐릭터마다
- 터치 안내(`input::prompt(Act::Dodge)`)와 조작 설정 줄이 "굴파기(회피)" 하나였다 → 캐릭터 표 `act_dodge`(굴파기·깡충·뒤로 뛰기 + "(회피)"). 입력은 캐릭터를 모르니 앱이 런을 시작할 때 `input::set_dodge_name`으로 넣는다.
- 조작 설정 이름 칸(102px)에 열한 언어 모두 들어가는 것을 글꼴로 쟀다(가장 긴 일본어 96px).

## 5. 물웅덩이
