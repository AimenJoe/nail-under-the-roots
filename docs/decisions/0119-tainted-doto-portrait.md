# 0119. 물든 도토 대화 초상화(나노바나나)

- 날짜: 2026-10-26
- 상태: 채택. 0118(도토)에 이은 열째.

## 결정(`tools/art/ai_portraits.py` `doto_tainted`, `tools/art/sources/ai/doto_tainted_glare.png`)
- 칸 30(노려봄 하나). 도토 보통 표정을 고쳐 그려 틀·잘린 줄(942, `CUT_AT`)이 같다. 높이 96%.
- 프롬프트에 앞서 배운 것을 넣었다: 실은 선만큼 굵게, 꼬리를 타고 귀 둘레·목에(0112), 눈은 "vivid, saturated amber like warm honey"(색을 박는다, 0114).
- 털이 보라 기운이라 눈 팔레트를 떼지 않는다(`NO_EYE_SPLIT`, 0114와 같은 까닭).
- **물든 눈 밝히기를 색마다**(`_glow_eyes(img, boxes, hues, out_hue)`): 들쥐 대장의 빨강 밝히기를 넓혔다. 물든 도토의 호박색 눈이 88px에서 흐린 주황 갈색으로 읽혀, 눈 상자(`DOTO_TAINTED_EYES`) 안의 호박색(색상 0.05~0.14)을 꿀빛으로 밝힌다. 들쥐 대장 칸은 그대로다.
