# 0251. Naïl의 길 무기(딱정벌레 발톱), 상자는 반딧불 90% · 물건 10%

- 날짜: 2026-10-29
- 상태: **구현**(v0.6.10)
- 사장(2026-10-29): "나일도 길에서 하나 찾도록 만들자. 상자에서 반딧불 나올 확률 90%, 10%가 무기 또는 장신구 나올 확률로 하자.
  단 해당 무기가 있으면 장신구. 어때? Reasonable한가? 변경하고 변경사항들 배포해줘."

## 1. 딱정벌레 발톱(`WEAPONS[12]`, `moveset::BEETLE`, 키 `weapon.beetle`)
- 모모(가시덩굴 각반)·도토(솔방울)처럼 Naïl도 길에서 찾는 무기 하나(`found_on_road`). 번호는 표 끝 — 쉼터 이어하기 저장이 가방을 번호로 적는다.
- 성격: Naïl 발톱 셋(새싹 = 빠름, 두더지 = 기본, 바위 = 무거움) 가운데 **등딱지를 여는 것**이 없었다(콩이·고슴도치의 말린 등에 튕긴다).
  그래서 **모든 타가 `crush`**(조약돌 덧신은 마지막 차기만) — 대신 기본 발톱보다 스윙 ×1.25, 마무리 넉백 330 → 260.
- 그림은 종류(발톱) 아이콘에 청록 껍질색. 글 열한 언어(일본어는 픽셀 글꼴에 甲·撃이 없어 "コガネムシのツメ"·一打).
- 안내 `h_gear_d`의 "나일 발톱 셋" → 넷. 같은 글에서 이름이 표와 달랐던 것(간체·번체 奈尔/奈爾 → 拿日, 러시아어 Наиль → Naïl)도 맞췄다.

## 2. 상자
- 상자를 열면(씨앗 2~3은 그대로) **90% 반딧불 한 줌**(`CHEST_GLOWBUGS` 6), **10% 물건**(`CHEST_GEAR`):
  그 캐릭터의 길 무기가 아직 없으면 그것, 있으면 아직 없는 장신구, 그것도 다 있으면 반딧불.
- 둥지·저장고 상자가 같은 규칙. 둥지 칸 설명 "장신구 상자가 있다" → "끝에 상자가 있다"(열한 언어).
- 0250에서 없앤 싸움방 장신구 드롭은 그대로 없음. 장신구가 확정으로 나오는 곳은 실타래 엘리트 하나, 사는 곳은 쉼터 가게.
- 시험 `chest_gives_glowbugs_or_the_road_weapon_then_a_charm`(넷 다), `each_character_finds_one_weapon_on_the_road`.

## 3. 판단(사장 "Reasonable한가?")
한 런 상자 ≈ 2.8개(길 지도 칸 확률로 계산, 고르게 골랐을 때).

| | 0250 | 0251 |
|---|---|---|
| 공짜 장신구 / 런 | ≈1.8(둥지 확정 1.1 + 실타래 0.7) | ≈0.9(실타래 0.7 + 상자 10% 중 무기 뒤) |
| 길 무기를 상자에서 | 30% × 상자 → 대개 한 런 | 10% × 2.8 ≈ 0.28 → 평균 3~4런 |
| 반딧불 / 런 | ≈242 | ≈257(+15, +6%) |

- 괜찮은 점: 상자가 "대개 반딧불, 가끔 대박"이 되어 연 순간의 기대가 생긴다. 반딧불 증가는 경제(0236·0244)를 흔들 만큼 아니다.
- 볼 점: ① 길 무기를 상자로만 기다리면 3~4런 — 쉼터 가게가 길 무기를 늘 팔고(씨앗 18) 있으니 "사거나 운"이라 막히지는 않는다.
  ② 장신구가 한 런 1개 안팎 + 가게라, 끼는 칸 둘을 다 채우려면 가게를 써야 한다. 적다고 느끼면 실타래를 둘로, 또는 `CHEST_GEAR`만 0.15~0.2로.
  ③ 둥지 칸이 "더 센 싸움 + 씨앗" 말고 고를 이유가 약해졌다 — 플레이 뒤 둥지에 다른 보상을 줄지 본다.
