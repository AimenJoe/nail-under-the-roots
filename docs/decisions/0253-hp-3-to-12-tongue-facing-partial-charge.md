# 0253. 체력 시작 3·최대 12, 두꺼비 혀가 뻗는 동안, 바라보는 쪽 표시, 덜 모은 강타 = 평타

- 날짜: 2026-10-29
- 상태: **구현**(개발판, 배포는 사장에게 묻는다)
- 사장(2026-10-29): "최대 12개까지만 얻을 수 있도록 재주를 조절하자. 시작 시에는 3개로 시작하도록 하고." "두꺼비 혀가 보이지도 않고 맞음.
  늘어나는 중간 프레임이 필요함." "UI, 어느 방향을 바라보고 있는지 표시가 있어야 그 방향으로 패링/원거리 조준 가능할 듯."
  "강공격 모으기 중 다 모으지 못하고 놓을 때는 일반 공격이 나가야 함." (앞서 "최대 체력 16개일 때 화면은 잘 나오나?")

## 1. 체력
- 시작 체력 `PLAYER_HP` 5 → **3**. 최대 체력 상한 `MAX_HP_CAP` = **12**(`Stats::compute`가 재주·뿌리 심장·장신구를 다 더한 뒤 묶는다).
  - 재주(뿌리 갈래 체력 덤 셋) +3 → 런 시작 6, 길 끝 보스 뿌리 심장 셋·가게 → 9~11, 장신구까지 12에서 멈춘다(전엔 16까지).
- 산딸기 `BERRY_CHANCE_MISSING_ALL` = 5% × 시작 체력 → 15%(시작 체력에서 한 칸 5% 그대로, 0252).
- HUD: 하트 12칸 + 반딧불·씨앗이 x≈165까지 와 가운데 보스 이름표(x 130~190)에 닿으므로, 닿을 때만 이름표·막대(할매 매듭 줄도)를 한 줄(14px) 아래로(`top_center_drop`).
- 볼 것: 개발 잡몹 방(심층 다섯 종)에서 3칸은 1초 안에 쓰러졌다. 첫 런·튜토리얼 난이도를 사장이 플레이로 확인.

## 2. 두꺼비 혀(`enemy::tongue_out`)
- 전: 혀를 내민 첫 틱에 다 뻗은 길이로 맞히고 그 뒤부터 말려 들어가는 그림 — 맞는 순간이 안 보였다.
- 지금: `TOAD_EXTEND_TIME` 0.12초 동안 혀끝이 자라고(감속), 맞는 판정도 **지금 뻗은 길이까지**. 다 뻗은 뒤 `TOAD_LASH_TIME` 동안 말려 들어갈 때는 안 맞는다.
  그림과 판정이 같은 함수. 시험 `toad_tongue_hits_only_once_it_has_grown_to_the_player`.

## 3. 바라보는 쪽(`render::actors::draw_facing_mark`)
- 발밑 빛 고리 가장자리에 금빛 삼각형(3/4 시점이라 눌러 그림). 싸우는 곳에서만(마을·쉼터는 고리만).
- 받아치기(`parry_dir`)·도토 던지기·모모 멀리뛰기·평타가 모두 `Player::facing` 쪽이다. 안내 "받아치기"에 한 문장(열한 언어).

## 4. 덜 모은 강타
- 전: 모으기 중 다 모으기 전에 떼면 아무것도 안 나갔다(평타는 누를 때 이미 나감).
- 지금: 모으기에 들어선 뒤 `HEAVY_TAP_GRACE`(0.2초)보다 오래 쥐었다가 떼면 **다음 평타**(마지막 타 뒤면 1타).
  그보다 짧으면 그냥 누른 것 — 보통 누름도 활성 구간 뒤까지 쥐고 있어 모으기에 잠깐 들어서고, 박자에 누르는 손은 0.25초까지 쥔다
  (0.12로 했더니 박자 시험 `every_weapon_chains_every_hit_on_the_beat_whatever_the_tap_length`에서 박자 이음이 엇박 평타로 바뀌었다).
- 시험 `releasing_a_partial_charge_swings_the_next_hit`.
