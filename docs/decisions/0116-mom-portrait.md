# 0116. 엄마 두더지 대화 초상화(나노바나나)

- 날짜: 2026-10-26
- 상태: 채택. 0115(누룩 할매)에 이은 여덟째.

## 결정(`tools/art/ai_portraits.py` `mom`, `tools/art/sources/ai/mom_gentle.png`)
- 칸 17(다정하게 감은 눈 하나). 원본이 칸을 채워 틀은 그대로.
- 시트를 건너뛰고 참고 그림(`ref_mom.png`) + **Naïl 초상화**를 함께 넣었다. 다른 캐릭터 초상화를 넣으면 생김새가 따라가는 버릇(0109)을 이번에는 일부러 썼다: 같은 종·같은 그림체가 목표였다.
- 첫 그림은 목도리만 없는 Naïl이었다(털 색·뾰족한 털 윤곽·크기가 같다). 0049 사양("더 크고 털이 한 단 짙다")대로 "한 단 짙은 코코아 갈색, 납작하고 매끈한 털, 머리 위에만 짧은 털"로 고쳐 그렸다. 오프닝 일러스트(`mother_burrow`)의 매끈한 엄마와도 맞는다.

## 남은 것
- 앞발 발톱이 깍지 낀 크림색 매듭처럼 보인다(고쳐 그리기에서 "not interlocked"를 적었지만 그대로였다). 칸에서 앞발 사이 노란 덩어리로 읽힌다. 사장이 고친 그림을 주면 원본만 바꾼다.

## 확인
- 색까지 비교: 커밋된 시트와 다른 칸은 17뿐이다.
- 헤드리스: 개발 → "오프닝 컷씬"의 엄마 대사에 새 그림이 나오고, 바로 다음 Naïl 대사와 확실히 갈린다.
