# 0077. 직접 그린 소품 중 팩에 맞는 것을 Sunnyside로 갈아 끼운다

- 날짜: 2026-10-26
- 상태: 채택. 0065·0066에 이어서.
- 사장: "우리가 만들어서 쓰고 있던 오브젝트 중에 갈아 낄 만한 녀석은 바꿔 줘."

## 어떻게 골랐나
팩의 그림 207장을 전부 보고(0064: 보고 고르기만), 코드로 그리던 것과 하나씩 맞대어 봤다. 모양과 쓰임이 같을 때만 바꿨다. 이야기에 묶인 것(뿌리 창살·뿌리 길 구멍·실의 꿈·이웃)과 팩에 없는 것은 그대로 둔다.

## 바꾼 것(자리표는 `src/sunny.rs`)
| 우리 것 | 팩 그림 | 덧붙인 것 |
|---|---|---|
| 가게 가판(쉼터·마을) | 장터 가판(흰 차양 + 판대 + 붉은 천) | 판대 위 산딸기·씨앗 자루는 직접 그린다. 무엇을 파는지 보이게 |
| 모모의 빈 자리(그루터기) | 그루터기(밝은 것) | 꽃잎 셋 규칙은 그대로(`seat_petals`, 0046) |
| 마을 꾸미기 "통나무 의자" | 나무 긴 의자 | 그림자 |
| 마을 꾸미기 "들꽃 화분" | 흰 들꽃 화분 + 들꽃 한 포기 | 그림자 |
| HUD 체력 네모 | 하트. 빈 칸은 같은 하트를 어둡게 | 간격 7 → 10px |
| HUD 씨앗 아이콘(3×4px) | 새싹 아이콘 | |

- 팩이 없으면(공개 CI) 모두 예전 그림이다. 새 그림은 모두 이미 쓰는 16px 타일셋 안에 있어서 비공개 에셋 레포에 넣을 파일은 없다.
- 반딧불 HUD 아이콘은 팩에 맞는 것이 없다. 가운데 검은 줄 때문에 "="로 읽히던 것만 고쳤다(빛 + 몸 + 머리 한 점).

## 안 바꾼 것과 이유
- **보물 상자**: 팩에 상자가 없다(나무 궤짝·가구뿐).
- **반딧불 병**: 팩의 병은 우유병처럼 보인다.
- **웅덩이**: 팩 물은 물가가 붙는 바닥 타일이라 작은 웅덩이 하나로 쓰기 어렵다.
- **굴 입구·출구·뿌리 길**: 팩의 구멍은 밭에 심는 구멍이다. 굴 입구로 읽히지 않는다.
- **저장 지점 버섯**: 0076에서 막 다시 그렸다. 팩의 빨간 버섯은 "빛나는 버섯"이 아니고, 파란 버섯은 심층 장식과 겹친다.
- **잠긴 문**: 뿌리 창살은 이야기(뿌리)에 묶여 있다.
