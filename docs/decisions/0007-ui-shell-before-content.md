# 0007: 게임 틀(인트로·타이틀·설정·일시정지 메뉴의 상태/가방/저널/지도)은 내용보다 먼저 만든다

- 상태: 채택 (2026-10-25)

## 맥락
1단계 범위는 전투 프로토타입이고 CLAUDE.md는 범위 밖(에셋, 허브, 저장, 두 번째 캐릭터)을 판정 전에 만들지 말라고 한다. 그러나 메뉴·설정·일시정지 화면은 어느 단계에서나 필요하고, 판정을 받을 사람에게 "게임처럼 보이는 틀"이 있어야 피드백의 질이 오른다. 아이템·퀘스트·층 구조는 아직 데이터가 없다.

## 결정
1. 장면 상태 기계(`app.rs`): 인트로 → 타이틀 → (설정) → 게임 ⇄ 일시정지. 일시정지는 탭(메뉴·상태·가방·저널·지도).
2. 내용이 없는 탭은 **틀과 빈 상태 문구**만 둔다. 가방은 빈 15칸, 지도는 현재 방 미니맵 하나, 저널은 프로토타입 통계(처치 수·솟구침 처치·웨이브)에 묶인 튜토리얼 퀘스트 4개. 가짜 데이터를 채우지 않는다.
3. UI는 커서 없이 동작한다: 상하좌우·확인·뒤로, 탭은 Q/E·L1/R1. 터치 탭과 마우스 클릭은 보조로, 직전 프레임에 그린 요소의 사각형(`hits`)에 맞춰 같은 동작을 한다.
4. 텍스트는 한글 픽셀 폰트 Galmuri11 Condensed(OFL, `assets/LICENSES.md`)를 KS X 1001 2,350자로 추려 넣고, 실제 해상도로 찍는다(내부 해상도에서 찍으면 깨진다). 레이아웃 좌표는 320×180 단위.
5. 설정(소리·흔들림·디버그 정보)은 메모리에만 있다. 저장은 3단계(런 구조·저장)에서 넣는다.
6. 에셋 폴더가 생겼으므로 APK 메타데이터에 `assets = "assets"`, 코드는 `set_pc_assets_folder("assets")`로 플랫폼별 경로를 맞춘다.

## 왜
- 틀은 한 번 만들면 단계가 바뀌어도 그대로 쓰인다. 반면 내용(아이템, 퀘스트, 층)은 설계가 바뀌면 버려진다. 틀만 먼저, 내용은 설계가 굳은 뒤.
- 커서 없는 UI는 핸드헬드(컨트롤러 필수) 요구에서 나온다(CLAUDE.md). 터치는 그 위에 얹는 보조다.
- 폰트는 "에셋 팩" 결정과 무관한 인프라다. 한글 UI를 기본 폰트로는 찍을 수 없다.

## 비용
- 폰트 450KB가 웹 첫 로딩에 더해진다(wasm 530KB와 비슷). 필요하면 Galmuri7(8px)로 바꾸거나 글리프를 더 줄인다.
- 메뉴 코드(`app.rs`)가 전투 코드와 별도로 커진다. 모듈 경계는 지킨다: `world`는 메뉴를 모르고, `app`만 장면을 안다.

## 재검토 조건
- 2단계에서 보상 선택이 들어올 때 가방 데이터 구조를 실제 아이템에 맞춰 다시 본다.
- 3단계에서 층 구조가 생기면 지도 탭을 방 연결 그래프로 바꾼다.
