# 0168. 작은 타격의 피드백 층, 강타의 보상, 박자 덤 — 0166의 B·C + 사장의 박자 아이디어

- 날짜: 2026-10-27
- 상태: 채택. 0167(박자 콤보) 뒤 사장: "다 넣어줘. 그리고 내 아이디어도 차용해줄래?" — 0166의 B(피드백 층)·C(강타 보상)를 다 넣고, 사장의 **박자** 아이디어(0167)를 B·C에도 엮었다: 박자에 맞춘 타는 더 세게 느껴지고, 이음을 다 맞춘 콤보의 마무리는 더 멀리 밀고, 다 모인 직후에 뗀 강타는 "딱 맞춘 강타"다. ("내 아이디어"를 이렇게 읽었다 — 다른 뜻이었으면 말해 달라.)

## B. 작은 타격의 피드백 층
| | 전 | 후 |
|---|---|---|
| 히트스톱(두더지 발톱 1·2 / 3 / 강) | 3f / 8f / 10f | **5f / 9f / 13f**(`CLAW_HITSTOP`·`heavy_of`). 다른 무기도 한 단씩(새싹 3→5f, 바위 5→6f·10→11f, 독 2→4f, `BASE` 3→5f) |
| 맞은 적 | 흰 실루엣만 | 히트스톱 동안 **맞은 축으로 ±1px 진동**(넉백 300 넘으면 2px), 첫 순간 **맞은 축으로 눌림**(14×18). 렌더만(`draw_enemy`, `feel.hitstop`), 상태 없음. 사쿠라이의 "멈추는 동안 맞은 쪽을 흔든다" |
| 공격자 | 없음 | 맞히면 **전진이 멈추고**(`player.vel = 0`) **카메라 킥**(`Feel::kick`, 맞힌 쪽으로 평타 2 / 마무리 3 / 강타 4px, 지수로 돌아옴 `KICK_DECAY`). trauma²가 0으로 만드는 작은 타격을 킥이 맡는다. 흔들림 설정 배율을 따른다 |
| 소리 | impactPunch | impactPunch + 짧고 높은 **'틱'**(`sfx::Id::HitTick`, 합성) |

안 넣은 것: 피격 자세 칸(잡몹 15종의 그림이 필요) — 눌림·진동이 그 자리를 대신한다. 소리 덕킹·피치 흔들림은 아직.

## C. 강타의 보상과 모으는 느낌(`moveset::heavy_of`)
| | 전 | 후 |
|---|---|---|
| 피해 | 2(= 마무리 타) | **마지막 타 + 1, 3 이상**(두더지 3). 같은 시간의 콤보(피해 4)보다 약하면 아무도 안 쓴다(0166) |
| 경직 / 넉백 | +0.1 / ×1.15 | **+0.5 / ×1.7**(≈62px) |
| 벽 쿵(새것) | — | 강타 넉백으로 `WALL_SLAM_SPEED`(120px/s) 넘게 벽에 박히면 **피해 +1**, 튕김, 파편·고리, 멈춤 0.12·흔들림 0.5(`Enemy::slam`→`slammed`, 월드가 효과). 넉백을 키운 이유 |
| 콩이 등딱지 | 튕김 | 강타는 **자세를 깬다**(평타만 튕긴다) — "모으기 = 자세 깨기" |
| 모으는 동안 | 발톱 끝 빛만 | **올라가는 소리**(`ChargeUp`, 시작부터), 몸 1px 웅크림, 발 쪽으로 **빨려 드는 먼지**(`CHARGE_PULL_EVERY`), 다 모이면 흰 번쩍 0.03초 |
| 맞혔을 때 | 10f·2px | 13f + 피격자 진동 2px + 킥 4px + 흰 번쩍 0.04초 |

## 사장의 박자 아이디어를 B·C에
- **박자 타**(`Player::on_beat`): 멈춤 +0.02초, 흔들림 +0.05, 킥 +1px(`BEAT_*`, `KICK_BONUS`).
- **이음을 다 맞춘 콤보**(`combo_beats >= last`): 마무리 타 넉백 ×1.25(`FULL_BEAT_KNOCK`).
- **딱 맞춘 강타**(`State::Heavy{perfect}`): 다 모인 뒤 `HEAVY_PERFECT`(0.15초) 안에 떼면 피해 +1·멈춤 +0.04초·킥 +1px, 뗄 때 박자 '틱' + 큰 반짝임(`Event::HeavyPerfect`). 늦게 떼면 보통 강타.

## 확인
- `cargo test` 153개: `heavy_knockback_slams_into_the_wall_for_extra_damage`(빠르게 벽에 박히면 +1·튕김·한 번만, 평타 넉백·느린 접촉은 아님), `late_release_is_an_ordinary_heavy_strike`, `on_beat_hits_stop_longer_and_a_full_beat_combo_knocks_farther`, 강공격 테스트에 딱 맞춤 +1·피해 3 이상.
- 사람이 볼 것: 킥 2/3/4px가 어지럽지 않은지(흔들림 설정으로 끌 수 있다), 피격자 진동이 흐려 보이지 않는지, 벽 쿵이 노림수가 되는지(넉백 ×1.7이 너무 멀면 1.5), 딱 맞춤 창 0.15초, '틱'·올라가는 소리의 크기, 강타 3·딱 맞춤 4가 너무 센지(잡몹 체력 기준).
