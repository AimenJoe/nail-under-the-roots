# 0090. 솟구치기에 밀쳐내기·충격, 마무리 타를 더 묵직하게(첫 바깥 판정)

- 날짜: 2026-10-26
- 상태: 채택. v0.2.0 조건 3(0079: 바깥 판정에서 나온 것 고치기).

## 배경 — 첫 바깥 판정(본인 외 한 사람, 2026-10-26, 사장의 아들)
phase-1 판정 기준 넷에 대한 답:
1. 30초 안에 굴파기 → 솟구침 → 때리기를 스스로 한다: **동의**.
2. "어디서 튀어나올까"를 생각한다: **아니다.** "튀어나오고 나서 뭔가 임팩트가 없으니 숨는 용도로 더 쓰지 공격용으로는 잘 쓰지 않음. 밀쳐내기 등이 필요할 듯."
3. 3타가 묵직하다: **그저 그렇다.** "밀쳐내기가 들어가면 좀 다르려나, 아니면 이펙트나."
4. 5분 뒤 더 하고 싶다: **동의**.

같은 날 사장이 Android 덮어 설치 뒤 저장이 남는 것을 확인했다(0079 조건 2 끝).

## 왜 약했나(숫자로)
KB `concepts/special-move-impact.md`: 크기의 손잡이는 시간·공간·감각 셋이고, 하나만 키우면 "조금 센 평타"로 남는다.
- **공간이 작았다**: 솟구침 반지름 16px(적 몸 반지름 ~6을 더해도 적 바로 밑), 넉백 190 ÷ 마찰 9 ≈ 21px(한 칸 남짓). 둘레의 적은 아무 일도 없었다.
- **보상이 없었다**: 피해 1(평타 한 대와 같음). 숨는 것보다 나을 이유가 없다.
- 3타: 넉백 230 → 약 25px. 멈춤 0.10초. 1·2타(90 → 10px)와 차이가 작다.
- 바깥 자료(포럼·블로그, 2차)도 넉백·멈춤·흔들림·소리를 **함께** 키우고, 범위 공격은 반지름이 보이게 고리를 그리라고 한다.

## 결정(수치는 `src/tuning.rs`·`src/moveset.rs`)
### 솟구치기
| | 전 | 후 |
|---|---|---|
| 맞는 반지름 | 16 (깊은 굴 22 / 얕은 굴 12) | 22 (30 / 16) |
| 피해 | 1 | 2 (기습 보상) |
| 넉백 / 경직 | 190 / 0.45 | 340 (≈38px) / 0.6 |
| 멈춤 / 흔들림 | 0.08 / 0.35 | 0.11 / 0.5 |
| 솟구친 뒤 공격 불가 | 0.10 | 0.06 (바로 발톱으로 잇기) |
| **밀쳐내기(새것)** | — | 반지름 44 안의 안 맞은 잡몹을 피해 없이 바깥으로(260, 가까울수록 세게, 끝은 0.55배), 0.25초 멈춤. 보스는 안 밀린다 |
| 감각 | 흙 고리 하나, 흔들림 0.15 | 흰 고리(맞는 반지름) + 흙 고리(밀쳐내는 반지름), 흙덩이·먼지 늘림, 흔들림 0.25, 맞으면 낮은 "쿵"(`sfx::Id::Impact`) |

### 마무리 타(3타)
- 두더지 발톱: 넉백 230 → 330(≈37px), 경직 0.40 → 0.50, 멈춤 0.10 → 0.13, 흔들림 0.40 → 0.55.
- 다른 무기도 같은 비율로 올렸다: 새싹 4타 150 → 205, 모모 뒷발 260 → 340, 바위 2타 300 → 390(멈춤·흔들림도 조금).
- 맞으면 충격 고리 + 맞은 쪽 불똥 + 흙덩이·먼지 + "쿵"(한 번만, 여러 마리를 맞혀도).

## 확인
- 단위 테스트 `emerge_pushes_nearby_mobs_outward_without_damage`: 둘레의 잡몹은 바깥으로 밀리고 피해 없음, 가까울수록 셈, 반지름 밖·보스·이미 맞은 적은 그대로.
- 재주 테스트(깊은 굴 > 기본 > 얕은 굴)는 새 반지름으로도 통과.
- **확인 못 함: 손맛.** 헤드리스로는 고리가 보이는 것까지. 판정 2·3을 같은 사람에게 다시 묻는다.

## 다시 볼 조건
- 밀쳐내기가 너무 세서 적이 화면 밖·벽으로 흩어져 싸움이 늘어지면 반지름 44 → 36, 넉백 260 → 200.
- 솟구치기가 너무 세서 굴파기만 반복하면(굴파기 대기 0.6초) 피해 2 → 1로 되돌리고 밀쳐내기만 남긴다.
