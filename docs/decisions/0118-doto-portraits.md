# 0118. 도토 대화 초상화(나노바나나)

- 날짜: 2026-10-26
- 상태: 채택. 0117에 이은 아홉째. 물든 도토(칸 30)는 따로.

## 결정(`tools/art/ai_portraits.py` `doto`, `tools/art/sources/ai/doto_{normal,happy}.png`)
- 칸 31~32(보통 = 눈 뜬 크고 반짝이는 눈, 기쁨 = 감은 눈 웃음). 틀은 높이 96%.
- 꼬리는 "등 뒤에서 솟아 머리 뒤로 말리게, 팔이 아니게"를 적었다(0052의 확인 항목 "꼬리가 팔처럼 보이지 않는지").
- **몸이 원본 아래 끝보다 위에서 잘렸다**(942줄 아래가 배경 띠). 크림색 배(225,210,179)가 배경(231,224,205)과 거리 30이라 배경 지우기(허용 34)가 그 띠를 타고 배까지 지워, 칸 아래 가운데에 구멍이 났다. 942줄까지만 쓰고(`CUT_AT`) 아래 끝 번지기를 끈다(`CHEST_AT_BOTTOM`).

## 시트에서 고친 것
- 첫 시트에 초록 조끼·보라 꽃·꼬리의 보라 리본·앞니가 생기고 털이 그냥 갈색이었다. 진한 보라는 할매의 실에만 쓰는 색이라, 꼬리의 보라 리본은 실이 남은 것처럼 읽힌다. 참고 그림 → 시트 순서로 첨부해 빼고, 털을 붉은 밤색으로 고쳐 그렸다.

## 함께 고친 것
- 프롬프트 문서의 세계 규칙이 "실에 묶인 동물은 빨간 눈, 모모만 초록"이었다. 사양은 도토 = 호박색(0052), 콩이 = 옅은 하늘빛(0054)이다. 문서를 고쳤다.

## 확인
- 색까지 비교: 커밋된 시트와 다른 칸은 31·32뿐이다. 공식 페이지 도토 그림(`site/img/p_doto.png`)도 다시 만들었다.
- 헤드리스 대화는 못 봤다: 돌아온 도토의 대사는 보스를 이긴 뒤와 마을에서 말을 걸 때만 나온다.
