# 0257. 굴의 방 짜임: 무리 표·세기 곡선·싸움 종류·곁방 보상·등장·손으로 짠 방 틀

- 날짜: 2026-10-30
- 상태: **구현**(v0.6.13)
- 사장(2026-10-29): "스테이지에 생성되는 각 방들이 너무 반복되는 느낌인데 이걸 어떻게 덜 지루하게 만들 수 있을까?"
  → 제안 B(무리 표 + 세기 곡선)·A(싸움 종류)·C(곁방 보상 표지)·F(등장 연출)·D(손으로 짠 방 틀) 중 "B, A, C, F까지 완료 후 D 몇 장 그려서 포함한 후 기존 개발 내용이랑 배포해 줘."

## 왜 반복되었나(코드에서 확인)
1. 목표가 늘 "다 잡기"(들어서면 잠김 → 0마리면 열림).
2. 등장이 하나: 정해진 여덟 자리에서 0.7초 뒤 한꺼번에 깬다 — 늘 "가운데에서 사방을 맞는" 그림.
3. 편성이 없다: 한 방 2~4마리를 지대 표에서 한 마리씩 따로 뽑아 대부분 "쥐 몇 마리".
4. 문은 늘 각 변 가운데, 지형도 문 앞 십자 길을 피해 놓여 동선의 뼈대가 같다.
5. 굴 안의 세기 곡선이 없고, 곁방은 보상 없이 의무 싸움.
→ 바꿀 것은 모양보다 **방마다의 판단**(무엇을 먼저, 어디서, 어떻게).

## 정한 것
### B. 무리 표 + 굴 안 세기 곡선
- `species::SQUADS`: 지대마다 손으로 짠 무리 11줄(섞인 무리·쥐 떼·도토리 진지·덮치기·가시 성벽·뒤쥐 사냥·두꺼비 진지·독 안개·하늘 습격·시궁쥐 굴·박쥐와 버섯). `core`는 꼭(앞자리), 나머지는 `fill`. 무리의 종은 모두 그 지대 뽑기 표의 종(시험).
- 놓기 `dungeon::place`: 뒷줄(던지기·혀·포자, `species::back_row`)은 **들어오는 문(시작 쪽 이웃)에서 먼 자리부터**, 나머지는 남은 자리를 섞어서.
- 세기: 시작 바로 옆·끝방 바로 앞(끝방과 이어진 방)은 작은 싸움(2 + 깊이 ≤1), 넓은 방은 물결, 나머지는 예전 수(2 + 깊이 ≤2 + 0~1).

### A. 싸움 종류 `dungeon::Encounter`
| 짜임 | 무엇 | 언제 |
|---|---|---|
| 다 잡기 | 예전 그대로 | 시작 옆·숨 돌리는 방·끝방, 굴리면 40% |
| 물결 | 남은 적이 `WAVE_NEXT_AT`(1) 이하면 뒤 무리(2 + 깊이 ≤1)가 땅에서 솟는다 | 넓은 방은 늘, 굴리면 25% |
| 매복 | 빈 방처럼 보이다가 가운데 `AMBUSH_TRIGGER`(56px) 안에 오면 잠기고 둘레(자리를 가운데로 0.55배 당긴 곳)에서 떨어진다 | 20% |
| 버티기 | `HOLD_TIME` 15초 동안 살아 있는 수가 `HOLD_ALIVE`(3)보다 적으면 `HOLD_SPAWN_EVERY` 1.2초마다 하나씩 솟는다(줄은 처음 수 + 4 + 깊이 ≤2, 다 쓰면 그만). 시간이 다 되면 남은 것은 무너지는 흙에 묻혀 사라진다(아무것도 안 떨어뜨림). 줄을 다 쓰고 다 잡으면 일찍 끝 | 15% |
- 런타임은 `adventure::Fight`(잠긴 방에만, 방이 열리면 없다) + `World::fight_tick`. HUD 위쪽 가운데 "무리 1/2" · "버티기 12" + 시간 막대(`render/hud.rs draw_fight_bar`). 잠길 때 한 줄 알림(열한 언어).

### C. 곁방 보상 `dungeon::Bounty`
- 끝방·시작 옆 작은 방 말고 싸움방에: 물결·버티기는 늘, 나머지는 `BOUNTY_CHANCE` 50%. 씨앗 2 · 반딧불 3 · 산딸기 1(40·35·25%), 버티기 방은 30% **상자**(길 무기 → 장신구 → 반딧불, `chest_gift`).
- 옆 방의 문 안쪽에 동그란 표지(`render/props.rs draw_door_signs`): 그림 = 보상, **테가 붉으면 물결·버티기 방**(센 방). 비운 방은 표지가 사라진다. 넓은 방은 짝 가운데 한 방에만.
- 경제: 한 런 곁방 보상 ≈ 15개 → 씨앗 +10~12, 반딧불 +15쯤(런 반딧불 ≈ 240의 6%), 산딸기 +3~4. 버티기 줄은 끝이 있어 처치 드롭이 크게 늘지 않는다.

### F. 등장 연출 `enemy::Entry`
- 그 자리에서 깨기(예전) · 땅에서 솟기(`BURROW_ARRIVE` 0.9초, 모모 땅속 둔덕 그림 `draw_dig_mound`) · 천장에서 떨어지기(`DROP_ARRIVE` 0.75초, 커지는 그림자 + 가속 낙하 `DROP_HEIGHT` 90px).
- 나타나는 동안은 **맞지도 때리지도 않는다**(`Enemy::hittable`). 끝나는 틱에 `Event::Arrived` → 흙덩이(솟기)·먼지 + 작은 흔들림(떨어지기).
- 고르기: 매복 = 떨어지기, 버티기·물결 뒤 무리 = 솟기, 끝방 = 깨기, 나머지는 굴린다(뿌리·심층·흰 실 25/50/25%, 들판 40/45/15%).

### D. 손으로 짠 방 틀(6장 × 좌우 뒤집기)
- `dungeon::TEMPLATES`: 18×9 ASCII(`#` 벽, `e` 적 자리). 네 기둥 · 두 능선 · 계단 담 · 네 모서리 비탈 · 긴 골짜기 · 섬.
- 규칙(시험 `templates_keep_lanes_spots_and_connect`): 가운데 두 열·두 줄은 비움(문 앞 십자), 적 자리 여섯 넘게·문 곁(두 칸) 밖, 뒤집어도 바닥이 한 덩어리.
- 싸움방 지형 굴림에서 `TEMPLATE_CHANCE` 35%. 틀이 방 모양 전부(모서리·혹·바위 대신). 덤불·그물·부술 것은 적 자리를 피한다.

### 안내·시험·개발
- 안내 "굴의 방"(열여섯째 주제, 힌트 그림 `pic_rooms`: 부푼 땅에서 들쥐가 솟고 문 곁 씨앗 표지).
- 시험: 무리 표·틀·짜임 분포·세기 곡선·물결/버티기/매복 런타임(`waves_rise_from_the_ground_then_the_room_pays`·`hold_out_spawns_then_caves_in`·`ambush_waits_for_the_middle`).
- 개발 시나리오 "방 짜임: 물결/매복/버티기"(같은 시드 굴, 시작방 옆 방).
