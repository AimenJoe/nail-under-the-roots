# 0200. 쥬시 지렁이가 쓰러질 때 일어나게(고장 고침)

- 날짜: 2026-10-28
- 상태: 채택(v0.4.4 패치).
- 사장: "쥬시 지렁이를 소지하고 있을 때 죽으면 다시 살아나야 하는데 그렇지 않네? 그것 보완하고 배포하자."

## 왜 안 됐나
- 일어나기 검사는 `tick_player`(플레이어가 움직인 단계)에서 "이번 틱의 `Event::Die`"를 찾았다. 그런데 플레이어가 맞는 것은 같은 틱의 뒤 단계 `hit_player`다(0169 R1 틱 순서). 쓰러짐 이벤트는 그 뒤에 쌓이고, 다음 틱 `Player::update`가 이벤트를 비우므로 검사가 한 번도 못 봤다. 플레이어에게 피해를 주는 곳은 `hit_player` 하나뿐이라 지렁이는 언제나 남았다.
- 틱을 단계 메서드로 나눈(0169 R1·R2) 뒤로 생긴 것으로 보인다(그 전 코드는 맞기와 검사가 한 덩어리였다). 일어나기를 다루는 테스트가 없어 못 잡았다.

## 결정
- 일어나기는 **맞은 자리에서**: `hit_player`가 `take_damage` 뒤 쓰러졌으면 가방의 지렁이를 꺼내 `World::revive`(체력 일부·잠깐 무적·둘레 밀어내기·토스트). 없으면 예전처럼 쓰러짐 소리·흩어짐. `tick_player`의 옛 검사는 지웠다(한 곳).
- 테스트 `juicy_worm_revives_on_death`: 체력 1 + 지렁이 + 적의 탄 → 그 틱에 일어나고 지렁이는 없어진다 / 지렁이가 없으면 쓰러진다.
