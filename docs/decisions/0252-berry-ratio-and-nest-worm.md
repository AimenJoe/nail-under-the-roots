# 0252. 산딸기는 깎인 비율로, 쥬시 지렁이는 줄이고 둥지에서 확정

- 날짜: 2026-10-29
- 상태: **구현**(v0.6.11)
- 사장(2026-10-29): "둥지엔 쥬시 지렁이 확정으로 할까? 지금은 산딸기랑 지렁이가 많이 나오긴 해.." →
  (지렁이가 이미 한 런 ≈7마리라 둥지 확정만으론 의미가 없다는 답에) "산딸기는 한 칸당 5% 하면 어때? 그리고 저 칸이 최대 체력이 높을수록
  더 잘 나온다면 부당한 듯. 지렁이는 처치 드롭 1%, 부술 것 1.5%로 하자. 둥지는 확정. 배포해줘 — 게임 밸런스 조정이니 빨리."

## 바꾼 것
| | 전 | 후 |
|---|---|---|
| 산딸기(처치마다) | 6% + 깎인 **칸**마다 8% | 6% + 깎인 **비율** × 25%(`BERRY_CHANCE_MISSING_ALL` = 5% × 기본 체력 5칸) |
| 지렁이 처치 드롭 `WORM_CHANCE` | 3.5% | 1% |
| 지렁이 부술 것 `BREAK_WORM` | 4% | 1.5% |
| 둥지 칸 끝 무리를 다 잡으면 | 씨앗 | 씨앗 + **쥬시 지렁이 하나** |

- 산딸기: 기본 체력(5칸)에서는 한 칸에 5% — 사장이 말한 그대로. 칸이 아니라 비율이라 최대 체력이 커도(뿌리 심장·장신구·재주) 같은 비율만큼 깎였으면
  같은 확률(예: 10칸 중 2칸 = 5칸 중 1칸). 전에는 체력 8칸이면 3칸 깎였을 때 30%였는데 5칸 Naïl은 최대 4칸 깎여도 38%뿐이었다.
  불운 보정(6번 안 나오면 확정)·실뜨기 배율은 그대로.
- 지렁이: 한 런 처치 ≈190(0244) → 처치로 ≈1.9 + 부술 것 조금 + 둥지(칸을 고르게 고르면 ≈1.1) ≈ 3마리 남짓(전 ≈7+).
  지렁이는 목숨 하나라(쓰러지면 저절로 먹고 일어난다) 흔하면 쓰러짐의 대가(0210)가 가벼워진다. 이제 "몰렸으면 둥지로" 길 고르기가 된다.
- 둥지 칸 설명: "더 센 무리가 모인 곳. 끝에 상자, 다 이기면 쥬시 지렁이."(열한 언어, 일본어는 글꼴에 勝이 없어 "ぜんぶたおすと").
- 시험: `nest_end_gives_a_juicy_worm`(둥지 끝 1, 보통 굴 끝 0), `berry_chance_grows_with_missing_hp_and_pity_guarantees`(한 칸 5%, 10칸 중 2칸 = 5칸 중 1칸).
