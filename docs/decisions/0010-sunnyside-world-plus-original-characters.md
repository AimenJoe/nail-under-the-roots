# 0010: 환경은 Sunnyside World, 캐릭터는 직접 찍는다. 팩 원본은 공개 레포에 넣지 않는다

- 상태: 채택 (2026-10-25)

## 맥락
2단계 에셋을 고르며 3/4 탑다운 16×16 팩을 조사했다(KB `guides/pixel-art-without-an-artist.md`). 사장 선택은 **Sunnyside World**(danieldiggle). 귀여운 동물(두더지·고슴도치·아르마딜로·개미핥기)은 어느 팩에도 없다. 환경은 초반 꽃밭에서 점점 어둡고 음습해져야 한다.

이 레포는 **공개**다(GitHub visibility public, 2026-10-25 확인). 검색으로 본 Sunnyside 라이선스 요약은 "상업·무료 프로젝트 사용 가능, 수정 가능, 크레딧 선택, 재판매·재배포 금지(NFT 포함), AI 학습 금지"다. 팩 PNG를 공개 레포에 커밋하면 누구나 원본을 내려받을 수 있어 재배포 금지와 충돌할 가능성이 크다. 이 세션에서는 itch.io 접속이 막혀 **라이선스 원문을 직접 읽지 못했다.**

## 결정
1. **환경(바닥·벽·소품·UI)은 Sunnyside World.** 사장이 구매·다운로드하고 라이선스 원문을 `assets/LICENSES.md`에 옮겨 적는다.
2. **캐릭터는 직접 찍는다.** Naïl부터 하나씩. 원본은 `tools/art/*.py`(문자 격자 + 자동 외곽선)이고 PNG는 산출물이다. 프로젝트 소유라 공개 레포에 둔다. 팩의 팔레트·해상도에 맞춰 다듬는다. 다른 팩과 섞을 때도 같은 규칙(라이선스 확인, 원본은 레포 밖).
3. **팩 원본은 레포 밖**: `assets/vendor/`는 `.gitignore`. CI는 레포 Secrets `ASSETS_REPO`(비공개 레포 `owner/name`)·`ASSETS_TOKEN`(읽기 권한 토큰)이 있으면 그 레포를 `assets/vendor/`로 받아 빌드한다. 없으면 직접 그린 대체 타일(`assets/art/tiles.png`)로 빌드한다. 게임은 vendor가 없어도 돌아간다.
4. **환경 변화는 같은 타일에 색조·장식·어둠으로**(`src/biome.rs`): 꽃 핀 입구 → 뿌리 지대(꽃이 줄고 뿌리, 가장자리 어둠) → 어두운 심층(흙 바닥, 이끼, 빛나는 버섯, Naïl 주변만 밝음). 층 구조가 생기기 전까지 웨이브 1~2/3~4/5~가 깊이를 대신한다.
5. **3/4 벽**: 위쪽 벽은 윗면 8px + 벼랑 앞면 16px(`WALL_TOP = 24`). 기둥은 16×32 스프라이트를 발판 아래에 맞춰 세우고, 모든 것을 발 위치(y)로 정렬해 그린다.
6. **컷씬 레터박스**: 컷씬에 들어가면 위아래 검은 띠 + 안쪽 그림자가 0.4초에 걸쳐 내려오고, 조작이 돌아오면 같은 속도로 걷힌다.

## 왜
- 1인 개발에서 "세계"(바닥·벽·소품)는 양이 많고 캐릭터는 정체성이다. 양은 사고 정체성은 만든다.
- 공개 레포에 유료 팩 원본을 올리는 것은 실수 한 번으로 라이선스 위반이 된다. 비공개 경로로 분리하면 레포를 공개로 유지할 수 있다.
- 색조·어둠으로 환경을 바꾸면 타일 세트를 환경마다 살 필요가 없고, 내려갈수록 어두워지는 흐름이 한 숫자표로 조정된다.

## 비용
- 비공개 에셋 레포와 토큰 관리가 하나 늘어난다. 대안: 게임 레포 자체를 비공개로(Actions 무료 분 제한).
- 팩을 받으면 칸 좌표 매핑을 한 번 해야 한다(팩 이미지를 보고 `src/art.rs`에 표).
- AI 도구에 팩 이미지를 넣으면 "AI 학습 금지" 조항에 걸릴 수 있다. 팩 이미지는 AI 도구에 넣지 않는다.

## 후속 (2026-10-25): 라이선스 원문 확인
itch.io 접속이 열려 페이지의 라이선스를 직접 읽었다(`assets/LICENSES.md`에 원문). **V1**: 무료·상업 프로젝트에 사용 가능, 수정 가능, 크레딧 불필요(권장). 튜토리얼·교육 과정에 한해 itch.io 페이지 링크와 함께 재배포 가능. 아무리 수정해도 재포장·재판매 금지(NFT 포함). AI 학습 금지. 가격은 "Name your own price"(0원 가능).
→ 상업 판매 가능. 공개 레포는 "튜토리얼·교육"이 아니므로 3번(레포 밖 보관)을 유지한다.

## 재검토 조건
- 라이선스 원문이 요약과 다르면(예: 공개 저장소 허용, 또는 웹 배포 제한) 3번을 다시 본다.
- 캐릭터 직접 제작이 한 마리당 너무 오래 걸리면 의뢰·다른 팩 혼용을 검토한다.
