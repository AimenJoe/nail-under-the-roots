# 0095. 어둠 지도: 야광버섯이 바닥을 밝히고, 빛 반대쪽으로 그림자가 진다

- 날짜: 2026-10-26
- 상태: 버섯 빛 수치는 0100이 바꿨다(은은하게 넓게). 채택. 사장: "우리 어두운 화면은 너무 어두우니 바닥에 야광버섯 같은 게 분포되어 있으면 좋을 듯, 빛에 따라 그림자도 지게 할 수 있나?"

## 전
- 어둠 = 플레이어 둘레만 둥글게 뚫린 검은 막 하나(`dark_mask`, 심층 불투명 0.78·반지름 92, 뿌리 지대 0.38·150).
- 빛나는 버섯은 어둠 위에 한 번 더 그려 **보이기만** 했다. 둘레 바닥은 깜깜했다. 그리는 순서 때문에 캐릭터 위에 겹치기도 했다.

## 결정(`render.rs`)
- **어둠 지도**: 월드와 같은 크기의 렌더 타깃(`dark_rt`)을 어둠으로 채운다. 빛 자리마다 빛 구멍 텍스처(`Art::light`, 가운데 불투명 → 가장자리 0)를 **뺄셈 섞기**(`cut_material`: ReverseSubtract One/One)로 찍어 어둠을 뺀 뒤 월드 위에 덮는다. 재질을 못 만들면 예전 막으로 돌아간다.
- **빛**(`light_sources`, 그림자와 같이 쓴다):

| 빛 | 반지름 | 세기 |
|---|---|---|
| 플레이어 | 환경 값(심층 92 · 뿌리 150) | 1.0 |
| 야광버섯 | 34 → 64(0100) | 0.6 → 0.28(0100, 숨 쉼) |
| 모닥불 | 80 | 0.95 |
| 반딧불 | 18 | 0.55 |
| 저장 지점 | 44 | 0.7 |
| 출구 | 34 | 0.65 |
| 잠긴 문(0094) | 22 | 0.4 |

- **야광버섯 더 많이**: 심층 9% → 14%. 뿌리 지대에도 4%를 새로 넣었다(`biome.rs` 장식 표). 버섯은 캐릭터 밑 바닥 높이에 그린다(겹침 고침).
- **그림자**(`draw_cast_shadows`): 플레이어·적·포포가 가까운 빛마다 그 반대쪽으로 길게 눕힌 그림자를 받는다. 3/4 시점이라 세로는 반. 빛에 가까울수록 진하고 길다(최대 알파 0.45). 플레이어 자신의 빛은 플레이어에게 그림자를 주지 않는다. 어두운 곳에서는 플레이어의 빛이 적에게 그림자를 드리운다. 밝은 들판에서는 플레이어 빛을 빼고 모닥불 같은 빛만 쓴다.

## 하지 않은 것
- 벽·바위가 빛을 가리는 그림자(레이캐스트·그림자 볼륨). 지도 전체를 다시 굽거나 프레임마다 다각형을 만들어야 해서 웹·폰 성능에 비해 얻는 것이 작다.

## 확인
- 헤드리스: 심층 아레나·뿌리 지대·콩이 방에서 버섯 둘레가 밝아지고 겹침이 사라진 것을 봤다. 그림자 진하기·길이는 사람 판정.
