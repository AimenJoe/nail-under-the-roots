# 0262 — 굴 출구는 버튼으로 내려간다

- 사장 지시(2026-10-30): 다음 스테이지로 넘어갈 때 구덩이를 밟는 것만으로 내려가지 않고, 보물 상자처럼 버튼으로 내려간다.
- 굴(`Place::Dungeon`)의 출구 칸(`Cell::Exit`) 곁(`INTERACT_RADIUS`)에서 `Interact::Exit`이 된다. 말풍선은 기존 `ia_descend`("{0} 내려가기")를 쓴다.
- 누르면 `World::use_exit`이 예전 밟기 로직을 그대로 한다: 길 칸 → 길 지도, 보스 칸 → 다음 쉼터, 마지막 길 보스 → 가장 깊은 곳, 길 없는 굴 → 나가기.
- 공터 입구(`Cell::Entrance`)와 저장 지점은 그대로 밟으면 동작한다.
- 우선순위: 상자 > 출구 > 쉼터 상호작용.
