# 0244. 넓은 굴: 방을 늘리고, 화면 두 칸짜리 넓은 방과 방 지형

- 날짜: 2026-10-29
- 상태: **구현**(v0.6.5). 사장: "각 스테이지의 지도 자체가 너무 적은 방들로 이루어져 있어. 여러 지형들 더 만들어서 지도를 넓히고."

## 왜 좁았나
길 지도의 칸 하나(굴)가 방 2~4개였다 — 시작방을 빼면 싸움 한두 번 + 끝방. 지도 탭의 굴은 네모 서너 개라 "굴을 탐험한다"는 느낌이 없었다.
방 모양(0063)은 모서리·혹·바위 무리 하나뿐이라 방마다 비슷했다.
Binding of Isaac은 층마다 방 7~20개(층이 깊을수록 많게)를 두고, 가로·세로 두 칸·네 칸·L자 큰 방을 섞는다(위키 2차 출처, 역공학).

## 바꾼 것
1. **방 수**(`route.rs Route::params`): 보통 굴 4 → 6, 둥지 4 → 6, 실타래 3 → 5, 저장고 3 → 4, 보스 굴(옛 굴 포함) 4 → 6. 샘은 2 그대로(싸움 없음).
2. **넓은 방**(`dungeon.rs`, `DRoom::hall`): 이어진 싸움방 둘(시작·끝방·상자·쉼방은 아님)을 하나로. 굴마다 `Params::halls`번 기회, 기회마다 `HALL_CHANCE`(0.8).
   - 사이 벽 줄(가로면 두 방의 맞닿은 세로 벽, 세로면 위 방 아래 벽 + 아래 방 위 벽 두 줄)을 방 모양을 다 만든 뒤 바닥으로 튼다 — 문 칸도 없어진다.
   - `Dungeon::area`(두 방을 합친 사각형)가 카메라·떨어진 것의 경계, `area_interior`가 잠그는 안쪽. 카메라는 원래 "경계 안 추적"이라(KB concepts/adventure-field-and-procedural-dungeon) 경계만 넓히면 방 안에서 따라 움직인다.
   - 들어서면 두 방의 적이 함께 깬다. 한 방에 하나씩 덜 둔다(둘 합쳐 한 방의 1.5배쯤). 다 잡으면 둘 다 비워진다.
   - 일시정지 지도: 두 칸 사이 틈을 같은 색으로 메워 한 방으로 보이고, 둘 중 어디 있든 둘 다 강조.
3. **방 지형**(`dungeon::Layout`, 굴 모양 위에 얹는다): 싸움방(이름 있는 주인의 방은 빼고)마다 하나 —
   굴 그대로(30%), 뿌리 기둥(2×2·2×1 기둥 넷 사분면, 25%), 골짜기(위·아래 벽에서 내려오는 능선 둘, 가운데 길에서 끊긴다, 23%), 돌밭(한 칸 돌 5~8개, 22%).
   모두 문 앞 십자 길과 `KEEP`(적·상자·출구 자리) 둘레를 비우고, 안 이어지면 네모로 되돌리는 0063 검사를 그대로 받는다. 굴 모양 난수와 따로라 방 배치·적은 그대로다.
4. **경제**(0236을 지킨다): 처치가 한 런 약 1.5배(33·44·46 → 50·69·71/길). 잡몹이 떨어뜨리는 반딧불 한 마리·씨앗을 `KILL_LOOT_KEEP`(0.65) 확률로만 —
   길의 주인은 그대로. `economy_probe`: 반딧불 239 → 242, 씨앗 48 → 54(부술 것이 방 수만큼 는다).

## 확인
- `halls_pair_two_linked_combat_rooms_with_an_open_seam`: 짝은 서로를 가리키는 이어진 싸움방, 문 없이 걸어서 이어지고, `area`가 한 방보다 크다. 방 여섯 굴의 60% 이상에 넓은 방.
- `every_layout_appears`, 기존 `shaped_rooms_keep_spawns_and_stay_connected`(지형도 적 자리·길을 막지 않음)·`generates_connected_dungeon_with_one_boss`(넓은 방 사이는 문 검사에서 뺌).
- 개발 시나리오 "넓은 방"(타이틀 → 개발 맨 끝): 헤드리스 Chromium으로 카메라가 넓은 방 안을 따라가고 두 칸의 적이 함께 깨는 것을 봤다.

## 홈페이지(같은 배포)
- 싸움·지대 스크린숏과 게임 장면 영상을 빈 아레나 대신 실제 굴에서 다시 찍었다: 꽃 핀 공터의 들쥐 대장 → 넓은 방의 나일·모모·도토 → 뿌리 실타래 굴 → 모모(길의 주인), 20초.
  쉼터 그림 칸에 "넓은 방"·"길의 주인" 두 장을 더해 2×2로.
- 클립 도구(`tools/site/clip.js`, 0228): 가짜 시계를 메뉴부터 건다(장면이 뜬 뒤에 걸면 월드가 검게 남는 칸이 여러 번 나왔다), 보스 만남 컷씬은 `ESC=1`, 말풍선은 `SKIP`.
  자동 조종(`src/autopilot.rs`, 찍기 전용)은 적이 없으면 아직 안 비운 싸움방으로 걷는다. 개발 시나리오 "넓은 방"은 둘째 길 굴(적이 더 많다), 모모·도토판도.

## 남은 것
- 네 칸·L자 넓은 방, 지형별로 다른 바닥(물·진흙)은 아직. 사장이 해 보고 굴 길이(한 런 시간)가 길면 `Route::params`의 방 수부터 줄인다.
