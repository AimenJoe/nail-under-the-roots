# 0115. 누룩 할매 대화 초상화(나노바나나)

- 날짜: 2026-10-26
- 상태: 채택. 0114(들쥐 대장)에 이은 일곱째.

## 결정(`tools/art/ai_portraits.py` `halmae`, `tools/art/sources/ai/halmae_{normal,happy}.png`)
- 칸 15~16(평온 = 감은 눈·작은 미소, 기쁨 = 웃는 눈·조금 넓은 미소). 원본이 칸을 채워 틀은 그대로.
- 몸이 칸 아래로 이어지고 흰 몸이 배경 베이지와 가까워, 아래 끝에서 배경을 번지지 않는다(`CHEST_AT_BOTTOM`, 0110).
- 시트에 없던 두 가지를 초상화 프롬프트에 넣었다: 눈가 주름(0049 사양 "늘 감은 눈과 눈가 주름"), 자두빛 바깥선(흰 몸이 배경과 갈리게).

## 고른 얼굴
- 첫 초상화는 볼에서 볼까지 큰 웃음선이 있는 사람 할머니 얼굴로 나왔다. 그 얼굴로 평온 표정을 만들자, 88px에서 평온과 기쁨이 거의 같아 보였다(웃음선이 남는다).
- 시트·마을 월드 그림(0045)의 **둥근 얼굴 판** 얼굴로 다시 그린 평온 표정은 칸에서 또렷이 평온했다. 이 얼굴로 기쁨을 만들어 짝을 맞췄다(사장이 받아 왔다).
- 표정 짝은 **같은 얼굴에서** 만든다. 그리고 줄인 칸에서 두 표정이 갈리는지 본다.

## 확인
- 색까지 비교: 커밋된 시트와 다른 칸은 15·16뿐이다.
- 헤드리스: 개발 → "이야기 일러스트"의 가장 깊은 곳 장면에서 할매 대사에 새 그림이 나온다. 공식 페이지 할매 그림(`site/img/p_halmae.png`)도 다시 만들었다.
