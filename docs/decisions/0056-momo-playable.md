# 0056: 모모 플레이어블 — 같은 버튼, 다른 동사

- 상태: 채택 (2026-10-25). 0040 순서 6("모모 플레이어블")이다. 모모 보스(0046)가 먼저였고, 보스의 수(뛰기·차기·이어 뛰기)가 그대로 기술 세트가 됐다.
- 사장: "모모 가자~". 고르는 곳 = "마을 뿌리 길에서", 끝 = "짧은 모모 장면"(둘 다 추천안).
- CLAUDE.md의 "1단계 범위 밖(두 번째 캐릭터)"은 0040에서 사장이 다회차를 지금 만들기로 정하면서 풀렸다.

## 결정
1. **킷**(`equipment::Character::Momo`, `Player::kit`). 버튼 자리는 Naïl과 같고 안에 든 동사만 다르다.
   - 공격 = **튼튼한 뒷발**(`moveset::KICKS`, 무기 종류 `Kick`): 두 번 콩콩 밟고, 셋째 타는 뒷발 차기(피해 2, 넉백 260).
   - 회피 = **깡충**(`State::Hop`): 0.34초 동안 56px 뛰고, 뛰는 동안 무적이다. 대기는 굴파기 대기와 같은 수치를 써서 굴파기 재주·실뜨기가 그대로 먹는다.
   - 특기 = **이어 뛰기**(`State::Chain`): 세 번 뛴다. 내려앉을 때마다 둥근 밟기(`StrikeKind::Stomp`, 반지름 28, 피해 2)를 하고, 뛸 때마다 방향을 다시 잡는다. 게이지는 기(Ki)다.
   - 수치는 `tuning.rs`의 `HOP_*`·`CHAIN_*`에 있다.
   - 콩이 등딱지는 뒷발도 튕겨 낸다. 밟기(발톱이 아닌 타)는 연다. 그래서 알림은 "이어 뛰기로 밟아 열자"다.
2. **무기 거르기**: 런 시작 가방, 런마다 받는 발톱(새싹·바위·독), 가방 장착 모두 `WEAPONS[w].kind == 캐릭터 종류`로 거른다. 모모는 발톱을 줍지 않는다.
3. **고르는 곳**: 모모가 돌아온 뒤(`momo`) 마을 뿌리 길에서 공격 버튼을 누르면 **누구와 내려갈까?** 창이 열린다(`app/pick.rs`).
   - 카드는 둘이다. 카드마다 초상화, 한 줄 설명, "끝까지 n번"을 보인다.
   - 좌우로 고르고 확인하면 내려간다. 고른 것은 `char_pick`에 남아 다음 창의 기본값이 된다.
   - 모모가 아직 안 돌아왔으면 창 없이 바로 내려간다.
4. **기록은 캐릭터마다**: 깬 수(`clears.<캐릭터>`)와 실뜨기 열린 단계(`knots_open.<캐릭터>`)를 따로 둔다. 마을 큰 나무 잎은 둘을 합친다.
5. **모모 런**:
   - 첫 길 끝방의 모모 보스 싸움은 끈다(`momo_fight = false`). 모모가 모모와 싸우지 않는다.
   - 마을은 늘 Naïl이다(허브 월드는 새로 만든다). 그래서 모모는 마을에서 이웃으로 서 있다.
   - 컷씬의 플레이어 배우는 이번 런의 캐릭터다(이름·초상화).
   - 오늘의 굴도 고른 캐릭터로 한다. 실의 꿈은 Naïl만 한다(꿈 목록에 모모가 있다).
6. **모모의 끝**: 가장 깊은 곳에 모모로 닿으면 짧은 장면이 나온다.
   - 그림은 새 일러스트 `momo_deep`이다(`illust.py`가 그린다. 할매 장면과 바탕이 같고, 실에 걸린 굴토끼 털 뭉치와 시든 꽃잎이 있다). 앨범은 10장(5×2)이 됐다.
   - 대사: "…엄마 꽃이야. 다들 여기를 지나갔구나." → "기다려. 언젠가 꼭 찾으러 올게."
   - 남는 것은 `momo_deep` 깃발이다. Naïl의 반쪽·참 엔딩 깃발은 세우지 않는다. 모모의 끝은 Naïl의 이야기를 대신하지 않는다.
   - 마을 씨앗·실뜨기 열기는 Naïl과 같다.
7. **이야기**:
   - 포포가 런 시작에 모모를 배웅한다(`again_momo`, 조건 셋).
   - 할매가 꽃잎을 한 번 말한다(`halmae_petal`): 실이 굴토끼 가족을 품고 아직 아픈 꿈을 꾼다. 굴토끼 가족 이야기의 다음 갈래로 남긴다.
   - 저널 "꽃잎을 따라"(모모로 가장 깊은 곳, 반딧불 40, 앞 목표 "꽃이 피다").
8. 글 17줄을 다섯 언어로 직접 썼다. 일본어 고르기 창 설명이 세 줄을 넘어 줄였다.

## 왜
- 같은 버튼 자리: 손이 배운 것(회피는 이 버튼)을 그대로 두고, 무슨 일이 일어나는지만 새로 배운다. 그러면 바인딩·안내·튜토리얼을 그대로 쓴다(KB `second-playable-character.md`).
- 보스의 수가 기술이 됐다. 플레이어는 세 번 싸우며 이 수들을 이미 봤다. "당했던 기술을 쓰는" 손맛이고, 그림(MOMO_BLOOM 줄)도 다시 쓴다.
- 기록을 나누면 "모모로 실뜨기 5단계"가 새 목표가 된다. 다양성 축(0040)이다.
- 엔딩 깃발을 따로 두는 이유: 모모로 깨도 Naïl의 참 엔딩 조건(모모·도토)을 건너뛰지 않게 한다.

## 확인
- 단위 테스트 94개.
  - 모모의 깡충·이어 뛰기(무적, 세 번 내려앉기, 끝나면 Recover).
  - 모든 무기의 마지막 타가 가장 세다(뒷발 포함).
  - 캐릭터의 첫 무기 종류 = 그 캐릭터의 무기 종류.
  - 글자 테스트(다섯 언어).
- 헤드리스:
  - 마을 뿌리 길 → 고르기 창(한·일·중·영·포) → 모모 → 포포 배웅 → 깡충(그림자)·뒷발 3타·이어 뛰기.
  - 개발 "가장 깊은 곳"(고른 캐릭터를 따른다) → 모모 장면(한·일).
- 사람 판정이 남았다: 깡충 거리·대기, 이어 뛰기 세기(세 번 × 피해 2), 뒷발 사거리, 모모가 작게 보이는지, 고르기 창, 모모 장면 길이, `momo_deep` 그림(털 뭉치가 털로 읽히는지).

## 알려진 것
- 터치 버튼 글자는 캐릭터를 모른다("DIG"). 입력 모듈이 캐릭터를 보지 않게 그대로 뒀다.
- 설정의 조작 이름("굴파기(회피)")도 Naïl 이름 그대로다.
- 큰 나무 재주 중 굴파기 갈래는 깡충에 대기 배율만 먹는다(숨는 시간·솟구침 넓이는 깡충에 없다). 드릴 갈래는 게이지가 차는 속도만 먹는다(달리는 거리는 이어 뛰기에 없다). 모모 갈래는 판정 뒤.
