# 0155: 공식 페이지를 "땅속으로 내려가는" 한 장으로 다시 짬

- 상태: 채택 (2026-10-27). 0069(공식 페이지)의 모습·내용을 바꾼다. 주소·배포(`pages.yml`)·릴리스에서 읽는 값은 그대로.
- 사장: "GitHub page 의 공식홈페이지.. 내용이 좀 더 추가될수 있지 않나? 아니면 아예 그냥 감각적으로 바꾸던지.."

## 결정
1. **한 가지 이야기로 짠다**: 스크롤하면 땅 위 → 굴 → 뿌리 지대 → 어두운 심층 → 가장 깊은 곳으로 내려간다.
   - 층마다 바탕이 짙어진다. 층 사이 가장자리는 계단 모양이다.
   - 넓은 화면(1240px 이상)에는 오른쪽에 깊이 눈금을 둔다. 나일이 스크롤만큼 내려가고, 지금 층의 이름이 밝아진다(`site.js`).
2. **첫 화면 = 타이틀 바탕 한 장**(`i_title.png`). 땅 위·굴 단면·큰 나무가 다 들어 있다.
   - 글은 하늘 쪽에 둥근 그늘을 깔고 놓는다(게임 타이틀과 같은 둥근 그늘, 0152). 반딧불이 떠다닌다.
   - 폰에서는 그림(16:9) 아래에 글을 둔다.
3. **게임 스프라이트가 움직인다**: 16px 칸 띠(`sp_*.png`, `make_images.py`의 `SPRITES`)를 CSS `steps()`로 돌린다.
   - 첫 화면 아래로 나일과 포포가 걸어간다. 지대마다 그곳 적이 서 있고, 두 캐릭터 칸에서는 나일·모모가 걷는다.
4. **더한 내용**:
   - 이야기(엄마 굴 일러스트)
   - 싸움 동작 넷과 키캡
   - 지대 셋(적·장애물, 실타래 칸)
   - 쉼터 셋(새 스크린숏)
   - 두 캐릭터
   - 소리(피아노·바이올린과 칩튠, 곡 크레딧)
   - 누구나(장치·도움 모드·색약·흔들림, 열한 언어)
   - 다음 버전(v0.4 "깊은 곳", 줄거리는 흐리게)
   - 팩트시트, 자주 묻는 것
   - 꼬리말 크레딧을 지금 에셋에 맞춤(나노바나나·음악 작가·폰트 셋)
5. **빼거나 바꾼 것**:
   - "v0.2" 같은 낡은 글
   - 쓰이지 않는 그림(`i_great_tree`·`i_molehill`·`s_deep`·`s_story`)
   - 일러스트 바탕 명화 크레딧(지금 게임 그림에 안 쓰인다, `assets/LICENSES.md`)
6. **움직임 줄이기**(`prefers-reduced-motion`)면 반딧불·걷기·화살표가 멈추고 제자리에 선다.

## 왜
- 인디 게임 공식 페이지의 관례(2차 출처, KB `guides/indie-game-landing-page`): 첫 화면이 "무슨 게임·어디서 하나"에 바로 답하고, 그 아래 기능·스크린숏·팩트시트·연락처를 둔다.
  - 지금 페이지는 첫 화면은 했지만 v0.3의 볼륨(새 적·지대·쉼터·모모·소리·접근성)이 보이지 않았다.
- "감각적으로": 게임의 한 줄 이야기(뿌리를 따라 땅속으로)를 스크롤 자체로 만들었다. 도트 그림을 그대로 키우고 게임 스프라이트를 직접 움직이면, 새 그림 없이도 게임과 같은 결이 된다.
- 영상(트레일러)은 관례상 가장 좋다. 하지만 헤드리스 녹화(Playwright `recordVideo`, VP8)는 도트를 흐리게 뭉개 넣지 않았다. 사람이 실제 기기에서 녹화한 클립이 생기면 첫 화면이나 싸움 칸에 넣는다.

## 확인한 것 / 못 한 것
- 헤드리스 Chromium, 한국어·영어 × 1440×900·390×844·320×640(움직임 줄이기):
  - 가로 넘침 없음(scrollWidth = 화면 폭, 넘는 요소 없음).
  - 콘솔 오류 없음. GitHub API가 403(요청 제한)이면 적어 둔 값이 남는다.
  - 글꼴을 불러온다. 반딧불이 뿌려지고 깊이 눈금이 끝까지 따라간다.

- 못 한 것: 실제 Pages 주소에서 보기(세션에서 github.io가 막힘), Safari·실제 폰.
