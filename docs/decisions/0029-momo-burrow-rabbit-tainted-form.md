# 0029: 모모 = 굴토끼. 물든 모습 그림(초상화 2 + 스프라이트)

- 상태: 채택 (2026-10-25, 사장 "굴토끼 좋다. 귀여워"). 0027의 "종 미정"을 채운다.

## 결정
1. 모모는 **굴토끼**(땅에 굴을 파고 무리 지어 사는 토끼). 실루엣 = 긴 귀 둘 + 하얀 솜꼬리. 이미 나온 종(두더지·쥐·다람쥐·청설모·라쿤)과 겹치지 않는다.
2. **물든 모습의 그림 문법**(졸개와 같은 계열이되 특별하게):
   - 털: 따뜻한 회갈색이었을 것이 자두빛·잿빛으로(`portraits.py` mfur, `critters.py` momo).
   - 눈: **초록 빛**(졸개 쥐들은 붉은 빛). 둥근 동공·큰 반사·속눈썹으로 귀여움은 남긴다 — 세로 동공·찌푸린 눈썹은 고양이·악당처럼 보여 뺐다.
   - 보라 뿌리가 목을 한 바퀴, 가까운 귀를 타고 오른다. 귀 안쪽은 분홍 대신 어두운 보라.
   - **시든 꽃**(가까운 귀 밑동, 꽃잎이 처지고 빛이 바램) — 돌아오면 이 꽃이 분홍으로 **핀다**. 회복을 그림 하나로 보여 주는 장치.
   - 눈 밑 그늘, 옅게 남은 볼 홍조(원래 모습의 흔적).
3. 초상화 칸 7 = 차가움(꾹 다문 입), 칸 8 = 괴로움(안쪽이 올라간 눈썹, 눈물). 오프닝 op_2는 차갑게, op_3("…돌아가")는 괴롭게.
4. 스프라이트 `critters.png` 줄 7(서기 2·깡충 2·웅크림·뛰어 차기·맞음). 오프닝 배우가 색 동그라미 대신 이 그림.
5. 이름표는 정체가 밝혀질 때까지 "???"(0027).
