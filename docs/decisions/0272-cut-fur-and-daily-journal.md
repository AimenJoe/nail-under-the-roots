# 0272. 털빛·오늘의 굴 빼기와 저널 다듬기

- 날짜: 2026-11-03
- 상태: 채택(사장 "털빛, 오늘의 굴 빼고, 저널에 대해서 수정/보완 해줘, 보상에 대해서는 게임내 경제를 해치지 않도록")
- 바탕: 0044(오늘의 굴), 0048(저널·털빛), 0040(보상은 힘이 아닌 것·옆으로), 0041(기록 키는 바꾸지 않는다)

## 왜
- **오늘의 굴**: 일일 도전의 재미는 "모두가 같은 시드를 한 번 돌고 비교한다"에서 나온다(KB `concepts/roguelite-replay-axes.md`, 2차 출처). 서버·순위표가 없는
  이 게임에서는 날짜가 붙은 보통 런 + 마을 씨앗 5였다. 그런데 타이틀 메뉴 한 칸, 런 흐름 갈래(가장 깊은 곳·쓰러짐), 저널 목표, 사이트 글을 계속 같이 고쳐야 했다.
- **털빛**: 21px 나일의 털 색만 바꿔 거의 보이지 않았고, 모모·도토로 걸으면 아무 효과가 없었다(`draw_nail`만 털빛을 썼다).
- 사장: 볼륨(이야기)을 넓히는 쪽이 낫다 — A 할매의 과거, B 이웃 사이드 스토리, C 저널 보상에 이야기 조각은 v0.8 목표.

## 정한 것
### 뺀 것
- 오늘의 굴: `daily.rs`, `Scenario::Daily`, `TitleItem::Daily`, 런 흐름의 갈래(쉼터 도착 기록·가장 깊은 곳·끝 처리), `VILLAGE_SEEDS_DAILY`, 글 넷.
  `World::camp_start_seeded`는 시험 전용으로 남긴다("같은 시드 = 같은 길").
- 털빛: `Reward::Fur`, `journal::fur`·`next_fur`·`fur_name`·`KEY_FUR`, `Inventory::fur`, `Art::nail_fur`·`nail_furs`, `Portrait::nail(fur)`(캐릭터 표의 초상화는 `Portrait` 하나),
  물웅덩이 상호작용 `Interact::Puddle`, 그림 `nail_fur1~3.png`와 `nail_ai.py fur_variant`·`check_rebuild.py`의 털빛 줄, 글 일곱.
  초상화 칸 18~29·`dig.png` 줄 1~3(옛 털빛)은 칸 번호가 밀리지 않게 시트에 남긴다.
- 물웅덩이는 마을 풍경으로 남는다. 수첩 글은 "들여다보면 내 얼굴이 비친다"로.

- 경제: 저널 전체로 반딧불 +70·씨앗 +5가 늘고 씨앗 5가 빠진다(오늘의 굴은 매일 +5였으니 반복 수입은 오히려 준다). 재주 나무(캐릭터마다 칸 24, 덤 칸 120~495)와
  짐 꾸리기(런마다 씨앗을 쓴다)에 견주면 1~2% 안쪽이라 깨우는 속도·가게 값을 바꾸지 않는다.
- 옛 기록(`journal::migrate`, 기록을 읽을 때마다): 털빛 목표를 받았던 기록(받음 `journal.<id>` + 털빛 깃발 `fur.<n>`)에 새 보상을 한 번, 표시 `mig.0272.fur`.
  `daily.<날짜>` 수는 지운다. 그 밖의 옛 키(`fur`, `fur.<n>`, `stat.daily_clears`, `journal.daily`)는 그대로 둔다(0041: 모르는 키도 보존).
