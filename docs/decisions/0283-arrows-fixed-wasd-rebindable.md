# 0283 화살표는 늘 움직이고, WASD는 다시 붙인다

- 상태: 채택(사장 2026-11-05 "방향키는 무조건 들어가 있는 거고, 설정에서 표시하지 않아도 됨. WASD는 설정에서 다시 맵핑 가능")
- 관련: 0022(다시 붙이기 — 이동은 고정이었다), 0280(WASD + 오른손), 0282(키 이름은 배열 글자)

## 정한 것
- **화살표는 늘 이동**(게임·메뉴 둘 다). 다시 붙일 수 없고(`KEYS` 표에 없다), 조작 설정·안내 글에 보이지 않는다.
- **이동 키 넷(위·왼쪽·아래·오른쪽, 기본 W·A·S·D)은 다시 붙인다**: `Bindings::moves`, `bind_move`. 동작 키 일곱과 합쳐 열한 칸에서 한 키는 한 칸에만 — 겹치면 맞바꾼다(ESDF로 바꾸면 E를 쓰던 "다음 아이템"이 W를 가져간다). 시험 `move_keys_rebind_and_swap_with_actions`.
- `KEYS` 표 끝에 W·A·S·D를 붙였다(저장 번호는 표 자리라 끝에만 붙인다 — 옛 저장의 번호는 그대로).
- 조작 설정 첫 줄 **"이동"**(`act_move` 열한 언어): 키보드 칸은 지금 걷는 키("WASD"·"ESDF" — 배열 글자, 0282), 확인하면 **↑ ← ↓ → 차례로** 넷을 받는다(칸에 "↑ 누르세요… 5"). 패드 칸은 "스틱"(고정, 흐리게, 고르면 거절 소리).
- 줄이 하나 늘어 **"기본값으로 | 돌아가기"를 마지막 한 줄에 반씩**(좌우로 고른다) — 창 크기는 그대로.
- 고정 안내 글(`ctl_fixed`)에서 이동 부분을 뺐다(열한 언어): 화살표는 안 보이고, WASD는 위 줄에서 바꾼다. 0282의 `{0}`도 없어졌다.
- 저장: prefs 칸 24..28 = 이동 키 번호 + 1(0이면 기본 W·A·S·D). 뒤에 붙인 칸이라 `MAGIC`은 그대로. 옛 표에는 W·A·S·D가 없어 옛 저장의 동작 키와 겹치지 않는다.
- 안내의 걷기 동사(`Verb::Walk`)는 지금 이동 키 넷의 이름("WASD", 긴 이름이 끼면 띄운다 "Tab A S D").

## 확인
