# 0178. 안내 화면(일시정지·타이틀의 "안내")과 산딸기다운 산딸기

- 날짜: 2026-10-27
- 상태: 채택. 사장: "메뉴에 각 인게임 기능들에 대한 안내가 있었으면 좋겠어. 지금은 튜토리얼을 지나가면 알아낼 방법이 별로 없네", "아이템 산딸기가 너무 산딸기 같이 그려지지 않았어".

## 안내 화면
- **왜**: 기능이 튜토리얼(0023) 한 번과 포포의 한마디에만 있었다. 강공격·박자(0174)·받아치기·솟구침 모으기·적 예고 고리(0176)·부술 수 있는 것(0177)처럼 나중에 붙은 것은 어디에도 글이 없다. 도감(적)·저널(목표)은 있는데 "내가 뭘 할 수 있나"는 없었다.
- **어디**: 일시정지 메뉴의 항목(계속·다시·설정·**안내**·타이틀로)과 타이틀 메뉴(앨범·설정·**안내**). 탭을 하나 더 두면 여섯 탭이 긴 언어에서 겹친다(0089)라 탭이 아니라 항목. `Scene::Help { back }`(`app/help.rs`), 돌아가면 온 곳.
- **모양**: 왼쪽 주제 목록(열셋, 위아래로, 다 안 들어가면 ▲▼), 오른쪽 제목 + 줄 바꿈한 설명. 설명이 한 쪽을 넘으면 확인(또는 설명 터치)으로 다음 쪽, 아래 점이 쪽 수. 주제 표는 `help.rs`(`TOPICS`: 제목·본문 `Tr`), 글은 `i18n`의 `h_*`·`h_*_d` 열한 언어(직접 번역).
- **주제**: 이동과 조준 / 발톱 콤보와 박자 / 강공격 / 굴파기와 솟구침 / 받아치기 / 필살기 / 먹기 / 적의 예고 읽기 / 반딧불과 씨앗 / 쉼터와 길 지도 / 무기와 장신구 / 부술 수 있는 것 / 마을·큰 나무·저널. 버튼 이름은 박지 않고 동작 이름(공격·굴파기·필살기·아이템)으로 — 설정의 조작 표가 버튼을 보여 준다.
- 새 기능을 넣으면 `TOPICS`에 한 줄 + 열한 언어 두 키.

## 산딸기
- 바닥의 산딸기가 3×4 빨간 네모 + 잎 하나라 "빨간 점"으로 보였다(가방 칸도 같은 모양). 산딸기는 **작은 알이 모인 송이**다: 9×10 비트맵(`render/props.rs draw_berry` — 밝은 알·빨강·어두운 틈이 번갈아, 위에 초록 꽃받침과 꼭지)으로 다시 그리고, 바닥 아이템과 가방 칸(반 배율)이 같은 그림을 쓴다. 터치 픽토그램(`Icon::Berry`)은 선 그림이라 그대로.
- 먹는 동작(세 입)은 그대로.
