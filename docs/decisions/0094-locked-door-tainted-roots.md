# 0094. 잠긴 문 = 물든 뿌리와 보라 실이 엮어 막는다(자라 닫히고 풀려 열린다)

- 날짜: 2026-10-26
- 상태: 채택. 사장: "보스방 등에서 문이 잠기는 컨셉인데, 문 자체의 퀄리티가 낮아 보여."

## 전
- 문 칸마다 갈색 막대 셋(4×16px, 외곽선 + 나무색)을 그렸다. 바로 나타나고 바로 사라졌다. 어두운 심층에서는 어둠에 묻혔다.

## 결정(`render.rs` `draw_root_gate`, `room.rs` `door_anim`·`tick_doors`)
- **그림**: 물든 뿌리 세 줄기(몸 3px: 밝은 쪽·몸·그늘 + 외곽선, 흔들리는 굵기)를 보라 실 두 가닥(밝은 실 + 어두운 그림자, 천천히 물결)이 가로질러 감는다. 문틈 뒤에 보라 아지랑이가 숨 쉰다. 이야기의 "실"(0037)이 길을 막는다는 뜻이다.
- **방향**: 남북 문은 세로 뿌리, 동서 문은 가로 뿌리. 무늬는 월드 좌표로 정해 두 칸짜리 문이 이어져 보인다.
- **움직임**: 잠그면 0.35초 동안 뿌리가 문틀에서 자라 나오고, 거의 다 자란 뒤 실이 감긴다. 방을 비워 열리면 0.5초에 걸쳐 걷히고, 문마다 보라 실이 풀려 흩어지며(쓰러진 이웃과 같은 `unravel`) 흙먼지가 인다.
- **어둠 속**: 더하기 빛 패스에 실과 문틈 빛을 한 번 더 그려 심층에서도 막힌 문이 보인다.
- 충돌은 그대로다(`doors_locked`). 그림 시계(`door_anim`)만 따로 간다.

## 확인
- 헤드리스: 콩이 방(심층) 남쪽 문을 크게 보고, 어둠 속에서 뿌리와 실이 읽히는 것을 확인했다. 열리고 닫히는 움직임은 사람 판정.
