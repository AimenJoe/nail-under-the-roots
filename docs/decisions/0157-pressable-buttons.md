# 0157: 눌리는 단추 — 슬롯 창의 시작·이어하기·덮어쓰기·지우기

- 상태: 채택 (2026-10-27).
- 사장: "이어하기의 버튼도 약간의 버튼감이 있었으면 좋겠는데.."

## 결정
1. `Ui::button(r, label, sel, edge, pressed)`: 오른쪽 아래 2px 그림자 위에 얹힌 면, 위·왼쪽 1px 밝은 모서리(빛은 왼쪽 위), 테두리 색은 고름(ACCENT)·경고(붉음)·보통(BORDER). `pressed`면 그림자 자리로 1px 내려앉고 그림자가 없어진다.
2. 슬롯 창(`app/slots.rs`): 확인(또는 탭)하면 바로 하지 않고 `slots_press`에 (슬롯, 단추, 시각)을 적어 **0.12초 내려앉은 뒤** 그 일을 한다(`slot_action`). 그동안은 입력을 받지 않는다. 설정에서 바꾼 것은 없다.
   - 누른 프레임에 내려앉은 모습이 한 번은 그려진 뒤 다음 프레임부터 시간을 재므로, 느린 기기에서도 눌림이 보인다.
3. 다른 단추(닫기 ×, 가게, 꾸미기)는 그대로다. 같은 느낌을 원하면 `Ui::button`을 쓴다.

## 왜
- 테두리 칸만 있던 단추는 "눌리는 것"으로 읽히지 않았다. 그림자와 밝은 모서리가 두께를, 내려앉음이 눌림을 준다(공식 페이지의 단추 `.btn`과 같은 문법).
- 0.12초는 메뉴 소리 길이와 비슷해 한 박자로 느껴진다(사람 판정 필요).

## 확인한 것 / 못 한 것
- 헤드리스로 평소 모습(그림자·모서리·고른 단추)을 봤다. 눌린 순간은 헤드리스 프레임(100ms 넘음)이 길어 사진으로 못 잡았다.
- 사람 몫: 0.12초가 늦게 느껴지는지, 터치에서 탭했을 때 눌림이 보이는지.
