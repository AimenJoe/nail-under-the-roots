# 0101. 굴파기: 누르고 있으면 땅속에 더 머문다(떼면 솟구침)

- 날짜: 2026-10-26
- 상태: 채택. 굴파기 명세(phase-1, "0.35초 후 또는 다시 누름 → 솟구침")에 누르고 있기를 더한다. 사장: "땅파기를 제자리에서 누른 후 움직이면 바로 튀어나오는데 이게 의도한 건가?" → 세 안(누르고 있는 동안 땅속 · 기본 시간만 늘리기 · 그대로) 중 "누르고 있는 동안 땅속".

## 전
- 땅속 시간은 0.35초로 정해져 있었다(재주 깊은 굴 0.6초·얕은 굴 0.2초). 움직임은 솟구침과 상관없었고, 제자리든 움직이든 0.367초(22틱) 뒤에 솟구쳤다(테스트로 잼). 땅속 이동 거리 약 41px라, 제자리에서 누른 뒤 움직이기 시작하면 이미 끝날 때였다 → "움직이자마자 튀어나온다".

## 결정(`input.rs` `Actions::dodge_held`, `player.rs` Burrow·`start_emerge`, `tuning.rs` `BURROW_HOLD_*`)
- **톡 누르기**: 전과 같다. 정한 시간(`burrow_time`, 재주를 따름) 뒤 솟구침. 땅속에서 다시 누르거나 공격하면 일찍 솟구침.
- **누르고 있기**: 정한 시간에 `BURROW_HOLD_EXTRA`(0.45초)까지 더 머문다(기본 최대 0.8초, 깊은 굴 1.05초, 얕은 굴 0.65초). 떼는 순간 솟구친다(정한 시간 전에 떼면 정한 시간까지는 머문다).
- **대가**: 정한 시간을 넘겨 머문 1초마다 굴파기 대기가 `BURROW_HOLD_CD`(1초) 늘어난다. 끝까지 머물면 대기 0.6 → 약 1.05초. 땅속에 숨어 지내는 쪽으로 기울지 않게(놀이 시험 2: "숨는 용도로 더 쓴다").
- **입력**: 키보드 `is_key_down`, 데스크톱·웹 패드 `is_currently_pressed`, Android 패드 F13~F25 키 `is_key_down`, 터치는 굴파기 버튼에서 시작해 아직 떼지 않은 손가락. 눌림 에지(`dodge`)와 따로 지금 상태(`dodge_held`)를 `Actions`에 싣는다.
- 모모의 깡충(회피)은 그대로.
- 튜토리얼 굴파기 힌트에 "누르고 있으면 더 오래 머문다"를 아홉 언어로 더했다.

## 확인
- `cargo test` `burrow_holds_while_pressed_and_pops_on_release`: 톡 = 0.35초·대기 그대로, 끝까지 = 0.8초·대기 늘어남, 0.6초에 떼면 0.6초에 솟구침.
- 손맛(0.45초가 알맞은지, 대기 대가가 무거운지)은 사람 판정.
