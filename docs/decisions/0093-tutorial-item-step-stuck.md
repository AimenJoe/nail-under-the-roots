# 0093. 튜토리얼 아이템 단계에서 막히던 것

- 날짜: 2026-10-26
- 상태: 채택(버그). 사장: "아이템이 안 먹어지는 버그가 있어서 튜토리얼에서 넘어갈 수 없어."

## 원인
- 아이템 단계는 "산딸기를 한 번 먹기"(`items_used`)로 넘어간다. 들어갈 때 체력을 한 칸 비우고 산딸기를 준다.
- 튜토리얼 동안은 맞지 않는다(`no_damage`). 그런데 시작 자리 곁의 저장 지점(버섯 고리)을 밟으면 체력이 가득 찬다(뿌리 심장도 같다).
- 체력이 가득이면 먹기는 아무 말 없이 무시된다(`start_eating`). 다시 체력을 잃을 길이 없으니 **영영 못 넘어간다**.

## 고침
- 아이템 단계 동안(아직 안 먹었으면) 체력이 가득이면 한 칸 비우고, 산딸기가 없으면 다시 두고, 슬롯이 비었으면 산딸기를 올린다(`tutorial.rs`).
- 체력이 가득할 때 먹기를 누르면 알림 "체력이 가득해서 먹을 필요가 없다"(`toast_eat_full`, 아홉 언어). 버퍼를 비워 프레임마다 다시 뜨지 않는다. 아무 반응이 없으면 고장으로 보인다.
- 테스트: 튜토리얼 테스트에 "체력 가득 + 산딸기 잃음 → 다시 먹을 수 있게"를 더했다.
