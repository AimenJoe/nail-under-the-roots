# 0117. Naïl 결의 표정 다시 그리기 + 얼린 팔레트

- 날짜: 2026-10-26
- 상태: 채택. 0108의 결의 표정을 바꾼다.

## 맥락
- 사장: "결연한 표정 너무 표독스럽네." 예전 결의는 눈썹이 눈 바로 위까지 깊게 꺾이고 입을 굳게 다물어, 대화창에서 화남으로 읽혔다. 아기 두더지가 처음 혼자 길을 나서는 장면이라 "겁나지만 마음먹은 다정한 결의"가 맞다.

## 결정
- 보통 표정 하나만 첨부해 다시 그렸다: "brows only slightly lowered … not angry; eyes open, bright and steady … same lavender eye color; a small, firm but soft closed mouth with the corners very slightly up … never fierce or angry". 원본은 1024px(나머지는 512px)지만 틀이 0.1% 안에서 같다.
- 눈 색을 프롬프트에 적어 처음부터 연보라로 나왔다 → 예전 결의의 호박색 눈 고침(`_eyes_to_lavender`)을 뺐다.
- **얼린 팔레트**(`frozen_palette`, `tools/art/sources/ai/nail_palette.png`): 확인을 받은 Naïl의 팔레트 64색을 **원래 순서대로** 파일로 두고, 표정들은 그 팔레트에 맞춰 찍기만 한다. 결의만 바뀌고 나머지 표정·털빛 변형 칸은 커밋된 그대로다(바뀐 칸 3·21·25·29).

## 함정
- **표정 하나를 다시 그려도 팔레트를 다시 만들면 다른 표정이 바뀐다**: 처음엔 네 표정으로 팔레트를 새로 만들었더니 기쁨의 볼이 (157,72,80) → (149,62,61) 진한 빨강이 됐다. 털빛 변형에서는 주둥이 중간 단이 털로 칠해졌다(주둥이 지키기가 색 경계에 기대서, 팔레트가 조금 바뀌어도 갈린다).
  - 세 표정으로만 만들어도(예전 결의 점이 빠져) 같지 않았다.
  - 주둥이 지키기를 넓히면(가까운 밝은 덩어리 묶기·세로 채우기) 그늘이 주황 점으로 남아 더 나빴다 → 되돌림.
- **PIL은 팔레트 순서에 따라 결과가 다르다**: 같은 색 64개라도 순서를 바꾸면 칸마다 2~8점이 달랐다(팔레트에 맞춰 찍을 때 정확한 최근접이 아니라 줄인 정밀도의 캐시를 쓴다). 그래서 예전 코드를 그대로 돌려 순서까지 꺼내 얼렸다.

## 확인
- 색까지 비교: 커밋된 시트와 다른 칸은 3·21·25·29뿐이다.
- 헤드리스: 개발 → "오프닝 컷씬"에서 엄마 다음 Naïl의 "응. …다녀올게!"에 새 결의 표정이 나온다. 눈썹이 조금 내려가고 입꼬리가 살짝 올라가, 화남이 아니라 용기로 읽힌다.
