# 0152: 타이틀 메뉴·내레이션 뒤의 네모 그늘을 없앤다

- 상태: 채택 (2026-10-27).
- 사장: "오프닝에서 내레이션 나오는 부분이 미묘하게 거슬린다. 타이틀 화면의 저 메뉴 뒤쪽 음영 배경 때문에.."

## 무엇이 거슬렸나
- 타이틀: 메뉴 뒤에 크기가 정해진 어둠 네모 두 겹(166×98)이 늘 깔렸다. 그래서 줄이 넷뿐인 첫 화면에서는 아래가 비었고, 밝은 노을 하늘 위에 모서리가 보였다. 고른 줄도 채운 막대(불투명 네모)였다.
- 오프닝 내레이션: 일러스트 위에 반투명 네모 띠(8, 132, 304×42)가 떴다. 양옆·위 모서리가 그림 위에 놓인 UI 상자처럼 보였다.

## 결정
- **둥근 그늘**(`Renderer::draw_soft_shade`):
  - 빛 얼룩 텍스처(가운데 진하고 바깥으로 부드럽게 0)를 어둡게 칠해 깐다.
  - 타이틀은 메뉴 줄 수에 맞춰 깐다(진하기 0.55). 고른 줄은 막대 대신 그 글 둘레에 그늘(0.75) + ▶ + 밝은 글이고, 다른 줄은 흐린 글이다.
- **내레이션**: 네모 대신 화면 아래(y 112 → 끝)에서 위로 옅어지는 어둠을 깐다(아래 0.72, 부드러운 곡선). 양옆·위에 모서리가 없다. 글에는 어두운 테두리를 둘러 밝은 그림 위에서도 읽힌다.
- 대화창(이름표·초상화가 있는 JRPG 창)은 그대로 둔다. 창이라는 것 자체가 정보라서다.

## 확인
- 헤드리스: 타이틀(줄 넷·여섯, 한국어·독일어), 오프닝 내레이션 세 장.
- 넘침 검사(F3): 타이틀·오늘의 굴 화면을 한국어·독일어·일본어·러시아어로 돌렸고 걸린 것이 없다.
- KB 도트 아트 안내의 "메뉴 뒤에는 옅은 어둠 네모 하나"를 고쳤다.
