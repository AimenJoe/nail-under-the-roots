# 0072. 컷씬 일러스트 v4: 초상화 v4의 털 규칙을 일러스트에도(비교 시험)

- 날짜: 2026-10-26
- 상태: 시험(`NAIL_ART_V4=1`일 때만. 기본 출력·v2 출력은 그대로)

## 배경
초상화는 v4가 기본이 됐다(0071). 일러스트는 아직 v1(색조 이동 전)이라 두 가지가 어긋난다.
- 대화창 초상화와 일러스트 속 털 동물의 색·털 느낌이 다르다.
- Naïl 초상화에는 목도리가 있는데, 일러스트의 Naïl에는 없다.

## 결정(`tools/art/illust.py`, V4는 V2를 켠다)
일러스트 생성기는 재질 대신 마스크를 칠하므로, 같은 규칙을 마스크판으로 다시 짰다.
- `shade()`: 털 경사(`FUR_RAMPS`: Naïl·엄마·보리·모모·도토)면 두 가지를 한다.
  - 단 경계를 털 뭉치로 휜다(`fur_clumps`, 빛 방향 톱니 워프). 톱니 주기는 인물 크기에 맞춘다(4.6~11px).
  - 가장 밝은 단을 작은 덩어리로 줄인다.
- `tufted()`: 털 덩어리 마스크에 삐침을 더한다.
  - 일러스트는 인물이 초상화보다 몇 배 크다. 1px 도장은 2px 바깥선에 묻혀 가는 송곳털(고슴도치)로 보였다. 그래서 인물 크기에 비례하는 뭉툭한 삼각형으로 찍는다.
  - 길이·간격은 섞는다.
  - 윗선은 끝이 뒤쪽 위, 뒤쪽 옆선은 끝이 뒤쪽 아래를 본다. 정면(모모)은 양옆 모두에 찍는다.
- `lit_outline()`: 털 덩어리의 빛 쪽 바깥선을 둘째 단으로 칠한다.
- Naïl(`mole(ramp=FUR)`): 정수리 한 가닥을 얹고, 목도리를 두른다.
  - 옆모습엔 목이 없다. 곧은 띠는 어깨띠, 기운 띠는 막대로 읽혔다. 그래서 머리 둘레(몸과 맞닿은 쪽)를 감은 깃으로 그린다.
  - 매듭은 머리 뒤 아래에 둔다. 앞에 두면 앞발에 가린다. 꼬리는 매듭에서 아래로 늘어진다.
- 엄마는 목도리를 떠 준 쪽이라 목도리가 없다.

## 남은 것
- 기본값으로 바꿀지는 사장이 비교를 보고 정한다. 바꾸면 `assets/art/illust/*.png`와 공식 페이지 일러스트를 다시 만든다.
- 작은 Naïl(s ≤ 22)에서는 목도리가 몇 픽셀 띠로만 보인다.
