# 0121. 콩이 대화 초상화(나노바나나)

- 날짜: 2026-10-26
- 상태: 채택. 0120(수수)에 이은 열두째. 물든 콩이(칸 35)는 따로.

## 결정(`tools/art/ai_portraits.py` `kongi`, `tools/art/sources/ai/kongi_{normal,happy}.png`)
- 칸 36~37(보통 = 조금 뽐내는 차분함, 기쁨 = 감은 눈 웃음). 원본이 칸을 채워 틀은 그대로.
- 시트의 앞모습은 귀가 토끼 귀처럼 길고 주둥이가 짧았다. 칸에서 모모(토끼)와 헷갈릴 수 있어 시트를 고치지 않고, 초상화를 **3/4 모습 기준**으로 그리며 "길고 가는 주둥이, 짧고 뾰족한 잎 모양 귀(not long rabbit ears)"를 박았다. 대화창 초상화는 모두 오른쪽을 보니 3/4 모습과도 맞는다.
- 틈 지우기(`HOLES`)는 켜지 않는다: 원본에서 잡힌 "둘러싸인 배경색 덩어리"(1,829점)는 틈이 아니라 주둥이 위 머리 판의 밝은 테두리였다. 켜면 지워진다.

## 확인 범위를 고침
- 지금까지 "바뀐 칸" 비교를 칸 0~35만 했다. 시트는 4줄 48칸이다. v0.1.18 시트와 다시 견주니 바뀐 칸은 0~3·5~34뿐이고 35~47은 그대로다. 앞으로 48칸을 다 본다.

## 확인
- 색까지 비교(48칸): 커밋된 시트와 다른 칸은 36·37뿐이다. 공식 페이지 콩이 그림(`site/img/p_kongi.png`)도 다시 만들었다.
- 헤드리스 대화는 못 봤다: 돌아온 콩이 대사는 보스를 이긴 뒤와 마을에서만 나온다.
