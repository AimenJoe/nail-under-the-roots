# 0109. 포포 대화 초상화(나노바나나) + 캐릭터마다 틀 맞추기·채도 높은 색 따로

- 날짜: 2026-10-26
- 상태: 채택. 0108의 둘째 캐릭터. 사장이 시트 → 보통(귀 더하기 고침) → 기쁨 순서로 그렸다.

## 결정(`tools/art/ai_portraits.py` `CHARACTERS`·`_fit`, `tools/art/sources/ai/popo_{normal,happy}.png`)
- 칸 5~6(보통·기쁨). 원본은 1024×1024(Naïl은 512). 로고 자리는 크기에 맞춰 늘린다.
- **틀 맞추기**: 캐릭터 영역이 Naïl은 칸 높이의 94%, 포포는 71%라 대화창에서 포포가 작아 보였다. 표정들을 합친 캐릭터 영역으로 같은 정사각형을 잘라 높이 92%, 가슴 아래 2%는 칸 밖으로. Naïl은 그대로(기준).
- **채도 높은 색 따로**(캐릭터마다 켬): 포포의 노란 연필이 회색 털에 밀려 황토색이 됐다. 채도 0.45 넘고 밝기 0.45 넘는 점에 팔레트 16칸을 따로 뗀다. Naïl에는 켜지 않는다. 켜면 나머지 색의 나뉨이 달라져 주둥이 중간 단이 털과 묶이고 털빛 변형의 주둥이가 물들었다.
- 연필은 그림 왼쪽 귀 앞(예전 초상화는 오른쪽). 왼쪽도 "귀에 꽂은 연필"로 읽혀 더 고치지 않았다(고칠수록 앞서 고친 것이 되살아나기 쉽다).

## 함정
- **PIL `getbbox()`는 RGBA에서 투명도만 본다**(`alpha_only=True`가 기본). 칸마다 바뀌었는지 볼 때 색이 달라도 모양이 같으면 "같다"고 나온다. 0108의 "칸 0~3·18~29만 바뀜" 확인도 처음엔 모양만 본 것이었다. `getbbox(alpha_only=False)`로 다시 재 0108 커밋은 맞았다(Naïl 칸만, 확인한 그림과 같음). 이번 채도 색 분리를 모든 캐릭터에 켰을 때 Naïl이 바뀐 것도 이걸로 찾았다.
- 다른 캐릭터 초상화(귀 없는 Naïl)를 크기 맞춤으로 첨부하자 포포의 귀가 사라졌다 → 시트에서 귀를 가져오게 고쳤다(`nano-banana-prompts.md` 0-2).

## 확인
- 색까지 비교: 커밋된 시트와 다른 칸은 5·6뿐이다. 88×88에서 포포가 Naïl과 같은 크기이고 연필이 노랗다.
- 헤드리스: 마을 첫 대화(포포)에 새 기쁨 표정이 나온다. 공식 페이지 포포 그림(`site/img/p_popo.png`)도 다시 만들었다.
