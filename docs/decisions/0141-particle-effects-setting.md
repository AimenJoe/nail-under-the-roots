# 0141. 입자 효과 설정(접근성)

- 날짜: 2026-10-27
- 상태: 채택. v0.3.0 조건 8(0081·0140). 흔들림 설정은 있었고 입자를 줄일 길이 없었다.

## 결정
- 설정에 **입자 효과** 줄(0~100%, 기본 100%)을 화면 흔들림 다음에 둔다. 아홉 언어(입자 효과·Particles·パーティクル·粒子效果·Partículas·Particules·Partículas·Partikel·Частицы).
- 줄이는 것:
  - 월드 효과 가운데 장식(먼지·흙덩이·불똥·반짝임·풀리는 실, `FxKind` Puff·Clod·Spark·Glint·Thread). 새로 생긴 것을 그 비율만 남긴다(`World::thin_fx`).
  - 환경 입자(꽃가루·포자·빛 알갱이, `draw_ambient`), 컷씬 일러스트 입자, 타이틀의 반딧불·보라 알갱이.
- 남기는 것: **고리(Ring)**. 솟구침 충격 고리·벽 쿵 고리처럼 공격이 닿는 범위를 보여 주는 놀이 정보다. 더하기 빛(모닥불·버섯·반딧불의 빛)도 입자가 아니라 그대로.
- 고르는 법: 난수를 쓰지 않고 몫을 쌓아 고르게(0.5면 둘에 하나). 게임 난수 차례가 설정에 따라 바뀌지 않게.
  - 월드 효과는 어디서 만들든(월드·모험·컷씬) `World::tick` 끝 한 곳에서 거른다. `fx` 앞쪽의 이미 거른 개수를 세어 두고(끝난 효과를 지울 때도 셈을 맞춤) 새로 붙은 것만 본다. 0이면 하나도 그리지 않는다.
- 저장: prefs 칸 19(입자+1). 옛 저장(0)은 기본 100%로 읽는다(MAGIC 그대로).
- 설정 줄이 열이 되어 창(아홉 줄)을 넘는다 → 고른 줄이 보이게 굴린다(개발 목록과 같은 방식), 가려진 줄이 있으면 ▲·▼.

## 확인
- 단위 테스트: 50%면 먼지 열 중 다섯 + 고리는 남음, 거른 것은 다시 거르지 않음, 0%면 장식 없음 / prefs 왕복·옛 저장은 100%.
- 헤드리스(960×540, F3 넘침 검사 켬): 한국어·일본어·러시아어·포르투갈어에서 설정 창 처음·끝(굴린 뒤) 화면, 넘침 보고 없음.

## 바깥 자료
- 접근성 지침들은 번쩍임·흔들림·움직이는 배경을 줄이거나 끄는 설정을 따로 두라고 한다(게임 접근성 지침, 2차 — 이번에 원문을 다시 읽지 않았다).
