# 0023: 튜토리얼 = 라쿤 포포가 단계마다 짧게 말하고 그 자리에서 해 보기(9단계)

- 상태: 채택 (2026-10-25, 사장 지시: "처음 우릴 도와서 알려주는 녀석은 라쿤", "기능이 늘었으니 튜토리얼을 체계적으로")
- 후속(2026-10-26 점검): 튜토리얼 끝은 0032가 공터 보스(보리)로 이었다(`open_glade`, `popo_glade`).

## 결정
1. **안내자**: 라쿤 **포포**(물들지 않은 이웃). 오프닝 끝에 뛰어와 돕겠다고 하고, 튜토리얼 동안 Naïl 뒤를 따라다닌다(`world.npc`). 대화창 초상화 2칸(보통·기쁨), 월드 그림은 `critters.png` 라쿤 줄.
2. **9단계**: 이동 → 발톱 줍기 → 3연타(허수아비) → 굴파기(연습 다람쥐의 도토리) → 솟구치기 → **패링**(도토리 받아치기, 30초 못 하면 "괜찮아" 하고 넘어감) → **필살기**(포포가 게이지를 채워 주고 허수아비 둘) → **아이템**(체력을 하나 깎고 산딸기를 줌, 지렁이 설명) → 메뉴·지도·저장 지점 안내.
3. 각 단계: 포포의 말 1~4줄(대화 컷씬, 월드 멈춤) → 화면 아래 힌트 "[n/9] {버튼} …" → 월드 통계(이동 거리, 마지막 타 명중, 굴파기·솟구침 명중·패링·필살기·먹기 횟수)가 늘면 다음.
4. 연습 동안은 맞아도 체력이 줄지 않는다(`world.no_damage`). 넉백·번쩍임은 있다.
5. 아레나에서 시작하면 끝난 뒤 웨이브 1, 필드면 그냥 걸어서 떠난다. 포포는 그 자리에 남는다.

## 왜
- 0009의 "상황이 가르친다"는 유지하되, 기능이 아홉 가지로 늘어 한 줄 힌트만으로는 순서와 이유가 안 보였다. **한 번에 하나**, 짧게 말하고 바로 해 보기(온보딩 관례: progressive disclosure, learning by doing — 2차 출처: 게임 UX 블로그·GDC 2016 Hodent 강연 소개글).
- "[n/9]"는 얼마나 남았는지 보여 줘 지루함을 줄인다. 버튼 이름은 지금 배치(0022)를 따른다.
- 패링은 실패가 잦은 기술이다. 막히면 진행이 멈추므로 시간으로 풀어 준다(익히는 건 실전에서).
- 연습에서 죽으면 배우는 게 아니라 벌을 받는다 → 체력은 줄지 않게.

## 재검토 조건
- 사람이 해 보고 "길다"면 6~8단계(패링·필살기·아이템)를 첫 던전 안의 상황 튜토리얼로 옮긴다.
- 포포의 말투·이름은 바꿀 수 있다(`src/i18n.rs`의 `popo_*`).
