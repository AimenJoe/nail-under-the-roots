# 0238. Naïl·콩이 스프라이트와 큰 나무를 처음부터 다시

- 날짜: 2026-10-29
- 상태: **제안**(그림은 사장이 Gemini 앱에서 받는다). 사장: "큰 나무도 좀 못생겼음... 명색이 주인공인데.. 두더지 스프라이트랑 아르마딜로 스프라이트는 처음부터 다시 만들고 싶을 정도."

## 지금
- **Naïl**(0206): 시안 1 몸 + 둥근 시트 얼굴을 붙인 24칸(게임 32칸 자리). 작게 줄이면 갈색 덩어리 + 주황 목도리 — 두더지라는 말을 코·목도리가 하고 있다. 0206에서도 같은 문제를 두 번 고쳤다(덩어리 → 실루엣 시안 1 → 얼굴만 갈아입기).
- **콩이**(0217): 옆모습 아르마딜로, 띠가 세로 줄 몇 개, 얼굴이 작고 밋밋하다. 공 두 칸은 줄무늬 원.
- **큰 나무**(0045·0065·0224): 코드로 그린 네모 줄기·선 뿌리 + Sunnyside 팩 둥근 나무 잎을 겹친 것. 마을에서 유일하게 새 그림 문법(굵은 외곽선·결)이 아닌 큰 물건이고, 이야기(나무가 다시 핀다)의 얼굴이다. 0224의 B 순서로 남아 있던 것.

## 정하는 것(제안)
1. **생김새부터**: 바로 도트 시트를 청하지 않고 큰 그림 여섯 안(3×2)을 받는다 → 사장이 고른다 → 우리가 실제 크기로 줄여 한 색 실루엣 시험(0206 방식) → 도트 시트. 이번에는 처음부터 "28~30px에서 실루엣으로 읽혀야 한다"를 프롬프트에 박는다(Naïl: 옆으로 편 큰 삽 손·크림 발톱·큰 둥근 분홍 코, 콩이: 띠 셋 + 머리·꼬리 방패·큰 귀).
2. **붙이는 그림**: 사장이 좋다고 한 새 그림(모모·도토·포포·수수·보리)만 모은 그림체 판 `ref_redo_style.png`(`tools/art/redo_ref.py`). 지금 Naïl·콩이는 붙이지 않는다.
3. **큰 나무는 두 장**(시든·다 핀, 줄기·뿌리 같게) → 자람 단계는 우리가 잎 덩어리를 잘라 얹어 만든다. 다섯 장을 따로 받으면 줄기가 단계마다 바뀐다.
4. 프롬프트: `docs/art/redo-nail-kongi-tree-prompts.md`. 변환은 지금 길 그대로(`nail_ai.py`·`kongi_ai.py`·`hub_ai.py`, `check_rebuild.py`).
