# 0065: 큰 나무와 들판 나무에 Sunnyside를 쓴다

- 상태: 채택 (2026-10-25). 0010(환경은 Sunnyside)의 첫 적용. 0064(보고 고르기 허용) 뒤.
- 후속(2026-10-26 점검): 배포 빌드는 지금 모든 CI(웹·Android·iOS)가 `ASSETS_REPO`·`ASSETS_TOKEN`으로 팩을 받는다(0077). 공개 레포의 Actions 아티팩트(APK·ipa·web-dist)에도 팩 그림이 들어간다 — 사장 판단으로 그대로 둔다(0088).
- 사장: "저 나무 같은 건 진짜 에셋이 필요하겠다." → "웹에 있는 프리뷰를 보고 골라서 사용하자"(0원으로 받음).

## 고른 것(팩을 보고)
- 단독 나무는 둥근 나무 `Elements/Plants/spr_deco_tree_01_strip4.png`(32×34 × 4칸, 바람에 흔들림)와 뾰족 나무 `tree_02`뿐이다. 큰 나무 한 그루짜리 그림은 없다.
  - 16px 타일셋 (851, 16)의 122×130은 둥근 나무 14그루 숲 무더기다.
  - 왼쪽 아래 큰 덩어리는 나무가 아니라 바위 기둥이다.
- 그래서 **마을 큰 나무 = 우리 줄기·뿌리 + 팩 둥근 나무의 잎(위 22px) 무더기**로 정했다.
  - 잎 무더기 수는 잎 단계를 따른다: 1 → 3, 2 → 7, 3 → 10, 4 → 12. 3부터 분홍 꽃은 직접 찍는다.
  - 무더기마다 흔들림 칸이 어긋난다.
  - 0단계(아직 안 깸)는 예전 마른 가지 그대로다.
- 마을 지도에서 큰 나무는 위쪽 가장자리 가까이 선다. 잎 꼭대기가 밑동 위 60px 안에 들어오게 줄기를 22px로 줄였다(처음 46px는 잎이 화면 밖으로 나갔다).
- **들판의 나무(T, 예전 그루터기)**: 꽃 핀 입구(Meadow)에서는 팩의 흔들리는 둥근 나무다. 충돌은 밑동 한 칸 그대로. 뿌리 지대·심층은 그루터기 그대로.

## 팩이 없을 때
- `Art::sunny`는 팩 파일이 있을 때만 읽는다(`assets/vendor/sunnyside/…`).
- 공개 CI(비공개 에셋 레포·토큰 없음)는 지금처럼 직접 그린 그림으로 빌드된다.
- 배포에 넣으려면 0010의 비공개 레포(`ASSETS_REPO`·`ASSETS_TOKEN`)가 있어야 한다. 사장 판정 전이다.
