# 0274. 다시 시작·타이틀로는 한 번 묻는다, 공터 굴 입구도 버튼으로, 첫 꽃잎은 공터 문 앞

- 날짜: 2026-11-03
- 상태: 채택(v0.8.x 패치). 0060(출구는 밟는 순간에만)의 공터 입구 몫을 바꾼다. 0190·0194의 꽃잎 하나는 그대로, 자리만.
- 사장: "모모의 첫 꽃잎이 보스방에 좀더 가깝게 있어야 함. 그리고 보스 잡은 후, 내려가기 없이 바로 화면 이동하도록
  되어 있는거 다른 화면처럼 버튼 클릭 후 내려가는것으로 수정해줘. 그리고 Lab 은 '타이틀로 가기' 위, 설정 아래 쪽에
  위치해야할듯 (인게임에서). 다시시작 이나, 타이틀로 가기에는 확인/취소 다이얼로그가 필요함."

## 왜
- **공터 입구**: 굴 출구는 2026-10-30부터 곁에서 확인 버튼으로 내려가는데(`Interact::Exit`), 필드 공터의 굴 입구(`D`)만
  밟으면 곧장 쉼터로 넘어갔다(0060). 보리를 이긴 뒤 뿌리 심장을 주우러 걷다 입구를 밟아 버리면 준비 없이 화면이 바뀐다.
  같은 일을 하는 칸은 같은 손으로.
- **묻기**: 다시 시작은 런을 버리고, 타이틀로는 굴 안의 진행을 버린다(이어하기는 마지막 쉼터부터, 0259). 메뉴에서 확인을
  한 번 더 누르는 실수로 되돌릴 수 없는 일이 일어나면 안 된다. 가게의 사기 전 묻는 창이 이미 있어 같은 모양을 쓴다.
- **Lab 자리**: 개발판에만 있는 줄이 끝(타이틀로 아래)에 붙어 "타이틀로"가 마지막이 아니었다. 떠나는 항목은 맨 아래.
- **첫 꽃잎**: 공터 문 세 칸 위(25줄)라 문과 따로 보였다. 문 바로 앞이면 "이 문 안으로 갔다"가 된다.

## 결정
- `Adventure::exit_near`가 필드에서는 대장을 이긴 뒤(`BossFight::Done`) 굴 입구 칸을 본다 → `Interact::Exit`(안내 "내려가기"),
  `use_exit`가 필드면 `Transition::EnterCamp`. `cell_triggers`의 입구 밟기는 지웠다(저장 지점만 남음).
- 일시정지 메뉴는 표 `PAUSE_MENU: [(이름, PauseItem)]` — 하는 일은 항목 이름으로 가른다(번호로 가르면 개발판 줄이 끼어들 때
  뒤가 밀린다). 순서: 계속하기·다시 시작·설정·(Lab)·타이틀로.
- `PauseItem::asks()`가 다시 시작·타이틀로에 물음을 붙인다. 창은 가게와 같이 `App::draw_ask`(물음 세 줄까지, 창 높이가 줄 수를
  따른다) + 입력 `ask_choice`(좌우 = 커서, 확인 = 커서 쪽, 뒤로·바깥 탭 = 아니오). 커서는 **"아니오"에서 시작**한다(가게는
  "사기"에서 — 사는 것은 되돌릴 수 없는 손해가 아니다). 단추 글은 하는 일 이름(다시 시작/타이틀로) + 새 글 `ask_cancel`("취소").
- 새 글 셋(열한 언어): `pm_restart_ask`("이번 런을 처음부터 다시 할까? 모은 반딧불·씨앗은 남는다." — `keep_run_currency`가
  반딧불은 마을로, 씨앗은 마을 씨앗으로), `pm_title_ask`("타이틀로 나갈까? 지금까지 모은 것은 남는다." — `suspend_run`),
  `ask_cancel`. CJK 폰트에 글자가 이미 있어 다시 만들지 않았다(`cargo test` 글자 시험).
- `field::petal_road`: 공터 문 두 칸 가운데, 문 한 칸 위(27줄). 시험이 문에서 1.5칸 안·가로 한 칸 안을 본다.

## 확인
- `cargo test`: `glade_loot_avoids_the_entrance_and_standing_on_it_does_not_enter`(밟아도·비켰다 다시 밟아도 안 내려가고,
  확인 버튼이면 내려간다), `glade_entrance_waits_for_the_chief`(대장 전엔 버튼도 없다), `field_has_start_entrance_and_save`(꽃잎 자리).
- 헤드리스(한국어·포르투갈어·러시아어·독일어·일본어): 묻는 창이 뜨고 "취소"에 커서, 물음이 두 줄 안, Lab이 설정 아래.
  F3 겹침 검사는 창 밑에 깔린 메뉴 줄과의 겹침만(가게 창과 같은 꼴).
