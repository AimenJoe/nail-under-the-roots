# 0038: 모든 행동은 바로 다시 나가지 않는다 — 먹기에 시간·대기, 패링 창에 대기

- 상태: 채택 (2026-10-25). 사장 "모든 행동에는 쿨타임이 있어야 해. 산딸기를 먹는 행동도 쿨타임이 없다면 게임이 좀 쉬워질 수 있음. 너무 길 필요는 없지만 같은 행동의 즉시 발동은 피해야지."

## 행동별로 무엇이 막나
| 행동 | 다시 나가기까지 | 비고 |
|---|---|---|
| 발톱 3연타 | 스윙 시간 + 마지막 타 후딜레이(한 바퀴 약 0.58초) | 따로 대기를 두지 않는다. 동작에 묶이는 시간이 곧 대기다. 더 넣으면 기본 손맛이 굳는다 |
| 굴파기 | `BURROW_COOLDOWN` 0.6초(장신구로 0.3~) | 그대로 |
| 필살기(드릴) | 게이지(맞혀야 참, 드릴은 게이지를 안 채움) | 그대로 |
| **먹기(산딸기·지렁이)** | **먹는 시간 0.35초(지렁이 0.6초) + 시작부터 1.5초 대기** | 새로 |
| **패링 창** | **창이 열린 뒤 0.45초 동안 새 창 없음. 성공하면 바로** | 새로 |
| 지렁이 부활(쓰러질 때 저절로) | 2초 무적 + 먹기 대기 1.5초 | 일어나자마자 산딸기를 못 먹는다 |

## 먹기
- 먹기를 누르면 `State::Eat`가 된다.
  - 걸음이 반으로 느려지고, 공격은 못 한다.
  - Naïl 입 앞에 산딸기(베어 물수록 작아짐)나 지렁이가 보이고, 머리 위에 작은 진행 막대가 뜬다.
- **다 먹어야 회복된다**(`Event::Ate` → 월드가 가방에서 꺼냄). 먹는 사이 체력이 가득 찼으면 꺼내지 않는다.
- **맞으면 끊긴다.** 먹지 않은 것으로 처리하고 아이템은 그대로 둔다. 아이 게임이라 Hollow Knight처럼 날리지는 않는다.
- **굴파기로 끊을 수 있다**(위급할 때 탈출). 이때도 먹지 않은 것으로 처리한다.
- 대기는 먹기 시작한 순간부터 센다. 끊겨도 마찬가지다. 그래서 "맞고 바로 다시 먹기"를 연타할 수 없다.
- 표시:
  - 퀵 슬롯이 위에서부터 어둡게 덮였다가 걷힌다.
  - 터치 버튼은 ITEM·DIG 테두리가 시계 방향으로 다시 차오르고, SP는 게이지만큼 찬다.
- 포포 튜토리얼 말에 한 문장을 더했다: "먹는 동안 맞으면 못 먹으니까, 틈이 날 때 먹어."
  - 다섯 언어. DeepL 초안을 고쳤다. 일본어 "殴られたら"는 너무 거칠어 "やられると"로, 포르투갈어 "levar uma surra"(두들겨 맞다)는 "te acertarem"으로 바꿨다.

## 패링 창
- 이전에는 스윙마다 첫 0.12초가 패링 창이었다. 1·2타가 0.12초짜리라 **공격을 연타하면 창이 거의 이어 붙었다.** 연타만 해도 패링이 되는 셈이었다.
- 이제는 창이 열리면 `PARRY_COOLDOWN` 0.45초 동안 다음 스윙에 창이 없다. 연타 중 창 비율은 0.12/0.45 이하다(테스트).
- 성공하면 대기를 지운다. 여러 공격을 연달아 튕겨내는 것은 보상으로 남는다.
- 노리고 한 번 누르는 패링은 그대로 된다. 0.45초 동안 휘두르지 않았으면 창은 늘 열린다.

## 왜
- **회복이 즉시면 위험이 없다.** 체력이 바닥나도 버튼 한 번으로 돌아오면 "언제 먹나"라는 판단이 사라진다. 먹는 시간은 그 판단에 값을 매긴다: 적과의 거리, 틈. 대기는 연타로 그 값을 피하는 것을 막는다.
- **실패에 대가가 없으면 연타가 정답이 된다.** 패링 창이 그 예였다(KB 패링 노트의 함정, 포럼의 "창이 열리는 순간부터 짧은 잠금" 방식).
- 발톱에 대기를 더 넣지 않은 이유: 기본 공격은 동작 시간이 이미 대기 역할을 한다. 여기에 대기를 얹으면 손맛(0009)을 해친다.
- 수치는 짧게 시작한다(사장: "너무 길 필요는 없지만"). 전부 `tuning.rs`에 있다.

## 수치 (`src/tuning.rs`)
`BERRY_EAT_TIME` 0.35 · `WORM_EAT_TIME` 0.6 · `EAT_MOVE_FACTOR` 0.5 · `ITEM_COOLDOWN` 1.5 · `PARRY_COOLDOWN` 0.45

## 확인
- 단위 테스트:
  - 연타 1초 동안 창 비율 ≤ 0.12/0.45, 성공 뒤에는 바로 창이 열림.
  - 먹는 시간 전에는 `Ate`가 없고, 대기 중에는 못 먹고, 맞으면 `Ate` 없음, 굴파기로 끊김.
- 헤드리스("장신구·필살기 확인" 시나리오):
  - 데스크톱: 먹는 그림 → 체력 +1·산딸기 −1 → 대기 중 연타는 무시 → 대기 뒤 다시 먹기.
  - 폰: ITEM 버튼 테두리가 흐려짐.
- 실기 손맛(0.35초가 답답한지, 1.5초가 긴지)은 사람이 판정한다.

## 재검토 조건
- 먹기가 답답하면 먹는 시간을 0.25초로 줄인다. 대기는 1.5초를 유지한다(즉시 재사용 금지가 핵심).
- 패링이 "안 걸린다"는 반응이 나오면 `PARRY_COOLDOWN`을 0.3초로 줄인다.
- 장신구로 먹는 시간·대기를 줄이는 효과를 넣을 수 있다(굴파기 대기 장신구처럼). 그때는 `Stats`에 배율을 둔다.
