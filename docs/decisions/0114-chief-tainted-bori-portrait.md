# 0114. 들쥐 대장(물든 보리) 대화 초상화(나노바나나)

- 날짜: 2026-10-26
- 상태: 채택. 0113(보리)에 이은 여섯째. 들쥐 대장 = 튜토리얼 보스 = 물든 보리(0032).

## 결정(`tools/art/ai_portraits.py` `chief`, `tools/art/sources/ai/chief_glare.png`)
- 칸 9(노려봄 하나). 보리 보통 표정 그림을 고쳐 그려 틀이 같다(원본 그대로).
- 물든 모모(0112)에서 배운 것을 프롬프트에 먼저 넣었다: 실은 선만큼 굵게, 귀 둘레·이마·볼·목에(높이 올려), 눈은 "숯불 같은 진한 빨강".
- **눈 팔레트를 떼지 않는다**(`NO_EYE_SPLIT`): 보랏빛(색상 0.6~0.85)에 팔레트 8칸을 떼는 규칙은 눈을 지키려던 것인데, 대장은 털이 보라 기운 잿빛이라 털이 그 칸을 다 차지했다. 보라 실이 털 색과 묶여 흰 줄로 보였다. 대장은 눈이 빨강이라 떼지 않고, 실은 채도 칸(16)으로 간다.
- **흰빛 물들이기를 캐릭터마다 지킬 자리와 함께**(`HALO`가 표 + `CHIEF_KEEP`): 실 가운데 흰빛은 보랏빛으로, 수염·눈은 그대로.
- **빨간 눈을 밝게**(`_glow_red_eyes`): 원본 눈은 검붉은 바탕에 빨간 점이라 88px에서 빛나는 눈으로 읽히지 않았다. 눈 상자 안의 빨강만 밝고 진하게 옮긴다. 실에 묶인 동물 = 작게 빛나는 빨간 눈이 이야기 약속이다.

## 확인
- 색까지 비교: 커밋된 시트와 다른 칸은 9뿐이다.
- 헤드리스: 개발 → "튜토리얼 보스"에서 공터로 걸어 들어가면 나오는 들쥐 대장 대화에 새 그림이 나오고, 빨간 눈과 보라 실이 또렷하다.
