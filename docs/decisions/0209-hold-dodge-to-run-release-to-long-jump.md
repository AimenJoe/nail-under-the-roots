# 0209. 모모·도토: 회피를 꾹 쥐면 달리고, 떼면 멀리 뛴다

- 날짜: 2026-10-28
- 상태: 채택(사장 "이 두 캐릭터는 땅파기 모으기가 없으니, 그 대신 꾹 누르면 달리기 시작, 떼면 점프 하는 식은 어떨까?" → 제안 → "괜찮은 제안 같네, 진행해")

## 왜
- 이 게임에서 "꾹 누르기"는 늘 "모았다가 떼면 터진다"다: 강공격(0161), Naïl의 땅파기(누르고 있으면 땅속에서 힘을 모으고 떼면 솟구친다, 0158). 모모의 깡충(0056)·도토의 뒤로 뛰기(0195)는 톡 하나뿐이라 같은 버튼을 쥐어도 아무 일이 없었다.
- 달리기 = 도움닫기, 떼면 멀리뛰기로 하면 같은 문법이 세 캐릭터 모두에 통한다.

## 함정: 톡/꾹을 떼는 순간에 가르지 않는다
- 다크소울·엘든링은 구르기와 달리기가 한 버튼이라 구르기를 떼는 순간에 낸다 — "구르기가 늦다"는 불만과 누르는 순간 구르게 하는 모드가 나왔다(포럼·모드 페이지, 2차).
- 우리도 같은 것을 겪었다: 강공격을 "떼면 평타"로 했을 때 모든 평타가 손을 떼는 시간만큼 늦었다(KB `concepts/melee-light-and-charged-attack-feel.md`, 0167).
- 그래서 **회피는 누르는 순간 그대로** 나가고, 내려앉을 때 아직 쥐고 있으면 달리기로 넘어간다. 톡 누름(깡충 0.34초·뒤로 뛰기 0.32초보다 짧다)은 예전과 똑같다.

## 규칙(`player/run.rs`, 수치 `tuning.rs` `RUN_*`·`JUMP_*`)
1. 깡충·뒤로 뛰기가 내려앉는 틱에 회피를 쥐고 있으면 `State::Run`: 입력 쪽으로 걷기의 1.5배. 맞는다(공중이 아니다), 발밑 함정(그물·가시·묻힌 것)도 밟는다(`on_foot`). 움직이는 동안만 도움닫기가 찬다.
2. 떼면 `State::Jump`(멀리뛰기, 0.42초, 공중 무적). 거리는 도움닫기 0.2초에서 64px, 0.7초에서 100px까지.
3. 0.2초보다 짧게 달리고 떼면 뛰지 않고 선다 — 회피 한 번으로 무적 두 번을 얻지 않게.
4. 회피 대기는 멀리뛰기가 끝난 뒤(또는 달리기를 그냥 끝냈을 때) 돈다.
5. 달리다 공격을 누르면 그 자리에서 1타, 게이지가 찼으면 특기.
6. 보상
   - 모모: 내려앉으며 둘레 밟기(반지름 22, 피해 2, 이어 뛰기 밟기의 밀침·경직). 재주 발 구르기(0142)를 골랐으면 1.3배 넓고 피해 +1 — 깡충 착지의 작은 밟기와 겹치지 않고 한 줄로 세진다.
   - 도토: 공중에서 한 번 던질 수 있다(1타 그대로, 겨눈 쪽으로). 물러나며 겨누는 몸(0195)을 살린다. 재주 떨구고 뛰기(뒤로 뛰기 자리에 도토리)는 멀리뛰기에는 붙이지 않는다(한 번 회피에 둘).
7. Naïl은 그대로(쥐기는 땅파기).

## 그림·안내
- 달리기는 걷기 두 칸을 빠르게, 멀리뛰기는 뜀 칸(도토가 공중에서 던졌으면 던지기 칸). 착지 `Event::JumpLand { stomp }` — 모모는 밟기 고리(반지름 = 타격)·흔들림, 도토는 흙먼지.
- 안내(일시정지) 열다섯째 주제 "달리기와 멀리뛰기"(`h_run`·`h_run_d` 열한 언어, 그림 `Pic::Run`: 모모 깡충 → 달리기 → 멀리뛰기 → 밟기). 일본어 새 한자로 CJK 폰트를 다시 만들었다.

## 시험
- `tap_is_still_a_plain_dodge`(톡은 예전 그대로, 누른 틱에 공중), `hold_runs_and_release_jumps_farther_with_run_up`(달리기 속도·맞음·대기, 도움닫기만큼 멀리, 짧게 달리면 안 뜀), `momo_stomps_and_doto_throws_once_in_the_air`, `attack_cuts_the_run_and_nail_never_runs`.
- 헤드리스: 빈 방에서 모모로 쥐고 오른쪽 → 깡충·달리기·멀리뛰기·착지 고리 확인(임시 빌드, 커밋하지 않음).

## 사장 확인
- 개발 "모모: 아레나"·"도토: 아레나"에서 달리기 빠르기(1.5배)·도움닫기 길이(0.2~0.7초)·멀리뛰기 거리(64~100px)가 손에 맞는지, 모모 밟기·도토 공중 던지기가 쓸 만한지.
