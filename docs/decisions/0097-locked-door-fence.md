# 0097. 잠긴 문 그림 = 팩 나무 울타리 + 감긴 보라 실

- 날짜: 2026-10-26
- 상태: 채택. 0096의 문 칸을 바꾼다. 사장: "우리가 쓴 건 사실 갑판 바닥 같은 느낌이야… 40, 1~4가 적당한 울타리야. 38,2 · 42,2 이게 남쪽 문이 되면 될 울타리."

## 전(0096)
- 남북 문에 두 짝 나무 문 칸(38,5), 동서 문에 가로 널 칸(40,5) → 통나무 칸(37,1~2)을 썼다. 위에서 보면 넓은 널판이라 문보다 갑판·나무 바닥으로 읽혔다.

## 결정(`sunny.rs` `FENCE_H`·`FENCE_V`·`FENCE_RAIL_*`, `render.rs` `fence_tile`·`draw_root_gate`)
- 타일셋 칸 번호는 (열, 줄), 16px 칸.
- **남북 문**(좌우가 벽): 가로 울타리. 왼쪽 끝 기둥(38,2) · 가운데(39,2) · 오른쪽 끝 기둥(42,2). 이웃 칸이 문인지 보고 고른다. 두 칸짜리 문이면 끝 기둥 둘이 가로대로 이어진다.
- **동서 문**: 세로 울타리. 위 끝(40,1) · 가운데(40,3) · 아래 끝(40,4). 교차 칸(40,2)은 옆으로 가로대가 뻗어 쓰지 않는다.
- **실**: 한 가닥이 가로대를 사선으로 감는다. 앞을 지나는 반만 그리고 뒤로 도는 반은 가로대에 가려진 것으로 본다. 두 가닥이 따로 물결치던 0094의 실보다 나무가 덜 가려진다.
- **아지랑이**: 문 칸 뒤 보라 네모는 가는 울타리 뒤에서 네모로 드러나 뿌리일 때만 그린다.
- 움직임(바닥에서 솟고 실이 감긴다, 0096)·빛 패스·팩이 없을 때 뿌리(0094)는 그대로.

## 확인
- 헤드리스: 콩이·모모 방 다섯 판에서 남쪽 문(가로 울타리)과 동서 문(세로 울타리)을 크게 보고, 어둠 지도 아래에서 기둥·가로대·실이 읽히는 것을 확인했다. 솟는 움직임과 실 굵기는 사람 판정.
