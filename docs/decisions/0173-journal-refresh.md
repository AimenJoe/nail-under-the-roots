# 0173. 저널 새 단장: 목록은 받을 것부터, 갈래 띠·진행 막대·보상 아이콘, 낡은 목표 손질

- 날짜: 2026-10-27
- 상태: 채택. 사장: "저널도 너무 낡았어.."(0048의 모양·목표를 v0.3.x 내용이 앞질렀다).

## 무엇이 낡았었나
- **모양**: 글자 목록(■◆□ + "3/30") 하나와 오른쪽 글 세 덩이. 받을 수 있는 것과 하는 중인 것이 섞여 있고, 갈래(이야기·싸움…)는 고른 것에만 글로 보였다.
- **목표**: 도감이 7종일 때 쓴 "모두 만났다(7종)"가 15종(0146·0165) 뒤에도 그대로. 강공격(0161·0168)·박자 콤보 같은 새 손맛에는 목표가 없었다.

## 결정
1. **목록**(`journal::visible`): 받을 것 → 하는 중 → 받은 것 순서(같은 묶음은 표 순서). 받으면 아래로 내려간다.
2. **한 줄 = 갈래 띠(왼쪽 2px, `Cat::color`) + 상태 표시 + 제목 + 진행 막대**. 상태는 받을 것 = 채운 마름모(깜박), 받음 = 체크, 하는 중 = 빈 네모. 막대는 받은 것엔 없다. 갈래 이름은 오른쪽에 글로도 나온다(색만으로 가르지 않는다, 0150).
3. **머리**: "이룸 n/m" + 받을 것이 있으면 "받을 것 k"(깜박).
4. **고른 목표**(오른쪽): 갈래(그 색)·제목·설명 세 줄까지 → 보상 아이콘(`draw_reward_icon`: 반딧불·씨앗·꾸미기 집·털빛 견본·장신구 색) + 글 → 맨 아래는 하는 중이면 "n / m" + 막대, 받을 수 있으면 **받기 상자**(테두리 깜박, 확인으로 받기), 받았으면 어디 있나(0050).
5. **목표 손질**(아이디는 그대로, 0041): `mobs2` 7종 → 10종("낯익은 얼굴들"), 새 `mobs3` = 도감 전부(`BESTIARY.len()`, "모두 만났다", 반딧불 60), 새 `heavy`(강공격 30, 반딧불 30) → `heavy2`(150, 씨앗 10). `stat.heavy_hits`를 기록에 쌓는다(`Tally`). 목표 39 → 42.
6. 글은 열한 언어. 일본어 達成·受け取れる, 간체·번체 完成·可領取·認識·之爪 글자를 폰트에 더했다(`build_cjk.py`).

## 확인
- `cargo test`(폰트 글자·저널 규칙·번역 키). 헤드리스(튜토리얼 보스 장면, 받을 것 다섯인 기록): 목록이 받을 것부터, 띠·마름모·막대, 받기 상자; 아래로 내려가면 하는 중 목표의 막대와 "0 / 10".
- 사람이 볼 것: 띠 색이 어두운 패널에서 읽히는지(색약 모드는 `tools/a11y/cvd.py`), 받기 상자 깜박임이 거슬리지 않는지, 강공격 목표 수(30·150)가 맞는지.
