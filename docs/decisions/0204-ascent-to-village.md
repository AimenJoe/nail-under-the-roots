# 0204. 엔딩 뒤 마을로 올라오기: 지층 단면을 거꾸로 + 뿌리 길 곁에서 튀어나오기

- 날짜: 2026-10-28
- 상태: 채택(사장 "할매 이후 다시 지상 마을로 가는게 제대로 표현되지 않음")

## 문제
가장 깊은 곳(할매, 0162)에서 엔딩 컷씬이 끝나면 `AfterCut::Village`가 마을을 새로 세우고 곧바로 마을 화면이었다. 내려갈 때는 쉼터·굴마다 지층 단면이 흐르고 "지하 몇 m"가 늘어나는데(0156), 130m에서 땅 위로 돌아오는 길에는 아무것도 없어 "어떻게 마을에 왔는지"가 안 보였다. 게다가 마을에 들어서자마자 포포의 한마디가 떠서 첫 화면을 말풍선이 덮었다.

## 정한 것
- **올라오는 전환 `Transition::Ascend`**: 내려가기와 같은 단면(`render/descent.rs draw_descent`)을 거꾸로 쓴다. 깊이는 가장 깊은 곳(130m) → 0m(HUD의 "지하 몇 m"가 줄어든다), 판 굴은 Naïl **아래**, 굴 벽 부스러기는 아래로 떨어지고, 앞으로 튀는 흙은 머리 위로, 파 내려가기 그림(`dig.png`)은 위아래를 뒤집어 머리가 위. 깊은 곳의 어둠·빛버섯 → 뿌리 → 겉흙 → 풀 줄·하늘을 차례로 지난다.
- 장소는 이미 마을이라 바꾸지 않는다(`swapped = true`로 시작). 엔딩이 검정으로 끝나니 **처음부터 다 덮고**, 끝 0.2만 마을과 섞인다(내려가기는 처음·끝 둘 다 섞임). 반의 길이 `ASCENT_HALF` 1.6초(내려가기 0.6초의 두 배 남짓 — 130m를 오르는 길).
- 끝나면 Naïl이 마을 시작 자리(뿌리 길 G 바로 곁, 마을 지도 P)에서 **튀어나온다**(`World::surface_burst`: 흰 고리 + 흙 고리 + 흙덩이 + 흔들림 + 큰 튀어나오기 소리 — 굴파기 튀어나오기 0090과 같은 말).
- 마을의 이야기 한마디(`story::When::Village`)는 튀어나온 뒤 `ASCENT_STORY_DELAY` 1초에(튀어나오는 모습을 말풍선이 가리지 않게). 올라오는 동안 마을 씨앗·반딧불 HUD는 숨긴다(깊이 숫자만).
- 개발 목록 "마을로 올라오기"(`Scenario::Ascent`)로 바로 본다. 시험 `ascent_climbs_from_deepest_to_village_and_bursts_out`(처음부터 덮음·깊이는 줄기만·0m·자리 그대로·흙이 터짐).

## 안 한 것
- 오늘의 굴은 그대로 타이틀로(엔딩 없음). 쓰러져 마을로 가는 길은 이번에 건드리지 않았다(쓰러짐 → 마을은 실에 잠기기 0163 등 따로).
- 파 내려가기 32px 그림(`dig.py`)은 아직 옛 옆모습 Naïl이다(0203 C3 새 옷 뒤 다시 그릴 것). 올라올 때도 같은 그림을 뒤집어 쓴다.
