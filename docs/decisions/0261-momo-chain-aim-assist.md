# 0261. 모모 이어 뛰기(필살기)에도 조준 도움

- 날짜: 2026-10-30
- 상태: 채택(사장 "모모의 필살기도 다른 두 캐릭터 처럼 조준 지원이 필요함.")

## 규칙
- 이어 뛰기를 시작할 때와 뛰기마다 다시 겨눌 때, 입력(없으면 보던 쪽) 방향의 원뿔(`CHAIN_ASSIST_CONE` 0.6rad) 안, `CHAIN_ASSIST_RANGE`(180px = 세 번 뛰는 거리) 안의 적 가운데 방향이 가장 가까운 적 쪽으로 방향을 맞춘다(`chain_assist`, 드릴 0139와 같은 규칙 `assist_target`).
- 적이 없으면 예전처럼 입력 방향 그대로.

## 보이는 안내(사장 "보이는 안내도 있어야지")
- 게이지가 찬 모모가 서 있거나 뛰는 중이면 첫 내려앉을 자리에 밟기 반지름 고리 + 가는 길의 점, 적에게 붙으면 그 적에 꺾쇠(`Player::chain_preview`, `render/actors.rs draw_chain_aim`). 멀리뛰기 조준(0211·0213)과 같은 그림 말.
