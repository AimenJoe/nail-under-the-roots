# 0107. 컷씬 일러스트를 나노바나나로 시험해 그린다(직접 그린 그림만 참고로)

- 날짜: 2026-10-26
- 상태: 시험. 첫 결과로 Naïl 대화 초상화를 넣었다(0108). 사장: "각 일러스트를 나노바나나에 넣으려고 하니, 프롬프트 만들어 줘."
- 지금까지 AI로 만든 그림은 사장이 정할 때까지 넣지 않았다. 사장이 컷씬 일러스트에 나노바나나(Google Gemini 이미지 모델)를 쓰기로 했다.

## 정한 것
- 프롬프트는 `docs/art/nano-banana-prompts.md`: 공통 스타일 + 세계 규칙 + 캐릭터 + 장면(11장 + 타이틀 바탕). 영어. 장면 사양은 `cutscene-illustrations.md` 그대로.
- **참고 그림은 직접 그린 것만**: 초상화(`portraits.png`)를 키운 캐릭터 시트와 지금 임시 일러스트(구도). 팩 그림·팩이 섞인 게임 화면은 넣지 않는다(0064). 다른 작가 이름·화풍도 넣지 않는다.
- 나온 그림은 Claude가 게임 크기로 잘라 픽셀 격자·팔레트·안전 영역·색 약속을 맞춘 뒤 넣는다. 원본(큰 그림)도 따로 받아 둔다.
- 넣을 때 `assets/LICENSES.md`에 AI로 만든 것(모델·날짜·만든 사람)을 적는다. 사람이 그린 그림으로 바꿀 때는 `cutscene-illustrations.md`의 계약 항목을 따른다(외주 작가에게는 AI를 쓰지 않는다는 약속을 받는다 — 이 시험 그림과는 따로).

## 고친 것(같이)
- `cutscene-illustrations.md`의 모모 눈 색이 0049와 거꾸로였다(돌아온 모모 = 초록 눈으로 적혀 있었다). 0049·초상화·임시 일러스트는 물든 = 초록 빛 눈, 돌아옴 = 검고 맑은 눈이다. 문서를 그쪽으로 고쳤다. Naïl의 빨간 뜨개 목도리, 모모의 접힌 귀 끝, 보리의 이마 흉터도 인물 메모에 더했다.

## 함정
- 한 대화에서 여러 장면을 이어 그리면 앞 그림이 섞이고 생김새가 흐트러진다 → 장면마다 새 대화(공식 블로그 "Fix character consistency drifts").
- 비율이 다른 그림을 여러 장 넣으면 마지막 그림의 비율을 따른다(공식 블로그) → 게임 그림과 같은 비율의 구도 그림을 맨 마지막에.
- Nano Banana 2 Lite는 참고 그림 여러 장·여러 번 고치기에 맞추지 않았다(공식 문서) → 2.1 또는 Pro.
- 도트처럼 보여도 진짜 격자가 아니다(한 칸이 6·7px로 들쭉날쭉, 2차) → 가장 큰 해상도로 받고 격자는 뒤에서 맞춘다.
- 참고 그림 없이 이름·종족 글만 주면 흔한 그림으로 채운다(첫 시험: 할매 → 빨간 독버섯 할아버지, 수수 → 사슴벌레, 모모 → 흰 토끼, 없는 이웃 넷).
- 처음엔 Google 문서가 세션 네트워크에서 막혀 2차 출처로 썼다. 사장이 `ai.google.dev`·`developers.googleblog.com`·`www.spritecook.ai`를 허용한 뒤 1차 출처로 다시 확인했다(WebFetch는 여전히 실패, `curl`은 프록시로 된다).
