# 0015: 대화창 초상화는 게임 픽셀의 2배 밀도 도트, 코드로 그린다

- 상태: 채택 (2026-10-25)

## 맥락
사장 요청: 캐릭터별 초상화. 도트지만 공을 많이 들여 해상도가 높은 것처럼. 그동안 대화창 초상 자리는 색 네모였다.

## 결정
1. **크기·밀도**: 원본 88×88을 대화창의 44×44(게임 픽셀) 칸에 찍는다 → 원본 1px = 게임 픽셀 반. 화면 배율 4(1280×720)면 원본 1px = 화면 2px.
   배율이 홀수면 원본 1px = 내림(배율/2) 화면 px로 조금 작게 찍어 픽셀 크기를 고르게 둔다(반 픽셀 번짐 금지).
2. **원본은 코드**(`tools/art/portraits.py` → `assets/art/portraits.png`, CLAUDE.md "PNG를 손으로 고치지 않는다"): 부위를 타원으로 놓고 재질마다 4~5단 색 경사, 왼쪽 위 빛으로 구 음영 + 단 경계만 2×2 디더, 털 뭉치 윗선, 털 결, 선택 외곽선(검은 선 대신 이웃 재질의 가장 어두운 색), 뒤쪽 가장자리 반사광, 눈의 큰·작은 흰 반사와 아래쪽 푸른 반사광, 볼 홍조 디더. 팔레트는 게임 스프라이트(tools/art/nail.py)를 늘린 것.
3. **표정**: Naïl은 보통·기쁨·걱정·결의 4칸. 컷씬 `Step::Say`에 `face`. 배우마다 `Portrait`(시트 첫 칸, 표정 여부).
4. **이웃은 아직 그림자**: 오프닝의 "???"는 정체가 정해지지 않았으므로 그림자 몸 + 빛나는 눈 + 몸을 감은 뿌리. 종을 정하면 그 칸만 바꾼다.
5. **얼굴 근처에 크림·분홍을 붙이지 않는다**(스프라이트 v1의 교훈): 배 쪽 밝은 털을 넣었더니 발톱·발과 함께 "벌린 입과 이빨"로 읽혀 뺐다. 입은 코 아래 작은 ω.

## 왜
- 게임 화면(320×180)은 픽셀이 굵다. 초상화를 같은 굵기로 그리면 44×44에 얼굴 표정을 담기 어렵다. 2배 밀도는 JRPG 대화창에서 흔한 선택이고, 정수 배율이라 도트 느낌은 남는다.
- 코드로 그리면 표정·색을 고칠 때 전체가 함께 바뀌고, 캐릭터가 늘어도 같은 그림체가 유지된다(같은 경사·빛·외곽선 규칙).

## 비용
- 손 도트만큼의 섬세함(털 한 올, 표정의 미묘함)은 아니다. 피드백을 받아 좌표·경사를 조정한다. 정말 손이 필요한 칸은 생성 뒤 패치 레이어(덧칠 좌표 목록)를 스크립트에 둔다.

## 재검토 조건
- 이웃의 정체(종)를 정하면 그 초상화를 그린다. 보스·상점 주인이 생기면 같은 규칙으로 칸을 늘린다.
