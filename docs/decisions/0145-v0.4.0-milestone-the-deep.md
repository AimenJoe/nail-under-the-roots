# 0145. v0.4.0 마일스톤 "깊은 곳": 이야기 마무리 + 볼륨

- 날짜: 2026-10-27
- 상태: **닫음**(2026-10-28, 사장 판정 F를 거쳐 "0.4.0으로 배포하자" → v0.4.0). A~E는 아래 후속대로 들어갔고, 판정 중 나온 손맛 수정(예고 0176~0190·박자 0174~0189·안내 0178~0182 등)도 함께 실었다.
- 처음 상태: 채택(범위). 사장: "스토리 좀 더 단단히 하고 스테이지 및 적들도 더 추가해야 게임 볼륨이 올라갈 것 같은데" → 제안 A~D에 "0.4.0 제안 좋아".
- 사장이 고름(같은 날): **A는 셋째 길의 갈래**(콩이의 문 / 굴토끼 옛 굴 중 하나, 런 길이 그대로), **A의 보스는 모모의 엄마**(실에 감겨 꿈꾸는 어미 굴토끼, 아기들을 실로 감싸 지킨다), **B는 실매듭 끊기**(할매는 싸우지 않고 실을 당긴다, 매듭 셋을 끊으면 놓아준다). 자세한 설계는 따로 적어 사장 확인을 받는다.
- 후속(같은 날, 0148): v0.3.0을 사장 결정으로 닫고 C(0146)·D(0147)를 v0.3.0에 함께 냈다. 남은 것은 A·B·E·F.
- 후속(같은 날, 0162): B를 넣었다(할매는 실을 당기고, 매듭 셋을 끊으면 놓아준다). 남은 것은 A·E·F.
- 후속(같은 날, 0165): A를 넣었다(셋째 길 갈래 '굴토끼 옛 굴', 흰 실 지대, 어미 토끼풀, 가족 귀환). E(새 글 열한 언어·도감·저널)도 함께. 남은 것은 F(사장 판정)와 그림 원본(토끼풀 초상·일러스트).
- v0.3.0(0081·0140)은 사람 몫(7·10·11·12)만 남았다. 그 확인이 끝나면 v0.3.0으로 닫고, 이 마일스톤의 일은 그 사이에도 작업 브랜치에서 한다(마이너는 v0.3.0을 닫은 뒤에만 올린다, 0079).

## 배경(지금 있는 것, 2026-10-27 코드·글로 확인)
- 길 셋(들판·뿌리·심층) + 가장 깊은 곳, 보스 넷(보리·모모·도토·콩이), 잡몹 다섯(들쥐·생쥐·시궁쥐·다람쥐·청설모).
- 잡몹이 모두 설치류이고 하는 일이 돌진·떼·던지기·덮치기뿐이라 바이옴이 바뀌어도 싸움이 같아 보인다.
- 이야기의 빈 곳:
  - **모모의 가족**: 할매 "내 실이 굴토끼들을 품고 있단다… 언젠가 깨워 주렴"(halmae_petal), 모모 "기다려. 언젠가 꼭 찾으러 올게"(mend_3), "우리 가족이 더 아래에 있어"(momo_r5). 떡밥만 있고 회수가 없다(0140에서 v0.4 이후로 미룬 "굴토끼 가족 갈래").
  - **가장 깊은 곳에 싸움이 없다**: 마지막 길 보스(콩이) 다음 바로 컷씬(half_*·true_*). 액션 게임의 절정이 대사로만 끝난다.

## v0.4.0 조건
| # | 조건 | 누가 |
|---|---|---|
| A | **굴토끼 가족의 길**: 할매의 흰 실에 감긴 새 바이옴과 그 끝의 보스(물든 굴토끼 가족). 이기면 가족이 마을로 돌아오고 모모의 이야기가 닫힌다 | Claude(설계 제안 → 사장 확인), 그림 원본은 사장(나노바나나) |
| B | **가장 깊은 곳의 마지막 싸움**: 할매를 때리지 않는 싸움("떠나보내기" 톤, 0037). 반쪽·참 엔딩 앞에 | Claude(설계 제안 → 사장 확인), 그림 원본은 사장 |
| C | **새 잡몹 4~6종**: 실제 땅속 동물, 지금 없는 행동(독·끌어당기기·가시·공중·범위·엘리트). 바이옴마다 대표 적 하나 | Claude |
| D | **스테이지 다양화**: 바이옴마다 장애물 하나(가시덤불·물웅덩이·무너지는 천장 등), 길 중간 엘리트 방 | Claude |
| E | 새 글은 열한 언어, 도감·저널·앨범에 이어지게 | Claude |
| F | 사장이 새 길·마지막 싸움·새 적을 해 보고 판정 | 사장 |

## 순서
C(새 적, 사람 그림 없이 코드 그림으로 끝난다) → D → A·B 설계 제안(사장 확인) → 나노바나나 프롬프트(`docs/art/nano-banana-prompts.md`) → A·B 구현 → F.
적·장애물은 길 셋에 먼저 넣어 지금 런이 바로 두터워지게 한다.

## 왜
- 사람 판정을 기다리는 v0.3.0 사이에도 게임이 바뀌어야 다시 해 볼 까닭이 생긴다(KB `roguelite-replay-axes`).
- 이야기의 빈 곳 둘은 이미 대사로 약속한 것이다. 약속을 회수하지 않으면 "또 같은 길"이 된다(KB `roguelite-narrative-delivery`).
- 적 다양성은 그림·코드가 가장 싸게 늘어나는 볼륨이다(보스·캐릭터보다 싸다, KB `action-roguelite-for-solo-dev`). 동물은 실제 습성에서 꺼낸다(KB `animal-behavior-for-character-design`).
