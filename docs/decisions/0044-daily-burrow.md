# 0044: 오늘의 굴 — 날짜가 시드, 첫 쉼터에서, 그날의 가장 먼 쉼터를 남긴다

- 상태: 채택 (2026-10-25). 0040 순서 5의 앞쪽이다(오늘의 굴. 실의 꿈은 보스가 늘면).

## 결정
1. **시드 = 날짜**:
   - UTC 날짜(1970-01-01부터 센 일)를 splitmix64로 섞어 런 시드로 쓴다.
   - 길·굴 생성은 이미 "같은 시드 = 같은 결과"(0019·0031)다. 그래서 같은 날엔 같은 첫 길이 나오고, 같은 칸을 고르면 같은 굴이 나온다.
   - 적의 행동·떨어지는 것은 시드를 따르지 않는다.
2. **어디서**: 튜토리얼을 마친 뒤 타이틀에 "오늘의 굴"이 생긴다.
   - 줄 오른쪽에 오늘 날짜(월/일)를 보인다. 날마다 다른 굴이라는 표시다.
   - 고르면 첫 쉼터에서 두더지 발톱을 들고 시작한다. 실뜨기는 0이다.
3. **기록**: 그날 닿은 가장 먼 쉼터(`daily.<날>.best`)와 완주(`daily.<날>.clear`).
   - 타이틀 줄에 "오늘의 굴 · 쉼터 2" / "오늘의 굴 · 완주"로 보인다.
   - 가장 깊은 곳에 닿으면 이야기 엔딩 없이 기록만 남기고, 타이틀에 "오늘의 굴을 끝까지 지났다!"를 띄운다.
   - 한 달 넘은 날의 기록은 오늘의 굴을 시작할 때 지운다.
   - 오늘의 굴에서 쓰러진 것은 이야기 기록(쓰러진 수·한마디)에 넣지 않는다.
4. 서버·순위표는 없다. 혼자 보는 기록부터 시작한다(0040).

## 왜
- 이미 있는 시드 생성기를 다시 쓰는 가장 싼 변주 런이다. "오늘은 어디까지 갈까"라는 짧은 이유가 생긴다(핸드헬드 세션 길이에 맞음).
- 날짜를 기기 시각에서 읽으니, 시계를 바꾸면 다른 날 굴을 할 수 있다. 순위표가 없으니 막지 않는다.

## 확인
- 단위 테스트:
  - 날짜 계산: 1970-01-01, 2026-10-25, 2000-02-29.
  - 같은 날 = 같은 시드, 다른 날 = 다른 시드.
  - 한 달 넘은 키 판정.
  - 같은 시드 = 같은 첫 길.
- 헤드리스(기록을 넣고 시작):
  - 타이틀에 "오늘의 굴 · 쉼터 2  10/25"가 보인다.
  - 고르면 첫 쉼터에서 시작한다.
  - 옛 날(10일째) 기록이 지워졌다.
