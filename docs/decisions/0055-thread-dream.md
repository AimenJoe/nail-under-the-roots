# 0055: 실의 꿈 — 이긴 길의 주인과 꿈속에서 다시 싸우기

- 상태: 채택 (2026-10-25). 0040 순서 5의 남은 반쪽이다(오늘의 굴은 0044).
- 브레인스토밍(`docs/replay-brainstorm.md` 5): Hollow Knight 신들의 전당 자리. 할매의 실이 기억하는 물든 모습들과 다시 싸운다. 방 하나 + 목록이면 된다.
- 사장: "그래 다음 진행하자" — 보스가 넷(대장·모모·도토·콩이)이 된 뒤다.

## 결정
1. **어디서**: 마을 할매 곁의 **실 고리**(`X`, 막대 둘에 걸린 실뜨기 모양, 보랏빛으로 숨 쉰다)에서 연다.
   - 할매가 온 뒤(반쪽 엔딩)에만 선다.
   - 할매가 한 번 알려 준다: "내 실이 기억하는 모습들이 있단다…"
2. **고르기 창**: 줄 다섯 — 들쥐 대장, 모모, 도토, 콩이, 이어서 꾸기(넷 모두).
   - 이긴 길의 주인만 열린다. 이기지 않은 줄은 "???"다. 이어서 꾸기는 넷을 다 이기면 열린다.
   - 줄마다 가장 빠른 기록(0.1초)과 ★(한 번도 안 맞고 이김)를 보인다.
3. **싸움**:
   - 빈 방(웨이브 아레나)에 보스 하나를 둔다. 보스는 1초 뒤에 깬다.
   - 모모는 세 번째 모습(수 셋을 다 쓴다)으로 나온다.
   - 화면에 옅은 보랏빛을 입히고, 오른쪽 아래에 시간을 보인다(★·이어서 꾸기면 n/4).
   - 이어서 꾸기는 보스 사이에 체력을 2만 돌려준다.
   - 만남·처치 컷씬은 나오지 않는다(굴 방 코드에서만 나온다).
4. **얻는 것 없음**:
   - 꿈에서는 쓰러진 적이 아무것도 떨어뜨리지 않는다. 산딸기 회복이 기록을 흐리지 않게 하고, 반딧불·씨앗을 모으는 꼼수도 막는다.
   - 통계·이야기 기록도 남지 않는다(기록하는 런이 아니다).
   - 남는 것은 `dream.<보스>`(가장 빠른 시간), `dream.<보스>.nohit`, `dream.all…`, `dream.wins`(꿈에서 이긴 보스 수)다.
5. **끝**:
   - 이기면 "꿈에서 이겼다!"(더 빠르면 "가장 빠른 기록!")를 띄운다. 쓰러지면 "꿈에서 깼다."다.
   - 어느 쪽이든 잠깐 뒤 마을 실 고리 앞에서 깨어나고, 고르기 창이 다시 열린다.
   - 깬 직후 0.8초는 창이 입력을 받지 않는다. 싸우던 연타가 다음 꿈을 열었다(헤드리스에서 봤다).
6. **저널**(마을 갈래):
   - "실의 꿈": 꿈에서 넷 다 이기기, 반딧불 60. 앞 목표는 "가장 깊은 곳".
   - "끝나지 않는 실": 이어서 꾸기 깨기, 마을 씨앗 30.
7. 글 18줄 다섯 언어, 직접 썼다.
   - 일본어 폰트에 없는 勝은 やっつける로 바꿨다(0048과 같다).
   - 안내 글이 일본어에서 두 줄을 넘어 다섯 언어 모두 줄였다.
8. 함께 고친 것: 아레나의 "wave · kills" 시험장 글을 꿈에서는 숨긴다.

## 왜
- 보스를 넷이나 만들었는데 런마다 한 번씩만 만난다(이기면 다시 안 나온다 — 0046·0052·0054). 다시 싸우는 곳이 있어야 손맛을 다시 본다(KB `recurring-boss.md` 다시 싸우기 모드).
- 보상이 없는 이유: 0040 "옆으로 넓히기". 꿈이 성장 수단이 되면 본편이 쉬워진다. 기록과 ★가 실력 축(0040)의 몫이다.
- 단계(Hollow Knight의 Attuned·Ascended·Radiant)는 아직 넣지 않았다. ★(안 맞고 이김)가 가장 높은 단계를 대신한다. 보스·단계 수가 늘면 다시 본다.

## 확인
- 단위 테스트(92개): 줄이 이야기를 따라 열리고 이어서 꾸기는 넷 다 필요하다, 기록은 더 빠를 때만 바뀐다, ★·보스 수.
- 헤드리스:
  - 마을 실 고리 → 창(한·일) → 꿈속 모모(보랏빛, 시간·★, 맞으면 ★가 사라짐).
  - 이기기 → 마을로 깨어 창이 다시 열린다(기록 ★0:02.0). 이 확인에서만 모모 체력을 낮춘 빌드를 썼다.
  - 대장 꿈에서 쓰러짐 → 깨어남 → 이어서 꾸기 1/4.
- 사람 판정이 남았다: 보랏빛이 거슬리지 않는지, 이어서 꾸기 체력 2 회복이 맞는지, 실 고리 그림.
