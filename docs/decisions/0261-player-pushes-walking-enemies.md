# 0261 — 플레이어는 걸어 다니는 적을 통과하지 못한다

- 문제: 플레이어와 적 사이에 충돌이 없어, 때리다 보면 적이 캐릭터 뒤로 넘어가 타격이 빗나갔다.
- 결정: `World::push_enemies_from_player`. 플레이어가 땅 위(`on_foot`)에 있거나 먹는 중일 때, 겹친 만큼 일반 적과 플레이어가 반씩 밀려난다(벽은 `resolve_circle`). 보스는 고정하고 플레이어가 겹친 만큼 밀린다.
- 예외: 회피·뛰기·땅속 상태의 플레이어, 날아다니는 적(박쥐), 나타나는 중·땅속의 적은 통과한다.
- 사람이 확인할 것: 좁은 방에서 적이 벽에 끼어 겹치는 느낌이 거슬리지 않는지.
