# 0009: 콤보는 무브셋 데이터로(무기·캐릭터별), 회피 캔슬은 타별 창, 튜토리얼은 플레이로

- 상태: 채택 (2026-10-25)

## 맥락
사장 요구: 무기 종류와 캐릭터에 따라 콤보가 달라야 하고, 콤보 마지막 타는 강력하며, 굴파기 같은 회피로 후딜레이를 취소해 다른 콤보를 빠르게 섞을 수 있어야 한다. 첫 시작에는 마리오식 튜토리얼(글이 아니라 상황이 가르친다)이 있어야 한다. 0003의 "캐릭터 = 반복 단위"와 맞물린다.

## 결정
1. **무브셋 데이터**(`src/moveset.rs`): `Moveset { name, hits: &[Hit], combo_window, move_factor }`, `Hit { swing, active, recovery, damage, knockback, stun, hitstop, shake, range, lunge, dodge_cancel_after }`. 플레이어는 `moveset` 참조만 읽는다. 발톱(`CLAWS`)은 tuning.rs 수치로 만들고, 실험용 `HEAVY`(2타)를 두어 무기가 바뀌면 손맛이 얼마나 달라지는지 본다. 캐릭터·무기 추가 = 상수 하나.
2. **캔슬 규칙**: 공격 입력은 활성 구간이 끝난 뒤 다음 타로 이어진다(연타 선입력). 굴파기는 각 타의 `dodge_cancel_after` 이후에 스윙을 끊는다. 발톱은 0(언제나), 무거운 무기는 활성 구간이 끝난 뒤. 마지막 타는 느리고 넉백·히트스톱이 크다. 솟구친 직후 0.1초 공격 불가(리스크)는 유지.
3. **튜토리얼**(`src/tutorial.rs`): 첫 시작(Normal)과 개발 시나리오 "튜토리얼"에서. 글은 아래 한 줄 힌트뿐. 단계는 월드 통계로 넘어간다: 40px 이동 → 앞에 허수아비(새 적 종류 `Dummy`, 안 움직이고 안 때림) → 마지막 타 명중 → 원거리형 등장 → 굴파기 1회 → 솟구침 처치(또는 적 전멸) → 2초 뒤 웨이브 1. 튜토리얼 중에는 자동 웨이브가 꺼진다.
4. 튜토리얼 완료 여부는 저장하지 않는다(저장은 3단계). 그때까지는 매번 보되 개발 시나리오로 건너뛴다.

## 왜
- 콤보를 데이터로 두면 캐릭터·무기가 코드가 아니라 표가 된다. 0003(보스 → 플레이어블)의 기술 세트도 같은 표로 적는다.
- 회피 캔슬 창을 타마다 두면 "가벼운 무기는 언제든, 무거운 무기는 휘두른 뒤"처럼 무기 성격이 캔슬 규칙으로 표현된다. 전부 언제나 캔슬되면 무기 차이가 사라진다.
- 마리오식 튜토리얼은 "설명 없이 30초 안에 굴파기→솟구침→때리기"라는 1단계 판정 1과 같은 목표다. 허수아비는 맞아도 반격하지 않아 3타째를 느낄 안전한 자리다.

## 비용
- 허수아비는 전투 외 적 종류라 enemy.rs에 분기가 하나 늘었다.
- 튜토리얼 문구가 코드에 있다. 다국어가 필요해지면 데이터화.

## 재검토 조건
- 두 번째 캐릭터(2단계 보스 → 3단계 플레이어블)를 넣을 때 `Moveset`에 회피 종류·특기도 들어가야 한다. 그때 `Character { moveset, dodge, special }`로 확장.
