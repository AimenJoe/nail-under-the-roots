# 0041: 기록(프로필) 저장과 첫 다회차 조각 — 건너뛰기·한마디·도감·앨범·포포의 응원

- 상태: 채택 (2026-10-25). 사장 "지금 만들자". 0040의 순서 1(저장 파일)과 2·3의 일부를 만들었다.
- 1단계 범위("판정 전에 저장·허브를 만들지 않는다")를 사람이 넓혔다.

## 결정
1. **기록 = 깃발 + 수**(`src/profile.rs`).
   - 이름은 안정된 문자열 키다(`tutorial`, `bori`, `deaths`, `mob.FieldMouse`, `illust.great_tree`, `line.first_wake` …).
   - 형식은 사람이 읽는 줄 단위 글이다. 머리줄 `nail-profile 1` 뒤에 `flag <키>` / `count <키> <수>`가 온다.
   - 모르는 키도 지우지 않고 다시 쓴다. 새 버전이 쓴 기록을 옛 버전이 망가뜨리지 않는다.
   - 깨진 줄은 그 줄만 버린다. 머리줄이 다르면 통째로 무시한다.
2. **저장소**:
   - 웹은 localStorage `nail.profile` 한 칸이다. `nail_save` 플러그인이 wasm 메모리(`wasm_memory.buffer`)에서 UTF-8 바이트를 직접 읽고 쓴다. wasm-bindgen 없이 문자열을 주고받는 방식이다.
   - 데스크톱은 사용자 데이터 폴더의 `nail/profile.txt`다(XDG·`APPDATA`·`Application Support`, `NAIL_SAVE_DIR`로 바꿈). 임시 파일에 쓴 뒤 이름을 바꾼다.
   - Android는 앱 전용 폴더 `/data/data/io.github.aimenjoe.nail/files`다.
   - 설정(prefs, 정수 칸)은 그대로 둔다.
3. **무엇을 남기나**(첫 시작 Normal만. 개발 시나리오는 이야기 기록을 건드리지 않는다. 본 일러스트는 예외로 어디서 봐도 남긴다):
   - 런 수, 쓰러진 수, 가장 멀리 간 쉼터
   - 튜토리얼을 마침, 보리가 돌아옴
   - 만난 이웃(도감), 본 일러스트(앨범), 본 한마디
   - 도움 모드와 그 누적
4. **다회차 첫 조각**:
   - **튜토리얼을 마친 뒤 새 런**: 오프닝·튜토리얼을 건너뛴다. 두더지 발톱을 들고 필드에서 시작하고 공터 문이 열려 있다. 보리가 돌아온 뒤면 대장은 없고 굴 입구가 살아 있다.
   - **런 사이 한마디**(`src/story.rs`). 조건이 다 맞는 줄 가운데 가장 구체적인 줄을 고르고, `once` 줄은 한 번만 나온다(KB 이야기 노트, Valve 규칙 DB 방식).
     - 깨어날 때: 갈색 뿌리가 데려왔다 → 또 뿌리가(나무가 지켜 주나) → 보리의 위로 → 응원 모드 알림 → 열 번째.
     - 새 런: 공터 문 / 보리 대장은 쉼터에.
     - 지는 사람도 이야기를 보게 쓰러진 수가 조건이다.
   - **도감**: 만난 이웃이 런을 넘어 남는다.
   - **앨범**(타이틀): 본 일러스트 4×2 칸. 고르면 패닝·입자 그대로 크게 본다. 못 본 칸은 "?".
   - **포포의 응원**(설정): 켜면 받는 피해가 20%에서 시작해 쓰러질 때마다 2%씩, 최대 80%까지 준다(Hades God Mode 참고).
     - 체력이 정수라 줄인 소수는 모아 두었다가 1이 차면 깎는다. 맞은 반응(넉백·무적)은 그대로다.
     - 설정 값에 지금 비율을 보인다("켬 32%").
   - **기록 지우기**(설정): 한 번 누르면 "한 번 더: 정말 지운다", 한 번 더 누르면 지운다. 줄을 옮기면 취소된다.
5. 글 14줄을 다섯 언어로 넣었다. DeepL 초안을 고쳤다. 앨범은 간체 "专辑"(음반) → "相册"으로 바꿨고, 기존 용어(쉼터·공터·대장·Opções)에 맞췄다. 일본어 恥가 폰트에 없어 문구를 바꿨다.

## 왜
- 0040의 모든 축(실뜨기·캐릭터·앨범·오늘의 굴)이 런을 넘는 기록에 기댄다. 그래서 바닥부터 만든다.
- 깃발 + 수 + 문자열 키: 기능이 늘 때마다 형식을 바꾸지 않고 키만 더하면 된다. 정수 칸 설정 저장(prefs)은 칸 번호가 곧 형식이라, 칸을 바꾸면 MAGIC을 올려 옛 저장을 버려야 했다.
- 다시 시작할 때 오프닝·튜토리얼을 또 보는 것이 반복의 가장 큰 마찰이었다(0012·0009 "비용"에 적혀 있던 것).

## 확인
- 단위 테스트:
  - 기록 왕복, 남의 데이터 거부, 깨진 줄 건너뜀, 모르는 키 보존, 파일 저장소 쓰기·읽기
  - 한마디 고르기(가장 구체적인 것, 한 번만, 응원 켜면 알림 생략, 새 런 줄)
  - 응원 피해 분산(0.5 × 1피해 4번 = 2)
  - 보리가 돌아온 공터
- 헤드리스(localStorage에 기록을 넣고 시작):
  - 튜토리얼 마친 사람은 포포의 "공터 문은 열어 뒀어"를 듣고 발톱을 든 채 필드에서 시작한다. 보리가 돌아온 사람은 "보리 대장은 쉼터에서…"를 듣는다.
  - 앨범 3/8, 못 본 칸은 눌러도 그대로, 본 칸은 크게 보인다.
  - 설정에 "켬 32%"가 보이고, 기록 지우기 두 번이면 `nail-profile 1`만 남는다.
- 확인 못 함:
  - 실제로 쓰러져 깨어날 때 한마디가 나오는 것(고르기는 단위 테스트, 앱 연결은 코드로만 확인)
  - Android 실기 파일 저장, 데스크톱 실행 저장
