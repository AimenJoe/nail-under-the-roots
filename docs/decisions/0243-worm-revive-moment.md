# 0243. 지렁이로 일어나기: 잠깐 눕고, 먹고, 터지며 일어난다

- 날짜: 2026-10-29
- 상태: **구현**(v0.6.x 패치 후보). 사장: "지렁이로 부활했을 때 뭔가 이펙트가 없으니 죽었었는지 잘 모르겠음."

## 왜 몰랐나
쥬시 지렁이(0200)는 쓰러지는 그 틱에 먹고 일어났다. 고리·분홍 가루·흔들림·한마디는 있었지만 **쓰러진 순간이 화면에 한 칸도 없었다** —
맞음 반응과 이어져 "세게 맞았다" 정도로 읽혔다.

## 바꾼 것
- 쓰러지면(지렁이가 있으면) `player::State::Revive`: `REVIVE_DOWN_TIME`(0.9초) 동안 누운 칸(쓰러짐)으로, 움직이지 못하고 안 맞는다.
  체력은 0 그대로 — HUD도 쓰러진 걸 보인다. 들어설 때 쓰러지는 소리(`Die`) + 멈춤 `REVIVE_HITSTOP`(0.2초) + 흙 튐.
- 누운 동안(`render/actors.rs draw_reviving`): 쥬시 지렁이가 위에서 떨어져 입가에서 꿈틀대다 쏙 들어가고(앞 60%), 분홍 고리가 몸으로 닫히며 반짝이 돈다.
- 다 먹으면 `Event::Rose` → `World::worm_rise`: 둘레 밀어내기·탄 지우기(예전 그대로) + 분홍·하얀 고리 + 분홍 가루 + 반짝 여섯 + 흔들림·짧은 멈춤 + 회복 소리 + 한마디.
  체력·무적(`REVIVE_INVULN`)은 이때(`Player::revive`).
- 모모·도토도 같다(누운 칸 `F::DOWN`).

## 확인
`juicy_worm_revives_on_death`: 맞은 틱에는 `Revive`(살아 있음·안 맞음·쓰러지는 소리), 누운 시간이 지나면 `Free` + 체력·무적·한마디. 지렁이가 없으면 그대로 쓰러진다.
