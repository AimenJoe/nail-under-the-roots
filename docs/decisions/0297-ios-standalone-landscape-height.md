# 0297 — iOS 홈 화면 앱을 가로로 켜면 아래가 빈다: 높이를 lvh로

- 날짜: 2026-11-19
- 상태: 정함(사장 2026-11-19 — iOS 홈 화면 앱을 가로로 켜면 아래쪽에 공간이 뜬다, Knellroot와 같은 증상) — **실기 확인**(사장 2026-11-19 "수정된 것 확인")
- 앞선 것: 0296(처음부터 가로일 때 캔버스 다시 재기)은 그리기 크기를 **상자**에 맞추는 고침이라 상자 자체가 짧으면 소용이 없었다.

## 원인(2차 출처 — 현장 보고)
`black-translucent` + `viewport-fit=cover`의 홈 화면 앱에서 WebKit은 화면 맨 위부터 그리지만 뷰포트 높이(`100%`·`innerHeight`)를 상태 막대만큼
뺀 값으로 준다 → 아래에 띠. `100lvh`만 전체 높이를 준다는 보고가 여럿이다(Knellroot 0253에 출처).

## 고침(Knellroot 0253과 같은 두 겹)
1. CSS: iOS 홈 화면 앱에서만 `html, body, canvas` 높이를 `100lvh`(`@supports (-webkit-touch-callout: none)` + `display-mode: standalone/fullscreen`).
2. 스크립트: `navigator.standalone`일 때 상자 높이가 화면의 짧은 변(가로)·긴 변(세로)보다 모자라면 px로 늘린다 — 0296의 다시 재기가 그리기 크기를 따라 맞춘다.

## 확인
헤드리스는 iOS 홈 화면 앱을 흉내 내지 못한다 — 스크립트 문법만 봤다. 실기 확인이 판정(가로로 든 채 켜기 · 세로로 켜서 돌리기).
