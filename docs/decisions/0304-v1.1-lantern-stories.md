## 포포 셋 — 한국어 초안(결 확인용)
포포의 말투: 밝고 먼저 챙기는 라쿤, 좌판 주인, 손을 씻는 버릇(부탁 "촉촉한 조약돌" → 좌판 곁 작은 샘 그릇).

### ① 지난날 — "씻는 손"
| 누가 | 글 |
|---|---|
| 포포 | 등불? 나한테? …고마워. 손이 다 환해지네. |
| 포포 | 있잖아, 다들 실에 감길 때 나만 멀쩡했던 거 이상하지 않았어? |
| 포포 | 나는 뭘 만지고 나면 꼭 손을 씻거든. 라쿤 버릇이야. |
| 포포 | 그때도 손끝에 보라 실이 감길 때마다 물에 헹궜어. 그냥 찝찝해서. |
| 포포 | 그게 나를 지켰나 봐. 별것 아닌 버릇이 말이야. |

### ② 사이 — "모모의 꽃"
| 누가 | 글 |
|---|---|
| 포포 | 모모가 물들기 전엔 날마다 좌판에 들렀어. 귀에 꽂은 꽃을 하나씩 두고 갔지. |
| 포포 | "팔아도 돼요" 하면서. 하나도 못 팔았어. 너무 예뻐서. |
| 포포 | 모모가 길을 막아섰던 날, 마지막 꽃은 시들어 있었어. |
| 포포 | 그 꽃을 아직 좌판 밑에 두고 있어. 이제 돌려줘도 되겠지? |
| 포포 | (모모로 걸을 때) …너한테 직접 줄게. 네 꽃이잖아. |

### ③ 놓아준 뒤 — "같이 씻은 실"
| 누가 | 글 |
|---|---|
| 포포 | 할매가 내 샘 그릇에 손을 담그더라. 손가락에 실이 잔뜩 감겨 있었어. |
| 포포 | 같이 헹궈 드렸지. 그런데 실이 물에 스르르 풀리는 거야. |
| 포포 | 할매가 그러셨어. "붙잡던 것도 씻으면 풀리는구나." |
| 포포 | 나는 그냥 손 씻는 걸 좋아했을 뿐인데. |
| 포포 | 이 등불, 샘 그릇 위에 걸어 둘게. 밤에도 손 씻으러 오라고. |
