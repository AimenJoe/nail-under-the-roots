# 0207. 떨어진 것은 모두 반딧불처럼 끌려온다 · 튜토리얼 과녁이 다시 나온다

- 날짜: 2026-10-28
- 상태: 채택(사장 "아이템 습득 반경이 좁아.. 반딧불이랑 비슷하게 습득했으면 좋겠는데. 적어도 범위만큼은?", "튜토리얼에서 적을 다 죽이면.. 타격이 필요할 때 다음으로 넘어갈 수 없는 문제가 있어")

## 1. 줍는 반경
- 반딧불·씨앗만 자석(44px, `GLOWBUG_MAGNET_*`)으로 끌려오고, 산딸기·지렁이·뿌리 심장은 8px(`LOOT_COLLECT_RADIUS`)까지 닿아야 주웠다. 바닥 무기(`Pickup`)는 10px(`PICKUP_RADIUS`).
- 고침: 자석을 모든 떨어진 것에(`LOOT_MAGNET_*`로 이름을 바꿈). 가방이 차서 못 담는 것(`can_take` 거짓)은 전처럼 끌리지 않고 제자리에 남는다. 바닥 무기도 같은 거리 안이면 같은 최고 속도로 끌려와 10px에서 줍는다.
- 시험 `every_loot_kind_is_pulled_in_like_glowbugs`: 다섯 종류 모두 자석 거리 4px 안쪽에서 주워지고, 못 담을 때는 움직이지 않는다.

## 2. 튜토리얼이 막혔다
- 허수아비(`Kind::Dummy`)는 체력 6이라 연타·강타로 부서진다. 3연타(`Attack`)·강공격(`Heavy`) 단계는 허수아비를 맞혀야 넘어가는데, 부숴 버리면 칠 것이 없어 영영 막혔다. 솟구치기(`Emerge`) 단계도 연습 다람쥐를 발톱으로 잡아 버리면 같았다. 패링(`Parry`)만 매 틱 다람쥐를 다시 불렀다.
- 고침: `Tutorial::ensure(kind)` 하나로 — 맞혀야 넘어가는 단계(3연타·강공격 = 허수아비, 솟구치기·패링 = 다람쥐)는 매 틱 과녁이 없으면 다시 둔다(허수아비는 바로 앞, 다람쥐는 떨어진 자리).
- 시험 `hit_lessons_bring_back_a_target_when_all_are_gone`: 네 단계마다 적을 다 없애면 다음 틱에 과녁이 하나 나오고 단계는 그대로.
