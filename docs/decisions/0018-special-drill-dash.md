# 0018: 특기 = 드릴 돌진(SP 게이지)

- 상태: 채택 (2026-10-25)

## 맥락
사장 요청: 필살기 — 드릴이 연타되면서 직진, 방향은 조금만 조절, 벽에 꿍 하면 추가 데미지.

## 결정
1. **SP 게이지**(오른쪽 위, 굴파기 바 아래): 발톱이 맞으면 1, 마지막 타는 2(장신구 "뿌리 부적"으로 1.5배). 12에서 가득, 깜빡인다. 드릴 자체는 채우지 않는다.
2. **드릴 돌진**(`player::State::Drill`): 0.85초 동안 170px/s로 직진, 입력 쪽으로 초당 2.6라디안만 튼다. 0.07초마다 앞쪽 원(반지름 11)을 1씩 연타하며 적을 앞으로 민다(벽까지 데려간다). 도는 동안 무적.
3. **벽 쿵**: 벽·기둥에 부딪히면 그 자리 충격파(반지름 28, 피해 3 + 공격력 보정, 큰 경직·히트스톱·흔들림) 후 0.4초 경직. 그냥 끝나면 0.22초 경직.
4. 공격(발톱) 활성 구간이 끝난 뒤라면 드릴로 캔슬할 수 있다(굴파기 캔슬과 같은 생각, 0009).
5. 무기가 있어야 쓴다(맨손이면 안 나감).

## 왜
- 게이지는 "공격을 맞혀야 필살기"라 적극적인 플레이를 부른다. 쿨타임만이면 쓰고 기다리는 버튼이 된다.
- 직진성 + 약한 조향 + 벽 보너스는 "어디로 몰아서 박을지"라는 위치 선정을 만든다(판정 2와 같은 방향).
- 무적은 필살기의 보상감과 실패 비용(빗나가면 경직)의 균형.

## 재검토 조건
- 보스가 생기면 보스에게 드릴 피해·무적 시간을 다시 본다. 패링이 생기면(맵 단계 질문) 패링 성공으로 SP를 크게 채우는 연결을 검토.
