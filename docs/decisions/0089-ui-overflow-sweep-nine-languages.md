# 0089. 화면 × 아홉 언어 점검: 개발 빌드 글자 넘침 검사(F3) + 헤드리스 순회

- 날짜: 2026-10-26
- 상태: 채택. 사장: "웹에서 화면들, 다국어들로 다 확인해줘. UI들 제대로 보이는지 검증하고 작은 버그들 고치자."

## 방법
- **검사기(개발 빌드만, `ui::check`, F3로 켬/끔)**: `Ui::text`가 그린 글자 칸을 프레임마다 모아 네 가지를 브라우저 콘솔에 한 번씩 찍는다.
  - 화면(320×180) 밖으로 나간 글
  - 글의 왼쪽 위를 품은 가장 작은 테두리(`rect_lines`·`panel`) 밖으로 나간 글(오른쪽·아래)
  - 서로 1.5px 넘게 겹친 두 글
  - `ui.fit`이 "…"로 자른 글
- 그리는 순서(z)는 모른다. 그래서 어둡게 덮인 HUD 위에 뜬 창(가게 확인 창, 일시정지 밑 HUD)은 거짓 양성이 나온다. 걸러서 본다.
- **순회(헤드리스 Chromium, 스크래치 스크립트)**: 로캘 9개 × 화면 약 25개를 돈다. 화면은 타이틀·슬롯·설정·조작·앨범·오늘의 굴·일시정지 탭 여섯·쉼터 가게·길 지도·말 걸기·마을(큰 나무·할매·꾸미기·실의 꿈·뿌리 길)·오프닝·튜토리얼·보스·가장 깊은 곳·HUD. 화면마다 스크린숏과 검사기 줄을 모았다.
  - 개발 시나리오는 위아래 키 횟수로 고르는데, 키를 빨리 누르면(60ms) 몇 번 빠져 다른 시나리오가 열렸다 → 140ms 이상.
  - 인트로가 첫 키를 먹는다 → 먼저 Esc.

| 조작 설정 | 고정 키 둘째 줄이 화면 밖, 안내가 잘림 | 영·간·프·스·독 | 10px 간격, 안내 폭을 창 폭까지 |

| 스페인어 표 | 실뜨기 이름·조작 안내가 칸보다 김 | 스 | 직접 줄임(`resistente`는 도감 말과 같게) |

## 그대로 둔 것
- **일시정지 밑 HUD가 창 아래로 반쯤 보인다**: 어둡게 덮인 맥락이라 그대로.
- **웹 콘솔 `register_plugin is not defined`**: v0.1.0부터 있었고 배포 사이트에서도 난다. `mq_js_bundle.js`에 든 quad-net 웹소켓 플러그인(안 씀)이 엄격 모드에서 선언 없는 전역에 대입해서 생긴다. 게임은 그대로 돈다. 번들은 의도적으로만 바꾼다(CLAUDE.md).
