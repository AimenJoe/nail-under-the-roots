# 0030: 스테이지 고리 — 쉼터(쉬는 곳·상점·동료)와 다음 스테이지

- 상태: 채택 (2026-10-25, 사장 "스테이지가 끝날 때마다 쉬는 지점(어드벤처)과 상점/동료들이 있는 장소가 있고 또 다음 스테이지로 이동할 수 있게").
- 1단계 범위(CLAUDE.md "허브·저장은 판정 전에 만들지 않는다")를 사람이 직접 넓혔다. 쉼터는 **런 안의 쉬는 곳**이고, 메타 허브(나무 아래 마을, 해금, 껐다 켜도 남는 저장)는 아직 아니다.

## 결정
1. 고리: 필드(튜토리얼) → 남쪽 공터의 튜토리얼 보스(0032) → 굴 입구 → **쉼터 1** → 길 지도(0031)에서 고른 굴들 → 그 길의 보스 → **쉼터 2** → …
2. 쉼터(`src/camp.rs`, ASCII 26×14, 화면보다 조금 넓어 살짝 걷는다): 싸움 없음. 들어오면 체력 가득, 저장 고리가 쓰러졌을 때 돌아올 곳(`adv.home`)이 된다.
   - 모닥불(F) 둘레: 포포의 가게(k 좌판, K 포포), 돌아온 보리(b, 0032), **빈 자리(M)** — 모모가 돌아올 곳(0027). 비어 있는 자리가 "누가 올까"를 말한다.
   - 뿌리 길(G): 곁에서 확인 → 길 지도.
3. 말 걸기: 말 걸 것 곁에서 **공격 버튼 = 말 걸기**(휘두르지 않는다). 그 위에 "버튼 이름 + 할 일" 말풍선(`input::prompt`). 버튼을 하나 더 쓰지 않는다 — 쉼터엔 적이 없으니 공격이 빈다(0022의 버튼 넷을 지킨다).
4. 가게(포포, `app/stage.rs`): 씨앗으로 산딸기 3 · 쥬시 지렁이 10 · 뿌리 심장 14(쉼터마다 하나, 최대 체력 상한까지) · 아직 없는 장신구 12. 값은 `tuning.rs`. 커서 없이 위아래 + 확인, 모자라면 포포가 말한다.
5. 쓰러지면 쉼터의 저장 고리로. 길(0031)은 **새로 짠다**(로그라이트: 같은 갈래를 외워서 넘지 않게). 씨앗·장신구·가방은 남고 반딧불 30%를 잃는다(0019 그대로).
6. 길의 굴에서 나와 쉼터로 돌아가지 않는다(다음 갈래를 바로 고른다). 쉼터는 길의 처음과 끝에만 — "쉬는 곳"이 드물어야 쉼이 쉼이다.

## 왜
- 스테이지 끝마다 멈춰 숨 쉬는 곳이 있으면 긴장 → 이완의 박자가 생긴다(Hades의 휴게실·Slay the Spire의 휴식처). 상점·이웃을 거기 모으면 "돌아온 이웃이 늘어난다"는 이야기(0003)가 눈에 보인다.
- 공격 버튼으로 말 걸기: 말 걸 수 있는 곳(쉼터)과 싸우는 곳이 겹치지 않아서 충돌이 없다. 컨트롤러 버튼 하나를 아낀다.

- 쉼터마다 모습 바꾸기(깊을수록 어둡게, 돌아온 이웃이 늘어남). 지금은 같은 지도.
- 상점 물건 늘리기(기술 해금은 반딧불, 별도 화면).
