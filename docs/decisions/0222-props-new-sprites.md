# 0222. C5 소품 새 그림: 부술 수 있는 것 넷 + 보물 상자

- 날짜: 2026-10-28
- 상태: 채택(사장 "1, 2 하자"), 그림은 받는 대로

## 왜 이것만
- C5(0191, 선택)는 "임시 타일·소품이 남은 곳". 개발판·운영판은 Sunnyside 팩(0066)을 받아 땅·벽·나무·꽃·바위·그루터기·모닥불·좌판·통나무·마을 꾸미기가 이미 팩 그림이다(`tiles.py` 코드 타일은 팩이 없는 공개 빌드에서만).
- 코드 그림으로 남은 것 가운데 **부술 수 있는 것 넷**(흙더미·뿌리혹·돌무더기·실뭉치, 0175)은 거의 모든 굴 방에 나오는데 폭 10px쯤의 밋밋한 덩어리라 24칸 잡몹(0221) 곁에서 가장 작다. **보물 상자**는 보물방에서만이지만 보상의 얼굴이다. 이 둘만 바꾼다.
- 그대로 두는 것: 출구 구멍·샘·저장 고리·뿌리 문(빛이 돌고 숨 쉬는 효과 — 코드가 맞다), 지대 장애물(가시 덤불·실 그물·떨어지는 돌·고치·묻은 도토리 — 예고·판정이 붙어 모양이 곧 신호), 줍는 것(작은 아이콘, 산딸기는 0178에서 다시 그렸다).

## 정한 것
- 크기: 바닥 칸 하나(16px) 위에 폭 14~16 · 키 11~14px(상자 열림은 뚜껑까지 17). 지금 10px보다 크게.
- 부술 수 있는 것 넷이 나눠 쓰는 표시(0205)는 지킨다: 어두운 외곽선(바닥 장식이 아니라 물건) + 밝은 금(깨진다)은 그림에, 2.5초마다의 반짝은 게임이 그린다.
- 받는 법: 수수·잡몹 때처럼 새 대화, 그림 한 장(`tools/art/props_ref.py` → `ref_props.png`: 게임 크기 Naïl 옆에 지금 코드 그림과 같은 모양·색을 목표 크기로 칠한 색 안내), 짧은 프롬프트(`docs/art/props-sprite-prompt.md`), 3×2 여섯 칸.
