# 0046: 모모 보스 — 첫 길 끝에서 세 번, 꽃잎, 돌아와 빈 자리에

- 상태: 채택 (2026-10-25). 0040 순서 6(모모)의 앞부분이다. 0037 3-A("세 번 이겨야 꽃이 핀다")와 0029의 보스 패턴 초안을 만든다. 모모 플레이어블은 다음 일이다.

## 결정
1. **자리**: 첫 길(쉼터 1 → 쉼터 2)의 보스 칸 굴, 끝방. 무리 대신 모모 혼자 있다(`dungeon::Params::boss`).
   - 같은 시드면 굴 모양은 모모가 있든 없든 같다(난수는 그대로 쓰고 끝방 적만 바꾼다).
   - 첫 시작(Normal)에서, 모모가 아직 돌아오지 않았을 때만. 오늘의 굴·개발 시나리오는 기록을 건드리지 않는다.
2. **세 번, 한 수씩**(0037 "패턴은 매번 하나씩 늘린다"):

   | 만남 | 수 |
   |---|---|
   | 1 | 높이 뛰기(웅크림 → 체공 0.5초 → 착지 고리 20px) ↔ 뒷발 차기(짧은 돌진 0.2초) |
   | 2 | + 굴로 숨기: 흙 둔덕이 1.1초 동안 플레이어를 따라온다(걸음보다 느린 64px/s) → 멈춰 떨며 고리를 보인다(예고 시간) → 튀어나오며 둘레 피해. 숨은 동안은 맞지도 때리지도 않는다 |
   | 3 | 뛰기를 세 번 이어서(이어 뛰는 웅크림은 예고의 55%만) |

   - 대장(0032)처럼 공격 중에는 맞아도 멈추지 않는다. 빈틈은 착지 뒤·튀어나온 뒤·차기 끝의 쉼.
   - 체력 28, 넉백은 조금 받는다(대장 0.15 → 0.25). 수치는 `species.rs` MOMO, 시간은 `tuning.rs` MOMO_*.
   - 굴파기 둔덕은 Naïl의 굴파기와 맞서는 거울이다(0029).
3. **이기지 않고도 지나간다**(0037): 모모에게 쓰러지면 그 런에서는 첫 길 끝이 보통 무리로 돌아간다. 모모는 다음 런에 다시 기다린다.
4. **이기면**:
   - 1·2번째: 한마디("…아파. 그래도 안 비켜." / "왜 날 미워하지 않아? …왜.") → 반대쪽으로 뛰어 사라짐 → Naïl "기다려!" → 내레이션 "큰 나무 아래 마을, 빈 자리의 꽃잎 하나가 분홍으로 물들었다."
   - 3번째: 모모가 돌아오는 장면(0039 일러스트) + 두 줄("먼저 마을에 가서 쉬고 있어" / "…빈 자리, 내 자리 맞지?"). 참 엔딩 조건 `momo`가 선다.
   - 끝방 보상(뿌리 심장·씨앗)과 출구는 보통 보스방과 같다.
5. **만날 때 한마디**: 이름표는 계속 "???"(이름은 돌아올 때 스스로 말한다, 0027). 말이 조금씩 무너진다: 막기("또 너야") → 사라진 가족("다 데려갔어") → 걱정("너도 데려갈 거야"). Naïl의 답은 "이번엔 너를 데리러 왔어"로 간다.
6. **기록**(`profile.rs`): 수 `momo_wins`(0~3), 깃발 `momo`(돌아옴).
7. **빈 자리의 꽃잎**(쉼터·마을 그루터기): 처음엔 시든 꽃잎 하나. 이길 때마다 분홍 꽃잎이 하나씩, 셋까지. 살펴보면 Naïl의 말도 바뀐다.
8. **돌아온 모모**: 마을 빈 자리 그루터기 위에 앉는다(말 걸기 세 줄 돌아가며). 스프라이트 줄 8(`critters.py` MOMO_BLOOM: 따뜻한 회갈색, 검은 눈, 핀 꽃, 뿌리 없음). 초상화는 아직 없다(이름표 + 색 네모).
9. **런 사이 한마디**(0041 표): 처음 이긴 뒤 마을의 보리 "그 아이를 만났구나. 굴토끼네 막내다…", 돌아온 뒤 포포 "빈 자리가 찼네!". 조건에 기록 수(`CountAtLeast`)를 더했다.
10. **도감**: 일곱째 "물든 굴토끼". 목록이 아래 "만난 이웃" 줄에 닿지 않게 줄 간격을 종 수로 나눈다. 칸마다 두 줄이 넘으면 잘리므로 모모 글은 다섯 언어 모두 두 줄 안으로 줄였다.
11. **보스 막대를 화면 위로**: 던전 방(높이 192px)이 화면(180px)보다 커서, 방 아래쪽에 서면 아래 막대가 Naïl과 보스를 가렸다(헤드리스에서 발견). 이름 + 막대를 위 가운데에 둔다. 알림(위 26px)과 겹치지 않는다.
12. 개발 시나리오 **"모모 첫 만남"·"모모 세 번째"**: 첫 길 끝 굴의 끝방 문 안쪽에서 시작(기록은 남기지 않는다).
13. 글 24줄 다섯 언어(그루터기의 꽃잎 셋 줄 포함). DeepL 오독을 고쳤다: 물든 = "dyed"·"色づいた"·"染色的", "질 때마다" = "whenever it withers", "걸어서 떨어지자" = "jump off them", "그 목소리가" = "your voice", 굴토끼네 = "Gultoki family"(이름으로 읽음), 아래 = "downstairs"·"楼下". 간체 概가 폰트에 없어 "也许"로 바꿨다.

## 왜
- 세 번 싸우는 게 지루하지 않으려면 매번 새 것이 있어야 한다(0037 위험 메모). 수가 늘고, 말이 바뀌고, 꽃잎이 는다.
- 실패해도 길을 막지 않는다: 런 하나가 모모 한 판에 걸리지 않게. 대신 그 런에선 꽃잎이 늘지 않는다.
- 숨은 둔덕을 걸음보다 느리게 한 것: 굴파기로 피하지 않아도 걸어서 피할 수 있어야 공정하다. 굴파기는 더 쉬운 길이다.

## 확인
- 단위 테스트: 모모가 만남마다 한 수씩 는다(1번째 숨기 없음, 2번째 숨기·튀어나옴, 숨은 동안 안 맞음, 3번째 착지가 더 잦음), 끝방 보스가 무리를 대신하고 굴 모양은 같다, 마을 한마디(보리 → 포포 순서).
- 헤드리스(Chromium):
  - 첫 만남 대사 → 싸움(착지 고리) → 이김(임시로 체력 1) → 달아나는 장면 → 꽃잎 내레이션
  - 세 번째: 둔덕·이어 뛰기, 쓰러지면 쉼터에서 깨어남, 이기면(임시로 무적) 모모가 돌아오는 장면 + 두 줄
  - 마을: 꽃잎 둘 그루터기 + Naïl 말, 돌아온 모모가 그루터기 위에 앉음 + 말 걸기, 보리·포포 한마디
  - 도감 다섯 언어(넘침)
- 사람 판정이 남았다: 손맛(체력 28, 체공 0.5초, 둔덕 속도), 세 번째가 너무 센지, 대사 톤.
