# 0144. 중국어 번체(대만)·폴란드어 — 열한 언어, 터키어·이탈리아어는 출시 전으로

- 날짜: 2026-10-27
- 상태: 채택. 사장: "번체랑 폴란드어 지원 추가해줘", "터키어·이탈리아어는 나중에 하자".

## 왜 이 둘
- Steam 언어 비율(2026-09, 2차 출처 요약): 폴란드어 1.49%, 번체 1.27%, 터키어 1.09%, 이탈리아어 0.56%. 이미 가진 아홉 다음으로 큰 둘이다(KB `small-game-localization` 권고 순서의 넷째 묶음 독·프·번체·폴).
- 번체: 대만·홍콩·마카오 기기는 그동안 영어로 떨어졌다(번체를 간체로 보내지 않는다, 0014). 폰트 길(Ark Pixel)이 이미 있었다.
- 폴란드어: 러시아어(0085)에서 푼 성·복수형 방법을 그대로 쓴다.

## 왜 터키어·이탈리아어는 나중
- 글을 바꾸면 모든 언어를 손으로 쓴다(CLAUDE.md). 언어가 늘수록 그 뒤 글을 고치는 값이 커진다. v0.3 개발 중이라 글이 아직 매주 바뀐다 → "구조는 처음부터, 번역은 글이 굳은 뒤"(KB). 출시 전에 넣는다.
- 터키어 글자(ğ ı İ ş)는 이번 서브셋(라틴 확장 A)에 이미 들어 있다. 대문자로 바꾸는 코드가 없어 터키어 i 문제도 없다. 남은 일은 번역뿐.

## 결정
- `Lang::ZhHant`("繁體中文", 간체 다음)·`Lang::Pl`("Polski", 러시아어 다음). 저장 칸 값 10·11(옛 값은 그대로).
- 기기 언어: `zh-Hant`·`zh-TW`·`zh-HK`·`zh-MO` → 번체(문자 표시가 먼저: `zh-Hans-HK`는 간체), `pl-*` → 폴란드어.
- 번역: 언어마다 하나씩 손으로 썼다(640키, 기계 번역 없음). 검사 스크립트(키·순서·자리표시자·빈 글·폰트 글자·넓어진 짧은 라벨)를 통과시킨 뒤 표에 넣었다.
  - **번체**: 간체 표의 이름·용어를 따르되 대만 말로(選單·存檔·設定·手把·輕觸·相簿·粉紅色·喔·「」, 이름 모르는 동물은 牠). 수수는 蘇蘇. Naïl은 보리에게만 您. 고정 칸은 간체보다 길지 않게.
  - **폴란드어**: 플레이어·Naïl의 성을 정하지 않는다(현재·미래형, 비인칭 "Udało się", 명사 "Nokaut…", 아기 두더지는 중성 "kreciątko", 내레이션은 역사적 현재). NPC 성은 다른 표와 같게(모모·수수 여성, 도토·콩이·보리 남성). Naïl은 보리에게만 Pan 꼴. 숫자는 라벨 뒤("Nasiona: {0}", 1/2–4/5+ 복수형을 피한다). 한 낱말 14~16자 안.

- 폰트:
  - **폴란드어**: Galmuri 원본(2.404)에서 "지금 글자 + 라틴 확장 A(U+0100–017F)"로 다시 줄였다(2,714 → 2,839자). 있던 글자의 윤곽·전진 폭은 원본과 같다(fontTools 비교).
  - **번체**: `build_cjk.py`에 번체 표(`NailCJK-zh-Hant.ttf`, 이름 Nail CJK 12 TC). 대만 모양 `zh_tw` → `zh_hant` → 기본 순으로 고른다.
    - Ark Pixel에는 번체 한자가 많이 빠졌다(擊 裝 沒 換 層 殼 絲 喚 鑑 蘇 …, Ark README "仍然缺少大量字符"). 처음 번역은 이 글자를 피하느라 142줄을 돌려 썼다(攻擊 → 出招, 裝備 → 使用中, 蘇蘇 → 酥酥 등). 게임 말로 어색했다.
    - → Ark에 없는 한자만 **俐方體11號(Cubic 11, OFL)**를 12px로 찍어 메운다. Ark의 자매 폰트 fusion-pixel-font가 12px 번체를 메우는 방법과 같다(크기 12, 자리 (-1, +1), 위아래 빈 줄을 덜어 12줄). 그 뒤 번역을 표준 대만 말로 되돌렸다. 지금 28자가 Cubic에서 온다. 확대해 보니 획 굵기·크기가 Ark와 어울린다.
    - 간체·일본어는 Cubic을 쓰지 않는다(모양이 다르다). 다시 만들 때 `python3 tools/fonts/build_cjk.py <ark> <Cubic_11.woff2>`.
- 공식 페이지의 언어 줄도 열하나로.
