# 0254. 두꺼비 혀 늦추기, 쓰러진 포자버섯 구름에 예고, 적 겨눔 회전 제한 — 포포의 응원 다시 짜기(제안)

- 날짜: 2026-10-29
- 상태: 1~3 **구현**(개발판). 4는 **제안**(사장이 고른다).
- 사장(2026-10-29): "포포의 응원이 옵션 하나밖에 없고 정확히 뭘 하는지 잘 모르겠네. 효용이 있는지도…"
  "두꺼비의 혀는 아직도 거의 즉시 발동이야. 패링 불가능할 정도." "버섯도 죽자마자 바로 독가스 생기는 게 난이도를 높임."
  "적들의 조준이 한순간에 변경되는 경우도 있어서 예측 못 하는 경로로 오게 됨. 공격 예고가 나온 후 공격 각도 조절에 어느 정도
  각 변경 최대 속도가 있어야 하고 가속도 후 최대 속도가 되도록 해야 함."

## 1. 두꺼비
- 겨눔(띠 예고) `TOAD.windup` 0.55 → 0.8초, 혀가 뻗는 시간 `TOAD_EXTEND_TIME` 0.12 → 0.22초(0253). 뻗는 동안만, 뻗은 데까지만 맞는다.
- 아래 3의 회전 제한도 받는다 — 전엔 겨누는 내내 플레이어를 정확히 따라가 띠를 보고 비켜도 소용없었다.

## 2. 쓰러진 포자버섯
- 전: 쓰러지는 틱에 구름이 생기고 0.3초 뒤부터 아팠다(때리던 자리 = 구름 한가운데).
- 지금: 그 자리에 `SPORE_DEATH_DELAY` 0.8초 동안 둘레 예고(X 원, 다른 예고와 같은 잉크)가 차오른 뒤 구름이 퍼진다(구름 시간이 음수인 동안이 예고).
  시험 `spore_cap_death_cloud_waits_for_its_tell`.

## 3. 적 겨눔 회전(`Enemy::aim_toward`)
- 예고(돌진 띠 `Windup`, 겨누기 `Aim` — 두꺼비·도토 부채꼴, 토끼풀 실 겨누기) 동안 겨눈 쪽은 **0에서 `ENEMY_TURN_ACCEL` 6 rad/s²로 빨라져
  `ENEMY_TURN_MAX` 2.4 rad/s(≈140°/s)까지만** 돈다. 새 예고마다 0부터. 0.45초 예고면 ≈35°.
- 그래서 예고가 보인 뒤 옆으로 크게 돌면 따라오지 못하고, 돌진·탄의 방향은 예고 띠가 보여 준 쪽에서 크게 벗어나지 않는다.
- 웅크렸다 뛰는 청설모(`Crouch`)는 예고가 시작될 때 자리를 정해 두니 그대로.
- 시험 `windup_aim_turns_with_acceleration_and_a_top_speed`.

## 4. 포포의 응원(제안 — 고르기 전)
지금 하는 일(설정에는 "켜짐 20%"만 보여서 무엇인지 알 수 없다):
- 받는 피해 -20%, 쓰러질 때마다 -2%씩 최대 -80%(Hades God Mode, 0041)
- 실뿌리 없음(쓰러져도 런이 안 끝남), 길의 주인에게 쓰러지면 그 주인 건너뛰기, 쓰러져도 반딧불 70% 남김

다른 게임(2차 출처):
- Celeste Assist Mode: 게임 속도(10%씩 50%까지)·무적·무한 스태미나·대시 추가 — 항목마다 따로.
- Dead Cells Assist Mode(2022 "Breaking Barriers"): 목숨 수(1~무한)·이어하기·자동 공격·적 체력/피해·함정 속도/피해·**받아치기 창**·지도 공개 — 항목마다 따로.
- Hades God Mode: 피해 저항 하나(20% + 2%/죽음).

제안: 한 줄 켜기/끄기 대신 **포포의 응원 창** 하나에 항목 넷, 고른 항목 아래에 한 줄 설명.
| 항목 | 값 | 하는 일 |
|---|---|---|
| 받는 피해 | 그대로 / -25% / -50% / -75% / 쓰러질수록(지금 방식) | |
| 쓰러져도 계속 | 끔 / 켬 | 실뿌리 없음 + 주인 건너뛰기 + 반딧불 70% |
| 공격 예고 길게 | 1× / 1.3× / 1.6× | 적의 예고(`windup_mul`)를 늘린다 — 받아치기·피하기가 쉬워진다 |
| 받아치기 창 넓게 | 1× / 1.5× / 2× | |
기록 키는 지금 `assist`를 "쓰러져도 계속" + "쓰러질수록"으로 옮겨 이어 쓴다. 글은 열한 언어.
