# 0088. 문서·KB·코드 교차검증, 안내 페이지 폐기, 팩이 든 아티팩트는 그대로

## 한 것
- **docs/ 현행화**: phase-1 "구현 상태"(체력 5, 아홉 언어, 일러스트 11장, iOS·아이콘 줄, 웨이브는 개발 시나리오만), concept(그림 방식·플랫폼·단계 5), README(언어·Android 패드·iOS·타이틀 흐름), 일러스트 사양(`momo_deep` 줄, 11장), 바탕 출처(여섯 장 채택), CLAUDE.md(Galmuri 서브셋 실제 범위).
- **결정 기록 17개에 "후속" 줄**: 뒤 결정이나 코드가 바꾼 것을 옛 기록 상태 줄 아래에서 가리킨다(0007·0009·0011·0013·0014·0017·0018·0023·0027·0030·0039·0041·0042·0062·0065·0072·0073). 본문은 역사라 고치지 않았다.
- **KB 16곳**: Android 패드는 "공통 공백"이 아니라 버튼은 패치로 해결(축만 남음), APK 실기 설치·아이콘·paths, 웹 배포 가이드는 실제 실행으로 검증(deploy-web 124번째 실행까지 배포 성공), 언어 예시(fr·de가 생겨 결과가 바뀜), 가나 수(블록 기준 86·87, 원본에서 다시 셈)·폰트 크기, 이야기·다회차가 구현된 것.
- **CI**: `build-android.yml` paths에 `android/**`(아이콘)·`third_party/**`(패치한 miniquad)를 더했다. 그것만 바꾼 push가 APK를 다시 빌드하지 않았다.

- **Android 패드 버튼**: 실기에서 "다 됨"(0075 후속).
- **안내 페이지(`docs/playtest/playtest.html`)와 그 공유 링크는 폐기**했다(링크도 지웠다, 되돌릴 수 없음). v0.2.0 조건 1(0079)은 "본인 외 한 사람이 10~15분 해 보고 판정 4개에 답한다"로 남기고, 건네는 방법은 자유.
