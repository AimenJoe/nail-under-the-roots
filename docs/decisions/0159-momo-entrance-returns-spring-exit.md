# 0159. 모모의 등장·돌아오는 장면·길의 샘·끝방 출구: 말로만 있던 것을 보이게

- 날짜: 2026-10-27
- 상태: 채택. 사장 피드백 넷: "모모 첫 등장의 임팩트가 너무 약해", "보리 등 되돌아오는 장면도 인게임 특수효과가 있어야", "내려가는 컨셉인데 스테이지 끝 이동 오브젝트는 올라가네? 잘 안 보여", "맑은 샘물이 말로만 샘물이고 실제로는 없네". 사장이 고른 안: 모모는 **어둠 속 등장 + 카메라 팬**과 **시든 꽃잎 복선**, 샘은 **그림 + 밟으면 회복**, 돌아오는 이펙트는 **넷 모두**.

## 전
- 모모: 끝방에 들어서면 0.7초 뒤 대사 두 줄, 바로 싸움. 음악·카메라·빛·이름 카드 없음.
- 돌아오는 장면: 보리는 일러스트 뒤 그냥 걸어오고, 도토·콩이는 0.6초 뒤 말했다. 실이 풀리는 이펙트(`unravel`)는 잡몹이 죽을 때만.
- 샘: `Goal::Spring` 방에 들어서는 순간 체력이 차고 토스트만. 샘 그림은 없었다.
- 출구: 구멍 위에 ▲ — 올라가는 것으로 읽혔고, 쓰러진 자리·플레이어에서 떨어진 칸에 생기니 화면 밖이면 몰랐다.

## 결정

### 컷씬 장치(`cutscene.rs` `Step`, `world.rs`)
스크립트가 쓰는 장치 다섯을 더했다. 컷씬은 여전히 월드 로직을 멈추지만 **입자 효과와 `time`은 흐른다**(`World::tick_fx`), 안 그러면 실·꽃잎이 얼어 있다.
- `Pan { to, secs }`: 카메라를 `to`가 가운데 오도록 옮긴다(smoothstep, 장소 경계 안 `World::cam_at`). `None`이면 플레이어로 돌아가고 `Adventure::cam_hold`를 푼다.
- `Gloom { to, actor, radius, secs }`: 환경 어둠 위에 덮는 어둠(`World::gloom`). 배우 둘레만 밝다. 보랏빛 장막을 옅게 깔고 검은 마스크(`art.dark`)로 뚫는다(`draw_gloom`, 어둠 지도·예전 어둠 두 경로 뒤에).
- `Hush(bool)`: 음악을 내린다. `App::music_track`이 컷씬 중 `hush`면 곡 없음 — 보스 곡은 장면이 풀 때 시작한다.
- `Cue { cue, at }`: 이펙트 묶음(`world::Cue`): `Unbind`(실이 풀림: 흰 고리 + 보라 고리 + 실 열 올 + 반짝임 + 소리 `Unbind`), `Petals(bloom)`(꽃잎 흩날림, `FxKind::Petal` 팔랑임), `Rise`(보라 고리·어두운 먼지·흙·땅 울림 소리 `Rumble`), `Sparkle`. 소리는 `World::sounds`에 쌓고 앱이 튼다 — 컷씬은 `Sfx`를 모르니 테스트에서 돌릴 수 있다.
- `Card { name, sub, secs }`: 화면 위 이름 카드(`World::boss_card`, 지대 카드 그리기 `draw_card`를 같이 씀). 컷씬 그리기와 HUD 둘 다 그린다.
- 건너뛰기(`finish_fast`)는 장치의 끝값만 적용한다: 카메라는 잡아 둔 자리로, 어둠은 그 값으로, 음악은 그대로.

### 모모 등장(`cutscene::momo_meet(w, level, at)`)
음악이 끊기고 어둠이 Naïl 둘레만 남기며 내려앉는다(0.9초) → 빛이 모모 쪽으로 옮겨 가며 카메라도 따라간다(1.6초) → 시든 꽃잎이 흩날리고 모모가 일어선다(땅 울림·흔들림) → '???' 카드(설명은 `mob_momo` "물든 굴토끼") → 말 두 줄 → 카메라·빛이 돌아오고 보스 곡. 두 번째·세 번째 만남은 꽃잎 없이 짧게(어둠 0.5초, 팬 0.9초).
**복선**: 모모가 지키는 굴(`Params::boss == Momo`)에서는 방마다 시든 꽃잎이 떠돈다(`World::petals`, `draw_wilted_petals`, 마을 빈 자리의 시든 꽃잎과 같은 색). 모모를 처음 보기 전부터 "누가 있다"를 묻게 한다.

### 돌아오는 장면 넷(`unbind_steps`)
쓰러진 자리에서 0.5초 뒤 실이 풀린다(`Cue::Unbind`, 흔들림) → 0.7초 → 제 모습의 배우가 나타나며 반짝임(`Sparkle`). 보리는 그 뒤 일러스트·대화, 도토·콩이는 바로 말. 모모(세 번째)는 배우 없이 실이 풀리고 분홍 꽃잎이 흩날린 뒤 꽃 피는 일러스트로. `boss_beaten`·`doto_returns`·`kongi_returns`의 배우는 처음엔 안 보인다.

### 길의 샘(`World::spring`, `spring_tick`, `draw_spring`)
`Goal::Spring` 쉼방 가운데에 돌 테두리의 맑은 샘(물결 고리·떠다니는 반짝임·빛 `LightSrc` 46px). **발을 담가야**(`SPRING_RADIUS` 15px, 걷는 중) 가득 회복 + 하늘빛 고리·반짝임 + 소리 `Heal` + 토스트. 한 번만(그 뒤 물결·빛이 잦아든다). 산딸기 셋은 샘 아래로. 저널 `springs`는 마신 수.

### 끝방 출구(`draw_exit`, `World::exit_at`, `draw_exit_mark`)
- 길의 굴(`adv.node.is_some()`)에서는 **파 내려가는 구멍**: 흙 테두리 안이 아래로 갈수록 검고, 숨 쉬는 빛 테두리, 위에서 구멍 속으로 떨어지는 ⌄ 셋. 필드에서 들어온 옛 굴(`Params::classic`)만 밝은 안쪽 + 떠오르는 ⌃(거긴 올라가는 게 맞다).
- 열릴 때 빛 고리·흙덩이·먼지.
- 화면 밖이면 `EXIT_MARK_DELAY`(1.5초, 보상을 줍는 동안) 뒤 HUD 가장자리에 작은 구멍 아이콘 + 그쪽 화살(맥박).

### 개발 시나리오
"길의 샘"(샘 방, 체력 반), "출구"(적 없는 끝방: 들어서면 출구).
