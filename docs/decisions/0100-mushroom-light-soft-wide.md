# 0100. 야광버섯 빛은 은은하게 넓게

- 날짜: 2026-10-26
- 상태: 채택. 0095의 버섯 빛 수치를 바꾼다. 사장: "야광 버섯은 은은히 넓은 범위로 비추도록 바꾸자."

## 전(0095)
- 버섯마다 반지름 34px, 세기 0.6으로 어둠을 뺐다. 버섯 둘레만 둥글게 밝은 웅덩이가 생겼고, 버섯 밑과 빛 패스에 가장자리가 딱 떨어지는 원(7px·8px)이 있어 테두리처럼 보였다.

## 결정(`tuning.rs` `MUSH_LIGHT_R`·`MUSH_LIGHT`, `render.rs` `draw_mushrooms`·`draw_world_lights`)
- 어둠 지도의 버섯 빛: 반지름 **64px**, 세기 **0.28**. 하나로는 바닥이 옅게 드러나고, 여럿이 모인 곳이 겹쳐 더 밝다.
- 버섯 둘레의 원은 동심원 세 겹(밑 13·9·5px, 빛 패스 16·11·6px, 겹마다 알파 0.035)으로 바꿔 가장자리를 풀었다.
- 그림자(0095)는 빛 세기에 비례하므로 버섯이 만드는 그림자도 같이 옅어진다. 모닥불·플레이어 빛은 그대로.

## 확인
- 헤드리스: 같은 콩이 방(심층)을 전·후로 찍어, 밝은 웅덩이와 원 테두리가 사라지고 방 전체 바닥이 옅게 드러나되 심층의 어둠은 남는 것을 확인했다.
