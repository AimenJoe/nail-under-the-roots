# 0012: 무기는 처음부터 주지 않는다. 스토리를 따라 기본 발톱부터 하나씩

- 상태: 채택 (2026-10-25). 0011의 "일반 시작은 두더지 발톱만"을 대신한다.

## 맥락
0011에서 발톱 4종을 만들고 일반 시작에 기본 발톱을 쥐여 줬다. 사장 결정: 무기는 처음부터 주는 게 아니라 스토리를 진행하며 기본 무기부터 하나씩 준다. 첫 무기는 튜토리얼에서 허수아비로 공격을 배우는 순간부터.

## 결정
1. **맨손 시작**: 첫 시작(Normal)과 튜토리얼은 가방이 비어 있고 `player.armed = false`. 공격 입력이 나가지 않는다. 이동·굴파기는 된다.
2. **튜토리얼에서 첫 발톱**: 이동(40px) → 앞에 반짝이는 **두더지 발톱**(바닥 획득물) → 닿으면 JRPG식 획득 창("새 발톱을 얻었다!", 아이콘·이름·설명, 0.5초 뒤 확인으로 닫힘, 3.5초면 저절로) → 자동 장착 → 허수아비 등장 → 3연타.
3. **획득 경로는 둘, 같은 통로**: 바닥 획득물(`world.pickups`)과 컷씬 단계 `Step::Give(무기)`. 둘 다 `world.gifts`에 넣고 앱이 가방에 넣은 뒤 획득 창을 띄운다. 여러 개면 차례로. 획득 창이 떠 있는 동안 월드는 멈춘다.
4. **이후 순서 — 0037이 대신한다(독 발톱은 Naïl 자신의 힘).** 옛 초안: 두더지 발톱(튜토리얼) → 새싹 발톱(1층 보스 전, 꽃 핀 입구의 이웃이 준다) → 독 발톱(뿌리 지대 보스 처치 보상) → 바위 발톱(심층 입구). 각 지점은 컷씬 `Give`로. 지금은 층·보스가 없어 코드에 걸린 지점은 튜토리얼 하나뿐이다.
5. **개발 시나리오는 예외**: 튜토리얼 외 개발 시나리오는 테스트를 위해 기본 발톱을 들고, "발톱 4종 비교"는 넷 다 든다.

## 왜
- 무기 획득이 스토리 보상이면 "왜 또 하나"(반복 동기)와 세계관(변해 버린 이웃을 깨우면 도움을 준다)이 한 줄로 묶인다(0003).
- 맨손에서 시작해 공격을 "얻는" 순간은 튜토리얼의 가장 강한 가르침이다. 버튼을 눌러도 안 되던 것이 발톱을 줍자 된다.
- 획득 통로를 하나로 두면 보상 선택(2단계)·상점(3단계)도 같은 길로 들어온다.

## 비용
- 재시작마다 튜토리얼을 다시 본다(저장이 3단계라). 그때까지는 개발 시나리오로 건너뛴다.

## 재검토 조건
- 스토리 초안이 나오면 4번의 지점을 확정한다. 무기 수가 보스 수와 안 맞으면 보스 보상을 무기 대신 다른 것으로.
