# 0059: 타이틀 버전은 Cargo.toml에서 읽는다

- 상태: 채택 (2026-10-25).
- 사장: "타이틀의 버전 정보가 실제 릴리스의 버전 정보가 아니지?" 맞다. i18n 표에 "v0.1"이 손으로 박혀 있었고, 릴리스 v0.1.0과 따로 놀았다.

## 결정
1. 다섯 언어 `version` 글은 "v{0}"다(2026-10-25 사장: "타이틀에서 프로토타입 빼자". 처음엔 "프로토타입 v{0}").
2. `{0}`은 `env!("CARGO_PKG_VERSION")`(= 릴리스 태그 `v<버전>`, `release.yml`과 같은 값)이다.
3. CI에서 빌드했으면 커밋 앞 7자를 붙인다(`option_env!("GITHUB_SHA")`): "v0.1.0 · 85d7c83".
   - 같은 버전이라도 main에 올라간 웹 빌드가 어느 커밋인지 알 수 있다.
   - 릴리스 APK에는 태그 커밋이 찍힌다. 로컬 빌드는 버전만 찍힌다.
4. 저작권 줄과 겹치지 않게 남은 폭에 `ui.fit`.

## 왜
- 버전은 한 곳(Cargo.toml)에만 둔다. 릴리스(0058 뒤 `release.yml`)·APK versionName·화면이 모두 거기서 나온다.
- 테스터가 "어느 빌드에서 봤는지" 말할 수 있어야 한다. 웹은 push마다 바뀌어 버전만으로는 모자라다.
