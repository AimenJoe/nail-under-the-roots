# 0104. 불이 아래(앞)에 있으면 그림자를 더 길게

- 날짜: 2026-10-26
- 상태: 시험 채택(사람 판정 전). 0103의 길이를 바꾼다. 사장: "광원이 아래쪽에 있을 때는 그림자가 좀 더 길어도 됨."

## 결정(`render.rs` `shadow_dir`, `tuning.rs` `FIRE_SHADOW_BACK`)
- 불이 물체보다 아래(화면 앞)에 있으면 그림자는 뒤(위)로 눕고, 3/4 시점에서는 몸에 가려 거의 안 보였다.
- 길이에 `1 + FIRE_SHADOW_BACK × (위로 향한 정도)`를 곱한다. 바로 위로 눕으면 1.8배, 옆으로 눕으면 그대로, 앞(아래)으로 눕으면 그대로.

## 확인
- 헤드리스: 쉼터에서 모닥불 왼쪽 위에 선 플레이어의 그림자가 몸 뒤(왼쪽 위)로 몸 밖까지 나오는 것을 전·후로 확인했다.
