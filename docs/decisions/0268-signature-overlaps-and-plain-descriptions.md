# 0268 — 고유 재주가 무기와 겹칠 때(호두·가시덩굴 각반), 고유 재주 설명을 쉬운 말로

- 날짜: 2026-11-02
- 상태: 채택(사장 2026-11-02 "호두·각반 겹치는 거 말한 대로 고쳐줘. 그리고 설명이 많이 어색하다"). 0247의 고유 재주를 고친다.

## 왜
- **갈라지는 열매 + 호두**: 재주는 마무리 던지기의 조각 수를 "둘 이상"으로 맞췄는데(`max`), 호두는 원래 셋으로 갈라져 아무것도 바뀌지 않았다.
- **가시 발 + 가시덩굴 각반**: 각반의 마무리 차기가 이미 덤불을 남겨, 재주를 깨워도 같았다.
- 설명은 "나일 자신의 힘: 두더지 침의 독. 깨우면 어느 발톱이든…"처럼 머리말과 번역투가 붙어 어색했고, 독일어·프랑스어는 재주 칸 설명 줄 수(큰 나무 창 4줄·일시정지 탭 3줄, 넘치면 잘린다)를 넘었다.

## 무엇을
- 갈라지는 열매: 원래 갈라지는 열매는 조각 +1(호두 3 → 4), 아니면 조각 둘(`Talents::with_signature`).
- 가시 발: 무기가 원래 덤불을 남기면(각반) 덤불이 `SIG_THORNS_LONG` 2배(3초 → 6초) 남는다. 덤불 길이는 `Spawn::Thorns { time }`으로 넘긴다(`Player::leave_thorns`, `Toss::plant`).
- 설명 셋을 열한 언어로 다시 썼다: 머리말("~ 자신의 힘")을 빼고, 무엇이 언제 일어나는지 + 겹치는 무기에서 무엇이 더해지는지 두 문장. Galmuri·Ark 글꼴 폭으로 재 보니 큰 나무 창(268px)에서 모든 언어가 2~3줄.

| | 한국어 |
|---|---|
| 독 발톱 | 어떤 발톱으로 쳐도 적이 독에 걸린다(마무리 타·강타는 더 오래). 독은 적을 멈추지 않고 체력만 깎는다. |
| 가시 발 | 마무리 차기와 강차기가 발 앞에 가시 덤불을 남긴다. 가시덩굴 각반이면 덤불이 두 배 오래 간다. |
| 갈라지는 열매 | 마무리 던지기와 큰 도토리가 맞거나 벽에 닿으면 조각 둘로 갈라진다. 호두는 조각이 하나 더 는다. |

## 시험
`split_adds_a_shard_to_walnuts_and_two_to_the_rest`, `thorn_feet_make_briar_patches_last_longer`.

## 사람이 볼 것
- 각반 + 가시 발의 덤불 6초가 너무 많지 않은지(덤불은 한 번에 여섯까지).
- 새 설명의 어감(특히 직접 쓴 외국어).
