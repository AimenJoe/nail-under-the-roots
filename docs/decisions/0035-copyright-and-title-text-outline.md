# 0035: 저작권 표시(Beardworks)와 타이틀 글자 테두리

- 상태: 채택 (2026-10-25, 사장 "개인사업자 있으니 카피라이트도 넣어야겠다. Beardworks", "메뉴 글씨가 깨진다 … 일본어·중국어만 제대로 나오네").

## 결정
1. **저작권**: 타이틀 왼쪽 아래 `© 2026 Beardworks`(i18n 키 `copyright`, 다섯 언어 같은 글 — 고유명사라 번역 안 함, 글 리터럴 금지 규칙은 지킨다).
   README에 저작권 줄, `assets/LICENSES.md`의 직접 그린 그림 = © 2026 Beardworks, `Cargo.toml` authors, `web/index.html` author·copyright 메타.
   레포는 공개지만 오픈소스 라이선스 파일을 두지 않는다 = 모든 권리 보유(코드·그림·글). 폰트·의존성은 각자의 라이선스.
2. **타이틀 글자 테두리**: 원인 확인 — 글자는 앞에 제대로 그려지고 있었다(뒤의 뿌리 선을 초록으로 바꿔 찍어 보니 글자 위에 초록이 없음).
   Galmuri11 Condensed(한국어·영어·포르투갈어)는 획이 1px로 가늘어서, 뒤의 2px 뿌리 선이 글자 사이를 지나가면 획이 끊긴 것처럼 읽힌다.
   일본어·중국어(Ark Pixel)는 획이 빽빽해 덜 드러난다. 최근 변경(0034) 이전 빌드도 같았다(픽셀 비교) — 부작용이 아니라 원래 있던 것.
   → `Ui::with_outline()`: 상하좌우 1게임 px에 어두운 글자를 먼저 찍는다. 타이틀 화면에만(바쁜 배경 위의 글). 패널 위 글은 그대로.
