# 0112. 물든 모모 대화 초상화(나노바나나): 88px에서 읽히는 실과 빛나는 눈

- 날짜: 2026-10-26
- 상태: 채택. 0110(돌아온 모모)에 이은 넷째 묶음.

## 결정(`tools/art/ai_portraits.py` `momo_tainted`, `tools/art/sources/ai/momo_tainted_{normal,pained}.png`)
- 칸 7~8(보통 = 차갑고 멀다, 괴로움 = 반쯤 감은 눈·찌푸린 눈썹·눈물 한 방울).
- 돌아온 모모 보통 표정 그림을 고쳐 그렸다(털 자두빛 회색·시든 꽃·초록 눈·보라 실). 그래서 캐릭터 영역이 1px까지 같다. 틀(1.22, 귀 끝을 칸 맨 위에), 자두빛 선, 아래 끝 번지기 끔을 돌아온 모모와 똑같이 쓴다.
- 보라 실은 눈 팔레트(보랏빛 8칸)를, 초록 눈은 채도 칸(16)을 쓴다. 따로 칸을 늘리지 않았다.
- **실의 흰빛을 보랏빛으로**(`_tint_glow`, `HALO`): 원본의 빛 번짐·실 가운데는 실 빛과 배경 베이지가 섞인 흰빛이라 어두운 대화창에서 하얗게 튀었다(사장: "흰색이 너무 튀는데?"). 거의 배경색인 번짐(채도 < 0.12)은 어두운 보라(밝기 0.42), 짙은 흰빛(채도 < 0.3, 밝기 > 0.75)은 연보라(0.62~0.88). 눈·눈물 상자는 그대로.
  - 처음엔 번짐이 빛으로 읽힌다고 보고 남겼다. 어두운 바탕에서는 흰 테두리였다.
  - 번짐을 바깥에서 벗겨 지우자, 남은 실 고리가 칸 한 점(원본 약 12px)보다 가늘어져 88px에서 귀 밖 고리가 사라졌다. 그래서 지우지 않고 물들인다.

## 함정(첫 그림 → 고쳐 그림)
- **실이 가늘면 88px에서 사라진다**: 원본의 실(6px쯤)은 칸 한 점(원본 약 12px)보다 가늘어 평균에 묻혔다. 게다가 목·어깨에 감겨 있어 이 틀에서는 칸 아래로 잘렸다. "선만큼 굵게, 볼·이마·귀 둘레로 올려" 다시 그렸다.
- **"빛나는 초록"이 흰빛에 가까운 민트(178,249,171)로 나왔다**: 줄이면 흐린 연두다. "반딧불 같은 선명한 초록"으로 다시 그렸다.
- 이야기 신호(실·눈 색)는 원본 크기가 아니라 **줄인 칸에서** 읽히는지 본다.

## 확인
- 색까지 비교: 커밋된 시트와 다른 칸은 7·8뿐이다.
- 헤드리스: 개발 → "모모 첫 만남"의 "???" 대화에 새 그림이 나오고, 실과 초록 눈이 또렷하다.
