# 0103. 모닥불 곁 그림자는 불에서 바깥쪽으로 퍼지고, 바닥에 깔린 장식은 높이만큼 짧게

- 날짜: 2026-10-26
- 상태: 시험 채택(사람 판정 전). 0102를 넓힌다. 사장: "모닥불이 있으면 모닥불 주위로 그림자가 퍼져야지. 바닥에 깔린 물체들은 높이별로 그림자가 짧으면 됨."

## 결정(`render.rs` `shadow_dir`·`campfires`·`ShadowLight`·`drawable_x`·실루엣 셰이더 `Fire`, `draw_cast_shadows`, `sunny.rs` `StampShadow`, `terrain.rs` `Baker::fires`, `tuning.rs` `FIRE_SHADOW_*`·`DECOR_LIFT_*`)
- **방향 하나로 정한다**: `shadow_dir(발, 가장 가까운 모닥불, 밝은 곳인가)`가 실시간 그림자와 지도 굽기에 같은 방향·길이를 준다.
  - 모닥불 곁: 불 밑동 → 발 방향(바깥쪽). 길이(높이 1px당)는 곁 0.5, 닿는 끝(150px) 1.6. 멀수록 길다. 불은 낮은 광원이라 해보다 길다.
  - 옆으로 눕는 그림자: 기울이기만 하면 발 줄 한 줄로 납작해져, 옆쪽일수록 뒤(위)로 높이 1px당 최대 0.3 두께를 준다.
  - 밝은 곳(마을): 불에서 90~150px 사이에서 해 방향(0102)으로 부드럽게 돌아간다. 불이 없으면 해.
  - 어두운 곳(뿌리 밑 쉼터): 불이 닿는 데(150px)까지만. 실루엣 셰이더가 그림자 자리마다 불까지 거리를 재 82px부터 옅어진다. 진하기 0.42(어둠 지도가 위에 덮여 해보다 진하게).
- **0095 타원 그림자**: 모닥불 몫은 뺀다(모양 그림자가 맡는다). 플레이어 빛·야광버섯·반딧불·저장 지점은 그대로 타원.
- **바닥에 깔린 장식**: 3/4 시점의 꽃·조약돌·풀포기는 그림 높이만큼 서 있지 않다. 그림자 길이에 높이 비율을 곱한다: 꽃 0.3, 조약돌 0.45, 풀포기 0.6. 0102에서 뺐던 꽃(무리로 핀 둘레 꽃까지)도 짧은 그림자를 갖는다. 어두운 쉼터에서도 불 곁 장식은 불 바깥쪽으로 굽는다.
- 굽기(`Baker`)는 모닥불 자리를 받는다(장소의 소품 'F').

## 확인
- 헤드리스: 쉼터에서 플레이어를 모닥불 둘레 네 곳(오른쪽·오른쪽 아래·왼쪽 아래·위)으로 옮겨 찍어, 그림자가 불 바깥쪽으로 도는 것과 불 곁 풀포기가 바깥쪽으로 그림자를 굽는 것을 확인했다. 마을에서는 불 곁 풀포기·바위가 바깥쪽, 먼 것은 해 방향.
- 어두운 쉼터에서는 그림자가 옅다(어둠이 위에 덮인다). 길이·진하기는 사람 판정.
