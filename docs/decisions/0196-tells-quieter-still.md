# 0196. 적 예고를 한 단계 더 은은하게 — 투명도 0.25

- 날짜: 2026-10-28
- 상태: 채택. 0192의 투명도(0.3·0.04, X 0.6)를 바꾼다. 모양·색·채움·시점은 그대로.
- 사장: "0.4에 공격 예측 인디케이터 투명도 조금만 더 올려 줘" (= 더 투명하게, 0192와 같은 뜻).

## 결정
- `TELE_A` 0.3 → **0.25**, `TELE_BASE_A` 0.04 → **0.03**, 가운데 X `TELE_MARK_A` 0.6 → **0.5**.
- v0.4 패치(0193 갈래): 운영판 줄기(v0.4.3 준비 커밋) 위에서 고치고 v0.4.3에 함께 넣는다. 마일스톤 갈래에는 합친다.

## 확인
- 헤드리스(개발 → 꽃 핀 입구·어두운 심층) 0.3과 나란히: 0.25에서도 풀밭의 다 찬 띠(옅은 갈색 띠 + 테두리)와 어두운 굴의 붉은 띠가 보인다. 0192에서 "다음 후보 0.25, 풀밭 테두리가 남는지 확인 안 함"이라 적은 것을 이번에 확인했다.
- 흑백 대비 근사(0192 방식): 굴 바닥 약 1.38·풀밭 약 1.11 — 풀밭은 밝기보다 색조·테두리 모양으로 읽힌다(0192).

## 사람이 볼 것
- 0.25가 이제 알맞은지. 더 내리면 풀밭에서 다 찬 순간이 흐려지기 시작한다 — 그다음은 모양(테두리 두께)으로 보강할지 정한다.
