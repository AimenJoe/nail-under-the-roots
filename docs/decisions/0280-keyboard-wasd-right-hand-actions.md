# 0280 키보드 = WASD + 오른손 동작(0022 그대로), 메뉴 뒤로에 회피 키

- 상태: 채택(사장 2026-11-05 "그럼 wasd로 하자. 액션은 오른손 쪽에 배치해야겠지?")
- 관련: 0022(기본 배치 — 그대로), 0278(보조 키 — 거둠, 웹 키 입력은 채택), 0279(방향키 전제 — 거둠), KB `concepts/controller-layout-and-remapping.md`

## 왜
0279는 "방향키 + 왼손 Z·X·C"를 관례로 들었는데, 근거로 든 Celeste·Hollow Knight는 **옆에서 보는 플랫포머**다. 쿼터뷰·탑다운 액션을 따로 찾아보니(공략·가이드 표, 2차) 모두 WASD였다:

| 게임 | 이동 | 동작 | 마우스 조준 |
|---|---|---|---|
| Moonlighter | WASD | J 공격 · K 보조 · Space/Q 구르기 · I 가방 · M 지도 | 없음 |
| Cult of the Lamb | WASD | K/좌클릭 공격 · Space 구르기 · E 상호작용 · L/우클릭 저주 | 둘 다 |
| Tunic | WASD | Space 회피·상호작용 · J/K/L 아이템 | 없음 |
| Hades II | WASD | 좌클릭 공격 · Space 대시 · Q 캐스트 · 우클릭 특수 | 있음 |

마우스로 겨누지 않는 쪽(이 게임처럼)은 **WASD + 오른손 J·K·L** — 0022(J 공격·K 굴파기·L 필살기·I 아이템·M 지도)가 Moonlighter와 거의 같다. 처음 배치가 맞았다. 잘못은 메뉴 "뒤로"가 Esc뿐이라 오른손을 옮겨야 했던 것과, 모바일 웹에서 키가 게임에 닿지 않던 것(0278에서 고침)이었다.

## 정한 것
- 키보드 기본값은 **0022 그대로**: 이동 WASD(방향키도 받는다), 동작 오른손 J·K·L·I, Q/E 넘기기, M 지도. 패드도 그대로.
- **메뉴 뒤로 = Esc·Backspace + 회피 키**(기본 K). 확인 = Enter·Space + 공격 키(J). 오른손이 J·K에서 떠나지 않는다. 다시 붙이면 따라간다.
- 0278·0279에서 바꾼 조작 설정 화면·글·저장 칸은 모두 0278 전으로. 0279가 쓴 저장(개발판에서만, 칸 24·키 Z·X·C·V)은 칸 24를 더 읽지 않고, 키는 저장된 그대로 읽힌다 — 개발판에서 Z·X·C로 보이면 조작 설정 → 기본값으로.

## 배운 것
비교할 때 **장르를 맞춘다**: 키보드 관례는 시점·조준 방식(플랫포머·쿼터뷰, 마우스 조준 유무)마다 다르다.
