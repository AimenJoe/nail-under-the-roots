# 0195. 플레이어블 도토의 싸움: 던지기·큰 도토리·뒤로 뛰기·도토리 묻기

- 날짜: 2026-10-28
- 상태: 채택(B2·B3 구현). 0191 B1 초안 그대로("0.5 버전에 대한 작업 별도로 진행해"). B4(이야기)·B5(글·안내)는 이어서.
- 사장: "0.5 버전에 대한 작업 별도로 진행해" — 마일스톤 갈래(`release/v0.5`, 0193)에서.

## 왜
- 근접 둘(Naïl·모모) 다음은 **거리가 다른 캐릭터**(0191, KB `second-playable-character`·`roguelite-replay-axes`). 도토의 보스 수(부채꼴 던지기·높이 뛰기·묻기, 0052)가 그대로 기술이 된다.
- 탄이 맞는 순간을 **손 타격과 같은 길**로 보낸다. 피해·멈춤·카메라 킥·등딱지 튕김·자세 깨기·게이지·박자 덤·다 맞춘 콤보 +1을 두 번 쓰지 않는다 — 규칙이 하나면 튜닝도 한 곳이다.
- 적의 탄(`Projectile`)과 따로 둔다: 받아치기·플레이어 피격 규칙이 플레이어 탄에 섞이면 "내 도토리가 나를 맞히는" 버그가 생긴다.

## 결정
### 킷(캐릭터 표 셋째 줄, `characters.rs`)
| 자리 | 도토 | 어디 |
|---|---|---|
| 공격 | 도토리 던지기 3타: 1·2타 곧게 하나(사거리 112px), 3타 부채꼴 셋. 박자 콤보 그대로 | `moveset::ACORNS`, `Hit::throw` |
| 강타 | 큰 도토리: 느리고(×0.65) 크게(×1.8) 날아 맞은 자리에서 둘레 22px를 친다 | `heavy_of`가 `Throw`도 바꾼다 |
| 회피 | 뒤로 뛰기: 서 있으면 겨눈 쪽 반대로, 움직이면 그쪽으로 62px, 공중 무적, **겨눈 쪽은 그대로** | `State::Leap`, `Dodge::Leap` |
| 특기 | 도토리 묻기: 게이지 가득 → 겨눈 쪽 앞에 셋, 1.3초 뒤 둘레 18px 피해 3(적만) | `Special::Bury`, `Spawn::Bury` |
| 받아치기 | 던지는 순간 손앞 13px의 짧은 판정(`StrikeKind::Toss`): 적은 안 맞고 날아오는 탄을 되받아치거나 벤다 | `Enemy::receive`가 `Toss`는 지나친다 |
| 게이지 | 도토리(`Gauge::Acorn`), 맞히면 찬다(다른 캐릭터와 같은 규칙) | |

- 무기 종류 `WeaponKind::Acorn`, 무기 `WEAPONS[5]` "볼주머니 도토리". 해금 깃발 `doto_memory`, 기록 번호 2, 재주 키 `leap`·`bury`.
- 그림은 임시(0191 C): 플레이어 = 돌아온 도토 줄(`DOTO_BACK_ROW`), 파 내려가기 = `dig.py` 줄 5(모모 몸 + 청설모 털빛).

### 탄의 길(`world/toss.rs`)
- 플레이어는 이번 틱에 낼 것을 `Player::spawns`에 쌓고(`events`처럼), 월드가 `take_spawns`로 받는다.
- 날아가는 틱마다 매듭·그물·고치·부술 것에 닿는다(`touch_world`) — 도토도 가장 깊은 곳의 매듭을 끊고 흰 실 그물을 끊는다. 고치·부술 것에 닿으면 탄이 멈춘다.
- 적에 닿으면 `resolve_strike(…, ranged = true)`: `apply_strike`에서 갈라 낸 함수. 탄·터짐은 플레이어를 튕기거나(등딱지) 멈추게 하지 않고, 받아치기·탄 베기·도토리 파내기(손만의 것)는 없다.
- 탄·터짐의 타격 번호는 윗자리(`0x8000_0000 |`)에서 센다 — 플레이어 스윙 번호와 겹치지 않게.

### 재주(자리 1·3, `DOTO_TABLE`)
- 뒤로 뛰기: A 떨구고 뛰기(뛰어오른 자리에 도토리 하나, 0.8초 뒤 피해 2, 대기 ×1.25) / B 가벼운 발(거리 ×0.7, 대기 ×0.7).
- 도토리 묻기: A 한가득(다섯, 게이지 ×0.8) / B 빨리 터지기(0.6초, 둘레 13px).
- `Talents`의 `momo: bool`을 `who: Character`로 바꿨다(셋째부터는 참·거짓이 모자란다). 자리 2·4(받아치기·먹기)는 함께.

### 개발 시나리오
- 개발 → "도토: 아레나"(웨이브), "도토: 새 졸개"(어두운 심층, 박쥐·고슴도치·두꺼비).

## B3: 해금·고르기·기록·장신구·저널
- **해금**: 도토를 이기고 기억이 돌아오면(`doto_memory`) 마을 뿌리 길 고르기 창에 칸이 생긴다. 고르기 창은 이제 **고를 수 있는 캐릭터만** 칸으로 둔다(`App::pick_list` = `characters::available`). 전에는 표 전체를 그려서, 모모만 돌아온 기록에서도 잠긴 도토를 고를 수 있었다. 창이 열리는 조건도 "모모가 돌아왔나" → "고를 수 있는 캐릭터가 둘 이상".
- **고르기 창 셋 칸**: 둘이면 예전 크기, 셋이면 316×162(화면 폭 가까이), 소개 다섯 줄. 일본어·중국어는 금칙으로 줄 끝에 매단 。、가 한 글자 더 나가 칸을 넘었다 — 셋 칸에서는 한 글자만큼 좁게 끊는다. 다섯 줄을 넘던 러시아어·일본어 도토 소개는 줄였다.
- **기록**: 캐릭터마다 `clears.Doto`·`knots.Doto`(표의 이름 그대로). 끝까지 닿으면 `doto_deep`(캐릭터 표의 `deep_flag`, 모모는 `momo_deep`, Naïl은 없음 = 이야기 엔딩 깃발). 다른 캐릭터의 끝은 Naïl의 이야기 엔딩을 대신하지 않는다(0056). 도토 엔딩 장면은 B4 — 그때까지는 Naïl의 장면이 나온다.
- **큰 나무**: 탭 셋(Naïl/모모/도토). LB·RB가 이제 방향대로(전에는 둘 다 다음). 탭 이름이 제목과 반딧불 수 사이에 안 들어가는 언어(일본어·중국어·포르투갈어·스페인어·러시아어·폴란드어)는 탭이 제목 자리를 쓴다.
- **도토 장신구 셋**(`Charm::only = Doto`, 옆으로: 얻는 만큼 잃는다):

| 장신구 | 얻는 것 | 잃는 것 | 어디서 |
|---|---|---|---|
| 솔방울 | 던진 도토리 사거리 ×1.3 | 공격 속도 −10% | 상자·가게(도토 런) |
| 깍정이 모자 | 뒤로 뛰기 거리 ×1.3 | 최대 체력 −1 | 상자·가게(도토 런) |
| 단풍잎 목도리 | 큰 도토리·묻은 도토리 터지는 둘레 ×1.35 | 도토리 게이지 −15% | 저널 "묻어 둔 길" |

  `Stats`에 `throw_reach`·`leap_mul`·`blast`(배율)를 더했다. 떨구고 뛰기(재주)의 도토리도 `blast`를 받는다.
- **저널**: "묻어 둔 길"(`doto_deep`, 도토로 가장 깊은 곳, 앞 목표 "도토") → 단풍잎 목도리.

## 사람이 볼 것
- 장신구 셋의 맞바꿈이 알맞은지(특히 깍정이 모자 체력 −1).
- 도토리가 너무 작게 보이지 않는지(지금 지름 5px). 1·2타 피해 1이 답답하지 않은지, 3타 부채꼴을 바로 앞에서 다 맞히면 3이 너무 센지.
- 뒤로 뛰기 방향(서 있으면 뒤, 움직이면 그쪽)이 손에 맞는지.
