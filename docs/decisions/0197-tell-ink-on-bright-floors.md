# 0197. 밝은 바닥의 적 예고는 짙은 빨강으로

- 날짜: 2026-10-28
- 상태: 채택(v0.4.3). 투명도는 0198의 "공격 예고" 설정이 곱한다(기본 50% = 이 문서 값의 5/7). 모양·채움·시점은 그대로. 잉크 색만 바닥에 따라.
- 사장: "어두운 것에서도 보이고, 밝은 곳에서도 보이려면 어떤 방식이 좋을까? 은은하게 보이는 게 좋은데…" → "응 보여줘 봐"

## 왜
반투명 잉크가 바닥과 얼마나 달라 보이는지는 바닥 밝기에 달렸다. 같은 밝은 빨강(1.0, 0.32, 0.36)을 0.25로 얹으면
풀밭(휘도 약 0.27)·뿌리(약 0.15)와 **밝기가 거의 같아진다** — 흑백 대비 1.10·1.03. 정상 시야에서는 빨강 대 초록의
색 차이로 읽히지만, 그 색 차이가 바로 1·2형 색약에서 사라지는 축이다(0150). 어두운 바닥(심층·흰 실 굴)에서는 같은
잉크가 바닥을 밝혀 1.4쯤으로 이미 읽힌다.

## 결정
- 잉크를 `TeleInk { rgb, a, base_a }` 하나로 묶고 지대로 고른다(`render/fx.rs tele_ink_for`).
  - **들판·뿌리**(`Biome::Meadow`·`Roots`, 필드·마을·쉼터 포함): 짙은 빨강 (0.55, 0.10, 0.12), 0.25·0.03.
  - **심층·흰 실 굴**: 원래 빨강 (1.0, 0.32, 0.36), 0.25·0.03 — 0196 그대로.
- 가운데 X는 잉크의 0.42배 어둡게·0.5 그대로(0160).
- 안내 그림(`render/help.rs`)은 원래 빨강.

## 검토한 것
| 잉크 | 풀밭 | 뿌리 | 심층 | 흰 실(어두운 곳) | 흰 실(실 위) |
|---|---|---|---|---|---|
| 원래 빨강 0.25 | 1.10 / ΔE 25.8 | 1.03 / 24.6 | 1.43 / 24.9 | 1.40 / 21.1 | 1.21 / 17.0 |
| 짙은 빨강 0.25 | **1.40** / 21.7 | **1.26** / 19.2 | 1.11 / 15.5 | 1.05 / 12.8 | 1.49 / 16.7 |
| 밝은 분홍 (1.0, 0.60, 0.58) 0.18 | 1.06 / 13.1 | 1.17 / 12.6 | 1.43 / 15.8 | 1.44 / 13.2 | 1.03 / 7.0 |

(흑백 대비 = WCAG 휘도비, ΔE = CIELAB 1976. 바닥 색은 헤드리스 스크린숏에서 뽑음.)
- 처음 제안은 어두운 바닥에 밝은 분홍(흑백 대비를 맞추려고). 같은 바닥 조각에 얹어 보니 오히려 흐렸다: 밝기 차는
  같아도 색 차이(ΔE)가 반으로 줄어 바닥에 묻힌다. 그래서 어두운 바닥은 원래 빨강을 둔다.
- 흰 실 굴의 실 위(밝은 곳)는 원래 빨강 1.21 — 실 조각은 작고 둘레가 어두워 테두리가 끊기지 않는다. 굴 전체를
  짙은 빨강으로 하면 어두운 곳이 1.05라 그대로 둔다.

## 확인
- 합성 비교(세션 스크래치, 커밋 안 함 — 타일 팩 그림이 들어 있다): 같은 바닥 조각(풀밭·뿌리·심층·흰 실 어두운 곳·실 위) 위에 왼쪽 원래,
  오른쪽 이번 잉크. 반쯤 찬 띠와 X 원판.
- `tools/a11y/cvd.py`(1·2·3형 + 흑백): 풀밭·뿌리에서 원래 띠는 1·2형·흑백에서 거의 사라지고, 짙은 빨강은 어두운 띠로 남는다.
- 실제 게임 헤드리스(개발 → 꽃 핀 입구·뿌리·심층·토끼풀): 풀밭의 띠가 짙은 갈빛 붉은 띠로 보인다.

## 사람이 볼 것
- 풀밭에서 짙은 빨강이 "붉은 예고"로 읽히는지(밝은 초록 위 짙은 빨강은 갈색 쪽으로 보인다). 더 붉게 하려면
  rgb를 (0.65, 0.12, 0.14)쯤으로 — 대비가 조금 줄어든다.
- 그래도 안 보이는 사람을 위한 "공격 예고 진하기" 설정(은은하게·보통·진하게)은 사장이 원하면 따로.
