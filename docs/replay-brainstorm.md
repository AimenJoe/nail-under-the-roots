# 다회차(반복 플레이) 설계 — 초안

> 상태: 후보 정리 (2026-10-25). 고른 것은 결정 기록(0040~)으로 남긴다. 이야기는 0037, 캐릭터 단위는 0003, 능력치 세 겹은 0017, 화폐는 0021을 따른다.
> 일반 지식은 KB `concepts/roguelite-replay-axes.md`에 있다.

## 0. "다회차"는 두 겹이다
1. **엔딩 전의 반복**: 런을 되풀이하며 조금씩 나아간다.
   - 이것이 로그라이트의 본체다. 지금 설계에 이미 반쯤 있다: 반딧불 기술 해금, 뿌리 심장, 보스 → 동료, 모모 세 번, 쉼터 대사.
2. **엔딩 뒤의 반복**: 다 본 사람이 다시 할 이유.
   - 더 어렵게(실력), 다른 캐릭터로(다양성), 못 본 것 채우기(수집·이야기).

플레이어가 반복하는 이유는 셋이다. 셋을 다 건드리되, **이미 만든 것을 다시 쓰는 축**부터 고른다(1인 개발).

| 이유 | 축 | 이 게임에서 |
|---|---|---|
| 실력 | 스스로 고르는 난이도 | **실뜨기**(아래 2) |
| 다양성 | 캐릭터·빌드 | 돌아온 이웃이 플레이어블(0003), 장신구·기술 조합 |
| 궁금함·애착 | 이야기·수집·마을 | 엔딩 뒤 이웃별 이야기, 도감·일러스트 앨범, 마을이 자람 |

## 1. 원칙
- **위로 쌓기보다 옆으로 넓히기.**
  - 영구 수치 성장이 크면 런이 점점 쉬워진다. "내가 늘었나, 캐릭터가 셌나"를 구별할 수 없게 되고 난이도가 무너진다(GMTK의 roguelike/roguelite 구분, 플레이어 불만).
  - 영구로 얻는 것은 **새 선택지**(기술·장신구·캐릭터)가 중심이다. 수치 성장은 뿌리 심장(최대 체력 +5 상한)처럼 상한을 둔다.
- **어려움은 스스로 고르고, 언제든 되돌린다.** Hades·Dead Cells 모두 첫 클리어 뒤에 켜지고, 낮출 수도 있다.
- **이야기는 지는 사람에게도 간다**(0037·KB 이야기 노트). 엔딩 뒤 이야기는 "몇 번 깼나"만이 아니라 "몇 번 내려갔나"로도 열린다.
- **아이도 끝을 본다.** 쉬워지는 도움 모드를 따로 둔다(Hades God Mode 방식). 기본 난이도를 깎는 대신 켜는 사람만 쉬워진다.

## 2. 실력: 실뜨기 (Heat / Ascension / Boss Cells 자리)
**세계관**: 참 엔딩 뒤, 놓아주는 법을 배운 누룩 할매가 아이들과 **실뜨기**를 한다. 실뜨기 모양 하나가 다음 런의 어려움 하나다. 첫 클리어(반쪽 엔딩) 뒤에 할매 곁에서 연다.
- 실뜨기는 한국 아이들의 실놀이다. 할매의 실이 무기에서 놀이로 바뀐다(주제 "놓아주기"의 뒷이야기).

**방식 후보**:
| 안 | 어떻게 | 장점 | 비용 |
|---|---|---|---|
| **A ★ 단계식**(Slay the Spire Ascension) | 1~10단계. 깰 때마다 다음 단계가 열리고, 단계마다 어려움이 하나씩 쌓인다. 캐릭터마다 따로 | 숫자 하나라 UI가 쉽다(핸드헬드). 균형 잡기 쉽다. 단계마다 보상 | 고르는 재미가 없다 |
| B 골라 묶기(Hades Pact of Punishment) | 매듭 열몇 개를 골라 묶고 합계가 "실뜨기 수" | 자기 약점·취향대로 | 조합 균형이 어렵고 UI가 크다 |
| C 단계식 먼저, 나중에 골라 묶기 | A로 시작하고 콘텐츠가 쌓이면 B로 | 단계적 | 두 번 만든다 |

**매듭(어려움) 후보** — 이미 있는 수치만 바꾸는 것부터:
1. 물든 이웃이 더 단단하다(체력 +25%)
2. 둥지(센 무리)가 더 자주 나온다
3. 예고가 짧다(공격 예고 −20%)
4. 샘이 하나 줄어든다(길 지도)
5. 산딸기가 덜 떨어진다(불운 보정은 유지)
6. 가게 값이 오른다
7. 먹기 대기가 길다(0038)
8. 보스에게 새 패턴(보스마다 하나)
9. 쓰러지면 반딧불을 더 잃는다(30% → 60%)
10. 물든 실이 바닥에 깔린 방(밟으면 느려짐)

**보상**:
- 단계를 처음 깰 때 **마을 꾸미기 씨앗**(힘이 아닌 것)과 그 캐릭터의 **다른 털빛**(옷 대신)을 준다.
- 높은 단계에서만 나오는 할매의 짧은 이야기가 있다.

## 3. 다양성: 캐릭터와 빌드
- **캐릭터**(0003): 모모가 첫 번째다(높이 뛰기·뒷발차기·굴에 숨기, 0029). 다음은 보리·도토·콩이 순.
  - 캐릭터마다 실뜨기 단계를 따로 센다.
  - 쉼터·할매 대사가 캐릭터에 따라 달라진다(같은 장면, 다른 말).
- **기술 해금**(반딧불, 0021): 세지는 것보다 **다르게 싸우는 것**을 연다.
  - 예: 굴파기 변형(더 오래 숨기 / 솟구칠 때 둘로 갈라짐), 패링 변형(튕겨낸 것이 두 배로).
  - 한 번에 하나만 장착하는 **결**(Hades의 Aspect 같은 것)도 후보다.
- **장신구 풀 넓히기**: 이웃이 돌아올 때마다 그 이웃의 장신구가 가게·저장고에 섞인다.

## 4. 궁금함: 이야기·수집·마을
- **엔딩 뒤 이웃 이야기**: 참 엔딩 뒤에도 쉼터에서 이야기가 이어진다.
  - 모모가 가족을 다 찾는다, 보리가 들쥐 마을을 다시 세운다, 도토가 잊은 곳을 하나씩 기억해 낸다 …
  - 런 한 번에 한 줄씩(쉼터 대사 표, 0037).
  - Hades는 첫 클리어 뒤에도 이야기가 계속되고, 에필로그는 여러 번 깬 뒤에 열린다.
- **도감**: 지금 있다. 돌아온 이웃 줄, 할매 줄, 숨은 종으로 채운다.
- **일러스트 앨범**: 본 컷씬 일러스트를 다시 본다(0039). "컷씬 보는 것도 재미"(사장).
- **마을이 자란다**(concept.md 메타 진행): 새싹 아래 마을에 돌아온 이웃의 집이 생긴다.
  - 씨앗(상점 화폐)으로 꾸민다. 실뜨기 보상 씨앗도 여기에 쓴다.
  - 큰 나무 자리의 새싹이 회차마다 자란다.

## 5. 변주 런 (싸게 만들 수 있는 것)
- **오늘의 굴**(일일 시드): 던전은 이미 "같은 시드 = 같은 던전"이다. 날짜를 시드로 정한 굴 하나에 기록을 남긴다(먼저 혼자 보는 기록). 서버가 필요 없다.
- **실의 꿈**(보스 다시 싸우기, Hollow Knight Godhome 자리): 할매의 실이 기억하는 물든 모습들과 꿈속에서 다시 싸운다. 보스는 이미 있으니 방 하나 + 목록이면 된다.

## 6. 도움 모드: "포포의 응원"
- 설정에서 켠다. 쓰러질 때마다 받는 피해가 조금씩 준다.
  - Hades God Mode: 20%에서 시작해 쓰러질 때마다 +2%, 최대 80%.
- 기록에는 작은 표시만 남긴다. 아이가 끝을 볼 수 있게 하는 장치다. 기본 난이도는 그대로 둔다.

## 7. 저장해야 하는 것(3단계 저장 파일)
프로필 하나에 다음을 둔다:
- 돌아온 이웃
- 캐릭터별 깬 횟수·실뜨기 단계
- 기술 해금, 장신구 풀
- 이야기 깃발·본 대사
- 도감·앨범에서 본 것
- 마을 꾸미기
- 도움 모드 누적
- 오늘의 굴 기록

웹은 지금의 localStorage 정수 칸(prefs)으로는 모자란다. 문자열(JSON) 한 칸을 쓰는 저장으로 넓힌다.

## 8. 만드는 순서(안)
1. **저장 파일**(프로필): 위 7. 모든 축의 바닥이다.
2. **반쪽·참 엔딩 연결 + 이야기 깃발 + 쉼터 대사 표**(0037에서 미뤄 둔 것).
3. **도감·앨범**(이미 있는 것에 "본 것" 표시만 더하면 된다).
4. **실뜨기 단계 1~5**(이미 있는 수치만 바꾸는 매듭).
5. **모모 플레이어블**(가장 큰 일: 보스 패턴 → 기술 세트).
6. 오늘의 굴, 실의 꿈, 마을 꾸미기, 실뜨기 6~10.

## 고를 것 (사장 몫)
1. 실뜨기 방식: **A 단계식**(추천) / B 골라 묶기 / C 단계식 → 나중에 골라 묶기
2. 영구 성장의 크기: **옆으로 넓히기 + 체력 상한만**(추천) / 수치 성장도 넉넉히 / 거의 없이
3. 도움 모드(포포의 응원): **넣는다**(추천) / 넣지 않는다
4. 먼저 만들 것(여럿): 캐릭터(모모) / 실뜨기 / 도감·앨범·마을 / 오늘의 굴·실의 꿈
