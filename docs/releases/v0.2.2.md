# Naïl: Under the Roots v0.2.2 — 입자 효과 설정

## 바뀐 것
- **설정 → 입자 효과**(docs/decisions/0141): 0~100%(기본 100%). 먼지·흙덩이·불똥·반짝임·풀리는 실, 들판 꽃가루·뿌리 포자·심층 빛 알갱이, 컷씬 일러스트와 타이틀의 입자를 그 비율만 그린다. 공격이 닿는 범위를 보여 주는 고리와 모닥불·버섯의 빛은 그대로 남는다. 눈이 피로하거나 화면이 어지러울 때.
- 설정 줄이 열이 되어 목록이 굴러간다(위·아래 끝에 ▲▼).
