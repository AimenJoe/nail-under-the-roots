# Naïl: Under the Roots v0.1.7 — 저장 슬롯, 이어하기, 팩 그림 소품

## 새로 들어간 것
- **저장 슬롯 셋**(docs/decisions/0078).
  - 타이틀에서 기록이 있으면 **이어하기**와 **저장 슬롯**이 따로 나온다. 처음이면 **새로 하기** 하나다.
  - 저장 슬롯 창에서 슬롯마다 가장 멀리 간 쉼터 · 끝까지 간 수 · 모험 수를 본다. 이어하기, 빈 슬롯에서 새로 시작, 지우기(두 번 눌러야 지워진다)를 할 수 있다.
  - **예전 기록은 그대로 슬롯 1**이다. 덮어 설치해도, 웹에서 새로고침해도 이어진다.
  - 설정(언어·소리·버튼 배치)은 슬롯과 상관없이 하나다.
  - 런 도중에 끄면 다음엔 마을에서 시작한다(기록은 남는다). 쉼터부터 이어가는 저장은 아직 없다.
- **팩 그림으로 바꾼 소품**(docs/decisions/0077): 가게 가판, 모모의 빈 자리 그루터기, 마을 꾸미기 의자·들꽃 화분, HUD 체력 하트·씨앗 새싹. 반딧불 HUD 아이콘이 "="처럼 보이던 것도 고쳤다.

**English (short)**: Three save slots. The title screen now shows Continue and Save slots when you have a record, or just New game the first time. The slot screen shows each slot's progress and lets you continue, start fresh in an empty slot, or erase (press twice). Your existing record becomes slot 1 automatically. Settings stay shared across slots. Quitting mid-run still returns you to the village next time; resuming from a camp is not in yet. Some props now use Sunnyside art: the shop stall, Momo's waiting stump, the village bench and wildflower pot, and the HP hearts and seed sprout in the HUD.
