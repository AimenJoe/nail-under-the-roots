# Naïl: Under the Roots v0.1.5 — Android에 설치된다

v0.1.4와 내용(게임·그림)은 같다. Android 12 이상 폰에서 APK가 설치되지 않던 것을 고쳤다.

## 고친 것
- **"App not installed as package appears to be invalid"**(docs/decisions/0074).
  - 앱의 주 화면 설정에 Android 12부터 꼭 있어야 하는 값(`android:exported`)이 빠져 있었다. 그래서 기기가 APK를 "잘못된 패키지"로 보고 설치를 거부했다.
  - v0.1.0~v0.1.4의 APK가 모두 이 문제를 갖고 있었다. 이번 APK부터는 설치된다.
  - 빌드할 때 이 값이 없으면 실패하도록 검사를 넣었다.

## v0.1.4에 들어 있던 것(그대로)
- 털이 보이는 대화 초상화, 파스텔·수채 바탕으로 다시 그린 컷씬 일러스트 열 장. 자세한 내용은 [v0.1.4](https://github.com/AimenJoe/nail-under-the-roots/releases/tag/v0.1.4).

## 해 보기

  - "출처를 알 수 없는 앱 설치"를 한 번 허용한다.
  - 이전 버전이 설치되어 있지 않을 것이다(설치가 거부됐으므로). 처음 설치로 보면 된다.

---

**English (short)**: The Android APK now installs. Earlier APKs (v0.1.0–v0.1.4) lacked `android:exported` on the main activity, which Android 12+ requires for apps targeting API 31+, so phones rejected them as "package appears to be invalid". The build now fails if the attribute is missing. Game content is the same as v0.1.4.
