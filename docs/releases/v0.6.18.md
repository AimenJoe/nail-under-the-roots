# Naïl: Under the Roots v0.6.18 — 굴 출구는 버튼으로 내려간다

## 바뀐 것
- **굴 출구는 버튼으로**: 다음 길·쉼터·가장 깊은 곳으로 가는 굴의 출구를 밟는 것만으로 내려가지 않습니다. 보물 상자처럼 곁에 서서 버튼을 누르면 "내려가기"가 됩니다(0262).
- **마을 비춰 보기**: Naïl로 걸을 때만 보입니다.
- **모모 이어 뛰기 조준 표시**: 필살기를 쓰는 중에만 보입니다.

## 해 보기
- **웹**: https://nail-under-the-roots.netlify.app
- **Android**: 아래 `nail.apk`. 덮어 설치하면 기록이 남습니다.
- **Windows**: `nail-windows-release.zip` → `Nail.exe`. 서명 전이라 처음에 "Windows의 PC 보호" 창이 뜨면 "추가 정보 → 실행".
- **macOS**(11 이상, 인텔·애플 실리콘): `nail-macos-release.zip` → `Nail.app`. 처음 열 때 막히면 "시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기".
- **Linux**(x64): `nail-linux-release.tar.gz` → `nail`.

## 출처
- 그림·소리·글꼴 출처는 v0.6.17과 같습니다. 게임 설정 → 라이선스와 `assets/LICENSES.md`에서 볼 수 있습니다.
