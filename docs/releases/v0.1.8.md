# Naïl: Under the Roots v0.1.8 — 시작하기 · 이어하기

## 고친 것
- **타이틀 메뉴를 시작하기 / 이어하기로**(docs/decisions/0078).
  - v0.1.7의 "이어하기 + 저장 슬롯"이 어색하다는 피드백을 받아 바꿨다.
  - **시작하기**는 늘 나온다. 슬롯을 고르면 처음부터 시작한다. 빈 슬롯은 "시작"이다. 기록이 있는 슬롯은 "덮어쓰기"이고, 두 번 눌러야 한다.
  - **이어하기**는 기록이 있는 슬롯이 있을 때만 나온다. 기록이 있는 슬롯만 고를 수 있고, 거기서 지우기도 할 수 있다(두 번).
  - 커서는 처음에 이어하기면 마지막으로 한 슬롯, 시작하기면 첫 빈 슬롯에 놓인다.

## v0.1.7에 들어 있던 것

**English (short)**: The title menu is now New game / Continue, and both open the slot picker. New game is always there. Pick an empty slot to start, or a used slot to overwrite it (press twice). Continue only appears when a save exists, lists only used slots, and can also erase one (press twice). This replaces v0.1.7's "Continue + Save slots" layout, which felt odd.
