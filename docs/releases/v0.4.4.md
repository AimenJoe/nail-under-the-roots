# Naïl: Under the Roots v0.4.4 — 목록을 손가락으로 끌어 굴리기

## 바뀐 것
- **터치로 목록 굴리기**: 저널·도감·안내·설정·앨범·상태 탭을 손가락으로 위아래로 끌면 목록이 따라 움직인다. 가려진 줄이 있다는 ▲▼도 누르면 한 줄씩 굴린다. 마우스 휠도 된다.
- **메뉴의 탭은 손가락을 뗄 때**: 끌려고 짚은 줄이 눌리지 않는다(설정 값이 바뀌거나 저널 보상을 받아 버리지 않게).

## 해 보기
- **웹**: https://nail-under-the-roots.netlify.app
- **Android**: 아래 `nail.apk`. 덮어 설치하면 기록이 남는다.

**English (short)**: v0.4.4 adds touch drag scrolling to menus (journal, bestiary, help, settings, album, status): drag a list up or down, tap ▲▼ to step one row, or use the mouse wheel. Menu taps now register when the finger lifts, so starting a drag on a row no longer presses it.
