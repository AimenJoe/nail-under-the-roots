# Naïl: Under the Roots v0.1.0 — 프로토타입

땅속 이웃들을 되찾으러 뿌리를 따라 내려가는 아기 두더지 나일의 탑다운 액션 로그라이트. 첫 공개 프로토타입이다. 그림은 아직 임시 그림이다(직접 만든 생성 스크립트).

## 해 보기
- **웹**: https://nail-under-the-roots.netlify.app (데스크톱·폰 브라우저, 키보드·게임패드·터치)
- **Android**: 아래 `nail.apk`(arm64). "알 수 없는 앱 설치"를 허락하고 설치한다.
  - 디버그 키로 서명했다. 다음 버전이 다른 키로 서명되면 **앱을 지우고 다시 설치**해야 하고, 그때 기록도 지워진다.
- 언어: 한국어·English·日本語·简体中文·Português (기기 언어를 따른다, 설정에서 바꿈)

## 조작(기본)
| 동작 | 키보드 | 게임패드 |
|---|---|---|
| 이동 | WASD / 화살표 | 왼쪽 스틱 |
| 공격(3연타) | J | X |
| 회피(굴파기 → 솟구침) | K | A |
| 필살기(게이지가 차면) | L | B |
| 먹기 / 넘기기 | I / Q·E | Y / LB·RB |
| 메뉴 | Esc | Start |

설정 → 조작 설정에서 바꿀 수 있다.

## 들어 있는 것
- 전투: 3연타 콤보, 굴파기 회피와 솟구치기, 공격 타이밍 패링, 드릴 필살기, 히트스톱
- 튜토리얼(라쿤 포포) → 필드 → 쉼터 → 갈래 길 지도 → 굴, 세 길과 가장 깊은 곳
- 이름 있는 보스 셋: 모모(세 번 만난다), 도토, 콩이. 이기면 이웃이 마을로 돌아온다
- 마을: 큰 나무 재주(반딧불), 꾸미기, 저널 목표, 도감, 앨범(컷씬 일러스트 10장)
- 다회차: 실뜨기 1~10단계(난이도), 오늘의 굴(날짜 시드), 실의 꿈(이긴 보스 다시 싸우기)
- 두 번째 캐릭터 모모(뒷발 차기·깡충·이어 뛰기), 반쪽·참 엔딩과 모모의 끝
- 포포의 응원(도움 모드), 기록 저장(웹은 브라우저, Android는 기기)

## 알려진 것
- 음악이 없다(효과음만).
- 그림·초상화·일러스트는 임시 그림이다.
- 터치 버튼 글자와 조작 설정의 이름은 모모로 해도 나일 기준이다.

## 의견을 듣고 싶은 것
1. 아무 설명 없이 30초 안에 굴파기 → 솟구침 → 때리기를 하게 되는지
2. 적 셋을 상대할 때 "어디서 튀어나올까"를 생각하게 되는지
3. 3타째가 "묵직하다"고 느껴지는지
4. 5분 해 보고 더 하고 싶은지

---

**English (short)**: A cute top-down action roguelite prototype. A baby mole, Naïl, follows the roots down to bring back the neighbors. Play on the web at the link above or install the arm64 APK (debug-signed; a future build signed with another key needs an uninstall, which erases saves). Placeholder art, no music yet.
