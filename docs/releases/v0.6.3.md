# Naïl: Under the Roots v0.6.3 — 콩이도 발을 딛고 걷는다

## 바뀐 것
- **콩이 걷기를 다시 만들었다**: 새 그림의 걷기 네 칸은 칸마다 등딱지 크기·머리 높이·눈이 조금씩 달라, 걸을 때 몸이 꿈틀거리듯 보였다. 이제 몸은 그대로이고 발을 번갈아 딛으며 한 걸음마다 살짝 들썩인다(마을의 콩이·물든 콩이 모두). Naïl 걷기(v0.6.1~0.6.2)와 같은 방식.

## 해 보기
- **웹**: https://nail-under-the-roots.netlify.app
- **Android**: 아래 `nail.apk`. 덮어 설치하면 기록이 남는다.
- **Windows**: `nail-windows-release.zip` → `Nail.exe`. 서명 전이라 처음에 "Windows의 PC 보호" 창이 뜨면 "추가 정보 → 실행".
- **macOS**(11 이상, 인텔·애플 실리콘): `nail-macos-release.zip` → `Nail.app`. 처음 열 때 막히면 "시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기".
- **Linux**(x64): `nail-linux-release.tar.gz` → `nail`.

## 출처
- 캐릭터·적·소품·마을 물건 스프라이트, 대화 초상화, 컷씬 일러스트, 타이틀 바탕: Google Gemini 이미지 모델(나노바나나)로 그린 원본을 게임 도트로 옮김(Naïl·콩이 걷기 네 칸은 원본 한 칸에서 발만 코드로 움직였다). 생성 그림에는 SynthID 워터마크가 들어 있다. 파 내려가기 그림은 직접 그렸다.
- 음악·효과음(모두 CC0)·타일·글꼴은 v0.6.0과 같다 — 게임 설정 → 라이선스, `assets/LICENSES.md`.
