# Naïl: Under the Roots v0.1.1 — 고침

v0.1.0에서 고친 것 둘. 내용(게임)은 같다.

## 고친 것
- **Android Chrome에서 글자가 검게 뭉개지던 것**(docs/decisions/0058).
  - 원인: 화면 밀도가 어중간한 폰(2.625·2.75 등)에서 글자를 화면 크기로 구워 글자 텍스처가 4096²까지 컸다.
  - 이제 작게 굽고 키운다(1024²~2048²).
  - Android APK도 같은 글자 코드를 쓴다.
- **타이틀의 버전이 실제 릴리스와 같다**(docs/decisions/0059). 전에는 "v0.1"로 박혀 있었다.
  - 이제 "v0.1.1 · <커밋>"이다. 웹 빌드도 어느 커밋인지 보인다.

## 해 보기
- **웹**: https://nail-under-the-roots.netlify.app
  - 예전 글자가 그대로면 탭을 닫았다가 다시 연다(브라우저 캐시).
- **Android**: 아래 `nail.apk`.
  - v0.1.0과 같은 디버그 키로 서명했다. 지우지 않고 덮어 설치하면 기록이 남는다.
  - "패키지가 유효하지 않음"이 나오면 키가 바뀐 것이다. 앱을 지우고 설치한다(기록도 지워진다).

조작·들어 있는 것·의견을 듣고 싶은 것은 [v0.1.0](https://github.com/AimenJoe/nail-under-the-roots/releases/tag/v0.1.0)과 같다.
