# Naïl: Under the Roots v0.1.13 — 타이틀 바탕

v0.3.0 마일스톤(완성도, docs/decisions/0081) 안의 작은 묶음이다(docs/decisions/0083).

## 바뀐 것
- **타이틀 화면에 바탕 그림**이 생겼다. 제목 그대로 "뿌리 아래"의 땅 단면이다.
  - 위: 해 질 녘 들판과 마을 둔덕.
  - 오른쪽: 큰 나무. 뿌리가 흙 속으로 번지고, 굵은 뿌리 끝은 보라로 물들었다.
  - 왼쪽 아래: 굴 방. Naïl이 반딧불 병 곁에서 잔다.
- 반딧불이 천천히 떠다니고, 가끔 마른 잎이 떨어진다. 메뉴 뒤는 살짝 어둡게 해 글이 잘 읽힌다.
- 슬롯 고르기·설정 창도 같은 바탕이다.
