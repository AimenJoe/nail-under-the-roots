# Naïl: Under the Roots v0.1.16 — Android 앱 아이콘, iOS 빌드 시작

## 새로 들어간 것
- **Android 앱 아이콘**(docs/decisions/0087): 홈 화면에 Naïl 얼굴이 나온다. Android 8 이상은 런처 모양(원·둥근 네모)에 맞춰 잘리는 적응형 아이콘이다.
- **iOS 빌드 1단계**(0086): CI가 iPhone용 빌드(서명하지 않은 `.ipa`)를 만든다. 아직 스토어·TestFlight 배포는 없고, iOS에서는 게임패드가 안 된다.

## 바뀐 것
- 문서·지식 베이스를 코드와 교차검증해 낡은 설명을 고쳤다(0088). 게임 동작은 그대로다.
- APK 빌드가 아이콘·패치한 엔진만 바꾼 경우에도 다시 돈다.

## 해 보기
- **웹**: https://nail-under-the-roots.netlify.app
