# Naïl: Under the Roots v0.3.14 — 적 예고는 면으로, 평타 박자는 느리게

## 바뀐 것
- **적 공격 예고는 면(0183)**: 공격이 닿을 자리가 면으로 그려진다(길 공격은 띠, 떨어지는 자리는 원판). 테두리는 처음부터 진하고 안쪽이 점점 진해져, **안쪽이 테두리와 같은 색이 되는 순간 공격이 맞는다**. 일부가 가려져도 남은 면으로 읽힌다. 황금은 받아칠 수 있는 것, 가운데 X가 있는 진홍은 피해야 하는 것.
- **평타 박자를 늦췄다(0183)**: 박자 간격 0.25초 → 0.36초, 박자 창 ±0.06초 → ±0.08초. 박자에 맞춰 늦게 누른 타도 콤보가 이어진다.
- 안내 탭의 받아치기·적의 예고 그림과 글도 새 모양으로.

**English (short)**: Enemy tells are now filled areas instead of thin lines: a lane for paths, a disk for landing spots. The border is solid from the start and the inside darkens; the attack lands the moment the inside matches the border. Gold can be parried, crimson with an X must be dodged. The combo beat is slower (0.25 s → 0.36 s, window ±0.06 s → ±0.08 s), so it is easier to hit on the beat. The Help pictures and text follow the new look.
