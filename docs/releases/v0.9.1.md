# Naïl: Under the Roots v0.9.1 — 키보드 다듬기

## 바뀐 것
- **조작 설정에서 이동 키도 바꿀 수 있다**: 맨 위 "이동" 줄을 고르면 ↑ ← ↓ → 차례로 새 키를 받는다(기본 W·A·S·D). 화살표는 언제나 그대로 움직인다.
- **메뉴의 "뒤로"를 회피 키로도**: 공격 키(J)로 고르고 회피 키(K)로 물러난다 — 오른손을 떼지 않아도 된다. Esc도 그대로.
- **다른 키보드 배열**: 키는 자판의 자리로 읽는다 — 프랑스(AZERTY)·독일(QWERTZ) 배열에서도 걷기·공격 키가 같은 손가락 자리다(이제 Linux도). 화면의 키 이름도 지금 배열의 글자로 보인다(웹은 Chrome·Edge, Windows, macOS — AZERTY면 걷기가 ZQSD).
- **모바일 웹 + 실제 키보드**: 포커스를 잃었을 때나 키보드 앱을 거친 입력에서도 키가 게임에 닿는다.
- 배포 파이프라인 정리(사용자에게 보이는 변화는 없음).

## 알려진 문제
- iPad에서 **홈 화면에 추가한 웹앱**으로 켜면, 화면을 한 번 클릭(탭)해 포커스를 주기 전에는 실제 키보드가 듣지 않는다.

## 해 보기
- **웹**: https://nail-under-the-roots.netlify.app — 폰에서는 홈 화면에 추가해 보세요.
- **Android**: 아래 `nail.apk`. 덮어 설치하면 기록이 남는다.
- **Windows**: `nail-windows-release.zip` → `Nail.exe`. 서명 전이라 처음에 "Windows의 PC 보호" 창이 뜨면 "추가 정보 → 실행".
- **macOS**(11 이상, 인텔·애플 실리콘): `nail-macos-release.zip` → `Nail.app`. 처음 열 때 막히면 "시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기".
- **Linux**(x64): `nail-linux-release.tar.gz` → `nail`.

**English (short)**: Keyboard polish. Movement keys can now be rebound (Controls → "Move" takes ↑ ← ↓ → in turn; default WASD) while the arrow keys always move. The dodge key (K) also backs out of menus, so your right hand stays on J/K. Keys are read by physical position on every PC platform (now Linux too), so AZERTY/QWERTZ players get the same finger layout, and on-screen key names follow your current layout (web on Chrome/Edge, Windows, macOS — e.g. ZQSD on AZERTY). On mobile web with a hardware keyboard, keys now reach the game even after focus is lost or input goes through a keyboard app. Known issue: on iPad, when launched as a Home Screen web app, the hardware keyboard only works after you click (tap) the screen once.
