# Naïl: Under the Roots v0.6.0 — PC로도, 다시 그린 Naïl

## 바뀐 것
- **PC 판**: Windows · macOS · Linux. 아래 파일을 받아 압축을 풀고 켜면 된다. 타이틀에 "끝내기", 설정에 "전체 화면"(F11로도).
- **Naïl을 다시 그렸다**: 서서 삽 같은 앞발을 벌린 새 모습, 주황 목도리는 그대로. 키가 커져 모모·도토와 나란히 선다.
- **콩이를 다시 그렸다**: 모래색 등딱지·큰 귀·꼬리, 공으로 말리는 모습도 새로.
- **큰 나무를 다시 그렸다**: 시든 나무에 잎이 단계마다 돌아오고(마지막엔 분홍 꽃), 마을 색에 맞췄다. 마을 위쪽이 조금 넓어졌다.

## 해 보기
- **웹**: https://nail-under-the-roots.netlify.app
- **Android**: 아래 `nail.apk`. 덮어 설치하면 기록이 남는다.
- **Windows**: `nail-windows-release.zip` → `Nail.exe`. 서명 전이라 처음에 "Windows의 PC 보호" 창이 뜨면 "추가 정보 → 실행".
- **macOS**(11 이상, 인텔·애플 실리콘): `nail-macos-release.zip` → `Nail.app`. 처음 열 때 막히면 "시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기".
- **Linux**(x64): `nail-linux-release.tar.gz` → `nail`.
- 기록은 PC마다 따로다(웹·폰 기록과 이어지지 않는다).

**English (short)**: Naïl is now on PC — Windows, macOS (Intel and Apple silicon) and Linux builds are attached below; unzip and run, with a Quit option on the title screen and fullscreen in Settings or with F11 (the builds are not signed yet, so allow the first launch). Naïl, Kongi and the Great Tree are redrawn: Naïl now stands with his spade paws out and is as tall as Momo and Doto, Kongi has a sand-colored shell and big ears, and the Great Tree regrows its leaves stage by stage in the village's colors.
