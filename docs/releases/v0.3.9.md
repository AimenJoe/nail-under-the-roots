# Naïl: Under the Roots v0.3.9 — 안쪽 정리, 쓰러짐 손맛 통일, 모모의 웅크림

## 바뀐 것
- **적이 쓰러지는 손맛이 어떤 원인이든 같아졌다**: 되받아친 투사체·떨어지는 돌·가시 덤불·벽 쿵으로 쓰러져도 발톱으로 쓰러뜨릴 때와 같은 소리·고리·흔들림이 난다(전엔 원인마다 조금씩 빠져 있었다).
- **모모도 강타를 모으는 동안 한 줄 웅크린다**(Naïl과 같게).
- 그 밖에는 **보이는 변화가 없다**. 안쪽을 크게 정리했다(docs/decisions/0169 R1~R8): 틱 순서·소리·적 행동·언어 표·그리기·메뉴를 파일별로 나누고, 저장 형식 호환 시험과 브라우저 연기 시험을 더했다. 기록·설정·이어하기 저장은 그대로 읽힌다(고정 샘플 시험으로 확인).

**English (short)**: Enemy defeats now feel the same whatever killed them (reflected projectile, falling rock, thorns, wall slam): same sound, ring and shake as a claw kill. Momo also crouches a pixel while charging a heavy, like Naïl. Nothing else visible changed; this release is an internal reorganization (tick order, sound queue, enemy behaviors, language tables, rendering and menus split into files) plus save-format compatibility tests and a browser smoke test. Existing saves, settings and suspended runs load unchanged.
