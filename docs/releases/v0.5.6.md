# Naïl: Under the Roots v0.5.6 — 버튼으로 여는 상자, 귀해진 반딧불

## 바뀐 것
- **보물 상자는 버튼으로 연다**: 닿기만 해서는 안 열린다. 곁에 서면 "공격 버튼 열기" 말풍선이 뜨고, 쉼터에서 말 거는 것과 같은 방식으로 연다.
- **반딧불·씨앗이 귀해졌다**: 떨어지는 수를 줄였다 — 한 런 반딧불 약 40%, 씨앗 약 40% 적게. 쉼터 가게에서는 뿌리 심장과 장신구 가운데 하나를 고르게 된다. 값은 그대로.
- **설정 → 라이선스**: 게임이 쓰는 글꼴·라이브러리·소리의 라이선스 고지를 게임 안에서 굴려 읽는다.
- **설정 창 정리**: 모든 줄이 한 줄로 맞춰졌고, 값·다른 화면·기록 지우기가 묶음으로 나뉜다. 돌아가기 줄 대신 닫기 버튼(패드 B·Esc)으로 닫는다.
- **APK가 절반으로**: Android에는 Android가 쓰는 소리 파일만 싣는다(약 52 MB → 28 MB).

**English (short)**: Treasure chests now open with a button press instead of on touch. Glowbugs and seeds drop about 40% less, so each camp shop becomes a real choice. Settings has a new Licenses page that lists third-party notices in-game, and the settings menu is regrouped with a single alignment and no separate Back row (close with B/Esc or the × button). The Android APK only carries the audio format it uses and is about half the size (≈28 MB).
