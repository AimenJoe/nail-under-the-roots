# Naïl: Under the Roots v0.1.6 — Android 패드 버튼, 눈에 띄는 저장 지점

## 고친 것
- **Android에서 패드 버튼이 듣지 않던 것**(docs/decisions/0075).
  - v0.1.5에서는 D패드와 왼쪽 스틱만 움직였다. 게임 엔진(miniquad)의 Android 키 표에 패드 버튼이 없어서 A·B·X·Y·LB·RB·LT·RT·Start·Select가 모두 버려지고 있었다.
  - 엔진을 고친 사본을 쓴다. 이제 Android에서도 웹·PC 패드와 같은 버튼으로 공격·회피·특기·먹기를 하고, 메뉴에서는 A 확인, B(또는 기기의 뒤로) 뒤로, Start 메뉴, LB·RB 탭을 쓴다. 설정의 버튼 다시 붙이기도 된다.
  - 스틱은 아직 디지털(8방향)이다. 오른쪽 스틱 조준은 Android에서 아직 안 된다.
- **저장 지점이 눈에 띄지 않던 것**(docs/decisions/0076).
  - 버섯 고리를 키우고, 바탕에 빛을 더해 숨쉬는 금빛 후광과 위로 떠오르는 포자를 그린다. 어두운 쉼터에서도 보인다.
  - 아직 들르지 않은 고리에는 빛기둥이 높이 선다.

**English (short)**: Gamepad buttons now work on Android. In v0.1.5 only the D-pad and left stick did anything, because the engine's Android key table dropped every gamepad button. The game now ships a patched copy of the engine, so A/B/X/Y, bumpers, triggers, Start and Select work as on web and PC, including rebinding. The stick is still digital, and right-stick aiming is not yet supported on Android. Save points are also easier to spot: a bigger mushroom ring with an additive golden glow and rising spores that show even in dark places, plus a tall light beam on rings you haven't visited yet.
