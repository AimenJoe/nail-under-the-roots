# Naïl: Under the Roots v0.7.0 — 놓아준 뒤

## 바뀐 것
- **맞을 때의 손맛**: 받는 피해가 다섯 갈래(가벼운 타격·무거운 타격·길의 주인·덤불 같은 위험물·포자처럼 스며드는 것)로 나뉘어, 세기마다 흔들림·번쩍임·멈칫이 다르다.
  - 설정의 **흔들림**과 **번쩍임**을 따로 고른다(전엔 한 줄). 예전 설정 값은 둘 다에 이어진다.
  - 웹·PC에서 게임패드 **진동**을 켜고 끌 수 있다.
  - 판정 상자 보기(F2)는 개발판에만 남겼다.
- **웹을 앱처럼**: 폰에서 "홈 화면에 추가"를 하면 주소창 없이 열리고, 한 번 연 뒤에는 인터넷 없이도 된다. 지원하는 기기(Android·PC 브라우저)는 설정에서 전체 화면 + 가로 화면으로. 폰을 세로로 들면 돌려 달라는 그림이 뜨고 게임이 잠시 멈춘다(탭하면 세로로 계속).
  - iPhone: 홈 화면에 추가한 앱은 Safari와 기록을 따로 둔다.
- **마을 창**: 포포에게 말을 걸면 탭 셋 — 꾸미기·짐 꾸리기·마을 수첩. 포포가 왼쪽 위에서 고른 것을 설명해 준다.
  - 터치로는 한 번 눌러 고르고, 한 번 더 눌러 산다. 꾸린 짐은 내려가기 전에 빼면 씨앗을 돌려받는다.
  - 새 꾸미기 셋: **돌 우물·해바라기·작은 소나무**. 쓰지 않고 맡겨 둔 반딧불은 돌 우물 위를 떠다닌다(많을수록 많이).
  - 큰 나무에 가려 보이지 않던 반딧불 등과 반딧불 병은 뺐다. 갖고 있던 기록에는 그 값을 마을 씨앗으로 한 번 돌려준다. 발자국 "빛을 돌려주기"의 보상은 마을 씨앗 15.
  - **마을 수첩**: 마을의 자리와 이웃 이야기. 이웃이 돌아올수록 늘어난다.
- **안내**(일시정지): 기록이 닿은 항목만 보이고, 새로 열린 항목에는 점이 붙는다.
  - 굴 안내를 다섯으로 나눴다: 싸움방·방 표지·길 위의 것(샘·상자·내려가는 구멍)·위험물·길 지도. 항목마다 움직이는 그림.
  - 마을 안내는 큰 나무와 재주·발자국과 짐·실뜨기와 실의 꿈(할매가 마을에 온 뒤)으로.
- **가장 깊은 곳**: 처음 들어설 때의 이름 카드와 목표 글, 나일의 한마디를 다듬었다. 어두운 굴의 버섯 둘레를 잘 보면 무언가 보일지도.
- 열한 언어 모두.

## 해 보기
- **웹**: https://nail-under-the-roots.netlify.app — 폰에서는 홈 화면에 추가해 보세요.
- **Android**: 아래 `nail.apk`. 덮어 설치하면 기록이 남는다.
- **Windows**: `nail-windows-release.zip` → `Nail.exe`. 서명 전이라 처음에 "Windows의 PC 보호" 창이 뜨면 "추가 정보 → 실행".
- **macOS**(11 이상, 인텔·애플 실리콘): `nail-macos-release.zip` → `Nail.app`. 처음 열 때 막히면 "시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기".
- **Linux**(x64): `nail-linux-release.tar.gz` → `nail`.
