# Naïl: Under the Roots v0.7.2 — 장 넘김과 저널 정리

## 바뀐 것
- **긴 대사는 다음 장으로**: 대화창은 세 줄까지만 보여 주고 넘는 글은 잘려 나갔다. 이제 세 줄이 넘으면 ▼를 눌러 다음 장으로 이어 읽는다. ▼는 글 끝과 겹치지 않는 자리로 옮겼다.
- **저널(발자국) 다듬기**
  - 새 목표 둘: 굴에서 부술 수 있는 것 30개 부수기, 모모로 날려 보낸 적을 다른 적에 20번 부딪히기(모모가 돌아온 뒤).
  - 털빛을 주던 목표 셋(받아치기 60번·상자 25개·재주 4칸)은 같은 단계 목표와 맞춘 반딧불·마을 씨앗을 준다. 이미 받았던 기록에는 새 보상을 한 번 돌려준다.
- **뺀 것**
  - **털빛과 물웅덩이 비춰 보기**: 나일에게만 들고 작아서 거의 보이지 않았다. 물웅덩이는 마을 풍경으로 남는다.
  - **오늘의 굴**: 함께 겨룰 순위표 없이 날짜만 붙은 런이라 뺐다. 타이틀 메뉴에서 빠지고, 저장된 오늘의 굴 기록은 정리된다.
- 열한 언어 모두.

## 해 보기
- **웹**: https://nail-under-the-roots.netlify.app — 폰에서는 홈 화면에 추가해 보세요.
- **Android**: 아래 `nail.apk`. 덮어 설치하면 기록이 남는다.
- **Windows**: `nail-windows-release.zip` → `Nail.exe`. 서명 전이라 처음에 "Windows의 PC 보호" 창이 뜨면 "추가 정보 → 실행".
- **macOS**(11 이상, 인텔·애플 실리콘): `nail-macos-release.zip` → `Nail.app`. 처음 열 때 막히면 "시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기".
- **Linux**(x64): `nail-linux-release.tar.gz` → `nail`.
