# Naïl: Under the Roots v0.5.1 — 마을·쉼터 새 그림, 도토 달리기, 마을에서 곧장 길로

## 바뀐 것
- **마을에서 곧장 길 지도로**: 마을 뿌리 길로 내려가면 땅 위 공터를 다시 거치지 않고 바로 길 지도부터 고른다. 첫 쉼터는 쓰러졌을 때 깨어나는 자리다.
- **실뿌리 셋 = 세 번까지**: 쉼터를 지난 런은 셋째로 쓰러질 때 끝난다(전에는 넷째). 끝나는 쓰러짐은 화면 가장자리에서 보랏빛 실뿌리가 자라 나일을 감는 연출로 보통 쓰러짐과 다르다. 둘째 뒤에는 "하나 남았다"고 알려 준다.
- **맞았을 때 알 수 있게**: 맞으면 화면이 밀리고 가장자리가 붉게 번쩍이며 '아야' 소리가 난다.
- **반딧불 값 ×3**: 큰 나무 재주와 독 발톱 값을 세 배로 올렸다. 줍는 반딧불 수는 그대로.
- **가게는 이 캐릭터 것만**: 모모·도토 전용 장신구가 다른 캐릭터 런의 가게에 나오지 않는다.
- **마을·쉼터 새 그림**: 가게 좌판, 모닥불 화덕, 그루터기, 바위, 통나무 자리, 뿌리 길 입구(팻말 + 구멍).
- **도토 달리기**: 달릴 때 꼬리를 휘날리는 네 칸 바운드로 뛴다.
- 그 밖에: 마을에 토끼풀 가족이 나오지 않던 것, 도감 그림 크기·자리, 메뉴 고른 칸의 글자 높이를 고쳤다. 보리는 마을 할매 아래·통나무 의자 왼쪽에 산다.
- 공식 페이지에 12초 게임 클립과 새 스크린숏.

**English (short)**: New village and camp art, Doto's run, and straight from the village to the path. Heading down the root path in the village now opens the path map right away instead of walking the surface meadow again. A run past the first camp now ends on the third fall (it used to be the fourth), with purple root threads growing in from the screen edges to bind Naïl so it reads differently from a normal fall. Getting hit now kicks the camera, flashes a red screen edge and plays an "ouch" sound. Great Tree talents and the venom claw cost three times as many glowbugs. Shops only stock charms for the character you are playing. The shop stall, fire pit, stump, boulder, log bench and root-path entrance have new art, Doto runs with a four-frame bound, and several bestiary, menu and village fixes are in.
