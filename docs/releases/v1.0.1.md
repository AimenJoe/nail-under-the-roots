# Naïl: Under the Roots v1.0.1 — 손질

## 바뀐 것
- **Windows에서 켜지지 않던 PC**: VC++ 재배포 패키지가 없는 Windows에서도 켜지게 실행 파일에 필요한 런타임을 함께 넣었다.
- **앱을 내려 두면 멈춘다**: 휴대폰에서 홈으로 나가거나 전화가 오면 게임이 일시정지 창을 열고 기록을 적는다. 웹은 탭을 가리면 소리도 멈춘다. PC 창을 최소화해도 같다.
- **iPhone 가로 화면**: 가로로 든 채 열거나 홈 화면 앱으로 켰을 때 아래가 비던 것을 고쳤다.
- **키보드**: 지도 키(기본 M)로 연 메뉴는 같은 키로 닫힌다. 왼쪽·오른쪽(위·아래)을 함께 쥐면 나중에 누른 쪽으로 간다 — 방향을 바꿀 때 멈칫하지 않는다.
- **큰 나무**: 목표 정하기를 뺐다(칸을 고르기만 해도 거기까지의 길과 모자란 반딧불이 보인다). 둘 중 하나를 고르는 칸은 한 틀로 묶이고, 칸마다 갈림의 제 쪽 가지가 밝고, 설명에 옆 칸 이름이 나온다(11개 언어).
- **마을 창**: 수첩의 이웃 줄에 그 이웃의 모습이 아이콘으로 나온다. 짐 꾸리기의 씨앗 주머니가 정신없이 반짝이던 것과 줄마다의 ●○ 점을 뺐다.

## 해 보기
- **웹**: https://nail.beardworks.io/play/ — 폰에서는 홈 화면에 추가해 보세요.
- **Android**: 아래 `nail.apk`. 덮어 설치하면 기록이 남는다.
- **Windows**: `nail-windows-release.zip` → `Nail.exe`. 서명 전이라 처음에 "Windows의 PC 보호" 창이 뜨면 "추가 정보 → 실행".
- **macOS**(11 이상, 인텔·애플 실리콘): `nail-macos-release.zip` → `Nail.app`. 처음 열 때 막히면 "시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기".
- **Linux**(x64): `nail-linux-release.tar.gz` → `nail`.

**English (short)**: Fixes and polish. The Windows build now runs on PCs without the Visual C++ runtime installed. The game pauses and saves when you leave it (home button, phone call, hidden browser tab, minimized window), and the web version mutes while its tab is hidden. iPhones no longer show an empty strip in landscape. The map key (M by default) also closes the menu it opened, and holding two opposite directions on the keyboard now follows the one pressed last. On the Great Tree, the goal pin is gone (selecting a cell already shows the path and the glowbugs you still need), and pick-one-of-two cells are framed together with the matching branch lit and the other option named (11 languages). In the village window, neighbors in the notebook have their own icons, and the seed pouch no longer flickers.
