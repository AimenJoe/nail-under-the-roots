# Naïl: Under the Roots v0.4.3 — 길 위의 꽃잎 하나, 더 은은한 예고

## 바뀐 것
- **오프닝의 시든 꽃잎은 길에 하나만**: 첫 발톱 옆(모모가 섰던 자리)에는 꽃잎이 흩날리기만 하고, 주울 꽃잎은 보리 공터로 내려가는 길에 하나 남는다. 처음 주우면 "누군가 이 길로 내려간 것 같다".
- **적 예고를 한 단계 더 은은하게**: 붉은 예고가 조금 더 투명해졌다. 채움이 테두리에 닿는 순간이 공격인 것은 그대로.

## 해 보기
